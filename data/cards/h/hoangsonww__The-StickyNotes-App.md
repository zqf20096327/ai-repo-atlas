**网页便签笔记应用，含语音记录与聊天机器人功能**

2023 年由 Son Nguyen 开发的笔记与任务管理 Web 应用：支持 Markdown 笔记、拖拽排列、置顶、语音记录、颜色自定义、标签与截止日期、搜索、暗色模式、JSON 导入导出、自动保存，并内置计算器、心情追踪、番茄钟等工具。聊天机器人 Eliza 协助用户查询应用相关问题；后端接入 Google Cloud Speech-to-Text 等服务，数据经 Firebase 云端同步。基于 Apache Cordova 与 React Native 的移动版尚在开发中。安装方式为克隆仓库后 npm install 运行。
