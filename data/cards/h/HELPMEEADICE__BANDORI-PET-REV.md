**基于 Live2D 的 BanG Dream! 桌面宠物，带 LLM 角色扮演对话**

BandoriPet 是基于 Live2D Cubism SDK 与 PySide6 的开源桌面宠物项目，收录 12 个乐团 51+ 位 BanG Dream! 角色与 305+ 套服装，渲染层由 Rust + wgpu 的原生后端（Neocari）经共享内存与主程序通信。AI 相关功能包括：接入大语言模型的角色扮演（每角色专属 System Prompt、好感度记忆系统）、Qwen3TTS 语音合成与口型同步、faster-whisper 本地语音识别、MCP 协议与 Computer Use 工具扩展。安装需 Python 3.10+、Rust 构建原生后端并另行下载约 900MB 模型包，代码以 GPLv3 开源，角色资源版权归原版权方。

## 能力要点

- 51+ 位角色与 305+ 套服装的 Live2D 桌宠，另支持 VRM 3D 与像素形态
- LLM 角色扮演配好感度/信任/记忆系统与聊天命令
- Qwen3TTS 语音合成口型同步 + faster-whisper 本地语音输入
- MCP 协议与 Computer Use 扩展（文件系统、鼠标键盘操控）

## 适用场景

- 在桌面上饲养 BanG Dream! 角色并与她对话
- 给角色接入本地 TTS/ASR 实现语音交互
- 通过 MCP 让桌宠角色调用本地工具
- 多角色同屏搭自己的小剧场
