**可定制的 RAG 聊天机器人模板，基于 Next.js 快速搭建**

基于 Next.js/React/Tailwind CSS 构建的全栈 AI 聊天机器人模板：集成 OpenAI、Fireworks AI、Anthropic 三家 LLM API 生成对话回复，通过 Pinecone 向量库与 RAG by Ringel 工具上传文档实现检索增强生成，回复带来源引用并支持流式输出。外观、身份人设与系统提示词通过配置文件定制，支持 Vercel 一键部署。运行前需配置四项 API key（OpenAI 账户余额不少于 $5），文档需转为 Markdown/TXT 上传。
