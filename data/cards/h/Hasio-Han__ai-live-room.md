# Hasio-Han/ai-live-room

⭐ 4 · TypeScript · AGPL-3.0 · 推送 2026-11-04 · [GitHub](https://github.com/Hasio-Han/ai-live-room) · 个人维护 · 中文 README

**给抖音主播提供本地大模型驱动的竖屏 AI 互动直播间**

在 Windows 本机运行的抖音竖屏 AI 直播间：通过小号 Cookie 读取真实弹幕与礼物，本地大模型（Ollama + Qwen2.5 7B/14B）逐条生成回复，微软语音配音，人物配合点头、挥手等动作，OBS 虚拟摄像机采集画面后由抖音直播伴侣推流。支持礼物触发动作、弹幕排队与优先级、11 类敏感词双向过滤，名字、人设、形象通过自定义文件夹配置，不改代码。提供一键部署 bat 自动下载免安装 Node.js/Python/Ollama 与模型，依赖 OBS Studio 与直播伴侣。

## 能力要点

- 本地大模型读弹幕现场生成回答并配音、做动作（Ollama + Qwen2.5 7B/14B）
- 礼物触发主播动作，弹幕与 @提问按优先级排队
- 一键部署 bat 自动下载运行环境与模型，按显存自动选 7B/14B
- 名字、人设、形象、挑战时长均在自定义文件夹配置，不需改代码

## 适用场景

- 抖音竖屏直播间让 AI 主播实时回答观众弹幕
- 用本地大模型离线开播，不依赖云端 API
- 礼物互动触发主播动作与直播挑战玩法
- 通过改配置快速更换主播人设与形象
