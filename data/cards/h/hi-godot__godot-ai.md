**将 MCP 客户端接入 Godot 编辑器的 MCP 服务器与工具集**

以 Godot 编辑器插件加 Python MCP 服务器的形式，连接 Claude Code、Codex、Cursor 等 MCP 客户端到运行中的 Godot 编辑器，提供 46 个工具与 120+ 操作，用于构建场景、编辑节点与脚本、连接信号、配置 UI/材质/动画/粒子/相机/环境。编辑器内 dock 可一键配置 26 个客户端，v4 客户端经 `godot-ai attach` 以 stdio 接入，本地链路采用轮换凭据认证且仅限回环连接。GDScript 完整支持（含解析校验与热重载），C# 仅限文本写入，不构建 .NET。需 Godot 4.7+ 与 uv。
