# HAibiiin/json-repair

⭐ 108 · Java · Apache-2.0 · 推送 2026-02-14 · [GitHub](https://github.com/HAibiiin/json-repair) · [官网](https://haibiiin.github.io/json-repair/) · 个人维护 · 中文 README

**修复 LLM 生成的异常 JSON 的 Java 库**

面向 Java 开发者的应用层库：接收 LLM 输出的异常 JSON 字符串，通过 JSONRepair.handle() 返回修复后的合法 JSON。修复能力包括补全缺失的右括号/右方括号、清理数组冗余逗号、缺失值填充 null、补左括号与最外层括号、个别场景补字符串引号，并支持自定义修补尝试次数；还可开启从文本中提取符合 JSON 格式内容的提取功能（提取后有限修复）。以 Maven/Gradle 依赖发布到 Maven Central，基于 ANTLR 语法生成解析器，附带基准测试与覆盖率报告。当前版本 0.4.0。

## 能力要点

- 修复括号/引号缺失、冗余逗号、缺失值等 JSON 异常
- 从文本字符串中提取 JSON 内容并可有限修复
- 支持自定义修补尝试次数
- 提供 JMH 基准测试与测试覆盖率报告

## 适用场景

- Java 应用中修复 LLM 输出的不合法 JSON
