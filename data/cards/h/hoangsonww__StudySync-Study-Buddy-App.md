# hoangsonww/StudySync-Study-Buddy-App

⭐ 29 · Vue · MIT · 推送 2026-09-27 · [GitHub](https://github.com/hoangsonww/StudySync-Study-Buddy-App) · [官网](https://study-sync-app.vercel.app) · 个人维护

**面向学生的全栈生产力应用：番茄钟、闪卡、待办与 AI 学习助手**

Vue+Vuetify 前端与 Node/Express 后端构成的学习生产力 Web 应用，功能包括 Pomodoro 计时器、闪卡、待办清单、学习计划、测验、进度追踪，以及基于 Google Gemini API 的 AI 聊天学习助手。集成 Spotify API 按心情推荐音乐、OpenWeather 查天气，使用 MongoDB 存储、JWT 认证。提供 Vercel/Render 在线部署与 Docker Compose 本地运行两种方式，后端冷启动受 Render 免费层 0.1 CPU/512MB 限制。
