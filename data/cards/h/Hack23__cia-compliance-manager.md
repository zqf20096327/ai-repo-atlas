# Hack23/cia-compliance-manager

⭐ 21 · TypeScript · Apache-2.0 · 推送 2026-10-28 · [GitHub](https://github.com/Hack23/cia-compliance-manager) · [官网](https://ciacompliancemanager.com/) · 组织维护

**面向企业的 CIA 三性安全评估与多框架合规平台**

由 Hack23 AB 维护的 Web 评估平台与 npm 库双形态产品：以机密性/完整性/可用性（CIA）三元组为统一视角，基于 5 级成熟度模型评估安全态势，自动映射到 ISO 27001、NIST 800-53、GDPR、HIPAA、SOC 2、PCI DSS、EU CRA 七个框架的控制项；提供 CAPEX/OPEX 成本估算与 ROI 计算、STRIDE 威胁建模与攻击树、数据分级和业务影响量化。面向 CISO、合规官、IT 管理者等角色。仓库另含面向开发流程的 GitHub Copilot 自定义 agent 配置。

## 能力要点

- CIA 三元组 5 级成熟度评估，自动映射 7 个合规框架控制项
- CAPEX/OPEX 成本明细与 ROI 计算器
- STRIDE 威胁建模、攻击树与风险量化
- 同时提供在线平台与 10 个子路径导出的 tree-shakeable npm 库（React 18.2+/19.x）

- 系统化评估安全态势并生成多框架合规报告

- 把 CIA 评估组件嵌入企业门户或 GRC 平台
