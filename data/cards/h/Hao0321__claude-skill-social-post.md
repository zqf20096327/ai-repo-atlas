**给社群经营者用 Claude Code/Codex 自动撰写与发布社群贴文的 Skill**

一个可安装到 Codex 或 Claude Code 的社群内容 Skill，另提供精简 ChatGPT Chat 版。功能分六个 Mode：内容规划、从授权样本学习个人声线、撰写平台化贴文（FB/IG/Threads/X）、经确认后发布、成效记录与跨平台规律比较，以及基于已登入 Chrome 的留言扫描与草拟。采用 MIT 开源，私人语气与成效数据只留本机 data/ 目录；live 送出开关默认关闭，需经 canary 验收解锁，真实自动回覆尚未完成三平台验收。需要 Python 3.10+ 运行本机脚本与工作台。

## 能力要点

- 六个 Mode 覆盖规划、声线学习、撰稿发布、成效记录、规律比较与留言操作
- Chrome 受控留言操作：扫描、草拟、核准，带 append-only ledger 与防重送机制
- 私人语气、贴文与账号数据只存本机，公开版仅含 schema、工具与 fictional 示例
- 本地工作台（localhost:8766）提供五平台×图文/影片十分区学习界面

## 适用场景

- 让 Claude Code 依个人声线撰写 FB/IG/Threads 贴文并排 14 天内容日历
- 本机记录各平台贴文成效并做同类型贴文比较
- 在已登入 Chrome 下受控扫描与管理社群留言草稿
