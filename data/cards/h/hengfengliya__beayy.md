⭐ 67 · Rust · MIT · 推送 2026-10-30 · [GitHub](https://github.com/hengfengliya/beayy) · [官网](https://beayy.com) · 个人维护 · 中文 README

**跨设备自动记日记应用：记录时间地点活动并生成 AI 日记**

Beayy 是一款本地优先的个人活动记录与自动日记应用，运行在 macOS、Windows、iPhone、Apple Watch 与安卓上。它在后台记录电脑/手机应用使用、输入、屏幕文字、停留点与健康数据，全部存于本机；将每 10 分钟的记录发给你配置的 OpenAI 兼容模型生成摘要，并写日、周、月总结。多设备同步支持官方服务器、自部署（server/ 目录 Docker）或同步文件夹，端到端加密。自带本机 MCP 服务，可接入 Claude Code、Claude 桌面版或 Cursor 查询过去数据。

## 能力要点

- 多端采集（键鼠/应用/位置/健康/手表录音转写），数据本机追加存储
- 每 10 分钟 AI 摘要＋日/周/月总结，模型走任意 OpenAI 兼容接口
- 本机 MCP 服务提供 list_days/get_day/search 等只读查询工具
- 同步三种方式：官方服务器（每账号 100MB）、自部署 Docker、同步文件夹；XChaCha20-Poly1305 端到端加密

## 适用场景

- 回顾每天在什么时间、什么地方、用电脑手机做了什么
- 接入 Claude Code 或 Cursor 直接问自己过去几天做了什么
- 对照自己定的规矩（如 22 点后不开电脑）看每天的执行情况
- 自部署同步服务端，端到端加密地多设备记录
