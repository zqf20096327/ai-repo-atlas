# HRuiCcc/RuiC-oc-ferry

⭐ 721 · JavaScript · MIT · 推送 2026-11-01 · [GitHub](https://github.com/HRuiCcc/RuiC-oc-ferry) · 个人维护 · 中文 README

**把 OpenCode 免费模型转发给 WorkBuddy/DSH 的托盘工具**

基于 Electron 的托盘应用：在数据目录放一份隔离的 OpenCode 运行时，按价格字段筛出免费模型，逐个并发探测其能否按客户端工具协议产生动作，将通过的写入 WorkBuddy 的 models.json 或 DSH 各 profile 的 cordis.patch.yml，并提供仅监听本机的 OpenAI 兼容转发口（/v1/chat/completions，支持 stream，并发上限 4）。判定结果按模型缓存（成功保留 6 小时），写入前备份、原子替换，退出时清理自己写入的条目。执行权保留在客户端，模型本机动作被拒绝或转交为外部工具调用。

## 能力要点

- 隔离 OpenCode 运行时 + 按价格字段（非名字）筛选免费模型
- 并发检测工具协议可用性，判定按模型缓存（成功 6 小时）
- 一键写入 WorkBuddy models.json / DSH cordis.patch.yml，写入前备份、退出时清理
- 本机 OpenAI 兼容转发口，Bearer 鉴权，拒绝带 Origin 的浏览器请求

## 适用场景

- 让 WorkBuddy 直接使用 OpenCode 免费模型池
- 给 DSH 各 profile 批量写入可用免费模型
- 在本机以 OpenAI 兼容接口调用免费模型
