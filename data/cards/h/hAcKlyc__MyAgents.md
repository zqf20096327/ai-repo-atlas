# hAcKlyc/MyAgents

⭐ 579 · TypeScript · AGPL-3.0 · 推送 2026-10-21 · [GitHub](https://github.com/hAcKlyc/MyAgents) · [官网](https://myagents.io) · 组织维护 · 中文 README

**本地优先的 Agent 桌面工作台与任务系统，供个人跨设备调度 Agent**

免费开源（AGPL v3）、本地优先的桌面端 Agent 工作台：用户通过 GUI 与 Agent 对话协作，Agent 可通过 myagents CLI 建立任务与互相调用。集成 Claude Agent SDK、DeepSeek Harness 与 Codex 多种 Runtime，支持订阅登录或 API 配置；提供定时/条件触发的 Task 系统、飞书/钉钉/Telegram 消息通道、跨设备 AgentNet 组网（端到端加密）与 Space 协作空间。个人组网无需自建服务器，但 AgentNet/Space 依赖相应云服务。安装包支持 macOS 13+ 与 Windows 10+。

## 能力要点

- 集成 Claude Agent SDK、DeepSeek Harness 与 Codex 多种 Runtime
- Task 定时任务与脚本条件满足后唤醒 Agent
- AgentNet 跨设备 Agent 调用，任务与结果端到端加密
- 内置飞书/钉钉/Telegram 通道，插件扩展更多平台

## 适用场景

- 在桌面端与多个 Agent 并行协作推进研究、开发等工作
- 把定时检查、整理摘要等日常事务交给任务系统持续运行
- 用多台电脑组成 Agent 网络跨设备派发与交接任务
