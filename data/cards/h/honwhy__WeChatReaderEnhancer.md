**增强电脑端微信公众号阅读的 Chrome 扩展**

面向电脑端微信公众号读者的 Chrome/Microsoft Edge 浏览器扩展：自动识别文章 HTML 标题层级生成结构化侧栏目录，点击目录项平滑跳转，滚动时高亮当前阅读位置；另提供图片点击放大、高清版本获取与全屏浏览。目录生成依赖文章使用标准 h1-h6 标签，缺失时可能无法生成。可从应用商店安装，开发者可通过 git clone + npm 构建后加载。README 未描述任何 AI/模型相关功能。
