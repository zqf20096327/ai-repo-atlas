# HamaWhiteGG/autogen4j

⭐ 52 · Java · 推送 2025-11-21 · [GitHub](https://github.com/HamaWhiteGG/autogen4j) · 个人维护

**微软 AutoGen 多智能体框架的 Java 实现，供 Java 开发者构建 LLM 应用**

将 Microsoft AutoGen 多智能体对话框架移植到 Java：提供可定制、可对话的 AssistantAgent 等智能体，支持多智能体协作、人类参与反馈、工具与代码执行，附代码执行自动反馈与群聊两个示例工程。依赖 Java 17+、Maven 3.5.4+ 与 Unix-like 环境，核心库发布至 Maven Central（autogen4j-core），使用时需设置 OPENAI_API_KEY 环境变量调用 OpenAI API。项目处于 0.1.0 版本。
