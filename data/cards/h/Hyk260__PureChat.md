# Hyk260/PureChat

⭐ 544 · TypeScript · MIT · 推送 2026-09-17 · [GitHub](https://github.com/Hyk260/PureChat) · [官网](https://im.purechat.cn) · 个人维护 · 中文 README

**集成多模型 AI 功能的即时聊天应用（Vue3/Electron）**

基于 Vue3 + Vite6 的聊天应用与 AI 开发框架：会话依托腾讯 IM 即时通讯 SDK，接入 OpenAI、Ollama、DeepSeek 等多模型，支持联网搜索、流式输出、深度思考与自定义预设提示词；另提供 Markdown 渲染、聊天记录生成截图、GitHub 快速登录、主题自动切换。桌面端提供 Electron 版本（macOS .dmg 与 Windows .exe）。注意：本仓库为旧版，当前维护项目已迁移至 PureChatNext。运行需 Node.js 18.20+ 及腾讯 IM AppID、服务器地址等环境变量。
