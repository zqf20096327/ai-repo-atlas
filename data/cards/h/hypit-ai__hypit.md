# hypit-ai/hypit

⭐ 30,952 · TypeScript · NOASSERTION · 推送 2026-11-20 · [GitHub](https://github.com/hypit-ai/hypit) · [官网](https://hypit.ai) · 组织维护 · 中文 README

**让编程 Agent 用 SVML 语言批量克隆/生成短视频的工作流系统**

Hypit 为编程 Agent（如 Claude Code、Codex）提供一套视频创作语言与系统：输入参考视频后，Agent 将其克隆为完整工作流（素材、字幕、B-roll、特效），以词为时间锚点而非秒数。也可从模板或文字描述从头生成。工作流可复用并批量产出变体；生成模型可选，纯代码渲染路径无需调用生成 API。通过 npx 安装 Skill，本地以无头 Chromium 并发渲染成片。

## 能力要点

- 视频被克隆为可编辑、可重跑的完整工作流而非一次性渲染
- 同一工作流可批量产出 100 个变体（换角色/产品/语言/比例）
- 生成模型可选：纯代码渲染路径不调用生成 API
- 插件化组件可替换（如换主持人不动字幕），npm 发布共享

## 适用场景

- 把爆款 TikTok/Reels 克隆成模板并批量换装变体
- 为电商和联盟营销每日产出同格式不同 SKU 的短视频
- 同一视频批量本地化为十种语言
- 不调用生成 API、纯前端代码渲染视频
