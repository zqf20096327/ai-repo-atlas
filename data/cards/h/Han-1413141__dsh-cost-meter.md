**为 DeepSeek Harness 提供会话成本、token 用量与配额追踪的插件**

以 DSH 插件形式安装的成本追踪工具：按会话、模型与调用维度记录费用与 token 用量，支持多 provider 定价（峰谷分时费率、可编辑倍率）、每日/每月/累计预算与峰谷切换提醒，并汇总 Codex、Claude、GLM、Kimi 等订阅配额与账户余额，区分 API 费用与 Plan 等价值。提供统计趋势、排名、缓存命中率与导出功能，中英双语 UI，深色主题与移动端布局。

## 能力要点

- 按会话、模型与调用记录成本与 token 用量，含父/子 agent 成本归属
- 峰谷分时定价同步、预算设定与切换前弹窗/系统通知
- 聚合多 provider 订阅配额与余额，支持自定义 HTTP 余额来源
- 中英双语 UI、深色主题与移动端布局

## 适用场景

- 追踪 DeepSeek Harness 各会话的 token 花费与缓存命中率
- 为团队设置每日/每月 API 预算并在峰谷切换前收到提醒
- 统一查看多个 provider 的订阅配额与账户余额
