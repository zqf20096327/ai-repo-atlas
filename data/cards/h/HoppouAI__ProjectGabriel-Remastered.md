# HoppouAI/ProjectGabriel-Remastered

**给 VRChat 玩家的开源实时 AI 伴侣，语音对话+视觉+OSC 控制**

面向 VRChat 用户的开源 AI 伴侣应用：通过 Gemini Live 原生音频流实现实时语音对话，YOLO 屏幕捕捉识别并跟随人物，经 OSC 接口控制虚拟形象完成行走、跳跃、打字等动作，并具备跨会话持久记忆、人格切换、世界导航、Discord 机器人与 WebUI。VRChat 为可选，Discord/WebUI/本地后端均可独立运行。需 Gemini API key 与 Windows 环境，Python 3.11/3.12；可选本地后端用 LM Studio 与 parakeet.cpp。生成式全身动作在 motion-server 分支。安装方式为下载 GitHub Release 后运行 setup.bat。
