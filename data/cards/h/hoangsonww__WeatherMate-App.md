# hoangsonww/WeatherMate-App

⭐ 28 · Java · MIT · 推送 2026-09-27 · [GitHub](https://github.com/hoangsonww/WeatherMate-App) · [官网](https://the-weathermate.vercel.app/) · 个人维护

**查询任意地点天气、空气质量与预报的 Web 应用**

由 Son Nguyen 于 2024 年创建的天气查询 Web 应用：从 OpenWeatherMap API 及自建数据库获取数据，提供当前天气、当地时间、空气质量指数（AQI）、湿度与降雨概率、收藏地点、单位切换与随天气变化的动态背景等功能。内置聊天机器人，可回答天气及其他问题。使用 HTML/CSS/JavaScript/jQuery/Bootstrap 构建，通过 GitHub Pages 部署；移动版本位于 WeatherMate-Mobile 子目录，开发中。获取方式为 git clone 后 npm install 并在浏览器打开 index.html。

## 能力要点

- 从 OpenWeatherMap API 与自建数据库获取天气数据
- 空气质量指数（AQI）、湿度与降雨概率查询
- 收藏地点、单位切换与动态背景
- 内置聊天机器人，可回答天气及其他问题

## 适用场景

- 查询某城市当前天气与未来预报

- 通过聊天机器人询问天气等信息
