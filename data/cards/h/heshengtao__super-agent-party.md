**自托管桌面 AI 伴侣：聊天、控制电脑、接入 IM 与直播**

一个桌面 AI 伴侣应用：支持自定义 VRM/Live2D 模型、3D 场景、角色人格与长期记忆的多角色群聊；通过桌面视觉与鼠标/键盘/终端工具链让 agent 操作计算机；任务中心支持 MCP 与 Agent Skills 后台执行；可一键部署为 QQ、微信、飞书、Telegram、Discord 等 IM 机器人及 Bilibili、YouTube、Twitch 直播机器人。提供开放 OpenAI 兼容 API 与 MCP 接口供外部调用，并有插件扩展系统。Windows/macOS(M 芯片)/Linux 提供安装包，另支持 Docker 与源码部署。
