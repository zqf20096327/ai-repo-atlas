# hawkinslabdev/mealie-planner

**自托管的 Mealie 周餐计划应用，支持 Home Assistant**

基于 Mealie 的自托管周视图餐计划器：浏览 Mealie 食谱库，将食谱拖放到周网格安排每日餐食，提供随机推荐（sparkle）、多用户共享访问与多语言界面。quick-add 功能可从视频、网页或图片导入食谱。以 Home Assistant 应用（add-on）形式安装，也可通过 Docker Compose 运行，启动后需配置 Mealie 实例地址与 API key。项目采用 AGPL 3.0 许可，声明与 Mealie 无隶属关系。

## 能力要点

- 周网格拖拽式餐计划管理，浏览并选用 Mealie 食谱库
- sparkle 功能随机推荐菜品
- quick-add 从视频、网页或图片导入食谱
- 提供 Home Assistant add-on 与 Docker Compose 两种安装方式

## 适用场景

- 配合自托管 Mealie 安排每周餐食
- 家庭多用户共享查看周餐计划
- 从视频、网页或图片快速导入新食谱
