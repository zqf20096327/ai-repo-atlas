# hoangsonww/Tic-Tac-Toe-Fullstack-Game

⭐ 16 · TypeScript · MIT · 推送 2026-09-27 · [GitHub](https://github.com/hoangsonww/Tic-Tac-Toe-Fullstack-Game) · [官网](https://tictactoe-ai-app.vercel.app) · 个人维护

**MERN-T 全栈井字棋游戏：多人对战与 AI 对手、ELO 排行榜**

基于 MongoDB、Express、React、Node.js 与 TypeScript 的全栈井字棋应用：支持本机双人、在线 PvP（Socket.io 实时通信与匹配）和对战 AI（Minimax 算法，三档难度），提供用户注册登录（JWT）、资料管理与社交链接、按 ELO 计分的全球排行榜与用户搜索。前端用 React + Material-UI，含明暗主题与移动端适配；后端提供 Swagger/OpenAPI 文档。已部署于 Vercel/Render，后端免费实例可能有 30-60 秒冷启动延迟。

## 能力要点

- Minimax 算法 AI 对手，含三档难度与多种棋盘尺寸（如 8x8）

- ELO 计分全球排行榜与用户搜索
