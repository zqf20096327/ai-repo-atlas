**用自然语言对话探索数据、生成 SQL 与仪表盘的 agent 框架**

开源、可扩展的 agent 框架，用于与数据对话及 RAG。基于声明式数据模型，LLM 可生成完整的数据转换管线、可视化与仪表盘，产物可序列化以共享或在 notebook 中继续分析。支持对接本地/远程文件、SQL 数据库与数据湖，可接入自有文档作为上下文；所有 LLM 输出可检查、修正与手动编辑，并可通过自定义 agent、工具和分析扩展。需 Python 3.11+，基于 Panel 渲染。

## 能力要点

- 自然语言生成 SQL 数据管线、图表与整个仪表盘

- 用对话方式探索 CSV 或数据库中的数据并生成图表

- 结合自有文档做检索增强问答
