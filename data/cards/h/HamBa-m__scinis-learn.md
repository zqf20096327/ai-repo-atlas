**从零实现基础机器学习算法的教学用 Python 函数库**

以非 OOP 函数形式从零实现基础机器学习算法的 Python 包：分类方面含单层感知机、Pocket 感知机、Adaline、线性/逻辑/多项式回归及 One-vs-All/One-vs-One 分类器；另含学习理论相关工具（非线性变换、K 折交叉验证、梯度下降、正则化、VC 维、覆盖数）与数据生成和 2D/3D 绘图辅助函数。代码源于 ENSIAS（摩洛哥）2023 秋学习理论课程作业，作者为应用数学与 AI 工程学生。安装方式为 git clone 源码。部分功能（偏差与方差）未实现。
