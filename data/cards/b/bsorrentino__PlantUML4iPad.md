# bsorrentino/PlantUML4iPad

⭐ 18 · JavaScript · MIT · 推送 2026-02-04 · [GitHub](https://github.com/bsorrentino/PlantUML4iPad) · 个人维护

**iPad 原生 PlantUML 图表编辑器，AI 辅助手绘识别与提示生成**

基于 SwiftUI 的 iPad 原生 PlantUML 编辑器：支持文档增删改与 iCloud 分享、ace 编辑器语法高亮与代码片段、通过 PlantUML 在线服务器预览（需联网）、图片分享与内置缓存。AI 为可选功能：需有效 OpenAI API Key（付费账户），支持手绘图经 OpenAI Vision（gpt-4o）生成 PlantUML 脚本、自然语言提示生成图表（可选 gpt-3.5-turbo 或 gpt-4）、提示历史与撤销。API 密钥存于设备钥匙串。通过 App Store 分发。

## 能力要点

- 手绘图经 OpenAI Vision（gpt-4o）自动生成 PlantUML 脚本
- 自然语言 Prompt 生成图表，可选 gpt-3.5-turbo 或 gpt-4 模型
- ace 编辑器提供语法高亮与图表片段自动补全
- 文档 iCloud 共享与图片分享（AirDrop 等）

## 适用场景

- 在 iPad 上以 diagram-as-code 方式绘制 PlantUML 图表
- 手绘草图后自动转换为 PlantUML 脚本
- 用自然语言描述需求生成图表代码
