# basicScandal/claude-skins

⭐ 20 · Shell · MIT · 推送 2026-05-11 · [GitHub](https://github.com/basicScandal/claude-skins) · [官网](https://basicscandal.github.io/claude-skins/) · 个人维护

**给 Claude Code CLI 用户：终端视觉主题皮肤合集**

为 Claude Code CLI 提供自定义皮肤（视觉主题）：通过 OSC 序列改变终端配色，会话启动时显示 ASCII/盲文横幅，主题化状态栏与工具反馈音效，并可调整 Claude 输出的语气风格（personality）。不改变核心行为。内置 9 款皮肤（Nebula、Mythos、Netrunner 等），通过 install.sh 安装并以 /skin 命令切换；也可手动复制文件并配置 settings.json hooks。需 Claude Code CLI 与支持 OSC 的终端；工具音效支持 macOS/Linux/WSL。

## 能力要点

- 9 款预置皮肤，/skin 命令即时切换无需重启
- 覆盖终端配色、ASCII 横幅、状态栏、personality、工具音效五层
- 提供 template.yaml 与 SCHEMA.md 支持自建皮肤
- 缺失配置项自动继承默认皮肤

## 适用场景

- 给 Claude Code 终端换个主题外观
- 用不同 personality 改变 Claude 的输出语气
- 在 dotfiles 里分享自己的皮肤配置
