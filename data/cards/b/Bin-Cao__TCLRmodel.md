**从数据中提炼变量与时间指数显式公式的树模型（材料腐蚀/蠕变）**

TCLR 是一个树结构机器学习算法的 Python 包（pip install TCLR）：基于提供的数据集，输出研究变量与时间指数等物理变量之间的显式公式，适用于腐蚀、蠕变等满足动力学或热力学规律的物理过程。V1.4 起集成 gplearn 符号回归，在叶子上推导特征与斜率之间的解析公式。论文发表于 JMI 2022（铁素体-马氏体钢在超临界水中氧化行为的公式发现），附用户手册与运行模板，2023 年版本新增用户文档与 Web 界面。
