**给企业的 AI 全渠道客服与团队 IM 一体化平台**

开源客服平台，整合团队 IM（多级组织/角色/权限）、全渠道客服（多渠道路由策略、坐席工作台）、知识库（内部文档/帮助中心/FAQ）、工单管理与 SLA 统计、AI Agent（对接 Ollama/DeepSeek 等本地与 API 模型，支持 RAG 知识库问答、function calling 与 MCP）、基于 FreeSwitch 的呼叫中心与 WebRTC 视频客服。提供 RESTful API 与多语言 SDK，桌面/移动/Web 等客户端，通过 Docker Compose 部署，依赖 MySQL、Redis、Elasticsearch、Artemis 等中间件。
