**面向想养 AI 的用户的桌宠 AI Agent 框架**

基于 .NET/C# 的全插件化桌宠 AI Agent，定位为陪伴向赛博生命而非角色扮演产品。客户端本体是空框架，对话、语音、视觉、记忆等内置功能均以插件实现，支持热编译热重载，AI 可自主编辑并重载插件。上下文采用分区复用与自动化记忆压缩，纯原生文本函数调用对 LLM 无特殊要求。提供 Windows 安装包与 Android APK，运行时自动下载依赖与本地模型。

## 能力要点

- 全插件框架：内置功能均为插件，支持热编译热重载与插件市场
- 纯原生文本函数调用，对 LLM 无特殊要求，缓存命中率与 token 开销低
- 永久唯一会话与基于多级 cache 思想的自动化记忆压缩系统
- 框架已 MCP 化，外部 Agent 可通过 alife-mcp 全量控制软件

- 让 AI Agent 通过 MCP 接口全自动开发 Alife 功能插件
