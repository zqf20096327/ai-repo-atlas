# boldare/openai-assistant

⭐ 104 · TypeScript · MIT · 推送 2026-11-20 · [GitHub](https://github.com/boldare/openai-assistant) · [官网](https://askdare.vercel.app) · 组织维护

**基于 NestJS 与 OpenAI Assistants API 的聊天机器人库（已弃用）**

用于 NestJS 应用的聊天机器人库，封装 OpenAI Assistants API：提供开箱即用的 REST API 端点与 WebSocket 服务端，支持 function calling、TTS/STT、文件知识库及 GPT-4o 视觉。仓库另含可嵌入网站的聊天脚本与 SPA 客户端。因 OpenAI 于 2026-08-26 关闭 Assistants API，本库已停止工作，仓库仅作参考保留，后继为同团队的 askdare。安装需 Node.js 20+、npm 10+、NestJS 10+ 与 OpenAI API key。
