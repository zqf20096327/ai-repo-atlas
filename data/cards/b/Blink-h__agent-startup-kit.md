# Blink-h/agent-startup-kit

⭐ 204 · MIT · 推送 2026-07-22 · [GitHub](https://github.com/Blink-h/agent-startup-kit) · 个人维护

**面向 Claude Code/VS Code 的 SaaS 开发可复用 AI 编码工作流**

为独立开发者和小团队提供可复用的 AI 编码技能与工作流，覆盖认证、订阅计费、落地页三类重复性搭建任务。每个技能包含 skill.md 工作指引与 checklist.md 审查清单，并附 before/after 示例文档；通过 Claude Code 与 VS Code 适配器接入，提供 Next.js SaaS 起始模板作为演示目标。使用方式为在 AI 编码工具中打开项目、按任务选用技能、分小步修改。MCP 适配器与更多技能在路线图中未实现。
