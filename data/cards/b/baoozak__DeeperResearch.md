# baoozak/DeeperResearch

⭐ 43 · Python · MIT · 推送 2026-08-25 · [GitHub](https://github.com/baoozak/DeeperResearch) · 个人维护 · 中文 README

**多智能体协作的深度研究系统：自动拆解课题并行检索并生成研报**

基于 LangGraph 的多智能体深度研究应用：哨兵预搜提炼时效背景，全局规划师将课题拆解为 3-5 个子任务，经用户审批（Human-in-the-Loop）后由并行搜索 Worker 执行，Worker 内置记录失败轨迹的“认知墓碑”自纠错循环，最终由综合撰稿人生成含来源指向与图表的研究报告。检索统一走 AnySearch 云端引擎，支持 DeepSeek、OpenAI 等模型后端；提供研究历史版本管理、多格式文件上传、SQLite 持久化与 SSE 实时状态可视化。前后端分离，需分别以 pip 与 npm 启动。

## 能力要点

- LangGraph 多智能体分工：预搜/规划/并行研究/综合撰稿
- Human-in-the-Loop 调研方案审批与反馈重规划
- Worker 级“认知墓碑”失败轨迹记录与重试规避
- 研究历史版本管理：续跑、重综合、双版本对比

## 适用场景

- 输入模糊大课题，让系统自动拆解并产出带来源的研究长文

- 复用历史检索资料重新综合报告而不重复联网搜索
