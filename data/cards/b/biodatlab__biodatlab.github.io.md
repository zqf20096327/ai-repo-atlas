**泰国玛希隆大学 Bio-Dat 实验室官网（Gatsby 构建）**

基于 gatsby-starter-delog 与 Gatsby 构建的实验室介绍网站：通过 markdown/YAML 数据文件管理博客文章、成员名单、资源列表与出版物条目，站点页面位于 src/pages，基本信息存于 site-meta-data.json。联系页面使用 EmailJS 发送邮件，需在 .env 中配置 EmailJS 服务、模板与 User ID 三项密钥后运行开发服务器。从仓库根目录 npm install 后执行 gatsby develop 即可在 localhost:8000 预览。
