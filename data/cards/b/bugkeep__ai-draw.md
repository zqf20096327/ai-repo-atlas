**通过对话创建和编辑图表与插画的画布应用**

Draw Agent Studio 是一个自托管的 Web 画布应用：用户以自然语言描述生成素描、插画与流程图，并通过对话移动对象、改色、删除、撤销重做；同时保留手绘能力，可在画布上选择、拖拽、用笔绘制与添加文字。画布自动保存，可导出 PNG/JPG/WebP/SVG 及可编辑的 Excalidraw 文件。需 Python 3.11+ 与 Node.js 20.19+，模型调用按所选服务商计费，要求模型具备图像输入与工具调用能力。

## 能力要点

- 文本描述生成素描、插画与流程图
- 对话式编辑：移动、改色、删除、撤销/重做
- 画布手绘与文字添加，自动保存
- 导出 PNG/JPG/WebP/SVG 与可编辑 Excalidraw 文件

## 适用场景

- 用自然语言生成科研流程图并迭代修改
- 对话生成插画草稿后手工补画完成
- 将作品导出为 Excalidraw 继续编辑
