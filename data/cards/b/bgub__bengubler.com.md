**个人博客网站：基于 TanStack Start 与 React 构建**

bengubler.com 的个人网站源码，使用 TanStack Start + React 19、Tailwind CSS v4、TypeScript 与 Vite 构建开发及生产版本，UI 设计来自 v0.dev，内容管线为 fig-content + content-pipeline（Markdoc + Highlight.js），组件采用 shadcn/ui 与 Radix UI。功能包括暗色模式、视图过渡、Giscus 评论、RSS 订阅、阅读时长与自动目录、自定义内容标签校验。README 未展示具体的机器学习功能实现，仅在仓库主题标签中出现 machine-learning。
