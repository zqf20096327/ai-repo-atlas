# banshoudigua/McD-Arcade-Adventure

⭐ — · [GitHub]() · 个人维护 · 中文 README

**面向家庭的麦当劳主题儿童卡牌桌游，接入麦当劳 MCP 真实数据**

单机同屏网页卡牌桌游：2-6 名玩家在 30 格环形地图上掷骰、抽事件卡、答营养题，胜者从麦当劳商城商品中选奖励。卡牌四维属性由 MCP 接口返回的 160 条真实营养数据推导，事件卡来自当月营销活动，奖励对接真实商城商品与积分兑换。零第三方依赖，Node.js 18+ 即可运行；未配置 MCP Token 时回退内置脱敏快照，离线可完整游玩。服务端对下单/扣款类工具做硬拦截，兑换需玩家绑定自己的 Token 并二次确认。

## 能力要点

- 卡牌属性由 MCP 真实营养数据（160 条）推导并可溯源
- 36 张事件卡中 12 张来自当月真实营销活动
- 零 npm 依赖，git clone 后 node scripts/start.js 即可运行
- 服务端白名单机制拦截写入类 MCP 工具，真实兑换需 BYOT + 二次确认

## 适用场景

- 带 3~10 岁孩子的家庭在等餐或在家玩一局 10~20 分钟的亲子桌游
- 家长用真实 kcal/蛋白质数据给孩子做营养认知教育
- 开发者参考其 MCP 代理层、快照降级、白名单实现来接入自己的 MCP
