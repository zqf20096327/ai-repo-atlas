**基于 PyTorch 的 Scala 3 深度学习与张量计算库**

Storch 是面向 Scala 3 的张量计算与深度学习库，底层基于 PyTorch。提供类 NumPy 的张量 API、GPU 支持、自动微分和用于构建与训练神经网络的 API。其 Scala API 设计目标为接近 PyTorch 的 Python API，便于移植已有模型和已有 PyTorch 经验的开发者上手。文档发布于 storch.dev，README 中以 Scala 代码示例展示张量创建等基本用法。
