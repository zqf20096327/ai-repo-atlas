**Flutter 太空探索应用：NASA 数据与 AI 对话助手**

基于 Flutter 的移动应用，整合 NASA 多个 API 提供每日天文图片（APOD）、火星车照片、实时 ISS 跟踪与太空任务数据库浏览；附带支持语音转文本输入的 AI 聊天机器人，用于对话式查询太空知识。运行需在 .env 配置 NASA、AI 模型与 Google Maps 的 API key，通过 git clone 源码并 flutter run 运行。依赖 Flutter SDK 与若干 Flutter 包。
