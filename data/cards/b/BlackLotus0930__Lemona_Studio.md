**面向长篇创作的集成 AI 写作编辑器**

基于 Electron + React + TypeScript + Tiptap 构建的桌面写作编辑器，面向大型虚构世界的长篇写作：提供智能改写（生成多个备选表达）、全文上下文理解与召回、世界观实验室（将零散想法组织成完整图景）、一键导入、版本控制等功能。目前提供 Windows 下载安装包，macOS 与 Linux 版本标注为即将推出；项目以 MIT 许可开源，接受社区贡献。
