**给开发者的可视化 AI 工作流开发框架与桌面端**

FlowGram 是字节跳动开源的可组合工作流开发框架，内置流程画布、节点配置表单、变量作用域链及 LLM、条件、代码编辑器等现成物料，供开发者搭建 AI 工作流平台。提供自由/固定两种画布布局，表单引擎支持校验、联动与副作用处理，变量引擎支持类型推断。另有 FlowGram Desktop 桌面端（macOS/Windows），支持对话式构建、节点调试、工作流版本发布为 HTTP 与 MCP 服务，含中英文界面。提供 npx 脚手架创建项目及安装包下载。

## 能力要点

- 内置画布、表单引擎、变量引擎与 LLM/条件/代码节点等物料
- 自由布局与固定布局两种画布，支持分支、循环节点
- 桌面端支持工作流发布为 HTTP 与 MCP 服务、历史快照回溯
- npx 脚手架一键创建项目，桌面端提供 macOS/Windows 安装包

## 适用场景

- 搭建面向业务的可视化 AI 工作流平台
- 用对话加画布方式构建、调试并复用 Agent 工作流
- 将工作流以 HTTP/MCP 服务形式发布给其他系统调用
