# browser-use/chat-ui-example

⭐ 23 · TypeScript · MIT · 推送 2026-10-23 · [GitHub](https://github.com/browser-use/chat-ui-example) · 组织维护

**浏览器操作 AI agent 的聊天界面示例应用**

基于 Browser Use Cloud SDK（v3）构建的示例聊天应用：用户在对话框下达任务，云端 agent 实时浏览网页并汇报结果，界面内置实时浏览器面板（仅桌面端）、会话录制 MP4 下载、浏览器配置文件/工作区/190+ 国家代理等设置项，可选 BU Mini/BU Max 模型。技术栈为 Next.js 15、React 19、Tailwind、TanStack Query。运行需注册 browser-use.com 获取 API key，属云服务依赖示例，面向基于 SDK 做二次开发的开发者。

## 能力要点

- 对话下达任务，云端 agent 实时浏览网页并流式返回结果

- 支持模型选择、浏览器配置文件、工作区、190+ 国家代理设置（localStorage 持久化）

- 任务结束后回看或下载 agent 浏览过程的录像
