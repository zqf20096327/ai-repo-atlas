# Bai-Cute/big-blue-fish-desktop-pet

⭐ 394 · C# · Apache-2.0 · 推送 2026-11-25 · [GitHub](https://github.com/Bai-Cute/big-blue-fish-desktop-pet) · 个人维护 · 中文 README

**内置本地大模型的 Windows/Linux/macOS 桌宠陪伴应用**

以 DeepSeek 二创形象"蓝色大肥鱼"为角色的 AI 桌宠，面向普通用户。读取前台窗口画面并经 OCR（Windows/Mac/Linux 各用系统 OCR、Apple Vision、Tesseract）整理后交给内置 Qwen3.5-4B Q4_K_M GGUF 模型（随包分发 llama.cpp，Windows/Linux Vulkan、macOS Metal），以文字气泡输出陪伴语句；结合天气与 IT之家科技新闻生成播报。无对话历史与记忆，读屏内容不上传。提供 106 段动画、节日与季节动作；标准版可经 ACP 连接 21 款 CLI Agent 实现长对话与电脑操控，另有无ACP版移除该功能。

## 能力要点

- 内置 4B 本地 GGUF 模型，llama.cpp 推理，支持 GPU/CPU 自动切换
- OCR 读屏后本地理解生成陪伴语句，读屏内容不上传云端
- 标准版经 ACP 连接 21 款 CLI Agent（Claude Code、Codex CLI 等）
- 106 段动画，覆盖节日、季节、三餐等场景，农历节日按农历计算

## 适用场景

- 连接本机 CLI Agent 进行长时间对话与电脑操作
