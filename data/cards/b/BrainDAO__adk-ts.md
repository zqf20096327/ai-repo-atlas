# BrainDAO/adk-ts

⭐ 119 · TypeScript · MIT · 推送 2026-06-26 · [GitHub](https://github.com/BrainDAO/adk-ts) · [官网](https://adk.iqai.com) · 组织维护

**TypeScript 原生的多 LLM AI Agent 开发框架**

面向 TypeScript 开发者的开源 AI Agent 构建框架：提供多供应商 LLM 接入（OpenAI、Anthropic、Google 等）、声明式自定义工具系统、完整推理循环、流式响应、持久记忆、顺序/并行/循环的多 Agent 编排，以及预置 MCP 服务器。通过 npm 包 @iqai/adk 或全局 CLI 安装使用，默认 LLM 为 Google Gemini，运行示例需至少一个 LLM 供应商的 API key。MIT 许可，由 IQAI 维护。
