# basionwang-bot/HermesPet

⭐ 603 · TypeScript · 推送 2026-11-10 · [GitHub](https://github.com/basionwang-bot/HermesPet) · [官网](https://hermespet.cc) · 个人维护 · 中文 README

**macOS 桌面 AI 伴侣：住进刘海的多引擎任务控制台**

基于 Swift 6/SwiftUI 的原生 macOS 应用，把对话、截图提问、语音输入、文件拖拽等 AI 交互嵌入刘海与屏幕边缘的侧边操作台。可连接在线模型（自配 API Key），也可复用本机已登录的 Claude Code、Codex、QwenCode、Kimi 等终端；多对话独立并行，展示执行步骤、系统负载与任务进度，并提供知识云图、本地历史记忆与计划任务。官方分发签名的 DMG 安装包（Apple Silicon/Intel），手机与手表配套端仍在开发中。

## 能力要点

- 接入 7 类 AI 节点：在线模型、OpenAI 兼容端点及本机 Claude Code/Codex/QwenCode/Kimi 登录态
- 屏幕边缘控制台展示 CPU、内存、温度、存储、网速与 AI 节点状态
- 多对话并行，呈现文件读取、命令与工具调用的执行过程
- 历史对话本地保存，可生成按关键词/主题检索的知识云图

## 适用场景

- 在不切换窗口的情况下随时向 AI 提问、截图圈选解释
- 同时运行多个 AI 任务并在完成时收到灵动岛提醒
- 把 Claude Code 等终端 Agent 的执行过程集中观察管理
- 离开电脑后用 iPhone 查看进度、批准操作和继续对话
