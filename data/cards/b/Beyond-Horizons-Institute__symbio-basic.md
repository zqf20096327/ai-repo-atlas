# Beyond-Horizons-Institute/symbio-basic

**带 3D 虚拟形象与屏幕视觉的桌面 AI 伙伴应用**

桌面端 AI agent 伴侣应用：AI 以 3D VRM 形象的透明悬浮层常驻桌面，支持语音对话（OpenAI/Gemini TTS 共 42 种音色）、屏幕视觉、定时截屏、持久记忆（MEMORY.md/SOUL.md，可配置 PostgreSQL/Neo4j）与沙箱文件读写。通过 AI gateway 接入智能：推荐 Hermes agent 框架获得工具与 MCP 集成，也兼容任何 OpenAI 型 API（OpenAI、Ollama、LM Studio、vLLM、OpenRouter）。提供 Windows/macOS/Linux 安装包，无需编程即可使用。

## 能力要点

- 3D VRM 形象：口型同步、情绪、35+ 动画、44 个内置形象且 AI 可自选
- 屏幕视觉与定时截屏，透明悬浮层常驻桌面
- 接入 Hermes 时走 /v1/runs API 获得自主 agent 行为（工具调用、会话延续）
- 持久记忆与演化人格：AI 自写 SOUL.md、偏好并可自选名字

- 让 AI 看屏幕、听语音并跨会话记住我
