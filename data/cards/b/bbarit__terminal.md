**Rust 编写的 AI 编码终端 IDE，内置编码 Agent**

BBARIT Terminal（빠릿터미널）是用 Rust 构建的 AI vibe coding IDE/终端/agent 一体化工具，内置带 verify loop 的编码 Agent 与 dev↔review AI 结对模式，可并排运行 Claude、Codex、Gemini、Kimi、Qwen 与 Ollama，并支持编辑 Word/Excel/PowerPoint，面向 macOS 与 Windows。本仓库 README 为韩文迁移公告：安装包与二进制发布的分发已终止，完整源码、内置 Rust agent 与浏览器控制 CLI 迁移至新的 MIT 开源仓库，需自行构建。
