**面向 agent 开发的领域编程语言**

BAML 是一门面向 agent 开发的编程语言，语法类似 TypeScript，提供类型系统、运行时类型保持、类型化错误与静态分析、文件系统组织的模块结构、并发机制，并内置测试/eval 框架与 agent 标准库。BAML 函数可从 TypeScript、Python、Go、C#、Java 等语言调用，支持独立运行或增量引入。安装方式包括 Homebrew，另提供 IDE 插件安装命令。
