**自托管文档平台，集成 Ollama/OpenClaw 提供私有 AI 功能**

基于 Laravel 与 Filament 构建的开源文档平台，面向希望自托管文档系统的用户。通过集成 Ollama 与 OpenClaw 提供私有 AI 功能：用户可选择活跃提供方，所有提示词与回答均保留在自己的服务器上，不发起外部 API 调用。支持 Docker 自托管或本地运行，README 提示项目仍在活跃开发中，并提示 AI 模型资源消耗较大需按主机配置选型。许可为 Functional Source License 1.1。
