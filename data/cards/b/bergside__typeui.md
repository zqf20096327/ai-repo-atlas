**给 AI 编码工具提供设计技能与 UI 提示词的资源库**

TypeUI 提供 AI 优先的 UI 设计资源集，包括 DESIGN.md/SKILL.md 两种格式的设计技能、17 类 UI 提示词（hero/pricing/faq 等，共约 160 个布局）以及 UI/UX 基础知识技能（间距、排版、对比度等）。通过 MCP 服务器接入 Claude、Codex、Cursor、VS Code 等约 25 种 AI 编码工具；资源声明可用于任何支持 markdown 或通用提示的 AI 提供方。README 未包含运行代码或完整安装命令，主要是指向 typeui.sh 各指南与技能页的链接索引。

## 能力要点

- DESIGN.md 与 SKILL.md 双格式的设计技能（60+ 风格）
- 17 类 UI 提示词分类（hero/pricing/testimonial 等）
