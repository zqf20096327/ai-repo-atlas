**AI 生成演示文稿的 SaaS Web 应用（Next.js + OpenAI）**

基于 Next.js 15、Clerk、Prisma/PostgreSQL、Lemon Squeezy 构建的全栈 Web 应用：用户输入提示词后由 OpenAI GPT 生成幻灯片大纲与文本，DALL·E 生成配图，再经拖放编辑器自定义主题、布局与视觉。含认证、订阅付费、项目管理与回收站。需 Node.js 18+、PostgreSQL 实例及 OpenAI/Clerk/Lemon Squeezy API key 方可运行；导出 PPTX/PDF 与团队协作尚在路线图未实现。
