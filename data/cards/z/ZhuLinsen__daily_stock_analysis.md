# ZhuLinsen/daily_stock_analysis

**给个人投资者的 LLM 多市场股票每日分析推送系统**

基于 LLM 的 A股/港股/美股/日股/韩股/台股自选股分析系统：聚合行情、K 线、技术指标、新闻与公告数据，生成含结论、评分、买卖点位与风险提示的决策报告，并推送到企业微信/飞书/Telegram/Discord/Slack/邮箱。支持 GitHub Actions 零成本定时运行、Docker/本地部署、Web 工作台、多轮策略问股 Agent（20 种内置策略），并可作为 Codex/Claude Code 插件安装。默认使用免费行情源，仅供学习研究，不构成投资建议。
