# zt994451054/winston-shopper

⭐ 3 · JavaScript · MIT · 推送 2026-11-16 · [GitHub](https://github.com/zt994451054/winston-shopper) · 个人维护 · 中文 README

**AI 编程助手只读查询淘宝/京东/拼多多购物数据的技能包**

一个 Agent Skill 技能包，装入 Claude Code、Codex、CodeBuddy 等支持 skills 目录的 AI 编程助手后，AI 依据随包的 SKILL.md 运行命令行程序，在用户自己已登录的 Chrome 里只读地读取淘宝/天猫、京东、拼多多（手机网页版）的搜索结果、商品详情、规格价格、评价、购物车与订单，整理为带来源的结构化数据并可导出 Markdown/CSV。程序通过 Playwright 扩展连接 Chrome，不调用平台接口、不生成 AI 内容；速度刻意放慢，遇登录、验证码或限流即暂停并锁定平台 15 分钟。仅 macOS 完整验证。

## 能力要点

- 只读设计：不下单、不加购、不付款，不读取 cookie、地址、支付方式等敏感数据
- 在你自己已登录的 Chrome 里读取页面，使用本来的登录状态
- 数据留本机，连接服务只监听本机地址，令牌存于权限 600 的本地文件
- 任务可恢复、操作间有随机间隔与次数上限，遇拦截自动暂停

## 适用场景

- 让 AI 助手跨三个电商平台比价并汇总成表格
- 读取并导出最近的订单或购物车为 CSV
- 查看某商品各规格价格与差评要点
