**用视觉模型替人操作 PC 游戏键鼠的 Windows 工具**

读取用户指定游戏窗口的画面，发送到自配的视觉模型接口，将返回的带时长动作序列换算为键盘鼠标输入执行；本地按毫秒精确执行并合并连续移动。配套白名单、危险动作拦截、每日预算、F10 急停等安全机制，多套配置方案切换，API Key 用 DPAPI 加密存本机。适用回合制、RPG 等节奏不快的游戏；云端视觉每轮 0.5–2 秒，不适合射击类。仅提供 Windows 64 位 exe，需自备支持图像输入的模型 API Key。

## 能力要点

- 模型返回带时长的动作序列（walk/click/turn 等），本地毫秒级执行
- 白名单、危险动作拦截、每日预算、F10 紧急停止等安全机制
- 峰谷计费提示：按北京时间显示高峰/空闲价格与倒计时
- 多套配置方案切换，适配不同游戏

## 适用场景

- 回合制、卡牌、策略等游戏里让 AI 替我完成重复操作
- 开放世界探索时让模型读画面自行走位与交互
- 按游戏切换保存好的键位与标定方案
