# zhang3c3c33c/BigBirdUI

⭐ 13 · Kotlin · MIT · 推送 2026-09-30 · [GitHub](https://github.com/zhang3c3c33c/BigBirdUI) · 个人维护 · 中文 README

**让 AI 通过对话操作手机的助手，支持安卓后台执行**

面向普通用户的手机 AI 操作助手：以自然语言下发任务，AI 识别手机页面并执行点击、输入、查找内容等操作，可随时停止或人工接管。安卓端借助 Shizuku 在独立任务屏后台执行，不设应用白名单；Windows 端通过 USB 连接 Android（基于 scrcpy/UIAutomator2）与 iPhone（基于 pymobiledevice3，需配合爱思助手）。模型通过 OpenAI 兼容协议接入（如 DeepSeek，需支持图片输入），任务文字与截图会发送给所选服务商，费用由服务商收取。

## 能力要点

- 自然语言任务驱动 AI 执行点击/输入/查找，可随时停止或接管
- 安卓在独立任务屏后台执行，不设应用白名单
- Windows 可连接 Android 与 iPhone 操作手机
- 支持 OpenAI 兼容 API 协议接入多模型与联网搜索（百度 AI 搜索）

## 适用场景

- 用一句话让 AI 打开 App 并完成操作，如打开计算器算数
- 任务在安卓后台执行，本人继续使用手机其他功能
- 在电脑上通过对话远程操作 Android 或 iPhone
