**自托管浏览器 AI 编程工作台，团队手机电脑协作长程任务**

自托管的 AI 编程工作台，将多 Agent 分工、上下文管理、工具执行与运行验证整合进浏览器界面；部署在自己服务器上，任何设备浏览器即可操作。五种子 Agent 角色并行执行，统一 Tool Gateway 授权安全架构，工具结果进入下一轮判断。支持 Docker 一键部署或本地三服务（JDK 21、Node 22+、Python 3.11/3.12）运行。MIT 许可，数据存本地；模型 API 与外部服务仍会接收请求中的数据。
