**Vue 示例项目：演示 OpenAI GPT 文本流、图像生成与音频转写**

基于 Vue CLI 的示例工程，调用 OpenAI API 演示 GPT 能力：文本流式输出（Streams）、对话/补全、DALL-E 图像生成与 Whisper 音频转写。运行前需自行注册 OpenAI 账号并配置 API key，通过 git clone 获取源码后 npm install 安装依赖、npm run serve 启动开发服务器。项目内含 gpt-simple-api-ts 的副本，README 未列明模型参数与许可信息。
