**自托管 RSS 阅读器：单二进制+SQLite，内置 AI 摘要翻译与 MCP**

运行在自己服务器上的 RSS 阅读器，单个 Go 二进制加 SQLite 即可启动，订阅/已读/星标数据自持。功能覆盖 RSS 2.0/Atom/JSON Feed 订阅、OPML 导入导出、文章/社交/通知/图片四视图、插件系统（zip 安装）、自动化规则引擎（关键词/正则/AI 相关性，可用自然语言生成规则）。AI 部分需自备 API Key，支持 OpenAI、Anthropic 及兼容接口做摘要与翻译，另有 4 条免费翻译通道轮换；提供双向 MCP：既可读外部 MCP 服务作订阅源，也可作为 MCP 服务器供 Claude 等客户端读取条目。

## 能力要点

- 单二进制 + SQLite 一条命令启动，数据目录备份即可迁移
- 自动化规则引擎：关键词/正则/AI 相关性条件，自然语言生成规则，可预览、回溯与撤销
- 双向 MCP：外部 MCP 服务作订阅源；自身作为 MCP 服务器供 Claude 等客户端读取
- AI 摘要与翻译支持 OpenAI/Anthropic 及兼容接口，另含 4 条免费翻译通道轮换

## 适用场景

- 在自己服务器上托管 RSS 订阅，数据不离手
- 用自动化规则自动星标/静音/推送特定文章
- 用 AI 批量翻译外文订阅源并阅读摘要
- 把订阅条目通过 MCP 接入 Claude 等客户端
