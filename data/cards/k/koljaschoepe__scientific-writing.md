**面向非技术用户的 Claude Code 学术写作模板，从选题到 LaTeX PDF**

基于 Claude Code 的学术论文端到端写作模板：通过 /start 面试式问答完成项目配置，提供 /recherche 文献检索（DOI 核验）、/quellen 引文管理（记录原文与页码）、/schreiben 章节撰写、/pruefen 以评审视角带评分预估的检查、/pdf 生成 LaTeX PDF 或 Word 等 11 个斜杠命令，并用 Dashboard 展示进度。面向无技术经验的学生（Windows/macOS，VS Code 或 Cursor），界面为德语，论文本身可德语或英语。一键脚本安装 VS Code、Git、LaTeX、Pandoc、Python 与 Claude Code。
