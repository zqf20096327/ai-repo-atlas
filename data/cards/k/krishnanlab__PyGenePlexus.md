**基于网络的基因功能相似性分类与全基因组预测 Python 库**

GenePlexus 分析流程的 Python 包：读取输入基因列表，在生物网络上进行基因分类，生成全基因组范围内与输入基因功能相似的基因预测。提供 Python API、命令行界面（geneplexus 命令）与示例脚本，配套方法论文（ModGenePlexus、GenePlexusZoo、Benchmarking）、数据 DOI、在线 Webserver 与包文档。通过 pip 安装，面向生信分析与计算生物学研究者。
