**给安全测试者的 Agent 自动化渗透测试平台**

基于 FastAPI + 原生前端 + SQLite 的自动化渗透测试平台。输入域名后由大模型 Agent 自主抓取页面、梳理接口，按用户勾选的 64 项测试能力（分 7 组）逐项验证，输出带请求包与响应包的漏洞清单。提供 24 个内置工具（HTTP 客户端、命令执行、漏洞归档等），破坏性操作在工具层拦截；配套资产管理、批量作业、API 连接器中心（28 个）与审计日志。整个过程通过对话驱动，支持 15 家大模型连接器接入。

## 能力要点

- Agent 自主决定发包顺序，对话驱动完成渗透测试
- 64 项测试能力分 7 组，勾选即逐项验证
- 24 个内置工具，破坏性操作在工具层拦截
- 28 个 API 连接器：15 家大模型、6 家测绘、本地检测工具

- 把自有 py/exe/jar 工具纳入统一界面运行
