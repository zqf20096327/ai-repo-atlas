**面向授权渗透测试的多 Agent 协同执行平台**

Go 服务端 + Web 控制台的单用户多项目安全测试平台，复用 cyber-harness 承载模型会话与工具调用。以意图生命周期组织工作：指挥官派发意图，执行者执行并交接；事实断言、线索与证据分开存放，成功 run 须通过默认开启的独立复核。提供操作员监督（暂停/接管/持续指令）、工具审批挂起、token 按角色分账与观测采集。当前为 0.x 版本，账本格式不保证迁移，声明不可用于无人值守生产环境。

- 意图生命周期管理：创建、派发、交接、重试、停放与完成
