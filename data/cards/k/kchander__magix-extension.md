# kchander/magix-extension

⭐ 21 · JavaScript · MIT · 推送 2025-11-23 · [GitHub](https://github.com/kchander/magix-extension) · [官网](https://chromewebstore.google.com/detail/magix/ebfhenlkpdngcofiegobedbahdeemgjo) · 个人维护

**用自然语言修改任意网页的 AI Chrome 扩展**

Chrome 浏览器扩展：用户以对话描述想要的网页改动（如加暗色模式、隐藏广告），AI 生成 JavaScript/CSS 并实时应用到当前页面，改动持久化并在重载后保留。支持 Gemini、Claude、OpenAI、xAI、OpenRouter 等多家 API，使用用户自有 key，无订阅。提供元素点选定位（含 Shadow DOM）、基于 Supabase 的云同步与公开修改的发现/分享社区。从 Chrome Web Store 安装即可用，源码构建需自行配置 Supabase 后端。

## 能力要点

- 自然语言生成 JS/CSS 并实时应用到任意网站
- 支持 Gemini/Claude/OpenAI/xAI/OpenRouter 等多家 provider（BYO API key）
- 点选元素定位、Shadow DOM 支持
- Supabase 云同步与公开修改的一键安装社区

## 适用场景

- 给没有暗色模式的网站加暗色模式、隐藏广告和弹窗
- 通过对话迭代式地定制任意网站的界面与功能
- 浏览并一键安装他人分享的网页修改
