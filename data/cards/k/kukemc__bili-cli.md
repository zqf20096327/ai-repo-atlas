**让 AI Agent 操作 B 站账号的命令行工具：登录、看视频、评论、投稿**

为 AI Agent 设计的哔哩哔哩命令行工具，提供 80+ 条命令覆盖扫码登录、视频观看与信息获取、评论/私信/动态互动、投稿与改稿、数据中心查询。输出统一为 JSON（含错误码与下一步提示），写入操作内置本地限流、审计日志、投币上限、私信白名单与 AI 内容声明等护栏。可通过 skills install 自动装进 18 个 Agent，或以 17 个 MCP 工具接入 Claude Desktop 等客户端。需 Python 3.10+；语音转写依赖 Qwen3-ASR，可本地 GPU/CPU 部署或接云端接口。

## 能力要点

- 80+ 条命令，统一 JSON 输出、错误码与 hint 下一步提示
