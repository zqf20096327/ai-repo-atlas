**韩国求职自荐书 8 阶段写作流水线（Claude Code 插件）**

面向韩国应届/实习申请者的 Claude Code 插件：输入公司名与岗位后，按企业调研（生成公司事实与简历对照表）、公告题目分析、起草、Python 实测字数（填至限制的 95%）、5 轴评审、修订、润色、最终验证 8 阶段生成自荐书。仅使用简历中存在的事实素材，检测素材重复与夸大；基于 1,080 篇合格范文分布做文体检查。不代提交申请表。核心为 SKILL.md 流水线，也可复制技能文件夹在 Codex Skills 中使用。

## 能力要点

- 8 阶段流水线：企业调研→题目分析→起草→字数→评审→修订→润色→验证
- 素材仅取自 이력서.md，含事实对照与素材重复检测
- verify.py 实测字数并填至限制的 95%，style_check.py 基于合格范文分布做文体范围检查
- 按公司生成带截止日期命名的文件夹，支持多公司并行处理

## 适用场景

- 同时申请多家公司时批量生成各公司定制的自荐书
- 按题目字数限制精确填充并最终验证
- 避免素材重复与简历外夸大表述
- 以非开发 HR 视角检查术语与机翻式句子
