**PyTorch 群体智能算法与模型架构库，供开发者与研究使用**

基于 PyTorch 的库，实现多种生物启发群体智能算法与架构：Particle Swarm Optimization、Ant Colony Optimization、Cellular Swarm Networks、Fish School/Sakana、Firefly 优化、Swarmalator 模拟，以及 Mixture of Mambas、SwitchMoE 等 MoE 架构。另提供模型权重合并方法（HyperSlice、随机子空间合并、进化交叉等）。以 pip 安装的 Python 库形式提供，要求 Python 3.8+ 与 PyTorch 1.12+，CUDA 为推荐配置。附使用示例与 API 文档，MIT 许可。
