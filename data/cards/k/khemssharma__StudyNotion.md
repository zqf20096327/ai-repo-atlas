**面向学生与讲师的 MERN 在线教育平台，含课程/支付/认证**

基于 ReactJS、NodeJS、ExpressJS 与 MongoDB 的全栈在线教育平台：学生可浏览课程、心愿单、购物车结算、观看课程内容与评分；讲师可创建/更新/删除课程、查看数据洞察。后端提供 OTP 验证、JWT 认证、Razorpay 支付集成、Cloudinary 云媒体管理，课程文档以 Markdown 存储。仓库描述另称包含深度学习（NCF）推荐、ETL 数据管道与 GenAI 查询能力，但 README 正文未展开。通过 git clone 与 npm install 本地运行。

## 能力要点

- 学生端：课程浏览、心愿单、购物车结算、评分与课程内容消费
