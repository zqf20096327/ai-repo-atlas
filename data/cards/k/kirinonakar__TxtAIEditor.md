# kirinonakar/TxtAIEditor

⭐ 16 · C# · MIT · 推送 2026-10-29 · [GitHub](https://github.com/kirinonakar/TxtAIEditor) · 个人维护

**带 AI 助手与 Agent 的 Windows 桌面文本编辑器**

基于 WinUI 3（.NET 10.0）的 Windows 桌面文本编辑器，面向开发者、写作者与高级用户。编辑核心支持虚拟化滚动，可打开 200MB+ 大文件；内置 Markdown/HTML/LaTeX 实时预览、终端、Git 面板、CSV/JSON 表格模式、Jupyter Notebook（含 Python 内核）、十六进制编辑、压缩包浏览、图片/文档/音视频查看，以及 SSH/SFTP/FTPS/WebDAV/WSL 远程工作区。AI 部分：多提供商助手（Gemini、OpenAI、OpenRouter、Ollama、LM Studio 等，密钥存于 Windows 凭据管理器）与可执行多步工作区任务的 AI Agent（支持 MCP、浏览器/计算机操作、ComfyUI 插件）。

## 能力要点

- 虚拟化编辑核心，可打开编辑 200MB+ 文件
- AI Agent 支持 MCP、多会话隔离、浏览器/计算机操作与 ComfyUI 插件
- 多提供商 AI 助手：翻译、上下文解释/摘要/润色、自定义命令
- SSH/SFTP/FTPS/WebDAV/WSL 远程文件编辑与同步

## 适用场景

- 在 Windows 上编辑大型文本与代码文件并实时预览 Markdown/LaTeX
- 用 AI 助手翻译、摘要、润色选中文本
- 让 AI Agent 执行文件、终端、网页等多步工作区任务
- 直接编辑远程服务器或 WSL 中的文件
