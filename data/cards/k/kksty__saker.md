**给授权渗透测试者的多 Agent 协作测试平台**

Go 服务端加 Web 控制台构成的单用户单实例多项目平台，复用 cyber-harness 的 Hub 与 scan 承载模型会话与工具调用。核心机制：意图生命周期（创建/派发/交接/重试/停放）、事实断言与证据分开存放的持久账本、成功意图的独立复核、guardrail 命名空间的工具人工审批、操作员暂停/接管/持续指令等监督手段。0.x 版本接口与账本格式会变，升级需独立数据目录，不建议无人值守用于生产环境。

- 意图生命周期管理：创建、派发、交接、重试、停放与完成，每个 run 记录输入/状态/用量/停止原因
- 工具审批机制：需人工决定的调用挂起在 guardrail 命名空间，裁判可插拔（none/jev/llm/hybrid）
- 实时攻击面图谱：前提、产出、引用与固定上下文以显式关系组织
