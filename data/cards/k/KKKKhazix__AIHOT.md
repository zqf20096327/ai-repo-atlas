**自托管行业热点日报站框架：LLM 筛选聚簇成刊**

自托管的热点资讯站框架，六步流程：采集、预筛、独立两次评分、中文写作、事件聚簇、按独立来源数计算热度并编出日报周报月报。支持 RSS、网页列表、JSON 接口、X 账号、微信公众号、脚本推送六种信源，提示词与入选门槛全部公开可改。通过 Docker Compose 部署，需要 Node.js 24、PostgreSQL 与任一 OpenAI 兼容模型 API Key。面向想把信源与精选标准换成自己行业的运营者。

## 能力要点

- 六种信源接入与三级信源分级门槛
- 同一标准独立打两次分的精选流程，提示词与门槛全部可改
- 标题摘要向量聚簇成事件，按 48 小时独立来源数计算热度
- 对外提供 RSS、公开 API、MCP 与 llms.txt 供 Agent 读取

## 适用场景

- 给自己关注的行业搭一个每日热点日报站
- 把多个来源重复报道的资讯聚合成事件时间线
- 用自己的标注样本校准 LLM 精选标准
- 通过 MCP/RSS 接口把精选内容供给 Agent 使用
