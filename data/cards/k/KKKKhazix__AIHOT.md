# KKKKhazix/AIHOT

⭐ 11,295 · TypeScript · MIT · 推送 2026-11-23 · [GitHub](https://github.com/KKKKhazix/AIHOT) · [官网](https://aihot.news) · 个人维护 · 中文 README

**自托管行业热点日报框架：AI 筛选、聚簇并自动成刊**

开源的新闻热点网站框架：从 RSS、网页列表、X、微信公众号等六种信源采集资料，用大模型预筛、独立打两次分，生成中文标题摘要，按向量与模型判断把多来源报道聚成事件并计算热度，定时输出日报、周报、月报。所有提示词与入选门槛公开可改，配套后台管理、SelectBench 校准脚本、MCP/RSS/API 等 Agent 接入出口。部署依赖 Docker Compose、Node.js 24 与一个 OpenAI 兼容的模型 API Key，仓库不含原站信源名单与运营数据。

## 能力要点

- 六种信源接入与三级信源分级门槛
- 预筛加独立两次评分，提示词全部公开可改

- 对外提供 MCP、RSS、公开 API 与 llms.txt
