# khulnasoft/gpt-computer-agent

⭐ 29 · Python · MIT · 推送 2026-07-21 · [GitHub](https://github.com/khulnasoft/gpt-computer-agent) · 组织维护

**跨平台计算机智能体开发框架：为产品嵌入可控 LLM 助手**

以 Python 库形式提供的 intelligence 开发框架，定位为将 ChatGPT 桌面应用的能力带到 Windows 与 Linux。开发者通过 remote API 配置模型（如 gpt-4o）与 API key、设置助手名称与开发者人设、安装函数库，并以 remote.input 向运行于用户电脑上的助手下发任务（读屏、提取配置、交互咨询等）。能力表列出本地 Ollama 视觉模型、本地语音、屏幕读写与点击、记忆、代码执行等；另提供预定义多智能体团队。要求 Python 3.10 或 3.11，提供 pip 安装与 macOS/Windows 二进制下载。

## 能力要点

- remote API 配置模型、人设并下发读屏/提取信息/咨询任务
- 能力表覆盖本地 Ollama 视觉、本地 TTS/STT、屏幕读写与点击、记忆、Python/SH 执行
- 预定义多智能体团队（联网搜索汇报、代码生成）
- 支持安装函数库扩展助手能力

## 适用场景

- 为自己的产品嵌入可操作用户电脑的 AI 助手
- 构建读屏、提取配置、交互式咨询类自动化流程
- 在 Windows/Linux 上获得类似 ChatGPT 桌面应用的本地能力
