**网站接入 AI 客服 agent 与人工在线聊天的 Web 插件 SDK**

Kommunicate 提供开源的网站聊天挂件插件：企业通过 Kompose 无代码构建器创建 AI 客服 agent，经托管集成或自带 API key 接入 OpenAI、Anthropic、Google Gemini、Google CX Agent Studio 等模型，再复制 JavaScript 代码片段嵌入网站。支持文件/图片上传、语音交互、表单、富消息与人工坐席接管，并统一网站、邮件、WhatsApp、Telegram 等渠道会话。使用需注册 Kommunicate 账号获取 APP_ID，平台为商业 SaaS。

## 能力要点

- JavaScript 代码片段嵌入网站的聊天挂件
- Kompose 无代码 AI agent 构建器，可上传文档/连接帮助中心训练
- OpenAI/Anthropic/Gemini 支持托管集成或自带 API key 两种接入方式
- AI 无法解决时可转接人工坐席，多渠道会话统一管理

## 适用场景

- 在网站上部署 AI 客服并自动回复常见问题
- AI 回答不了时无缝转人工在线客服
- 把 WhatsApp、Telegram 等消息渠道客服统一到一个平台
