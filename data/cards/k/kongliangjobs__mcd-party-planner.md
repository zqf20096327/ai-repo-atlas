**面向家长的麦当劳儿童生日会一句话策划与下单方案生成**

基于麦当劳 MCP 的多 agent「专家团」应用：5 个角色按六级依赖链编排（串行定主题与门店档期、并行算预算与餐食），把一句话需求转成含门店、场次、成团人数与总价的派对方案及下单参数卡。运行于腾讯 WorkBuddy，需先申请麦当劳 MCP Token 并配置自定义连接器；提供 zip 打包安装与源码复制注册两种方式，另附不依赖 WorkBuddy 的链路验证脚本。为麦当劳程序员创意开发大赛参赛作品，非官方产品，下单仅支持 shopId=5。

## 能力要点

- 5 角色 agent 团队按 MCP 数据依赖编排（串行+并行）
- 六级依赖链产品化：商品→城市→门店→场次→预算→餐食
- 提供 tools/verify_chain.py 独立验证 MCP 链路，仅用 Python 标准库
- 沉淀价格单位、滚动窗口、成团人数等 4 条工程约束
