⭐ 19 · Python · BSD-3-Clause-Clear · 推送 2026-10-28 · [GitHub](https://github.com/KhiopsML/khiops-python) · [官网](https://khiops.org) · 组织维护

**Khiops AutoML 套件的 Python 接口库**

Orange Innovation 的 Khiops 团队开发的 Python 库，封装 Khiops AutoML 套件，用于构建监督模型（分类器、回归器、编码器）与无监督模型（共聚类）。提供两种使用方式：khiops.core 模块以原生方式运行（字典文件+表格数据输入），khiops.sklearn 模块提供 Scikit-Learn 估计器接口（Pandas/NumPy 输入）。安装支持 conda 与 pip，要求 Python>=3.10、Pandas>=2.3.3、Scikit-Learn>=1.7.2。
