# KaneGong/muse-frame

⭐ 3 · JavaScript · AGPL-3.0 · 推送 2026-11-23 · [GitHub](https://github.com/KaneGong/muse-frame) · 个人维护 · 中文 README

**给摄影师的本地 AI 人像摄影工作台，生成人像作品**

一个运行在 Mac 和 Windows 上的本地 AI 人像摄影 WebUI 工作台：用户选择人物、服装、场景与姿势参考图，设定构图与色调后提交任务；任务将所选参考与提示词发送到用户已连接的 Lovart、LibTV 或 Ark 账号进行生成。项目、保存的图片与任务历史保留在本地，高级控制支持光线、身体参考与拍摄参数调整，并提供工作区迁移备份。软件 AGPL-3.0-only 许可，桌面包自带运行时。
