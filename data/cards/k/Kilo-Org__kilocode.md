# Kilo-Org/kilocode

⭐ 28,148 · TypeScript · MIT · 推送 2026-11-27 · [GitHub](https://github.com/Kilo-Org/kilocode) · [官网](https://kilo.ai/) · 组织维护

**面向开发者的开源 AI 编码代理，覆盖 VS Code、JetBrains 与 CLI**

Kilo Code 是一个 agentic 编码平台，在 VS Code、JetBrains IDE 与 CLI 中运行，从自然语言生成代码。内置 Code/Plan/Ask/Debug 四种专用 agent 并支持自定义 agent；提供 500+ 模型可在任务中途切换，按模型提供商原价计费且无需 API key 即可开始。功能含多文件代码生成、内联补全、自检修正、终端与浏览器控制，以及可安装 agent/技能/MCP 服务器的 Marketplace；`kilo run --auto` 用于 CI/CD 流水线的无提示自治运行。CLI 是 OpenCode 的 fork，许可证为 MIT。
