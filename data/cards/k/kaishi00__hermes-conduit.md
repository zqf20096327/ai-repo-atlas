# kaishi00/hermes-conduit

⭐ 703 · Swift · MIT · 推送 2026-11-26 · [GitHub](https://github.com/kaishi00/hermes-conduit) · [官网](https://hermesconduit.app) · 个人维护

**为自托管 Hermes Agent 提供的原生 iOS/Watch 客户端**

Conduit 是面向 iPhone、iPad 与 Apple Watch 的原生 SwiftUI 应用，用于连接用户自托管的 Hermes Agent 仪表盘：提供流式聊天（Markdown/Mermaid/diff 卡片）、Gemini/Qwen/GPT/Grok/本地语音的实时通话、Apple Watch 呼叫与 CarPlay、任务看板、bots 与群聊、定时任务、文件与 Artifacts 浏览，以及位置/日历/健康等手机能力授权。应用本身免费、无广告、无追踪，通过 App Store 与 TestFlight 分发，配合主机上的 Notifier 插件解锁通知与语音功能。

## 能力要点

- 支持 Gemini Live、Qwen Live、GPT-Live、Grok Live 与本地语音服务器的实时通话，可随时打断
- 通知内直接审批工具调用，主机与手机间端到端加密
- 聊天、会话与桌面版共享同一数据库，跨设备接续会话
- 支持 CarPlay、Live Activities、桌面小组件与 Siri/快捷指令集成

## 适用场景

- 在手机或手表上与自己的 Hermes agent 实时语音对话
- 通过通知批准 agent 的工具调用与提问
- 在 CarPlay 或锁屏小组件中恢复会话、启动新聊天
- 在手机上查看和编辑 agent 所在主机上的项目文件
