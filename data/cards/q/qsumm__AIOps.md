# qsumm/AIOps

⭐ — · [GitHub]() · 个人维护 · 中文 README

**自托管 AI 运维平台：告警收敛后由 Agent 带证据链排查根因**

开源监控与运维平台，FastAPI 后端、Docker Compose 部署。功能包括拉取式 Agent 主机/服务监控（被监控机零入站端口）、阈值/3σ/孤立森林告警与指纹去重、ReAct 多步 AI 诊断（结论须引用证据、全程留痕）、白名单 4 动作处置（九道护栏、三档执行）、事件沉淀为向量案例卡、定时巡检与诊断评测。监控告警可脱离 LLM 独立工作，AI 诊断需在系统设置中配置 OpenAI 兼容端点。提供全量 REST API 与 MCP 接入，AGPL-3.0 许可。

## 能力要点

- 拉取式 Agent 监控，被监控机零入站端口，穿透 NAT/防火墙
- ReAct 诊断带证据链（每步留痕可回放，结论须引用 step 证据）
- 处置白名单仅 4 动作，九道护栏准入与三档执行模式
- SKILL.md 技能插件系统，告警自动路由装载
- 事件沉淀向量案例卡，同类故障可召回历史处置

## 适用场景

- 凌晨告警后让 AI 先排查取证并给出带证据的根因报告
- 在防火墙/NAT 后的主机上做零改动监控接入
- 按白名单与护栏做受控的服务重启、容器重启等处置
- 沉淀历史故障案例供后续诊断召回
