**浏览器扩展：一站式管理多个 AI 中转站账号与密钥**

面向同时使用多个 New API/Sub2API 兼容中转站的用户，提供统一看板查看余额、用量与账号状态，支持跨站模型价格对比、多站自动签到、页面快速抓取 Base URL/Key 并入库，一键导出到 CC Switch、Cherry Studio 等客户端，并可对自托管 AI 网关（New API、CLIProxyAPI 等）做渠道创建与模型同步。数据默认本地存储，支持加密 WebDAV 同步。通过 Chrome/Edge/Firefox 应用商店或 GitHub 手动安装，Safari 需 Xcode 编译。

- 多中转站余额、用量、模型价格的统一看板与趋势图
