**SpringAI 教学项目：覆盖 SSE/RAG/Agent 等知识点的配套代码**

以教学为目的的 Spring AI 示例项目，内容覆盖 SSE 流式输出、Agent 智能体、FunctionCall、Embedding、向量数据库、RAG、Graph RAG、历史消息、图片生成与图片理解等知识点，配套文档与视频地址。运行需 Java 17、Node.js 18+、MySQL 8、Redis-Stack（用于向量查询）、Neo4j 5+ 及 DashScope 或兼容 OpenAI 协议的 API Key；通过 git clone 后用 IDEA 运行后端、npm 运行前端。README 中含作者运营的 API 中转服务广告及 QQ 群联系方式。
