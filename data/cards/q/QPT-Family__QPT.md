# QPT-Family/QPT

⭐ 793 · Python · LGPL-2.1 · 推送 2026-02-06 · [GitHub](https://github.com/QPT-Family/QPT) · 个人维护 · 中文 README

**面向深度学习开源项目的 Python 打包工具（Py 转 EXE）**

QPT 将 Python 项目封装为 Windows 可执行文件，设计上针对深度学习开源项目分发场景，内置 CUDA 打包逻辑，支持 NoAVX、DML 等环境，使非开发者能运行深度学习项目。提供脚本、命令及规划中的图形化三种打包方式，可通过 SubModule 自定义封装策略，支持源码可见或编译为 pyd 保护源码，并区分秒安装/首次安装/在线安装三种体积模式。仅支持 Windows10 1806+。注意：README 声明项目自 2024.4.23 起停止更新。

## 能力要点

- 内置 CUDA 打包逻辑，面向深度学习项目分发
- SubModule 自定义封装策略与三种体积模式
- 源码可见或编译为 pyd 两种源码形态
- 仅支持 Windows10 1806+，V1.0b7 起放弃 Python3.7 及以下

## 适用场景

- 把深度学习 Python 项目打包成 EXE 交给普通用户使用
- 为 PaddleOCR 等业务程序生成免环境配置的发行版
- 以在线安装模式控制 EXE 体积
