# QianYan-Art/SafetyRAISE-OS

⭐ 43 · Python · Apache-2.0 · 推送 2026-10-07 · [GitHub](https://github.com/QianYan-Art/SafetyRAISE-OS) · [官网](https://safetyraise.cn) · 组织维护 · 中文 README

**道路交通事故分析报告生成系统：从影像材料到文书导出**

面向事故分析场景的前后端系统：用户上传事故图片/视频，经 YOLO+ByteTrack+抽帧的视觉链路生成结构化事故信息草稿，再经专家指导、本地稀疏/稠密混合检索增强生成分析报告，导出 md/docx/pdf 文书。含用户体系、会话隔离与可选的报告 Harness（证据快照、独立审查、预算、审计）。使用前需自备模型服务、非空知识库正文、ffmpeg 与 YOLO 权重；仓库不包含真实事故材料和知识库正文。技术栈为 React+FastAPI+PostgreSQL，检索打分含 Rust 原生加速。

## 能力要点

- 图片/视频上传到结构化事故信息、检索增强报告与文书导出的完整工作流
- 视频链路接入 YOLO + ByteTrack + 自适应抽帧 + 视觉模型
- 本地稀疏/稠密混合 RRF 检索，reranker 可选
- 可选报告 Harness：证据快照、独立审查与修订、预算、审计与恢复

## 适用场景

- 把事故图片与视频材料整理成结构化事故信息草稿
- 基于私有知识库生成检索增强的事故分析报告并导出文书
- 多用户环境下按账户隔离地管理事故分析会话与产物
