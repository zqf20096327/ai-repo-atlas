**面向大规模实时数据流的分析平台，支持结构化与非结构化数据**

QMiner 是一个用 C++ 实现并通过 npm 分发的 Node.js 数据分析平台，面向包含结构化与非结构化数据的大规模实时流，设计目标是在高端商用硬件上扩展到百万级数据点，提供存储、检索与分析机制并保持实时响应。文档包含 JavaScript API（qm/la/analytics 模块）与 C++ 文档；README 列出示例包括 Twitter 情感抽取与推荐系统。要求 node.js v10.x–v14.x 与 npm 5.3+，Windows 下需 Visual C++ 2015 运行库，也可从源码编译。
