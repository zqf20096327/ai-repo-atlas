**开源自托管 AI 运维监控平台：告警收敛后 AI 带证据链诊断根因**

自托管的运维监控平台，覆盖主机与服务监控、探活四件套、多维指标与 Prometheus 数据源读取。拉取式 Agent 从被监控机主动出站拉任务，主机零入站端口，可穿透 NAT/防火墙。告警经指纹去重收敛成事件后，由 ReAct 诊断 Agent 多步排查，结论必须引用证据并留痕可回放；处置动作限定 4 个白名单动作，经九道护栏准入，三档执行模式默认人工确认。监控、告警、探活、巡检不依赖模型可独立工作。以 docker compose 部署，AGPL-3.0 许可；完整操作手册不在开源包内，需关注公众号获取。

## 能力要点

- 拉取式 Agent 采集，被监控机零入站端口，穿透 NAT/安全组
- ReAct 诊断 Agent 每步留痕，结论必须引用证据，支持逐帧回放
- 处置白名单仅 4 个动作，九道护栏准入，执行后强制后置校验
- 诊断技能采用 SKILL.md 插件，告警自动路由装载

## 适用场景

- 凌晨告警时让 AI 先自主排查取证、产出带证据链的根因报告
- 在防火墙/NAT 后的主机上做无入站端口的监控接入
- 把同类故障的历史处置沉淀为案例卡供下次召回
