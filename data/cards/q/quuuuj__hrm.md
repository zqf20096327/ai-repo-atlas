**面向企业的前后端分离人事管理系统，含 Flowable 审批流与 RAG 智能问答**

基于 Spring Boot 3.4 + Vue 2.6 的人力资源全流程系统，覆盖组织架构、员工档案、RBAC 权限、考勤加班、假期、薪资与五险一金配置；审批流基于 Flowable 8.0，与业务状态共享同一本地事务。AI 部分为企业知识库问答：文档解析切块向量化入库 PostgreSQL/pgvector，检索采用向量+关键词召回经 RRF 融合与 DashScope 精排，回答带引用编号与证据充分度评估，流式输出。本地中间件由 docker compose 编排，后端 Maven 启动、前端 npm 启动。
