**给 WorkBuddy 桌面客户端加账号一键切换，并整合上游 API 面板**

在 workbuddy2api-panel 底座上开发的 Go/Windows 桌面工具，自身新增的功能是把 WorkBuddy 桌面客户端的登录态存为快照并一键覆盖切换，省去退出登录、扫码、重新初始化的流程；同时把上游的账号池、OpenAI 兼容 API 转发与 Web 管理面板装进同一进程和窗口。快照每 3 分钟自动同步续期，另提供对话 user_id 归并、自动更新与活动任务跟进。仅支持国内版客户端，需 Windows 10/11 与系统自带 Edge。

## 能力要点

- 账号登录态整文件快照，切换时覆盖并重启客户端，不解密不伪造凭据
- 快照每 3 分钟同步活动登录态，随客户端 refresh token 续期
- 单进程复用同一 http.Server，账号切换页与上游 API 面板同窗口
- 自动更新支持多源并发探测、断点续传与失败回滚

## 适用场景

- 在 WorkBuddy 客户端里快速切换多个账号，不用反复扫码登录
- 把多个 CodeBuddy 账号跑成本地 OpenAI 兼容 API
- 跟踪账号登录态剩余有效期，避免快照过期失效
