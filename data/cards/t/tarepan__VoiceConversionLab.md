**语音转换研究论文的自动收集与社区确认清单**

汇集 Voice Conversion（语音转换）领域研究论文的策展仓库。通过 GitHub Actions 中的 ArXiv Search 与 ArXiv API 定期自动采集论文信息，以“候选”形式发布到 Twitter；候选信息汇入仓库 Issue，社区可评论判断论文是否属于 VC 领域，机器人检测到评论后自动完成确认流程。README 标注当前为第一代实现（1st gen. established）。
