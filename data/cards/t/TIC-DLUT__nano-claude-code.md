**Go 从零手搓 Claude Code 式编码智能体的七天教学项目**

教学导向的开源实践项目：不使用 LangChain、LlamaIndex 甚至官方 SDK，仅以 Go 标准库及少量辅助库，从零手写 Anthropic API 调用、SSE 流式解析，逐步构建 ReAct 循环、TODO 架构、subAgents、skills 框架、上下文压缩、Tasks 系统、后台任务、多智能体与记忆持久化等编码智能体组件。面向希望理解 AI Agent 底层实现原理的学习者，另有 Python 版本分支，欢迎社区贡献。
