# Tencent-Hunyuan/HY-Motion-1.0

⭐ 2,681 · Python · NOASSERTION · 推送 2026-11-13 · [GitHub](https://github.com/Tencent-Hunyuan/HY-Motion-1.0) · [官网](https://hunyuan.tencent.com/motion) · 组织维护 · 中文 README

**文本生成3D人体骨骼动画的模型库：开发者输入文字即得动作**

腾讯混元发布的文本到3D人体动作生成模型系列，基于 DiT 与 Flow Matching，从文字提示生成骨架驱动的角色动画，可接入 3D 动画管线。提供 1.0B 标准版与 0.46B Lite 版，训练数据覆盖 3000+ 小时动作。本地推理最低需 24-26GB 显存，支持 CLI 批量推理与本地 Gradio 界面；内置 LLM 提示词改写与时长估计模块，可禁用。仅支持人形角色，不支持多人、动物、场景与镜头描述。

## 能力要点

- 1.0B 与 0.46B 两个尺寸的文本生成动作模型，最低 24GB 显存运行
- CLI 批量推理脚本与本地 Gradio 可视化界面
- 可选 LLM 提示词改写与时长估计模块（可禁用）
- 三阶段训练：大规模预训练、高质量微调、人类反馈强化学习
