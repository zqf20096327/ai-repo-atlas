# tarikurrahmann/Chatbot-Python-Project

⭐ 17 · Python · MIT · 推送 2026-09-29 · [GitHub](https://github.com/tarikurrahmann/Chatbot-Python-Project) · 个人维护

**给初学者的 Tkinter 聊天机器人：意图识别的本地对话应用**

基于 Python 的桌面聊天机器人：Tkinter 图形聊天窗口，意图与回复数据存于 intents.json，内置预训练 Keras 神经网络模型（chatbot_model.h5）与 words.pkl/classes.pkl 词表文件，用 NLTK 做文本处理，按意图模式与模型输出回复。提供训练脚本 train_chatbot.py 可重建模型，附带 test_chatbot.py 测试脚本。通过 pip 安装 nltk/numpy/tensorflow/keras 依赖后本地运行，README 声明适合 Windows 与初学者学习。
