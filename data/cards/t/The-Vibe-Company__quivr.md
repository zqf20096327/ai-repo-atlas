**为开发者把持续内容流转成可搜索可告警的引擎**

以 HTTP API 交付的开源内容引擎，无自带界面：接收文档（PDF、新闻、邮件、帖子），可从 RSS、Microsoft 365 邮箱与 X 列表定时拉取；保留每个版本，数秒内可检索，并按保存的告警规则匹配新文档、以签名 webhook 推送。检索支持关键词、语义或混合方式，结果指向具体段落与版本，最多联合检索 16 个语料库。格式、嵌入模型、排序与告警规则均为可替换的 HTTP 插件，存储基于 PostgreSQL 17，需 Linux x86_64 或 Apple Silicon Mac 自托管。
