**macOS 本地大模型聊天应用，Apple Silicon 端上运行**

基于 SwiftUI 与 MLX Swift 的开源 macOS 应用，面向 Apple Silicon Mac 用户本地运行开源模型：可浏览并下载 mlx-community 上的模型、完全在设备上对话、查看模型与内存的匹配情况，并含 MLX Audio/VibeVoice 文字转语音、会话自动摘要、隐藏术语的初学者模式与 VoiceOver 无障碍支持。要求 macOS 26 与 M1 及以上芯片，从源码用 Xcode 26 构建，无云端、无 API key。
