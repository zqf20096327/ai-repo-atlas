# TharaneshA/answergit

**AI 驱动的 GitHub 仓库浏览器：提问获得代码解释**

基于 Next.js/React/TypeScript/TailwindCSS 构建的 Web 平台，读取 GitHub 仓库（需 GitHub Token），使用 Google Gemini 对代码结构、依赖与工作流提供解释、摘要与测试建议。提供文件浏览器与交互式问答界面，支持深色模式与响应式布局。安装方式为克隆源码后 pnpm/npm 安装依赖并配置 .env.local（GEMINI_API_KEY、GITHUB_TOKEN），以开发服务器运行；未提供桌面构建或 Docker。
