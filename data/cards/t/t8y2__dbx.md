**面向开发者/DBA 的 25MB 跨平台数据库管理客户端**

用 Rust 构建的数据库管理工具，单个约 25 MB 二进制文件，无 JRE/Python/Chromium 依赖，支持 MySQL、PostgreSQL、达梦等 100+ 数据库及 Kafka 等消息队列中间件控制台。功能包括查询编辑器、数据网格、模式工具、数据导入迁移、插件商店。内置 AI 助手可将自然语言转 SQL 并做安全检查；独立的 MCP Server 让 Claude Code、Cursor 等 agent 经 DBX 连接查询数据库，支持只读/读写/完全访问三级权限模式。提供桌面端、Docker、CLI、Web 多种形态。
