**给个人知识管理者的开源 AI 笔记与知识库工作区**

开源三栏式（目录树·笔记列表·编辑器）笔记与知识库应用，提供多端客户端与网页工作区、即时多设备同步、富文本/Markdown 双模式编辑，支持表格、思维导图、Mermaid 图表、海报等富笔记类型，并内置网页剪藏（20+ 平台解析）与从 Evernote/Obsidian/Notion 等迁移的导入工具。AI 部分包括侧边栏助手（BYOK 兼容 OpenAI/Anthropic/Gemini 端点）、会话式生成图表与信息图、音视频转录，以及内置 MCP/ACP 协议驱动本地 agent。可零成本部署在 Cloudflare 免费额度内，或用 Docker 自托管。

## 能力要点

- 三栏工作流 + 富文本/Markdown 双模式编辑，支持表格、思维导图、Mermaid 图表、海报笔记
- 浏览器剪藏扩展，针对 20+ 平台的专用解析器
- 内置 Remote MCP（按笔记本读写权限）与桌面 ACP，可驱动 Codex、Claude Code 等本地 agent
- BYOK 侧边栏 AI 助手与 OpenAI 兼容语音模型转录

## 适用场景

- 自托管一个免费的多端同步笔记与知识库
- 从 Evernote/Obsidian/Notion/Joplin 一键迁移笔记
- 用浏览器剪藏把网页文章转成干净 Markdown 收藏
- 通过对话生成思维导图、流程图和信息图卡片
