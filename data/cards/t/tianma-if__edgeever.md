**开源三栏布局笔记与知识库应用，支持自托管同步与 AI 集成**

开源笔记与知识库工作区，保留树视图、笔记列表、编辑器的三栏工作流，提供 Web/macOS/Windows/Linux/iOS/Android 客户端与浏览器 Web Clipper 扩展。支持富文本/Markdown 双模式编辑、思维导图、Mermaid 图表、20+ 平台的网页剪藏解析，以及从 Evernote、Obsidian、Notion 等一键迁移。部署上可在 Cloudflare 免费额度内以 serverless 方式运行，或用 Docker 自托管于 VPS/NAS；AI 功能采用 BYOK 模式接入用户自备的模型端点。

## 能力要点

- 三栏工作流 + 富文本/Markdown 双模式编辑器，支持公式、大纲、修订历史
- 20+ 平台深度结构化剪藏解析，及 Evernote/Obsidian/Notion 等一键迁移
- 内置 MCP 远程服务（按笔记本读写权限）与桌面 ACP 驱动本地 agent
- Cloudflare 免费额度零成本 serverless 部署或 Docker 一键自托管

## 适用场景

- 自托管搭建跨平台即时同步的个人知识库
- 从 Evernote/Obsidian/Notion 迁移笔记并保留层级与附件
- 把网页文章剪藏为干净的 Markdown 存入自己的实例
- 通过 AI 对话生成表格、思维导图与信息图笔记
