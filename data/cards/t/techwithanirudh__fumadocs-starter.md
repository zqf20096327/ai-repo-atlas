# techwithanirudh/fumadocs-starter

⭐ 67 · TypeScript · MIT · 推送 2026-04-10 · [GitHub](https://github.com/techwithanirudh/fumadocs-starter) · [官网](https://fumadocsstarter.vercel.app) · 个人维护

**基于 Next.js 的 Fumadocs 文档站启动模板，含 AI 聊天功能**

由 Create Fumadocs 生成的文档站点启动模板，基于 Next.js 与 Fumadocs 框架，内置 MDX 文档渲染、OpenAPI 接口文档支持、Twoslash 类型检查代码示例嵌入，并集成 Vercel AI SDK 提供 AI 聊天功能（需配置 OpenAI 兼容 API key，不启用 AI 可填占位值）。支持可选接入 MCP Server 扩展工作流。要求 Node 22+，通过 bun 或 pnpm 安装依赖并启动开发服务器。
