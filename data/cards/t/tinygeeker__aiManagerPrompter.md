**AI 绘画提示词标签工具：分类整理标签生成可用提示词**

基于 Vue 3 与 Element Plus 的网页应用，面向使用 Stable Diffusion WebUI 等 AI 绘画工具的用户：按基础属性、人物特征、服装、动作、场景、风格、机甲等类别组织标签，提供中文界面，支持标签加权与降权语法，可实时预览并一键复制生成的提示词。通过 git clone 源码本地运行，无桌面安装包或 Docker。项目声明 MIT 许可证同时注明禁止商用。
