**AI 联盟的开放可信数据集目录计划：为 LLM 训练提供可信数据**

AI Alliance 的开放可信数据计划工作仓库：目标是构建面向 LLM 预训练、微调与领域应用的高质量可信开放数据集目录。包含四个项目：定义数据集开放性标准、征集多模态多领域数据集（含欠发达语言、科学、时序等）、使用 DPK 等工具构建数据管道以校验候选数据集、以及发布满足开放标准的开放数据集目录。仓库同时承载 Jekyll/Just the Docs 主题的 GitHub Pages 网站，文档按 CC-BY-4.0、代码按 Apache 2.0、数据按 CDLA-Permissive-2.0 许可。
