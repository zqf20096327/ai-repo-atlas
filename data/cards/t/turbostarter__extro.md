# turbostarter/extro

⭐ 413 · TypeScript · MIT · 推送 2026-10-13 · [GitHub](https://github.com/turbostarter/extro) · [官网](https://turbostarter.dev) · 个人维护

**浏览器扩展生产级起步模板，覆盖认证/存储/AI 等功能**

基于 TypeScript、React、WXT、Supabase、shadcn/ui 等技术栈的浏览器扩展 starter kit，面向需要快速搭建生产就绪扩展（Chrome MV3 / Firefox MV2）的开发者。预配置 background、popup、options、content 等全部扩展页面，内置 OAuth 认证、存储、消息通信、热重载、一键发布、国际化、分析与 CI/CD 流水线，并含实验性的原生 AI 集成。通过 git clone 与 Bun 安装运行，支持开发调试与手动/CI 两种发布方式。
