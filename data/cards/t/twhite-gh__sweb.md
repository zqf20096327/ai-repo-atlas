**Go 单文件 Web 服务器：静态文件/上传/WebDAV/多协议代理**

用 Go 编写的轻量级单文件服务器，提供静态文件服务、网页文件浏览、拖拽多文件上传、WebDAV（RFC 4918，独立端口 8081，支持读写/只读模式与 Basic 认证）、HTTPS/TLS 加密连接，以及 SOCKS5（RFC 1928）、HTTP、HTTPS 三种代理服务，各代理均可启用 Basic 认证。默认关闭高级功能，需命令行参数显式开启。支持中英双语界面按浏览器语言自动切换，跨 Windows/Linux/macOS 多架构编译，从 Releases 下载可执行文件或源码编译运行。仓库描述称由 AI 辅助编写，但 README 未描述任何 AI 功能。
