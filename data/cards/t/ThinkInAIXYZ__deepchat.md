**开源本地优先的 AI Agent 桌面客户端**

基于 Electron 的跨平台桌面应用，将云端/本地模型、MCP 服务、Skills、ACP agent 运行时与长时会话整合于一体。会话遵循 Tape.systems 理念，保留可恢复、可追溯的工作历史与 token 预算视图。支持从文件夹/ZIP/URL 安装 Skills，可从 Telegram、飞书、QQBot、Discord、微信 iLink 远程控制会话。以 Apache License 2.0 开源，支持 Windows/macOS/Linux。

## 能力要点

- 支持 MCP（Resources/Prompts/Tools、多种 transport、一键安装）与 ACP agent 集成
- Tape 机制记录会话结构化历史，支持恢复、续跑与调试
- 内置 Ollama 管理：无需命令行即可下载、部署、运行本地模型
- 可从 Telegram/飞书/QQBot/Discord/微信 iLink 远程控制桌面会话

## 适用场景

- 在一个桌面应用中同时使用云端 API 和本地 Ollama 模型对话
- 为不同任务安装和启用可复用的 Skills（代码审查、Office/PDF 等）
- 通过消息应用远程查看和操控家中电脑上的 AI 会话
