**开源桌面 IDE：编辑、预览、终端与模拟器合一工作区**

基于 Electron 与 React 的免费开源桌面 IDE，将编辑器、终端、调试器、浏览器面板、QEMU 虚拟机与 Android 模拟器整合在一个可停靠工作区中。支持 50+ 语言编辑、多框架测试发现、Node.js/Python 调试、VS Code 兼容扩展，并提供 MCP server 使本地 AI 客户端可操作项目文件、Git 与 shell。Windows 走 Microsoft Store，macOS/Linux 走下载页或源码运行。采用 GPLv3 许可，商标另有规则。
