**Windows 一键安装便携版 ComfyUI 的桌面管理器**

为 Windows 用户提供一键式便携 ComfyUI 安装：自动配置 Git、内嵌 Python 3.12、PyTorch+CUDA、ComfyUI 与 Pixaroma 教程所用节点包，并附带 EZi Desktop 桌面壳与 EZi Launcher。桌面端提供控制台、截图录屏、模型文件夹链接、启动参数编辑、版本管理、UV/PIP 缓存与快照恢复；另有 Nunchaku、SageAttention、FlashAttention、GGUF 转换等一键插件。要求 Windows 10/11 与 NVIDIA RTX 20 系列以上 GPU，卸载即删除文件夹。
