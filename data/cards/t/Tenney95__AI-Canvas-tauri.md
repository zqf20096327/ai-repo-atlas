**面向短剧创作者的本地优先 AI 多模态画布桌面应用**

基于 Tauri 2 + React 19 + React Flow 12 的桌面应用，将文本、图像、视频、音频、动画、Markdown、分镜等组织为可连接的画布节点；集成 ComfyUI、对话 Agent 与 MCP，提供剧本写作、角色/场景/道具资产管理、帧动画编辑、内置视频剪辑、3D 导演台与剧集分集画布。本地优先存储项目与媒体，凭据独立管理；在线网页版仅可体验画布界面，插件、本地模型等能力需桌面环境。当前采用 Source-Available 许可，Stars 达 10k 后转 MIT。

## 能力要点

- 多模态节点画布与剧本/分镜/剧集化管理，角色库整剧共享
- 连接 ComfyUI 多服务器、RunningHub、云端模型与本地 ONNX 模型
- 对话 Agent 可查询修改画布、生成媒体、派出只读子智能体
- MCP 外部控制：外部 AI 工具经 stdio 或 HTTP 控制画布与剪辑

## 适用场景

- 在一张画布上完成 AI 短剧从剧本、分镜到视频生成与剪辑
- 统一管理短剧的角色、场景、道具等创作资产与提示词
- 通过 ComfyUI 工作流批量生成图像和视频素材
