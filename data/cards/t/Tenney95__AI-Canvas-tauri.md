**面向短剧创作者的本地优先无限画布，集成生成与剪辑**

基于 Tauri 2 + React 19 + React Flow 12 的桌面多模态画布应用：将文本、图像、视频、音频、逐帧动画、分镜、3D 全景组织为可连接节点，覆盖剧本写作、角色/场景/道具资产管理、ComfyUI 多服务器工作流执行、图像/视频生成、内置多轨视频剪辑与剧集分集管理。支持对话 Agent 与 Skill 协作、MCP 外部控制（默认关闭）、JS/Python 用户插件。提供在线体验版（部分能力受限）与桌面安装包；当前许可为 Source-Available，声明 Stars 达 10k 后转 MIT。
