**本地大模型驱动的国家模拟策略游戏**

基于 pygame 的国家模拟游戏：2–6 个 AI 国家各拥有资源、领土、统治者记忆、计划与外交关系，由本地语言模型在结构化响应中提出行动（共 55 种动作类型），Python 引擎校验所有权、资源、科技与条约后执行结算。内置 llama.cpp 引擎从 models 目录加载 GGUF 模型，全程本地运行、无需网络或 API key。Windows 提供安装包与便携版，源码需 Python 3.12 运行；发布包不含模型权重，需自备 GGUF 文件。
