**基于 TileDB 存储引擎的向量相似度搜索 C++ 库与 Python API**

TileDB Vector Search 是构建在 TileDB 存储引擎之上的向量搜索 C++ 库与 Python API，提供向量存储与相似度检索能力，定位为云原生、可无服务器扩展的向量数据库。以 pip/conda 预构建包形式分发，另有 LangChain 集成已发布。面向需要在自有存储基础设施上构建检索系统的开发人员。
