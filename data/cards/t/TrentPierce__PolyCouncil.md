# TrentPierce/PolyCouncil

⭐ 45 · Python · NOASSERTION · 推送 2026-03-24 · [GitHub](https://github.com/TrentPierce/PolyCouncil) · 个人维护

**多模型商议桌面应用：并行运行多个 LLM 并产出加权共识结果**

基于 PySide6/QML 的桌面应用：让多个本地或托管 LLM 回答同一提示，互相评分，按共享规则产出加权获胜结果；支持讨论模式、persona 分配、流式输出、会话回放与 JSON 导出、排行榜历史。接入 LM Studio、Ollama 及 OpenAI/OpenRouter/Gemini/Anthropic/Groq/Together/Kimi/MiniMax 等托管 API。提供 Windows exe 与源码运行两种方式，采用 Polyform Noncommercial 1.0.0 许可。
