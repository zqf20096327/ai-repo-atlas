# thoughtspot/visual-embed-sdk

⭐ 13 · TypeScript · NOASSERTION · 推送 2026-10-30 · [GitHub](https://github.com/thoughtspot/visual-embed-sdk) · [官网](https://developers.thoughtspot.com) · 组织维护

**将 ThoughtSpot 分析与 AI 搜索嵌入 Web 应用的前端 SDK**

ThoughtSpot 官方的 Visual Embed SDK，TypeScript 编写，以 ESM/UMD 模块发布到 npm，用于在自有 Web 应用中嵌入 ThoughtSpot 的搜索式分析、Liveboard、可视化图表或整个应用。支持事件触发与监听（EmbedEvent/HostEvent），并提供等价的 React 组件（props 传参、on<EventName> 绑定事件）。使用需持有 ThoughtSpot 账户，README 提供免费试用入口、CodeSandbox 演示与本地 vite 开发服务器说明。
