# TDYSKY/TDYCODER

**面向开发者的本地 LLM 代码编辑器，已弃用**

Windows 桌面代码编辑器，内置 Monaco 编辑器引擎，支持 50+ 语言语法高亮、文件管理与多标签。通过集成 Ollama 接入本地 LLM，提供代码生成、代码解释、错误检测与从描述自动生成完整项目的功能，强调本地运行与隐私。AI 功能为可选路径，需另行安装 Ollama 并拉取模型（约需 2-8GB 模型存储）。安装方式为下载安装包，仅支持 Windows 10/11。项目已停止开发，由 Lumo Studio 接替，Early Access 版本仍可下载但标记为 deprecated。

## 能力要点

- Monaco 编辑器引擎，50+ 语言语法高亮与智能补全
