# TuringOpsSH/NextConsole

⭐ 18 · Vue · Apache-2.0 · 推送 2025-12-01 · [GitHub](https://github.com/TuringOpsSH/NextConsole) · [官网](https://www.nextconsole.cn) · 组织维护 · 中文 README

**面向企业的 LLM 应用构建平台：智能体、知识库与工作流**

Apache 2.0 许可的企业级 LLM 应用构建平台，供企业搭建智能体、知识库与工作流类应用。功能模块包括：AI 资源库（文件管理、预览、共享及为 RAG 提供语义索引数据）、AI 工作台（关键词与语义搜索、可指令调用的 AI agent 应用）、AI 应用工厂（图形化拖拽构建大模型 agent，含版本管理与性能监控）。部署方式为 Docker Compose，要求 Linux、至少 2 核 CPU 与 4GB 内存、Chrome 110+；也支持从源码构建后端与前端镜像，构建需 Docker 21+、Node.js 16+、Python 3.11+。

## 能力要点

- 图形化拖拽构建大模型 agent（AI 应用工厂）
- AI 资源库为 RAG 提供文件语义分析与索引
- AI 工作台集成关键词/语义搜索与 agent 应用
- Docker Compose 部署，默认账号 admin@nextconsole.cn

## 适用场景

- 企业搭建基于知识库的智能客服或问答系统
- IT 运维场景用智能体监控系统并诊断问题
- 法务等团队按预定义规则做文档智能审查
- 业务人员无代码拖拽构建 agent 工作流
