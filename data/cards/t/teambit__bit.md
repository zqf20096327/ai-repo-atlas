**给开发者的组件化构建系统，供人与 AI agent 复用组件**

Bit 是一个把源代码组织为可组合组件的构建系统，覆盖从开发到 CI 的流程：创建可复用的 UI 组件与模块、组装应用壳、语义化版本管理、通过 Ripple CI 或本地构建发布，并可用标准包管理器安装已构建组件。支持 monorepo、polyrepo 或无仓库结构，内置 NodeJS、React、Angular、Vue、NextJS 等官方开发环境，原生支持 TypeScript 与 ESM。通过 MCP 使 AI agent 能创建和复用组件。提供 Bit Cloud 托管 scope，也可自行托管。
