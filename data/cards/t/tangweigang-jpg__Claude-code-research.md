**Claude Code 架构的 14 章深度分析报告，提供 7 种语言版本**

基于 Claude Code TypeScript 源码快照（约 51.2 万行、约 1900 个文件）的架构分析报告：由 14 个并行 AI 子代理（5 个 Opus + 9 个 Sonnet）分别分析一个子系统，产出含代码引用的章节。内容覆盖查询引擎、工具系统、Agent 编排、Prompt 工程、上下文管理、安全权限、MCP 集成等 14 章，每章含理论依据、架构图、决策树与源码索引（file:line 引用）。报告提供中、英、韩、日、西、葡、俄 7 种语言版本。项目声明不含原始源码文件，仅作教育与技术研究用途，Claude Code 源码知识产权归 Anthropic 所有。
