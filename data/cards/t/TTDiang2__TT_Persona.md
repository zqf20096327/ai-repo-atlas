# TTDiang2/TT_Persona

⭐ 5 · TypeScript · MIT · 推送 2026-11-05 · [GitHub](https://github.com/TTDiang2/TT_Persona) · 个人维护 · 中文 README

**给本地 Qwen 等大模型做人格注入的本地调音台**

跑在本地的「人格调音台」，基于激活转向：用户写几对语气不同的提示词，算激活均值差生成人格向量（13 KB 的 .pt 文件），选定注入层与 α 后在对话中实时生效；偏置每次前向现算，进程关闭即复原。另提供神经元级扫描（相关性 + 因果/KL）作为备选路径，支持人格组合叠加与 JSON 导入导出。界面为 FastAPI 后端 + 浏览器前端，另有 Tauri 桌面外壳；依赖 NVIDIA 显卡 8 GB 显存，默认绑定 Qwen3.5-4B，换模型后向量需重建。

## 能力要点

- 提示词对→激活均值差→人格向量，13 KB 存储、运行时注入、关进程即复原
- 逐层试层定位注入点，支持区间写法与 32 层全扫
- 神经元级相关性扫描 + 因果扫描（KL）攒配方
- 多人格组合叠加与权重归一，支持 JSON 导出复现

## 适用场景

- 给本地跑的 Qwen 模型定制说话语气并随时开关
- 做激活转向 / 机制可解释性实验的教学演示台
- 对比不同注入层与剂量（α）下模型输出的差异
- 攒一批人格向量在多台机器间导入导出复现
