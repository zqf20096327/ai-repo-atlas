# TheD0ubleC/StickerSelector

⭐ 32 · Python · GPL-3.0 · 推送 2026-01-03 · [GitHub](https://github.com/TheD0ubleC/StickerSelector) · 个人维护 · 中文 README

**AI 聊天场景的表情包语义选择服务**

基于 FastAPI 的本地表情包选择服务：将 AI 生成的“表情包意图描述”与本地表情包库做语义向量匹配，选出符合当前语境的表情包，替代关键词/规则方案。提供 Web 管理后台，支持系列管理、批量上传、打 Tag、启用/禁用与导入导出，首次启动时从 Web 页面选择并下载 Hugging Face 模型。可在 1 核/1GB 内存的小型服务器运行，通过 HTTP 服务接入 QQ/微信等聊天应用或 QQSafeChat。需 Python 3.10+，从源码克隆部署。
