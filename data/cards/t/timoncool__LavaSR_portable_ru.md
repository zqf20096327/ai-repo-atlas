# timoncool/LavaSR_portable_ru

⭐ 17 · Python · Apache-2.0 · 推送 2026-10-28 · [GitHub](https://github.com/timoncool/LavaSR_portable_ru) · [官网](https://github.com/timoncool/LavaSR_portable_ru/releases) · 个人维护

**Windows 便携语音增强工具：LavaSR 超分辨率+降噪，一键安装离线运行**

LavaSR 语音增强模型的 Windows 便携封装：将 8-48kHz 音频超分辨率到 48kHz，并支持降噪；提供文件批量处理与麦克风实时录音增强，输出保存到 output/ 目录。通过 install.bat 一键安装便携 Python 与模型（首次需联网下载），运行 run.bat 后在浏览器打开 Gradio 界面，全部缓存本地化，可放 USB 携带。支持 NVIDIA GTX 10xx+ GPU（约 500MB 显存）或 CPU，模型约 50MB。俄语界面版本。
