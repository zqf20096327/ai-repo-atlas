**在 Nuxt DevTools 中接入 Claude Code 的聊天开发模块**

面向 Nuxt 3/4 开发者的 Nuxt 模块：将 Claude Code CLI 集成到 DevTools 面板，提供聊天界面、流式输出、语音输入、文件附件与会话管理；支持通过 Skills、Subagents、Slash Commands 与 MCP 服务器扩展能力，可从页面选取 Vue 组件或发送视口/路由上下文，并支持协作分享会话与 cloudflared 隧道远程访问。需预装并认证 Claude Code CLI，仅在开发模式运行。

## 能力要点

- DevTools 内与 Claude Code 聊天，流式输出与语音输入
- Skills/Subagents/Slash Commands/MCP 服务器管理与扩展
- Component Picker 将页面 Vue 组件文件路径作为上下文
- 协作模式分享会话与 cloudflared 隧道远程访问

## 适用场景

- 开发 Nuxt 应用时直接在 DevTools 中与 Claude 对话求助

- 团队通过分享链接共用同一 Claude 会话协作调试
