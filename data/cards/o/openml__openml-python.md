**OpenML 平台的 Python API：下载/上传数据集与实验结果**

OpenML-Python 是机器学习开放科学协作平台 OpenML 的官方 Python 接口：支持下载和上传数据集、任务、基准测试套件（benchmarking suites）与机器学习实验结果；通过 get_dataset/get_task/get_suite 等 API 以名称或 ID 获取资源，可按 curated 任务列表组织基准实验。兼容 Python 3.10-3.14，覆盖 Linux/macOS/Windows，pip 安装。附 JMLR 2021 论文供引用，面向科研与基准评测场景。
