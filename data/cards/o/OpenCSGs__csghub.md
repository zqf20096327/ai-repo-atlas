# OpenCSGs/csghub

⭐ 4,085 · Vue · Apache-2.0 · 推送 2026-11-13 · [GitHub](https://github.com/OpenCSGs/csghub) · [官网](https://opencsg.com) · 组织维护 · 中文 README

**面向企业的开源 LLM 资产管理平台，提供上传/下载/部署全流程**

CSGHub 是 OpenCSG 团队开发的用于管理 LLM 资产的开源平台，支持通过网页界面、git 命令行、自然语言 Chatbot 或 CSGHub SDK 对模型、数据集、Space、代码等资产进行上传、下载、存储、验证与分发。提供微服务子模块与标准化 OpenAPI 以便与现有系统集成，可 On-Premise 部署实现离线安全运行；同时提供开源版与 SaaS 版两种交付形态。文档提供 Docker Compose 与 Helm Chart 安装方式，支持阿里云市场一键部署。

## 能力要点

- 支持网页、git 命令行、Chatbot 与 SDK 多种方式管理 LLM 资产
- 提供微服务子模块与标准化 OpenAPI 集成
- 支持 On-Premise 离线部署与多源数据同步
- 含数据处理与智能标注系统、Space 管理助手

## 适用场景

- 企业内网私有化部署自托管的模型/数据集资产管理平台
- 统一管理 LLM、数据集与 Agent 的全生命周期
- 通过 SDK 从私有平台拉取模型用于训练与推理部署
