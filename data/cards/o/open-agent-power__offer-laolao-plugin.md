**帮求职者在招聘网站自动填写简历的 Chrome 扩展**

面向求职者的浏览器扩展：解析 PDF/DOCX/DOC/TXT/JSON 简历（云端 API 解析），管理多份简历模板数据，在招聘网站表单上通过一键预填或字段级点选填充简历信息，自动触发表单事件以通过校验。集成国内多家大模型（DeepSeek、Kimi、通义千问、豆包、智谱、百川及任意 OpenAI 兼容 API）做简历内容优化与自我介绍生成；AI 优化功能需 Star GitHub 仓库解锁。支持 JSON/LaTeX 导出，可通过开发者模式加载构建产物或从 Edge 商店安装。注意：一键预填在 README 中标注为 Coming Soon。

## 能力要点

- 解析 PDF/DOCX/DOC/TXT/JSON 多格式简历并自动映射字段
- 一键预填与字段级点选填充，自动触发 input/change/blur 事件
- 支持 DeepSeek/Kimi/通义千问/豆包/智谱/百川及 OpenAI 兼容 API 做简历优化
- 导出 JSON 备份与可在 Overleaf 编译的 LaTeX 简历

## 适用场景

- 在智联、51job、Boss直聘等招聘网站快速填写简历表单
- 用 AI 改写自我介绍、工作与项目描述（STAR 方法）
- 维护多份简历模板并导出 LaTeX 版本投递
