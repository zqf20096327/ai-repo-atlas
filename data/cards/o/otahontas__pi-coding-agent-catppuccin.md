**Pi 编码代理的 Catppuccin 四款配色主题包**

为 Pi coding agent 提供的 Catppuccin 主题包，包含 Latte（浅色）、Frappé、Macchiato、Mocha（深色）四种配色。提供三种安装方式：通过 Pi 包管理器 pi install 安装后在 /settings 中选择主题；通过 Nix flake 以 Home Manager 模块启用并自动跟随 catppuccin/nix 的 flavor 设置；或手动 clone 仓库并复制 JSON 主题文件到 ~/.pi/agent/themes/ 目录。配色遵循官方 Catppuccin 色板，工具成功/错误背景采用 catppuccin/delta 的混合惯例。
