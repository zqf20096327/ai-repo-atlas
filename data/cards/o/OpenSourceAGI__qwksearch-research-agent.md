# OpenSourceAGI/qwksearch-research-agent

⭐ 77 · TypeScript · NOASSERTION · 推送 2026-10-24 · [GitHub](https://github.com/OpenSourceAGI/qwksearch-research-agent) · [官网](https://qwksearch.com) · 组织维护

**AI 研究搜索代理：多源检索、正文提取与大纲摘要写作**

QwkSearch 是一个以“自组织思维导图”为定位的 AI 研究搜索平台：STREAM 支持跨 100+ 站点、10 个类别的搜索，对文章/PDF/YouTube/URL 做正文提取、APA 引用格式化与摘要；REASON 提供基于 Lexical 的嵌套文档研究编辑器，含 AI 改写、全文检索、团队协作与 SQLite 存储。模型可选 Claude、GPT、Gemini、Grok、Llama 及中文 LLM 等。另含 Tauri 桌面应用、浏览器标签管理扩展、VS Code 扩展，以及十余个 npm 包（PDF/网页/引用/字幕提取、MCP server 等）。
