**面向学者的 Jekyll 个人网站主题（al-folio 实例）**

基于 al-folio Jekyll 主题的学术个人主页仓库：支持 CV 页面（json/yml 双数据源）、从 BibTeX 自动生成发表论文页、news 与 projects collections、Distill 风格博客、MathJax 公式与代码高亮、明暗模式、相关文章与 Atom feed。安装部署细节指向 INSTALL.md，Docker 镜像以徽章形式展示。仓库另含两个需 GitHub Copilot 订阅的辅助 agent（网站定制与文档维护），为主题的可选开发辅助功能。MIT 许可。
