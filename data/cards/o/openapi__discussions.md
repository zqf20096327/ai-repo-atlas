**面向 API 开发者的社区讨论空间：提问、展示作品、交流想法**

Openapi 组织的社区讨论仓库，定位为其 SDK、工具与集成代码库之外的人际交流空间。设有 Ideas、General、Show and tell、Open Source AI、Q&A、Polls 等九个讨论分类，覆盖 API 设计、工具与工作流讨论以及 LLM 与真实 API 结合相关话题（Agents、MCP servers、evals）。提供 Openapi Pulse 定期栏目，轮换展示社区成员与值得关注的讨论；维护者为 Francesco Bianco，所有者为 Openapi S.p.A.。本仓库本身不含可安装的软件。
