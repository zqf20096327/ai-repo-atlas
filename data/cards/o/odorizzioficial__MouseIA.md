# odorizzioficial/MouseIA

⭐ 3 · C# · MIT · 推送 2026-11-24 · [GitHub](https://github.com/odorizzioficial/MouseIA) · [官网](https://www.youtube.com/@odorizzioficial) · 个人维护

**Windows 屏幕划选即问 AI 的工具：翻译、OCR、读码、Lens 检索**

面向 Windows 的屏幕交互工具：晃动鼠标或快捷键后，用鼠标圈选屏幕任意元素弹出提问卡片，可调用云模型或本地模型回答、就地翻译 110+ 语言、用 Windows OCR 离线复制图片/视频/文件中的文字、读取二维码并跳转 Google Lens 检索。支持 Gemini/ChatGPT/Claude/Grok 的 API key，也支持 .gguf/.litertlm 本地模型文件及 Ollama/LM Studio 等本地服务器；API key 以 DPAPI 加密存储，无自有服务器与数据收集。提供安装包与便携版，自动更新。

## 能力要点

- 鼠标圈选屏幕任意内容直接向 AI 提问，支持多区域合并提问
- 就地翻译 110+ 语言并支持语音朗读与语音输入
- Windows OCR 离线复制图片文字、读取二维码（无需 AI 与网络）
- 本地模型支持：.gguf/.litertlm 文件或 Ollama/LM Studio/llama.cpp 服务器，自动下载 llama.cpp/LiteRT-LM 引擎

## 适用场景

- 阅读外文网页时圈选段落就地翻译
- 从截图、视频或 PDF 中复制无法选中的文字
- 遇到二维码或想视觉检索的图片时直接圈选处理
- 在内网或离线环境用本地模型完成屏幕问答
