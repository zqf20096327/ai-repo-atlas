**TiddlyWiki5 的 CodeMirror6 编辑器插件，带多种补全**

为 TiddlyWiki5 提供 CodeMirror6 编辑器的插件：支持 emoji、tiddler 链接、widget、图片、代码片段补全，以及 Wiki 语法高亮模式、颜色修改与链接预览等功能。以源码方式开发与构建，通过 git clone 拉取后用 pnpm 安装依赖、本地调试与构建插件。README 于 2024-01-24 声明进入维护状态，此后以修复 bug 与兼容性改进为主，不再做重大改动，另提供 basic 分支的最小版本。
