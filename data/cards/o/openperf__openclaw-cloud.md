**为 OpenClaw AI Agent 提供云端部署与统一管理的面板**

面向 OpenClaw Agent 生态的管理面板与调度中枢：通过 Docker 一键拉起独立的 Agent 实例，每实例拥有独立运行时与数据存储；支持 Element、Telegram、Discord 等多渠道对话接入；可从 ClawHub 市场（700+ 技能）一键安装技能并热插拔生效；提供实例状态监控、技能插件管理、对话历史查看的 Web 界面。技术栈为 React 19 + Node.js/Express/tRPC + MySQL/TiDB，以源码方式本地部署，需 Node.js 22+、pnpm、Docker 与 MySQL 8+。
