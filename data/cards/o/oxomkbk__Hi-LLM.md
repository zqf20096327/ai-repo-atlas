# oxomkbk/Hi-LLM

⭐ 14 · TypeScript · MIT · 推送 2026-09-19 · [GitHub](https://github.com/oxomkbk/Hi-LLM) · [官网](https://www.hillm.ai/) · 个人维护 · 中文 README

**开源自托管 AI 资源导航与内容社区站点**

基于 Next.js 16 / React 19 / PostgreSQL 17 的 Web 应用：访客可按分类浏览 AI 工具、Skills、MCP Server 与 Prompts，支持关键词搜索、热门排行、收藏与投稿；内置内容社区（问答/新闻/作品）、投稿审核流程、管理后台（分类/用户/媒体/站点配置/安全中心）以及邮箱验证、OAuth 登录与角色访问控制。面向想自建 AI 资源导航站的内容运营者，本地运行需 Node.js 20.19+、pnpm 与 Docker（本地 PostgreSQL）。

- AI 工具/Skills/MCP Server/Prompts 四类内容的目录、详情页与投稿流程
