**给流式数据的在线深度学习库：神经网络增量训练与预测**

Python 库，将 river 的在线机器学习 API 与 PyTorch 的神经网络构建能力结合，支持在数据流上增量训练和预测。提供分类、多目标回归与异常检测三类接口，示例基于网站钓鱼数据集等演示增量学习流程。通过 pip 安装，可单独安装或作为 river 的 deep 扩展引入；开发环境推荐 uv 管理依赖。发表于 JOSS 期刊（DOI 10.21105/joss.07226），由 FZI 等机构参与。
