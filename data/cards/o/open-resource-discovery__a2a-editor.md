**A2A 协议 agent 的编辑/查看/测试 UI 组件**

提供基于 Agent2Agent（A2A）协议的 agent 编辑、查看与测试 UI 组件。以 npm 包 @open-resource-discovery/a2a-editor 形式发布，可在应用中导入 AgentPlayground 组件并引入样式使用；同时提供在线 playground 演示与 Docker 镜像（ghcr.io）运行方式，也可从源码构建 Docker 镜像，编辑器默认在 localhost:8080 访问。面向集成 A2A agent 的开发者。
