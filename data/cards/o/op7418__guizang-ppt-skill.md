**给 Claude Code/Codex 等 Agent 的网页 PPT 生成技能**

适配 Claude Code / Codex 等 Agent 环境的 Skill，用户以自然语言触发后由 Agent 生成单文件 HTML 横向翻页 PPT、PPT 配图与多平台封面。内置电子杂志风与瑞士国际主义两套视觉系统（分别提供 10 种与 22 种锁定版式）、主题色预设与品牌色收束脚本、演讲者模式（双窗口观众屏、备注、计时排练、故障恢复）以及低性能静态模式。交付为无需构建与服务器的单文件 HTML；瑞士风与演讲模式提供 Node 校验脚本，可用 Playwright 做渲染后量化检查。不导出 PPTX，不适合多人协作编辑场景。
