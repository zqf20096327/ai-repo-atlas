# oluiscabral/studorama

⭐ 110 · TypeScript · MIT · 推送 2026-09-03 · [GitHub](https://github.com/oluiscabral/studorama) · [官网](https://studorama.vercel.app) · 个人维护

**面向学习者的多 AI 提供商学习平台：生成题目并按间隔重复法复习**

部署在 Vercel 的 Web 学习平台：用户输入任意学科，由 6 个 AI 提供商（OpenAI、Gemini、Claude、DeepSeek、Ollama 本地、Browser AI）之一生成选择题/开放题并作评估，题目难度根据表现自适应调整。实现间隔重复、交错练习、检索练习等基于认知科学的学习技术，提供会话跟踪与学习分析。数据存储在浏览器本地，无需注册账户，支持英文与巴西葡萄牙语界面。开发部署通过 git clone 源码进行。
