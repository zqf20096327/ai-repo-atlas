**开放科学平台：共享机器学习数据集、算法与实验**

OpenML 是一个在线机器学习平台，用于共享和组织数据集、机器学习算法与实验，面向科研人员、学生、公民科学家与从业者。它提供多语言 API（Python/R/Java）及 WEKA 插件，可集成到现有工作流中复用他人实验与结果，支持任务对比与在线协作。本仓库为其 Web 应用与 REST API；仓库声明处于仅维护模式，正在以 FastAPI 版 API 替换原有 PHP 版 REST API。
