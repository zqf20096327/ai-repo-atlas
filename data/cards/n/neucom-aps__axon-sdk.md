**构建与仿真脉冲神经网络的 Python 工具包**

基于 STICK 框架（Spike Time Interval Computation Kernel）的 Python 工具包，用于构建和仿真脉冲神经网络（SNN）。提供模块化、事件驱动的框架，面向控制、计算与嵌入式神经形态应用的时间编码脉冲算法开发。功能包括 SNN 计算内核库、脉冲间隔编码的仿真、网络组合与模块扩展 API、脉冲时序图与拓扑的交互式可视化。通过源码 pip install -e . 安装，含预定义计算网络库与文档教程站点。
