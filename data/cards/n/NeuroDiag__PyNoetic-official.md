**面向科研人员的 EEG 脑机接口无代码开发 Python 框架**

端到端的 Python 框架，用于脑机接口（BCI）系统的开发，覆盖刺激呈现、数据采集、通道选择、滤波、特征提取、伪迹去除、脑连接性度量、机器学习分类模型、可视化与仿真测试等各阶段，支持离线与实时部署。面向认知神经科学研究者与 Python 新手，通过 GUI 无代码操作，同时允许脚本添加自定义分类器等功能。通过 git clone 源码安装，Windows/macOS/Linux 均有测试记录；高级仿真功能需 Microsoft Visual C++ 14.0 或更高版本。随附 Emotiv Epoc X 采集的 14 通道示例数据。
