# NikolasEnt/ollama-webui-intel

⭐ 52 · Python · 推送 2026-10-19 · [GitHub](https://github.com/NikolasEnt/ollama-webui-intel) · 个人维护

**在 Intel (i)GPU 上以 Docker 运行 Ollama 并附基准测试**

提供 docker-compose 配置，将打了补丁的 Ollama 与 ipex-llm 加速后端封装在 Docker 中，兼容 Intel 核显与 Arc/Flex/Max 独显，并附带 Open WebUI 界面。包含一个独立基准脚本 scripts/benchmark.py，可对任意 OpenAI 兼容 API 测 tokens/s（含 LLM 与 VLM），在 Intel Ultra 5 125H + 64GB RAM 及 RTX 3090 上给出多模型对比数据。需 Intel firmware、Docker 与 docker compose，支持内存限制、DEVICE、GPU offload 等参数调整。

## 能力要点

- docker-compose 封装 Intel 加速补丁版 Ollama 与 Open WebUI
- ipex-llm 后端兼容核显与 Arc/Flex/Max 独显
- benchmark.py 可测试任意 OpenAI 兼容 API 的 tokens/s（LLM/VLM）
