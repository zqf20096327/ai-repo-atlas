# nemori-ai/nemori-desktop

⭐ 13 · Python · Apache-2.0 · 推送 2026-03-05 · [GitHub](https://github.com/nemori-ai/nemori-desktop) · 组织维护 · 中文 README

**本地优先的桌面个人记忆助手：记录屏幕活动并可对话回忆**

Electron 桌面应用，持续观察屏幕活动并自动生成结构化记忆：按职业、财务、健康等 8 个生活维度归类，形成情景记忆、语义知识与个人档案；提供桌面宠物、AI 对话（Chat 与 Agent 两种模式）、自动日记、记忆浏览搜索与 AI 生成的行为洞察。数据全部本地存储，无云端同步；需配置用户自己的 LLM API（OpenAI 兼容接口，推荐 OpenRouter）。目前发布 macOS（Apple Silicon/Intel）安装包，开发构建需 Node.js 18+ 与 Python 3.12+。参考了 MIRIX 与 MineContext 的技术。

## 能力要点

- 屏幕活动自动记录并按 8 个生活维度归类为情景记忆/语义知识/个人档案
- Chat 与 Agent 两种对话模式，基于记忆回答与深度分析
- 数据本地存储，无云端同步与追踪
- 提供桌面宠物、自动日记、记忆搜索与 AI 行为洞察

## 适用场景

- 自动记录我每天在电脑上做了什么，之后用对话询问回忆
- 回顾某段时间的工作内容与行为模式
- 在不上传数据到云端的前提下保留个人数字生活记忆
