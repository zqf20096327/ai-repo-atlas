**txtai 的 Go 客户端：通过 API 访问语义搜索与 LLM 工作流**

txtai 是提供语义搜索、LLM 编排与语言模型工作流的 AI 框架；本仓库为其 API 的 Go 语言绑定库，通过连接已运行的 txtai API 实例使 Go 程序调用其能力。安装方式为 go get 或在模块中 import；示例目录覆盖功能概览、抽取式问答、零样本分类、流水线与工作流四个示例，运行示例需先启动 txtai API 实例。
