**给开发/运维团队的 AI Agent 与工作流自动化平台**

n8n 是一个 fair-code 的工作流自动化平台，用户通过可视化画布结合 JavaScript/Python 代码构建多步骤 AI agent 与自动化流程，可自托管或使用云服务。平台提供 1500+ 集成与 9000+ 工作流模板，支持接入 OpenAI、Anthropic、Google 或开源模型并可切换，内置人工审批、可观测性、基于角色的访问控制与审计日志。通过 Docker 安装脚本或手动 docker run 部署，编辑器默认运行在 5678 端口。
