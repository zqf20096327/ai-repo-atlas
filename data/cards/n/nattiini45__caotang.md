**本地优先的小说与剧本写作工作室，带可审批的 AI agent**

面向小说、剧本与故事世界观的写作工作室：提供章节/场景 binder、卡片板、inspector、角色地点 codex、编译导出 Word/EPUB/Markdown，并含 Fountain 剧本、Ink 分支对话与分镜编辑器。AI 部分：自带 agent 可规划并起草修改，计划与草稿需作者批准，每轮改动留下可恢复的检查点；支持自带 API key 接入多家模型服务商，含目标式并行检查、独立评审、本地词法搜索与运行日志导出。纯浏览器运行，无账号与服务器，MIT 许可。

## 能力要点

- agent 提议计划、作者审批，每轮改动有可恢复检查点
- 自带 API key 的 BYOK 模式，模型服务商按 provider/model 自动处理并发与限流
- binder/corkboard/codex/compile 结构，支持 Fountain 剧本与 Ink 分支对话导入
- 目标式确定性检查与可选的独立背景评审，运行日志可导出 JSONL/Markdown

## 适用场景

- 在本地管理长篇小说的章节、场景与设定集
- 让 AI agent 按目标检查并修订稿件，人工逐轮批准
- 编写 Fountain 剧本或 Ink 分支对话并编译导出
- 在浏览器中离线写作，项目以文件夹或 .caotang 包保存
