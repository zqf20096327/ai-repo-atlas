**供 AI 助手通过 MCP 生成 Mermaid 图表的 MCP 服务器**

基于 Model Context Protocol 的 TypeScript 服务器，使 GitHub Copilot、Claude Desktop、Cursor 等 AI 助手能用自然语言生成 22+ 种 Mermaid 图表（流程图、时序图、ER 图、甘特图等），并通过 Puppeteer 浏览器渲染输出 XML 合规的 SVG 文件。提供 50+ 预置模板，支持 VS Code、CLI、MCP Inspector 等 6 种接入方式。需 Node.js 18+，经 npm 全局安装或源码构建。
