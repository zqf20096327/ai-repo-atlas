**面向科研的量子多体系统神经网络机器学习库**

NetKet 是一个 Python 库，基于 JAX 构建，提供用人工神经网络与机器学习方法研究多体量子系统的算法实现，属于神经量子态（NQS）方法的开源实现。面向量子物理研究人员，运行于 macOS 与 Linux，要求 Python 3.13 及以上，推荐用 pip 或 uv 安装，README 明确提示不要用 conda 安装以免 JAX 出问题；提供 GPU 支持（仅 Linux）的额外安装选项、文档、教程与示例脚本，项目为 NumFOCUS 附属项目，采用 Apache 2.0 许可。
