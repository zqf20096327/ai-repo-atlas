**把 Neocortex 平台上的 AI 角色接入 Unity 游戏的 SDK**

Neocortex Unity SDK：将用户在 Neocortex 网页平台上构建的角色导入 Unity 游戏，使其能对话、听取语音输入、执行动作并相互交谈。功能包括桌面/移动/WebGL 通用的麦克风组件、按行携带情绪的回复、动作关键词触发、场景物体感知标签、多角色共享对话（含 AI 导演决定发言顺序）、一键生成的聊天 UI，以及用量与额度查询。需要 Neocortex 账号、Unity 6 及以上版本与 Git，通过 Unity Package Manager 以 git URL 方式安装，并粘贴 API key。附带六个示例场景。

## 能力要点

- 文本/语音输入输出的角色对话组件，支持桌面、移动与 WebGL
- 回复按行携带情绪信息，可逐行配音与动画
- 角色可感知场景中标签物体并触发作者定义的动作关键词
- 多角色共享对话由 AI 导演决定发言顺序

## 适用场景

- 在 Unity 游戏中接入会说话的智能 NPC 或虚拟助手
- 搭建多角色群体对话场景
- 控制每个玩家的 AI 用量与功能开关
