# needsbuilder/easyclaw

⭐ 132 · TypeScript · MIT · 推送 2026-10-18 · [GitHub](https://github.com/needsbuilder/easyclaw) · [官网](https://easyclaw.kr) · 个人维护

**非官方桌面安装器：免终端命令安装 OpenClaw AI agent**

面向 macOS（Intel/Apple Silicon）与 Windows 的桌面安装器，以图形界面完成 OpenClaw AI agent 的安装流程：自动检测并安装 WSL（Windows）、Node.js 与 OpenClaw，用户下载运行后填入 API key 即可。支持 Anthropic、Google Gemini、OpenAI、MiniMax、GLM 等多种模型提供方，并提供 Telegram bot 集成。明确声明为非官方第三方工具，与 OpenClaw 项目无隶属关系；基于 Electron + React 19 + TypeScript 构建，MIT 许可，由个人维护，另提供付费远程安装协助服务。
