**VS Code 扩展：浏览、搜索、导出 Antigravity AI 对话记录**

面向 Antigravity IDE（Google 的 AI 编程 IDE）用户的 VS Code 扩展：以仪表盘形式按日期或工作区分组展示全部 AI 对话，支持标题快速搜索、步骤数与状态统计；可单条或批量导出为 Markdown/JSON，导出路径与详细程度可配置。自动发现并恢复未被索引的对话（含被 100 条上限自动清理的部分），本地 JSON 缓存加速启动。数据 100% 本地、只读、无遥测。提供 VSIX 手动安装与 OpenVSX 安装两种方式，在 Windows 上测试验证。
