**NativeScript 流式 Markdown 渲染组件，面向 AI 输出展示**

nstudio 出品的 NativeScript 原生 Markdown 组件库，为移动应用提供流式渲染能力：内容随到达逐步显示，适配 AI 应用中 LLM 生成输出的实时展示。支持 Angular、React、Vue、Svelte、Solid 五种前端框架的独立导入路径，通过 npm 安装。项目受 Vercel 的 Streamdown.ai 启发，要求 NativeScript 8.x+ 与 Node 22.x+。提供组件级文档与开发脚手架。
