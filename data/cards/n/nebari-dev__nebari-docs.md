**团队数据科学与 MLOps 平台的文档仓库：Nebari 使用与部署说明**

本仓库为 Nebari 的文档仓库。Nebari 是基于开源技术组合的可定制数据科学与 MLOps 平台，以基础设施即代码方式部署共享数据科学环境，可在本地或所选云上运行；它是预配置的 JupyterHub 发行版，通过 Terraform、Helm 与 GitHub Actions/GitLab CI/CD 在 Kubernetes 集群上部署，面向不掌握 Kubernetes/Terraform/Helm 的团队用户。支持 macOS 与 Linux（Windows 不支持），兼容 Python 3.7+，约 30 分钟完成安装部署。
