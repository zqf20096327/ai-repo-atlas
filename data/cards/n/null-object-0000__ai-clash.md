**浏览器扩展：一次提问让多个网页 AI 同屏作答并总结**

Chrome/Edge 浏览器扩展，用户一次提问后由多个已登录的网页版 AI（DeepSeek、豆包、通义千问、腾讯元宝、文心一言、Xiaomi MIMO）并行回答，同屏对比；内置「AI 裁判」自动归纳共识、分歧与最优答案。核心机制为本地 DOM Hook 驱动网页版通道，无需 API Key，也支持配置各模型 API Key 的模式；支持中英文界面，英文界面当前可用 DeepSeek 与 Qwen 国际版。通过商店安装或下载 Releases 手动加载。

## 能力要点

- 一次提问多通道并行回答，同屏实时输出对比
- 内置 AI 裁判自动归纳共识、分歧与最终建议
- 纯本地 DOM Hook 接入网页版 AI，无需 API Key
- 通道独立开关、失败通道单独重试、深度思考/联网搜索开关
