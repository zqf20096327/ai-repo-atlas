# nacivageer/dsh-see-now-more

⭐ 4 · JavaScript · Apache-2.0 · 推送 2026-11-26 · [GitHub](https://github.com/nacivageer/dsh-see-now-more) · 个人维护 · 中文 README

**让 DSH 像视频通话一样边看你的屏幕边聊天的插件**

面向 DSH 桌面版用户的插件，提供悬浮聊天窗、屏幕共享与系统声音监听：每帧按 HSV 变化分决定取舍，多帧拼进一张图以摊薄 token 成本（low 档每张约 222 token）；支持思考中途插话（steer/say）、台词转写（WASAPI 回环 + SenseVoice 或 OpenAI 兼容服务）、以及 edge-tts/SAPI/DeepSeek TTS 三档语音适配器。核心机制「黑听抬头」默认只听声音、命中台词才取图。仅源码安装，只在 Windows 10 + DSH 0.2.2-rc.5 验证，麦克风输入未测试。

## 能力要点

- 变化分采样：静止屏幕几乎不出图，多帧拼一张摊薄 token
- 黑听抬头：0.5fps 低频采集 + 台词语义触发取图，四档节奏（警觉/瞥/看/追）
- 悬浮窗支持思考中途插话、消息镜像、引用选中文字与热切换语音适配器
- 系统声音转写进上下文，台词与画面帧共用同一时间坐标系

## 适用场景

- 让 AI 陪你看视频/直播，边看边用 IM 式悬浮窗聊
- 看长文档或网页时按画面变化省 token 地截屏讨论
- 游戏或教程场景让 AI 结合画面和台词一起回应
