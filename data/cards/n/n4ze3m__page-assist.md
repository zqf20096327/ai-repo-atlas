**连接本地 AI 模型的浏览器扩展：侧边栏与网页 UI 对话**

开源浏览器扩展，为本地运行的 AI 模型提供侧边栏和 Web UI，可在任意网页上与模型交互，并支持与当前网页内容对话。支持 Chromium 系浏览器与 Firefox，官方渠道提供 Chrome/Firefox/Edge 商店安装包，也可用 Bun 从源码构建加载。本地 AI 提供方包括 Ollama、Chrome AI（Gemini Nano）及任何 OpenAI API 兼容端点。声明不收集个人数据，数据存储在浏览器本地，仅分享功能会与服务器通信且可关闭。

## 能力要点

- 任意网页可打开侧边栏与本地模型对话，支持 Chat With Webpage
- 支持 Ollama、Chrome AI（Gemini Nano）与 OpenAI API 兼容端点
- Chrome/Firefox/Edge 商店安装包，另可 Bun 源码构建
- 丰富的可自定义键盘快捷键（侧边栏、Web UI、聊天模式切换）

## 适用场景

- 在浏览网页时随时向本地模型提问
- 针对当前网页内容进行提问与总结
- 用 LM Studio 等 OpenAI 兼容端点作为聊天后端
