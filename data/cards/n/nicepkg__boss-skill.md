**生成 AI 老板替身的 Claude Code Skill：PUA 检测、反击话术、劳动法速查**

遵循 AgentSkills 开放标准的 Claude Code 技能包，零外部依赖，需 Python 3.9+。输入一句话描述即可生成专属 AI 老板 Skill，提供 16 个模式：PUA 检测（10 大厂流派鉴定）、三档反击话术、画饼 5 维度量化、结构化证据收集（可导出劳动仲裁时间线）、劳动法速查、谈薪与 1v1 面谈模拟、汇报优化、翻车互动文字游戏等。数据来源支持飞书/钉钉/Slack API 采集及微信聊天记录、邮件、截图等文件解析。安装方式为 git clone 到 skills 目录，也兼容 OpenClaw 等其他 AI CLI 工具。

## 能力要点

- 一句话描述即可生成专属 AI 老板 Skill，支持创建多个
- PUA 检测含 10 大厂流派鉴定与受害者画像
