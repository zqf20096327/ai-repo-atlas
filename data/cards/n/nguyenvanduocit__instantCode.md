# nguyenvanduocit/instantCode

⭐ 52 · TypeScript · 推送 2026-01-23 · [GitHub](https://github.com/nguyenvanduocit/instantCode) · 个人维护

**网页元素级 AI 前端助手：点击元素用自然语言改代码**

浏览器检查工具与 Vite 插件：在开发的应用中点击任意元素，输入简短指令（如改颜色、居中），由 Claude Code 定位并修改源码文件，改动实时反映到浏览器。支持 React/Vue/Angular/Svelte/Vanilla JS 等 Vite 系框架；也提供独立服务器与 CLI 模式，可配置监听地址供团队共享修改。使用前需全局安装 Claude Code（依赖 bun 安装），插件本身通过 bun add 安装。
