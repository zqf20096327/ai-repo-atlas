**txtai 的 Java 客户端：通过 API 接入语义搜索与 LLM 编排**

txtai.java 是 txtai 框架的 Java 绑定，通过连接 txtai API 实例，使 Java 程序调用 txtai 提供的语义搜索、LLM 编排与语言模型工作流能力。安装方式为 JitPack（Gradle 依赖）或从源码用 Gradle 构建 JAR。仓库附带示例目录，覆盖功能概览、抽取式问答、零样本分类标签、流水线与工作流四类示例，用 Gradle 命令运行。
