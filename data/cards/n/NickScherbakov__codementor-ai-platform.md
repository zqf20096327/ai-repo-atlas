**三层架构的 AI 编程学习平台：AI 导师、代码评审与学习分析**

由 Next.js 前端、Node.js/Express 后端与 Python/Flask AI 引擎组成的三层开源编程学习平台。提供带模型/提供商选择的 AI 控制台、严格代码评审模式、学习仪表盘与评估流程。模型路由支持本地模型、Gemini/Vertex AI 与 OpenRouter，无需付费 API 即可运行。通过 Docker Compose 一键启动，或以脚本手动运行；附 Docker 与 GCP Cloud Run 部署指南。
