# Nerif-AI/Nerif

⭐ 16 · Python · GPL-3.0 · 推送 2026-04-08 · [GitHub](https://github.com/Nerif-AI/Nerif) · [官网](https://nerif-ai.com) · 组织维护

**在 Python 中编排 LLM 的编程框架：自然语言与代码混用**

面向开发者的 Python 库，将 LLM 接入编程流程：控制 LLM 行为、把响应转为可用数据格式、以指标跟踪成本与成功率、构建带可观测执行轨迹的多 agent 工作流。支持多提供商路由（OpenAI、Anthropic、Gemini、Ollama 等）、流式/异步、Pydantic 结构化输出、重试与回退链、轻量 RAG、ASR/TTS，可选安装 rag/img-gen/viz/otel 特性组。需 Python>=3.10 与 LLM API key，GPL-3.0 许可。
