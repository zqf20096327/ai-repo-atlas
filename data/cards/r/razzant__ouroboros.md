# razzant/ouroboros

⭐ 1,707 · Python · MIT · 推送 2026-11-25 · [GitHub](https://github.com/razzant/ouroboros) · [官网](https://ouroboros-agent.ai/) · 组织维护

**跨任务保留身份与记忆的通用自主 AI agent**

开源通用 AI agent，跨任务与重启保持身份、持久记忆和历史。可在外部项目上工作、协调多个专家 agent 的集群，并能重写自身运行的代码、架构、提示词与依赖。以桌面应用或无头 CLI 运行，仓库、记忆与界面在本地，模型推理可走远程 API 或本地 GGUF 模型。默认不发送遥测，内置支出限额（总计 $200、单任务 $50、后台意识每 24 小时 $15），首启向导引导账户、模型与预算配置。
