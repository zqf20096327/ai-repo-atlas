**自托管低代码工作流平台：构建应用、自动化、数据与 AI 集成**

Flow-Like 是一个可自托管的开发平台，将界面、工作流与数据组合为应用：提供 1,900+ 内置类型化节点，覆盖 SQL、API、文档、媒体、UI、桌面自动化、AI 与机器学习；通过 Package 打包自定义节点与 UI 组件；同一工作流可用画布或 FlowScript 文本编辑。架构为 Rust 执行引擎 + Tauri 桌面客户端（Studio）+ TypeScript/React 界面，支持本地执行与 Docker Compose/Kubernetes 共享后端，源码以 BSL 1.1 提供。

## 能力要点

- 1,900+ 类型化内置节点与可复用 Package 机制
- Rust 执行引擎 + Tauri 桌面客户端 + TypeScript/React 界面
