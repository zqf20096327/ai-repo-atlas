**Bark TTS 语音提示词共享目录网站，含预览音频库**

面向 Bark TTS 用户的语音提示词（history prompts）目录网站，附有 Bark 生成内容的预览音频库。社区可通过指定的 Pull Request 流程（PR #2）添加新音色，或通过 PR #7 添加 Bark 生成的声音。网站本身为 Next.js 项目，运行 npm/yarn/pnpm dev 启动开发服务器。README 含 Suno 发布的 AI 模型使用免责声明，要求合法使用、禁止冒充与欺诈，Suno 对滥用不承担责任。
