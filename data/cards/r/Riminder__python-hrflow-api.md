**HrFlow.ai 人才数据 API 的官方 Python SDK**

面向使用 HrFlow.ai 服务的开发者的 Python 客户端封装库，用于调用其人才与劳动力数据 API 套件，包括 Parsing、Tagging、Embedding、Searching、Scoring、Imaging API 与 OEM Widgets。使用需通过 api_secret 与 api_user 凭据初始化客户端；官方文档与 Slack 社区提供支持。通过 pip 或 conda 安装，本体不实现 AI 模型，AI 能力由云端 API 提供。
