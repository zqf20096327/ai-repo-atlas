# rokrokss/shizue-extension

⭐ 22 · TypeScript · MIT · 推送 2026-11-10 · [GitHub](https://github.com/rokrokss/shizue-extension) · [官网](https://shizue.net) · 个人维护

**浏览器侧边栏 AI 助手扩展：聊天、摘要与双语翻译**

开源 MIT 许可的 Chrome 扩展，将 LLM 集成到日常浏览流程：侧边栏聊天（可附页面、标签、图片、PDF 及 Office/EPUB 文件）、网页双语对照翻译、YouTube/Twitch/Netflix 等视频双语字幕、一键页面摘要、右键菜单的图像 OCR 与翻译、浏览器控制代理，以及本地笔记。可通过 ChatGPT 账号登录、自带 API key 或本地模型（Ollama/LM Studio/llama.cpp）使用；数据仅存于浏览器，无自建服务器与追踪。从 Chrome Web Store 安装。

## 能力要点

- 网页双语对照阅读与多平台视频双语字幕
- 浏览器控制：分步点击/输入/滚动，敏感操作前确认
- Sign in with ChatGPT 或自带 API key 或本地模型（Ollama 等）
- 右键菜单支持图像 OCR、气泡翻译、链接预览

## 适用场景

- 阅读外文网页时获得双语对照翻译
- 看 YouTube/Twitch/Netflix 时显示双语字幕
- 不离开当前页面向 LLM 提问或总结页面
- 用自然语言让浏览器代理代为填写表单、操作页面
