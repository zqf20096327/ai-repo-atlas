**手工策展的开源 AI Native 项目清单站（600+ 项目）**

以 Astro 构建的双语（中/英）项目目录网站：以双语 Markdown + YAML frontmatter 收录 agents、MCP 服务器、RAG 框架、AI 运行时等开源项目，按类别组织，含项目详情页与分类页；评分（activity/community/quality/sustainability→health 五维）在运行时从外部 API 拉取并客户端缓存。提供 JSON/CSV 导出、JSON Schema 校验脚本，部署到 Cloudflare Pages；另提供面向 6 种 AI 编码工具的自然语言搜索技能包（npx 安装），以及仅限仓库内使用的批量维护技能。社区通过 GitHub Issues 提交项目。
