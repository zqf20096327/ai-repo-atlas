**给写作者的免配置 Markdown 阅读编辑器，带可选 AI 修改建议**

基于 Tauri、React、TypeScript 构建的桌面 Markdown 阅读与编辑器：打开 .md 即可阅读，支持阅读/代码/分栏三视图、实时预览（KaTeX 数学、mhchem 化学、Mermaid 图表）、斜杠命令、多光标、表格可视化编辑、文件历史与崩溃恢复。AI 部分为可选功能：侧栏聊天（提问模式）与 Agent 模式以行内 diff 提出修改，用户逐条接受或拒绝；支持任意 OpenAI 兼容端点，API key 存于系统钥匙串。提供 Windows/macOS/Linux/Android 安装包，安装包尚未代码签名。
