# RanitManik/Gemini-Clone

⭐ 39 · JavaScript · MIT · 推送 2025-11-07 · [GitHub](https://github.com/RanitManik/Gemini-Clone) · [官网](https://gemini-clone-v0.netlify.app) · 个人维护

**调用 Gemini API 的 React 聊天机器人网页克隆项目**

基于 React 与 Vite 构建的聊天网页应用，接入 Google Gemini API 生成回答，界面含聊天窗口、输入框与逐字打字动画。功能范围较基础：不保存历史会话，表情/头像与图片搜索等列为未来计划。面向学习 API 对接与 React 项目开发的使用者，需自行申请 Gemini API key 写入 .env.local 后本地运行，也有 Vercel 部署徽章显示在线部署。MIT 许可。
