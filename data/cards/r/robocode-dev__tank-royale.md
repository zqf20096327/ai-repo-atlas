**编程对战游戏：写程序控制虚拟坦克在竞技场对战**

Robocode Tank Royale 是一个编程游戏：玩家编写程序控制虚拟坦克的移动、扫描、开火与事件反应，在 2D 战场与其他 bot 对战，新版支持通过 WebSocket 在互联网上对战。项目定位为帮助学习编程、锻炼 AI 技能并进行竞技。运行需 Java 11 或 newer，支持 Windows/macOS/Linux；提供 Python、Java/JVM、.NET、TypeScript 四种官方 Bot API，其他语言可通过 WebSocket 协议接入。另提供可在 JVM 应用中无 GUI 运行对局的 Battle Runner API（Maven Central 发布），以及配套的网页版对战查看器与进阶策略文档。Robocode 旧版 API 的桥接仍在进行中。

## 能力要点

- 编写程序控制坦克的移动、扫描、开火与事件反应
- 四种官方 Bot API：Python、Java/JVM、.NET、TypeScript，语义与 Java 参考实现 1:1
- Battle Runner API 支持从任意 JVM 应用无 GUI 运行对局，用于自动化测试与基准测试
- 支持通过 WebSocket 跨互联网对战
