**Unity 虚拟智能体（NPC）创建框架，提供架构、资源与示例**

面向 Unity 开发者的虚拟智能体（NPC）框架：提供创建虚拟智能体所需的架构、资源与示例，通过 Unity 包形式分发，要求最低 Unity 版本 2022.3。支持三种安装方式：OpenUPM 包管理器 UI、manifest.json 直接编辑、Git URL 安装；依赖 i5 Toolkit for Unity（Git 安装方式需先手动安装）。随包附带示例工程，可在 Package Manager 中导入到 Assets 目录。代码采用 MIT 许可，美术资源采用 CC-BY 4.0 许可。由 RWTH Aachen（rwth-acis）团队维护，人物模型基于 CC0 许可的 MPFB 资产创建。
