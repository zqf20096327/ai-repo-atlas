**开源非营利的 AI 营养追踪应用：拍照或文字记录饮食**

Flutter 编写的营养追踪应用，面向关注饮食与健康的个人用户：拍照或用自然语言描述餐食，由 AI 识别食材、估算份量并记录热量、蛋白质、碳水、纤维、咖啡因等指标，同时支持运动记录与卡路里消耗。隐私优先，无分析与追踪；通过用户自带的 OpenRouter API key 调用模型，按用量付费。提供 Android（Google Play）、Web、Windows/macOS/Linux 构建版本；iOS 未提供，需用 Web 版。GPLv3 许可，非营利。

## 能力要点

- 拍照或文字描述即可由 AI 拆解食材并记录营养指标
- 支持热量、蛋白质、纤维、钠、咖啡因、水分等多项指标追踪
- 自带 OpenRouter API key 按用量付费，无订阅
- Flutter 单一代码库覆盖 Web/Android/Linux/macOS/Windows

## 适用场景

- 拍照记录一餐并自动获得热量与营养摄入
- 追踪每日水分、咖啡因、钠等健康指标
- 在本地运行或自选模型 key，掌控自己的健康数据
