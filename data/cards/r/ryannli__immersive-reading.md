**把长文/论文变成沉浸式阅读学习空间的 agent 技能**

以 SKILL.md 形式发布的 agent 技能：用户投喂文章、帖子、转录稿、笔记、论文、URL 或本地文件，由 coding agent（Claude Code、Codex、Cursor、Antigravity 等 SKILL.md 兼容代理）生成分章、含锚定引语、来源归属、搜索、高亮、笔记、主题与可选双语支持的静态交互阅读空间，输出可在本地或 Vercel 使用。通过 Claude Code 插件市场或 npx skills CLI 安装，仓库本身无需发布为 npm 包。
