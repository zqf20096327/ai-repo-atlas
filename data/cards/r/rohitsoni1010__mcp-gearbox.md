**跨平台桌面应用：统一管理多个 AI agent 的 MCP 服务器**

基于 Electron/React/TypeScript 的桌面应用，为 Claude Code、Cursor、GitHub Copilot、Kiro、Continue 等 10 种 AI agent 提供 MCP 服务器的发现、一键安装、启用/禁用与移除操作，自动更新配置文件，免于手动编辑 JSON。服务器目录数据来自 Model Context Protocol Servers 与 GitHub MCP Registry。提供 Windows/macOS/Linux 预构建安装包，也可从源码构建；运行需 uv、Python 3.11+ 与 Git。
