**面向 ML 研究者的 Claude Code 技能集市：论文写作/引用核验/实验追踪技能**

社区驱动的 AI 辅助研究技能市场，以 Claude Code 插件形式分发 30 个工作流，按 discover/write/verify/toolkit 四个插件组织：引用事实核查、论文草稿批判性审阅、实验声明与代码仓库一致性核验、统计严谨性检查、证明分解、LaTeX 构建调试、实验结果同步到论文草稿等。技能为纯 Markdown，以 /plugin 命令安装，配套共享 CLAUDE.md 编码课题组规范；使用需 Claude Code 订阅（$20/mo Pro 起）加 API token 费用，主要受众为 ML 研究者（PI/研究员/学生）。

## 能力要点

- 30 个按论文生命周期组织的可验证工作流，分 4 个插件分发
- paper-references 核查 .bib 引用（每次约 $0.10–0.30）
- paper-verify-experiments 对照源码仓库核验论文实验声明
- 技能为纯 Markdown，可跨提供方迁移，无锁定

## 适用场景

- 投稿前核查论文引用与实验声明的一致性

- 在课题组内通过共享 CLAUDE.md 统一核验标准
- 调试 LaTeX 与同步论文公式和代码实现
