# realkalash/fluent_gpt_app

⭐ 29 · Dart · NOASSERTION · 推送 2026-06-26 · [GitHub](https://github.com/realkalash/fluent_gpt_app) · 个人维护

**跨平台 GPT 桌面聊天客户端，Fluent 界面多聊天室**

基于 Flutter/Dart 的多平台桌面应用，在 Windows/macOS/Linux 上通过 OpenAI token 接入 ChatGPT，也可在设置中填写自定义 GPT 模型 URL（Local AI 字段）接入自有模型。提供多聊天室（每室可绑定不同模型与自定义指令）、系统托盘、自定义快捷键、置顶、Shell 命令执行、本地 Python 代码运行、Brave API 网页搜索、快速提示词与文本选中覆盖层（macOS）等特性。安装途径为 GitHub Releases 下载；Python 为可选安装。许可证为 CC BY-NC-ND 4.0。

## 能力要点

- 多聊天室，每室可分配不同 GPT 模型与自定义指令
- 支持经 URL 接入自定义 GPT 模型（Local AI 字段）
- GPT 可执行 Shell 命令并在本地运行 Python 代码
- Brave API 网页搜索与快速提示词（含 macOS 选中文本覆盖层）

## 适用场景

- 在桌面端通过多聊天室与不同 GPT 模型对话
- 接入自有 GPT 模型 URL 使用本地/自托管模型
- 借助 Shell 与 Python 执行能力让 GPT 完成本机任务
