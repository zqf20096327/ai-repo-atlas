# rupac4530-creator/super-builder-platform

⭐ 15 · TypeScript · NOASSERTION · 推送 2026-03-16 · [GitHub](https://github.com/rupac4530-creator/super-builder-platform) · 个人维护

**开源一体化 AI 创作平台：AI 工具、媒体管线、自主 Agent 与应用**

基于 Next.js 14 / Node.js / TypeScript / Express 的统一 AI 平台，聚合多模型对话助手、自主 Agent 中心（OpenClaw，含规划执行、多 Agent 团队、10+ 内置工具、沙箱执行）、7 个创作者工作室（视频/音频/3D/游戏/设计/时尚/机器人）、10 个创新模块与自改进引擎，并提供 Plugin SDK。支持 OpenAI、Gemini、Groq、Ollama、LLM Studio、OpenRouter、DeepSeek 等多 Provider 接入；默认以 mock 模式运行，无需 API key。通过 docker compose 或手动源码方式部署，本地开发脚本为可选辅助。

## 能力要点

- 自主 Agent 中心：多 Agent 团队协作与沙箱执行、任务暂停/恢复/取消
- 7 个创作者工作室与 10 个创新模块（知识图谱、代码生成、数据分析等）
- Plugin SDK 与插件市场，可构建并分享扩展
- 默认 mock 模式运行，无需 API key；docker compose 一键启动

- 在单一平台内完成 AI 对话、Agent 任务执行与媒体生成，减少工具切换

- 通过 Plugin SDK 扩展平台能力并在市场分享
- 用本地模型（Ollama/LLM Studio GGUF）离线运行平台功能
