# reaviz/reachat

⭐ 221 · TypeScript · Apache-2.0 · 推送 2026-08-19 · [GitHub](https://github.com/reaviz/reachat) · [官网](https://reachat.dev) · 组织维护

**构建 LLM/聊天界面的 React UI 组件库**

reachat 是面向开发者的 React UI 组件库，提供搭建 LLM 聊天界面所需的现成组件，通过 Tailwind 定制主题与样式。功能包括 Console/Companion 两种模式、Markdown 渲染（GFM、代码高亮、表格、数学公式、YouTube 嵌入、remark/rehype 插件）、文件上传、图片预览、消息来源、分页、会话智能分组、动画（Motion.dev）、Tiptap 驱动的提及与命令，以及 user/assistant/system/tool 角色的 agentic 消息模型。通过 npm 安装，可运行 Storybook 本地开发。
