**带 AI 聊天与邮件生成的 Next.js 个人作品集网站**

个人作品集网站模板，基于 Next.js 15、TypeScript、Tailwind CSS 与 Framer Motion 构建，展示项目与贡献，含响应式布局与暗色模式。AI 部分：通过 OpenRouter API 接入 LLM 提供"AI 版本人设"对话（Gemini 嵌入 + Pinecone 向量检索 + Tavily 搜索）、自然语言驱动的动态主题定制、以及 AI 邮件生成（Nodemailer 发送）。需配置多项环境变量，首次运行会向向量库写入嵌入。MIT 许可，部署于 Vercel。
