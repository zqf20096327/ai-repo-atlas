# RhythrosaLabs/DuoGPT

⭐ 20 · Python · MIT · 推送 2026-10-13 · [GitHub](https://github.com/RhythrosaLabs/DuoGPT) · 组织维护

**接入 OpenAI GPT 与 DALL-E 的双 Agent 桌面对话应用**

基于 Python/tkinter 的桌面应用，调用 OpenAI GPT 系列模型（GPT-3.5-turbo、GPT-4、GPT-4-turbo）与 DALL-E，提供团队模式与单人模式两类对话：团队模式按营销、开发、数据科学、商业策略、平面设计、音乐、游戏设计七类预置多 bot 协作完成内容生成、代码片段、图像设计等任务；单人模式一对一对话。支持 API key 保存加载、对话暂停/插话/停止、自动整理提取代码片段并打包 zip、保存对话到文本文件。运行需 Python 3.8+ 与 OpenAI API key，从源码克隆安装。
