# runzhliu/welink

⭐ 330 · TypeScript · AGPL-3.0 · 推送 2026-11-16 · [GitHub](https://github.com/runzhliu/welink) · [官网](https://welink.click) · 个人维护 · 中文 README

**本地化的微信聊天记录 AI 分析与对话模拟平台**

面向个人用户的微信聊天数据分析平台，读取本地聊天数据库后提供 AI 分析、AI 分身（学习联系人说话风格并模拟对话）、AI 群聊模拟、跨联系人问答、关系报告与群聊画像等功能；另含 21 个统计/Lab 小工具与定时分析任务。AI 分析支持三种检索模式（全量、FTS5+向量 RAG、单日聚合），接入 25+ LLM 提供商，内置 MCP 服务器供 Claude Code 查询。v0.4.0 提供 SFT 工作台，可在 Mac MLX 或 NVIDIA GPU 环境训练 LoRA Adapter。本地优先设计，云端模型使用时数据会发送到所选服务商。

## 能力要点

- AI 分身：从私聊+共同群聊学习联系人说话风格并模拟对话
- 三种检索模式：全量上下文、FTS5+语义向量 RAG、时光机单日分析
- 接入 25+ LLM 提供商，含 Ollama 本地离线部署
- SFT 工作台支持 MLX 与 LLaMA-Factory Worker 训练 LoRA Adapter

## 适用场景

- 分析自己与好友或群聊的聊天记录并直接提问
- 用 AI 分身模拟某个联系人的对话风格
- 本地离线分析不想上传云端的聊天数据
- 在 Claude Code 里通过 MCP 自然语言查询微信数据
