# rushter/MLAlgorithms

⭐ 11,178 · Python · MIT · 推送 2026-09-29 · [GitHub](https://github.com/rushter/MLAlgorithms) · 个人维护

**面向学习者的机器学习算法最小化实现合集**

用 Python（基于 numpy、scipy 和 autograd）从零实现的机器学习算法集合，覆盖 MLP/CNN/RNN/LSTM 等深度学习结构、线性与逻辑回归、随机森林、带核函数的 SVM、K-Means、GMM、PCA、t-SNE、梯度提升树与深度 Q 学习等。项目面向希望理解算法内部原理或自行从零实现的读者，代码以求易读为目标而非追求优化性能。提供 git clone 加 pip 依赖安装、免安装直接运行示例以及 Docker 运行三种使用方式。
