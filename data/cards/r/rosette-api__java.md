# rosette-api/java

⭐ 15 · Java · Apache-2.0 · 推送 2026-10-26 · [GitHub](https://github.com/rosette-api/java) · 组织维护

**面向 Java 开发者的 Babel Street Analytics API 客户端绑定库**

Babel Street（原 Rosette）Text Analytics 服务的官方 Java 客户端绑定库：封装 Analytics Platform API 各端点，使 Java 应用可调用实体与事件抽取、语言识别、语义相似度、情感分析、主题抽取、名称翻译等文本分析能力，分析在云端执行。通过 Maven Central 分发（坐标 com.basistech.rosette:rosette-api），仓库内含各端点示例程序；绑定本身以 Apache 2.0 许可，需注册 Analytics Cloud 获取 API 访问。
