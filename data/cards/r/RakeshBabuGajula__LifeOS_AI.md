# RakeshBabuGajula/LifeOS_AI

⭐ 14 · TypeScript · 推送 2026-10-16 · [GitHub](https://github.com/RakeshBabuGajula/LifeOS_AI) · 个人维护

**面向工程师的 AI 职业规划与倦怠监测全栈平台**

Next.js + FastAPI + MongoDB Atlas 构建的全栈 Web 应用：确定性算法层（SkillGapEngine/CareerEngine/BurnoutEngine）负责三级技能分类、职业路线图里程碑计算与多因子倦怠评分；生成层通过 Google Gemini 1.5 Flash 做简历解析、JSON Schema 约束的结构化职业诊断与项目建议。功能还包括统一仪表盘、7 天倦怠趋势图（Recharts）与 PDF 报告导出（react-to-print）。运行需 Python 3.11+、Node 18.17+、MongoDB Atlas 与 Gemini API Key，从源码部署。
