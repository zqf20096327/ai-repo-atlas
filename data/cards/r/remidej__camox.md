# remidej/camox

**供编码 agent 构建并持续管理网站的 CMS 框架**

基于 Vite 的 Web 框架，核心为 CMS：用代码定义 block，由人或编码 agent 在 UI 或 CLI 中组装页面，共享草稿与发布流程，无需改代码或重新部署即可发布。框架还会在后台监视内容变化并主动改进。面向由 coding agent 长期维护网站的开发者，提供可视化编辑、CLI 内容管理、版本化 skills、schema 推导类型及 SEO 元数据生成等特性。开发本仓库需运行 .agents/prepare 安装依赖并初始化本地数据库，再用 pnpm dev 启动。
