**给 Hermes Agent 加多模型并行工作流的操作层**

在 Hermes Agent 之上运行的操作层：将任务拆成有向图节点并行执行，每条工作通道按类别（如 ultrabrain/deep/quick）路由到不同模型与推理强度，provider 拒绝时按链路切换到下一个模型。提供百余个 omh-* 专家技能由路由按需加载、LSP 集成（默认关闭）、带理由的长期记忆写入、以及以测试/评审/CI 通过为完成依据的验证机制。以 CLI 安装，另有 omher desktop 桌面应用聚合 Hermes 机器人与编码代理。

## 能力要点

- 目标拆为并行节点图（/dag-ulw），各节点按类别路由到不同模型与推理强度
- 百余个 omh-* 专家技能由路由器按需加载为工具调用
- provider 拒绝模型时链路自动落到下一个模型
- 以测试/评审/CI 通过作为 done 的验证门槛，未执行的准备工作不报告为已执行

## 适用场景

- 让复杂开发任务在多条通道上按适配模型并行执行
- 在 Hermes 中按工作类别切换与校准各模型家族的提示
- 用验证门槛（测试/CI）约束 agent 报告的真实性
