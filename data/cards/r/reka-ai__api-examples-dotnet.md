**Reka API 的 .NET (C#) 示例集合：教学如何接入 Research/Vision**

Reka 官方维护的 C#/.NET 示例仓库，演示通过原生 HTTP 请求与 OpenAI 兼容 SDK 调用 Reka Research 与 Reka Vision，涵盖带引用来源的逐步推理 agent、response_format 结构化输出、web_search 域名范围控制，以及跨视频检索分析。示例包括 C# 10 脚本三用法、餐厅深搜、技术活动检索与视频分析四个工程，另有 Python 与 TypeScript 版本仓库。面向学习集成 Reka API 的 .NET 开发者。
