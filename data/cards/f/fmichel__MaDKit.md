**开发与模拟多智能体系统的开源 Java 库**

面向 Java 开发者的多智能体系统（MAS）开发工具包：采用组织中心方法与 AGR（Agent/Group/Role）组织模型，提供智能体生命周期管理、组织化通信基础设施、多智能体仿真引擎构建工具，不预定义智能体模型，允许开发者自由实现任意智能体架构。通过 Gradle/Maven 依赖引入，仓库含 Gradle wrapper、示例浏览器与三个应用示例（仿真模板、竞拍市场、蜂群仿真）。运行需 JDK 25+，GUI 示例需图形桌面。
