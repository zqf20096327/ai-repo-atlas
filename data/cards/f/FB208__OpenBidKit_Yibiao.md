**给投标企业的开源 AI 标书生成与投标工具箱**

面向招投标场景的 Electron 桌面工具，功能包括 AI 生成技术方案、图文生成、商务标、企业知识库管理、标书查重、废标项检查、招标文件解析（18 项）、多标段/多阶段投标支持等。技术栈为 Electron + React + TypeScript + SQLite，配置与生成结果保存在本机。接入 OpenAI 兼容 API，亦支持 ollama、lm studio 本地模型；由 Pi Agent 执行智能体任务。Windows/macOS 提供安装包，开发需 Node.js 22，本地打包需 .NET 10 SDK。采用 AGPL-3.0 协议。

## 能力要点

- AI 生成技术方案、已有方案扩写、字数无上限
- 招标文件解析（18 个解析项）与标书查重、废标项检查、错别字检查
- 本地知识库沉淀企业资料，支持多份标书查重
- 支持 OpenAI 兼容 API 及 ollama、lm studio 本地模型接入

- 本地部署二开以适配团队投标流程
