⭐ 65 · HTML · MIT · 推送 2026-04-12 · [GitHub](https://github.com/Felix-Forever/hermes-agent-desktop) · [官网](https://github.com/NousResearch/hermes-agent) · 个人维护 · 中文 README

**多智能体桌面客户端：20 个 AI 专家自动协作完成任务**

基于 Hermes Agent 重建的原生桌面客户端（pywebview + Python/aiohttp 后端 + 单文件前端），内置 20 个专业 AI 智能体，由 PM 编排器自动分解任务、分派专家并汇总交付，无需手工提示工程。提供可视化 Skill Store（50+ 技能来自 CocoLoop 市场、一键安装）、智能体 CRUD 管理面板、流式聊天与多会话管理。兼容任意 OpenAI 兼容 API（DashScope、OpenAI、DeepSeek、OpenRouter、Moonshot 等），支持一键切换模型。主要面向 macOS，也支持 Linux/WSL2，从源码安装运行。
