# FunplayAI/funplay-godot-mcp

**Godot 编辑器 MCP 服务器：让 AI 客户端直接操作运行中的项目**

MIT 许可的 Godot 编辑器插件，内置 HTTP MCP 服务器（默认 127.0.0.1:8765），使 Claude Code、Cursor、Codex、VS Code Copilot 等 MCP 兼容客户端能操作运行中的 Godot 4.2+ 项目。提供 129 个内置工具，覆盖场景编辑、语言感知的脚本工具（GDScript 与 .NET）、项目地图、execute_code 代码执行（默认开启安全检查）、播放模式自动化、输入模拟与截图验证，含一键生成各客户端 MCP 配置与项目技能文件。仅限编辑器使用，不向导出游戏添加运行时组件；另提供可选的 npm stdio 包装器。

## 能力要点

- 129 个内置工具：场景编辑、脚本生成、UI、动画、性能检查与编辑器自动化

- 一键生成 Codex/Claude Code/Cursor/VS Code 的 MCP 配置
- 中英文双语 Dock UI 与 core/full 工具档案切换

- 为支持 MCP 的 AI 编程客户端接入 Godot 编辑器工作流
