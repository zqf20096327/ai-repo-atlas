**闲鱼自动化 CLI，以 MCP/skill 形式供 AI Agent 调用**

把闲鱼核心运营能力封装为 17 个结构化命令，覆盖商品发布/下架/查询、图片上传、AI 类目识别、默认地址、IM 收发与会话列表；同一命令注册表同时输出 CLI、MCP server 和 5 个 Claude Skill 三种入口。内置账号限流（经营 1 次/分钟、媒体 9 次/分钟）与 RGV587 风控熔断，支持 --format json/yaml/table/md/csv 多格式输出。提供 Docker 沙箱模式隔离桌面环境，声明仅限用户自有账号使用。

## 能力要点

- 17 个命令覆盖发布、下架、查询、图片上传、IM 收发等闲鱼核心链路
- 一次定义三种入口：CLI / MCP server / 5 个内置 Claude Skill 共享同一 registry
- WebSocket 长连实时 IM，三类事件分类 JSONL 输出并自动重连
- 账号与业务桶限流 + RGV587 自动熔断的风控护栏

## 适用场景

- 用 AI Agent 自动回复买家消息和处理议价

- 实时监控闲鱼会话消息与已读回执
- 诊断店铺曝光下滑并生成归因清单
