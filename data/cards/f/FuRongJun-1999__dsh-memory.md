**给 AI Agent 挂载可审计长期记忆的 MCP 记忆基础设施**

灵枢（LINGSHU）是一套长期记忆基础设施：对话沉淀为纯文本 md 认知图，写入按层级设复核闸门（contextual 直写、knowledge 需反思、structural 需验证、self/anchor 需人工），记什么、取什么、能否写入由确定性规则裁决，不依赖 LLM 判断，自称无幻觉、可审计、结果可复现。以 stdio MCP server 形式运行，任何支持 MCP 的 Agent 宿主可挂载；含 Rust 检索内核、多智能体并发与权限三层（读/写/裁）。需自行接入 Agent，完整评测需 Rust 工具链与 Node。

## 能力要点

- 写入按层复核闸门（MDCG_WRITE_GATE 三态）与只读 guest 默认权限
- 零 LLM 确定性规则裁决，写入以 committed 确认
- stdio MCP server，README 列出 DSH/CodeBuddy/ZCode/Codex CLI/Claude Code 五端接入目录
- Rust 检索内核 --serve 进程实例支撑多智能体并发

## 适用场景

- 给 MCP Agent 加跨会话长期记忆与审计留痕
- 多智能体共享同一份记忆库并发读写
- 按层控制记忆写入的复核与人工裁定流程
