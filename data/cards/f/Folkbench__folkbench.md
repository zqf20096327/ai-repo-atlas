# Folkbench/folkbench

⭐ 3,737 · TypeScript · NOASSERTION · 推送 2026-11-26 · [GitHub](https://github.com/Folkbench/folkbench) · [官网](https://folkbench.com) · 组织维护 · 中文 README

**为开发者评测与选择 AI API 中转站的榜单与配置切换工具**

Folkbench 由两部分组成：一是公开评测体系，按模型汇总各中转站的可用率、稳定性、响应速度、会话成本与价格数据，每日发布带快照版本的公开快照，并提供降智监控（模型身份探针一致率、Token、模型指纹）；二是 Folkbench Switch，基于 Tauri + Rust 的开源桌面客户端，保存服务商 Base URL 与 API Key，写入 Claude Code、Codex、Gemini CLI 等工具的本地配置文件，支持配置差异预览、凭据暂存、托盘切换与本地脱敏代理。网站榜单含合作档位与运营加权，且推荐中转站支持其持续运营。

## 能力要点

- 每日公开快照：按模型对比各中转站可用率、稳定性、价格与会话成本
- 降智监控：模型身份探针一致率、输入/思考 Token 与模型指纹
- Folkbench Switch 桌面客户端：为 7 类 AI 编程工具写入中转站配置
- 本地脱敏代理：请求发出前替换 API Key、邮箱、IP 等敏感信息

## 适用场景

- 为 Claude Code 或 Codex 挑选并切换中转站线路
- 检测某个中转站是否存在模型降级（降智）
- 比较不同中转站同一模型的价格与可用率
- 在多个中转站配置之间一键整组切换
