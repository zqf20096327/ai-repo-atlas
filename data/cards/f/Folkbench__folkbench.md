**AI API 中转站评测榜单与本地客户端配置切换工具**

Folkbench 汇集 AI API 中转站的公开目录与每日快照榜单，按模型比较可用率、稳定性、响应速度、会话成本与价格；降智监控通过身份探针的一致率、Token 与模型指纹展示不同线路的表现差异，并附选站指南与充值风险提示。配套 Folkbench Switch 为基于 Tauri + Rust 的开源桌面客户端（Apache-2.0），保存服务商 Base URL 与 API Key，向 Claude Code、Codex、Gemini CLI、Aider 等 8 类工具写入配置，支持差异预览、凭据暂存与本机脱敏。排序含合作档位与运营加权，快照数据承诺可复算。

## 能力要点

- 每日公开快照榜单：可用率、稳定性、价格与会话成本多维比较
- 降智监控：模型身份探针一致率、Token 与模型指纹
- Switch 桌面客户端向 Claude Code / Codex / Gemini CLI / Aider 等写入中转配置
- 本机隐私脱敏：代理请求前替换 API Key、邮箱与 IP

## 适用场景

- 为 Claude Code 或 Codex 挑选并配置中转站线路
- 检测某家中转站的模型是否与标称一致
- 在多家服务商之间一键切换客户端配置
