**AI API 中转站评测榜单与桌面配置切换工具**

Folkbench 将 AI API 中转站的公开目录、榜单快照与降智监控聚合在一起，按模型比较各中转站的可用率、稳定性、响应速度与会话成本，并提供模型身份探针一致率、Token 与指纹数据。配套 Folkbench Switch：基于 Tauri + Rust 的开源桌面客户端，保存服务商 Base URL 与 API Key，写入 Claude Code、Codex、Gemini CLI 等 CLI 工具的本地配置文件，支持差异预览、组合档案与凭据暂存恢复。排序规则包含合作档位与运营加权，快照不承诺可复算。
