**面向开发者的本地人脸识别 Python SDK，覆盖检测比对全流程**

Faceplugin 发布的 Python 人脸识别 SDK，在 Windows 与 Linux 上本地运行，提供人脸检测与边界框提取、关键点检测、特征嵌入生成与相似度比对（默认阈值 75，返回 0-100 分值），支持 JPG/PNG/BMP/TIFF 多格式与单图多人脸。全部处理在本机完成，数据不出设备；GPU 可选，CPU 环境亦可运行。安装路径为 conda 环境 + pip 依赖，通过 run.py 验证。Liveness/防伪、证件识别等能力指向该公司单独的商业 SDK 产品线。
