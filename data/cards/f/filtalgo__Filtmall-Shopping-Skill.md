**为 AI 助手提供筛电商城查货、比价、下单与售后的购物 Skill**

筛电官方开源的 Agent Skill 插件（filtmall-shopping），装在支持 Skill 的 AI 助手中后，可对接筛电后台购物 Agent，在对话内完成商品筛选、规格与成分核对、同款比价、加购下单与售后跟进。浏览搜索免登录免 API Key，写操作（购物车、地址、下单、售后）需单独授权并先确认，付款由用户在官方收银台完成，Skill 不代付。运行需本机 Python 3.10+，npx 安装另需 Node.js 22.20+，也可从 GitHub Releases 离线包安装。
