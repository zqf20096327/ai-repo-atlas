# FatelessAI/SkyrimNet-GamePlugin

⭐ 390 · Papyrus · NOASSERTION · 推送 2026-11-23 · [GitHub](https://github.com/FatelessAI/SkyrimNet-GamePlugin) · [官网](https://fateless.ai) · 组织维护

**让 Skyrim 全部 NPC 可对话、记忆、行动的 AI 模组**

SkyrimNet 是将 Skyrim 中每个角色变为可交互 AI NPC 的游戏模组：玩家通过语音或文字与 NPC 对话，NPC 以各自声音与性格实时回复，具备基于语义回忆、随时间衰减的私有记忆系统，可感知环境并执行游戏内动作（跟随、给予物品、锻造等）。支持本地与云端 TTS、语音识别、视觉描述、AI 吟游诗人歌曲与可自定义字幕。以单个 Skyrim 模组形式运行，需语言模型后端：官方 Fateless 订阅、OpenRouter/OpenAI 兼容云端服务，或通过 LM Studio/Ollama/KoboldCpp/llama.cpp 本地运行。闭源发布（LICENSE 声明），经 GitHub Releases 配合模组管理器安装。

## 能力要点

- NPC 私有记忆按语义回忆并随时间衰减，可写日记
- 本地与云端 TTS 引擎、声音克隆，语音随生成流式播放
- NPC 可执行动作，动作库可被其他模组扩展
- 向模组开发者提供 Papyrus/C++ API、YAML 触发器与 MCP server

## 适用场景

- 在 Skyrim 中用语音与任意 NPC 实时对话
- 让 NPC 记住并提起玩家先前的言行
- 为模组开发接入 AI NPC 的动作与提示词 API
