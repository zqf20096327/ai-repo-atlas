# Felix-au/QuantX-Stock-Analysis-and-Forecast

⭐ 19 · Python · MIT · 推送 2026-07-21 · [GitHub](https://github.com/Felix-au/QuantX-Stock-Analysis-and-Forecast) · [官网](https://quantx.streamlit.app) · 个人维护

**面向个人投资者的股票分析与多模型价格预测 Streamlit 仪表盘**

基于 Python 和 Streamlit 的开源金融分析与预测工具：提供全球指数实时概览、技术指标（SMA/RSI/MACD 的 Plotly 交互图与买卖标注）、字典算法的新闻情感评分，以及包含 Linear Regression、Random Forest、XGBoost、ARIMA、Prophet 等 8 种算法的预测引擎，支持一键对比全部模型并按 RMSE/MAE/MAPE 输出基准表。自动识别印度 NSE 股票代码（.NS）切换 INR/USD 货币格式。通过 uv 本地运行，或访问 Streamlit Cloud 托管版；情感分析为词典法而非 LLM。
