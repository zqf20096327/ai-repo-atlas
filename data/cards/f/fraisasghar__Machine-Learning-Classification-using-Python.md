**用 Python 与决策树对股票数据做分类的示例项目**

面向学习者的 Python 机器学习分类演示项目：对包含 1,833 条股票价格与交易量的数据集做预处理、探索性可视化（matplotlib/seaborn），训练 Decision Tree 分类器并用 GridSearchCV 调参，通过混淆矩阵、分类报告与决策边界图评估结果，README 记录调参前后准确率从 90% 到 91%。通过 git clone 获取仓库，pip 安装依赖库后在 Jupyter Notebook 或脚本中按顺序运行。
