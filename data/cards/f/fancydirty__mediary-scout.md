**网盘用户的 AI 追更与媒体库整理工具**

自部署的开源媒体库工具：用户指定片名后，agent 自动搜索资源、转存到自己连接的网盘（夸克/UC/115/123/光鸭/天翼）、读回验证，并定时巡检补齐缺失剧集。提供 macOS/Windows 桌面版与 Docker 版两种形态，Docker 版支持多用户与 24 小时定时巡检。AI 模型接口为可选配置，未配置时默认使用 Kilo Code 公共免费模型池；资源搜索依赖 PanSou，可选接入 Prowlarr。

## 能力要点

- agent 自动完成搜资源→转存→读回验证的流程
- 支持六家网盘的分享链转存与扫码登录，多盘联合按容量与画质分配
- 桌面版与 Docker 版两种部署形态，Docker 版 24 小时定时巡检
- 提供 Agent API 供 Claude Code、Codex、OpenClaw 等 agent 操作

## 适用场景

- 自动追更剧集并补齐缺失集数
- 把资源转存到自己的多个网盘组成联合媒体库
- 在 NAS 上以 Docker 常驻部署供家庭多用户使用
