**面向独立财产险经纪团队的保险代理管理系统（含 AI 功能）**

Quickfire 是面向独立 P&C 经纪人、批发商与代理团队的保险代理管理系统（AMS），管理客户、保单、续保、报价、任务、附件与 PDF 表单，并集成第三方 API。AI 部分：OpenAI 集成用于数据录入、摘要与工作流自定义提示，以及自然语言查询数据、后台自动化任务。开源版 Openfire 为 .NET 10 + Blazor + SQLite 的 Web 应用，另有闭源商业版（Quickfire/Pro）。支持通道为 Windows + .NET SDK 10 + 自备 Syncfusion 许可，OpenAI key 非核心启动必需。
