# facunicedev/nonoisenews

**由 Claude 生成的本地个人日报：按你的偏好选写新闻**

在本地 Windows 电脑上运行的个人新闻简报工具，依赖 Claude 应用与 Claude Code 驱动：用户填写问卷设定语言、话题数量与各话题权重，Claude 读取近 24-48 小时新闻并自行撰写每条故事，每条至少附两个来源并标注是否付费墙。页面提供「Tell me more」「Ask me」「Not interested」等按钮，由 Claude 执行相应动作；数据全部保存在本地文件夹，每周自动检查更新。需要付费 Claude 计划。

## 能力要点

- 问卷式配置：话题数量与 Always/More/Normal/Less/Never 权重
- 每条故事至少两个来源，标注 free/paywalled
- 四种界面语言（英/西/法/德）及故事翻译
- 数据全部保存在本地 datos/ 文件夹

## 适用场景

- 每天生成一份只含自己关心话题的新闻简报
- 对某条新闻追问细节或让其解释难懂之处
- 关注全球大势与关键指标的读者
