# FEZtool-team/FEZrs

⭐ 25 · Python · Apache-2.0 · 推送 2026-10-28 · [GitHub](https://github.com/FEZtool-team/FEZrs) · [官网](https://feztool.com/) · 组织维护

**遥感多光谱图像处理与光谱分析 Python 库**

由 FEZtool 开发的 Python 库，面向地学遥感的栅格图像处理与光谱分析：提供高斯/拉普拉斯/Sobel 等滤波、对比度增强与边缘检测、TIFF 地理栅格数据支持，以及 NDVI/NDWI/SAVI 等遥感指数计算。通过 KMeansCalculator、SVMCalculator 等模块支持图像分类与聚类，并含 Landsat8、Geoeye 等传感器专用模块。以 pip/conda 包形式分发，可与 FastAPI 等 Python Web 应用集成。

## 能力要点

- 滤波、对比度增强、边缘检测等图像处理工具
- NDVI/NDWI/SAVI 等遥感指数与光谱剖面计算
- KMeans/SVM 分类与聚类、PCA 特征提取模块
- 支持 TIFF 地理栅格数据，含 Landsat8/Geoeye 专用模块
