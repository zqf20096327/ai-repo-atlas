# fal-ai-community/video-starter-kit

⭐ 2,408 · TypeScript · MIT · 推送 2026-10-21 · [GitHub](https://github.com/fal-ai-community/video-starter-kit) · [官网](https://fal-video-studio.vercel.app) · 组织维护

**浏览器端 AI 视频应用开发脚手架（Next.js+Remotion+fal.ai）**

面向开发者的视频应用启动模板：基于 Next.js 与 Remotion，通过 fal.ai 接入 Minimax（视频生成）、Hunyuan（视觉合成）、LTX（视频操控）等视频模型，在浏览器内完成视频处理与合成。内置多片段合成、音轨集成、配音、时长扩展等媒体能力，以及元数据编码、处理管线、现成 UI 组件与 TypeScript 支持；存储使用 IndexedDB，无需云端数据库，可部署到 Vercel。使用方式为 git clone 后 npm/yarn/pnpm 安装并配置环境变量运行。

## 能力要点

- 通过 fal.ai 接入 Minimax/Hunyuan/LTX 三类视频模型

- 提供多片段合成、音轨、配音、时长扩展等媒体能力
- 含现成 UI 组件、处理管线与 TypeScript 支持
