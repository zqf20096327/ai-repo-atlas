**DSH 的 Prompt 模板工具箱插件：一键注入常用提示词**

面向 DSH（DeepSeek Harness）CLI 的 Prompt 提示词工具箱插件：将常用 Prompt 保存为模板，点击按钮或通过 /prompt 斜杠命令注入对话框；提供 24 条预制模板，自定义模板支持名称、标签、文字颜色、正文的配置，正文按原样保留并可用 {{cursor}} 控制光标落点。悬浮面板支持范围与标签筛选、预制模板屏蔽开关、悬浮/点击两种触发方式。安装依赖 DSH CLI，通过 npm 全局安装后重启生效。

## 能力要点

- Prompt 按钮悬浮面板：标签筛选、一键屏蔽/展示官方预制模板
- /prompt 或 /p 触发斜杠候选列表，继续输入可缩小范围
- 自定义模板支持名称、标签、60 色文字颜色、描边与 {{cursor}} 光标标记
- 正文按原样保留换行与空行，只忽略首尾空格与制表符

## 适用场景

- 把重复使用的 Prompt 存成模板，点击注入对话框省去复制粘贴
- 给团队常用提示词打标签分类，在面板里按标签筛选
- 需要控制插入后光标位置的多段式提示词模板
