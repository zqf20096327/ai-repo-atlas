**桌面语音听写工具：快捷键说话，本地识别后写入光标处**

TypeLeast 是面向 macOS（Apple 芯片）与 Windows 11 的桌面听写工具：按一下 Fn 开始说话，说完再按即结束，语音经识别并由大模型整理后直接写入光标位置。语音识别可使用本地模型，也可接入用户自己的 API；提供 Fn+Shift 选中文字翻译、Fn+空格打开 Harness EQ 选择 Skill 或 MCP 后写入。附听写统计与使用热力图，GPL-3.0 许可，提供安装包与源码构建说明。

## 能力要点

- 快捷键触发，识别文本直接写入光标处
- 语音识别支持本地模型（SenseVoice，经 sherpa-onnx）或用户自有 API
