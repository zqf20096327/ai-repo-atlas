## 能力要点

- 浏览器控制台粘贴 JavaScript 即可运行 EA，无需 Node.js
- EA 与指标仅存于浏览器 Web LocalStorage，不上传服务器
- FIX API 个人版免费，路径为浏览器→本地 Java 包→FIX API
- EA 代码生成器与 C/C++/MQL 编译工具链

## 适用场景
