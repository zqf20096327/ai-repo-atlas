**微信聊天机器人：接入 LLM 自动收发拟人化消息**

基于 KouriChat 修改的微信聊天机器人，通过 wechatauto-replica 收发微信消息，调用 LLM 生成回复。功能覆盖多用户/群聊独立 Prompt、图片与表情识别、情绪识别回复表情包、记忆总结、AI 定时任务与语音通话提醒、联网搜索、防撤回、朋友圈交互、WebUI 配置与 Prompt 管理。以 Python 包发布，另提供自带 Python 运行时的免安装离线包；需 Windows 10/11 64 位与微信 4.1.12+ 已登录环境。维护者在 README 中声明开学后更新频率将降低。

## 能力要点

- 多用户/群聊独立 Prompt 与聊天记录生成风格档案
- 图片/表情包/情绪识别与表情包回复
- AI 定时任务、语音通话提醒、联网搜索、防撤回与朋友圈功能
- WebUI 配置与 Prompt 管理，提供免安装离线包

## 适用场景

- 在微信上部署一个拟人化角色陪聊机器人
- 给不同好友或群聊配置不同人格提示词
- 让机器人定时提醒、联网搜索并回复图片消息
