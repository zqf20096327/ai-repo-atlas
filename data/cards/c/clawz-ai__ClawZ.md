# clawz-ai/ClawZ

⭐ 16 · TypeScript · MIT · 推送 2026-03-14 · [GitHub](https://github.com/clawz-ai/ClawZ) · [官网](https://claw-z.com) · 组织维护 · 中文 README

**OpenClaw AI agent 的可视化桌面管理工具**

基于 Tauri（Rust 后端 + React 前端）的跨平台桌面应用，用于安装、配置和管理 OpenClaw agent：提供引导式安装向导、6 个内置场景模板（默认助手、每日简报、邮件管家等）、模型与消息渠道接入、网关启停监控、成本看板、多 agent 编排、定时任务与日志中心。支持 OpenAI/Anthropic/MiniMax/智谱/Qwen 等模型供应商和 Telegram/Discord/Slack/飞书/WhatsApp 渠道。macOS 与 Linux 提供安装包，Windows 计划支持；全程本地运行，无需终端。
