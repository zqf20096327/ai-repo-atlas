**约2000行核心代码的终端 LLM Agent，支持 MCP 与 Agent Skills**

用 TypeScript 实现的极简终端 AI Agent，核心代码约 2,000 行，是 MiniMax 开源 Mini-Agent 项目的 TypeScript 版本。提供 ReAct 多步推理与工具调用、交错式思维链、MCP 协议接入外部工具、Agent Skills 自定义技能目录，以及文件读写与命令执行等内置工具。支持 OpenAI/Anthropic 兼容 API，可配置 MiniMax、DeepSeek 等提供商。通过 git clone 源码与 YAML 配置文件运行，面向想学习 Agent 实现或自建 AI 助手的开发者。
