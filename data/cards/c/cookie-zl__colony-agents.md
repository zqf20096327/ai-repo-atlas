**团队共享的多租户 Agent 云端部署平台**

将 DeepSeek Harness（dsh）部署到云端的多租户 Agent 基础设施：一个团队一个实例，提供账号准入、审计、卷/子域/数据隔离与闲置休眠唤醒；技能与 MCP 以带版本的市场包分发，支持公共/团队私有/点对点分享；会话经钉钉 Stream 或飞书回调进入群聊，可按岗位配置多个数字员工。通过 Docker Compose 或 Helm 部署，单实例有状态，README 声明尚未到 1.0。

## 能力要点

- 一团队一实例的多租户隔离（进程/卷/子域/数据库行）
- 技能与 MCP 带版本市场，安装台账与升级回滚
- 钉钉/飞书群 @ 数字员工，群间会话隔离与 msgId 幂等去重
- 会话存算分离：容器可丢，会话与产物入对象层

## 适用场景

- 给团队部署共用且租户隔离的 Agent 实例
- 在钉钉/飞书群里接入数字员工回答业务问题
- 统一管理团队技能与 MCP 连接器的版本分发
- 为 Agent 平台补充账号、审计与密钥管理
