**开发者个人站点与内容管理系统，含写作 agent 与 RAG 后台**

以 pnpm + Turborepo 组织的 monorepo，包含四个应用：Next.js 公开站点（博客/项目/搜索/阅读 agent）、Next.js 管理后台、Hono 服务端（认证/数据库/AI 路由）与工作流应用（持久化工作流、索引任务）。后台提供多会话写作 agent（读写文章、长期记忆、流式与回退）与 RAG 管理面板（chunk/嵌入索引维护、重建索引）。基础设施为 Better Auth、Postgres/Drizzle、Redis、Vercel Workflow SDK 与 ParadeDB。AI 是站点内容生产与检索功能，非本体。
