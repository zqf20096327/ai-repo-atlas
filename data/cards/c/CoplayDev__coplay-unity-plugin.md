**面向 Unity 开发者的自然语言 AI Copilot 插件**

Unity 编辑器插件形式的 AI 助手：通过自然语言控制 Unity 执行操作、创建/修改/管理游戏元素，基于项目资源、场景与脚本结构提供上下文相关建议，支持 GPT-4.1、Gemini 2.5 Pro、Claude 4-Sonnet、Grok 3 等多模型选择，可录制与回放操作序列（Pipelines），并支持脚本生成与错误调试。安装通过 Unity Package Manager 从 git URL 导入，需登录账号。README 顶部声明 Coplay 已被收购并更名为 Aura。
