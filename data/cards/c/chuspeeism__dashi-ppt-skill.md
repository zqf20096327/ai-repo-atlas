# chuspeeism/dashi-ppt-skill

⭐ 10,949 · JavaScript · AGPL-3.0 · 推送 2026-11-06 · [GitHub](https://github.com/chuspeeism/dashi-ppt-skill) · 个人维护 · 中文 README

**让 AI Agent 从文档生成可浏览器编辑、可导出 PPTX 的技能包**

面向职场人的 AI Agent 技能（skill）：把文档交给 Claude Code、Codex、豆包等本地 Agent，自动组稿生成带 12 套视觉主题、1020 个版式的演示文稿。每页附带浏览器编辑控制台，可拖滑杆调整模块数量、布局、配色，点击就地改文字、替换媒体，最终导出为 HTML 离线包、PDF 或逐节点可编辑的 PPTX。安装需 Node.js 20+，导出依赖本机 Chrome/Chromium/Edge；生成与编辑全程在本机完成。

## 能力要点

- 12 套视觉主题、1020 个版式页面、20 种页面角色
- 浏览器内编辑控制台：滑杆调节布局、模块数量、配色与页面重点
- 一键导出 HTML 离线包 / PDF / 逐节点可编辑的 PPTX
- 内容零上传：生成、编辑、导出均在本机完成

## 适用场景

- 把行业研究或竞品分析文档快速变成结构完整的演示文稿
- 路演或项目汇报材料生成后在浏览器里继续改细节
- 需要可继续编辑的真实 PPTX 文件交付给同事
