# CalebYcj/codex-rehome

⭐ 452 · Rust · MIT · 推送 2026-11-13 · [GitHub](https://github.com/CalebYcj/codex-rehome) · 个人维护 · 中文 README

**把 Codex Desktop 的项目、对话、Skills 离线迁移到另一台电脑**

为 Codex Desktop 用户提供离线数据迁移与备份工具：在原电脑选择项目、对话、Skills、Plugins 和生成内容，打包为 `.rehome` 迁移文件，经网盘/局域网/移动硬盘传输后在目标电脑导入恢复，支持 Windows 与 macOS 间四个方向的迁移。处理压缩会话解压、项目目录映射、路径改写、同名项目冲突、分叉对话依赖等边界情况；迁移默认排除令牌、私钥等敏感内容，过程离线不上传。另有保留的 Codex Agent Skill 工作流供自动化使用。

## 能力要点

- 三步迁移：选择内容生成 `.rehome` 包、传输、在新电脑导入恢复
- 支持 Win↔mac 四个方向及重装系统前的备份恢复
- 处理 `.jsonl.zst` 压缩会话、SQLite WAL、路径改写与同名项目冲突
- 迁移保持离线，默认排除登录令牌、Cookies、私钥等敏感文件

## 适用场景

- 换电脑时带走 Codex 的项目与对话历史
- 重装系统前备份 Codex 数据并事后恢复
- 在 Windows 和 macOS 之间迁移 Codex 工作环境
