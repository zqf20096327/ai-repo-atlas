**面向工程团队的 agent 原生软件交付研究语料库**

一个关于 agent 原生软件交付的研究语料库，记录团队如何接入编码 agent、合并前的验证方式，以及生产环境中出现的拓扑结构。内容组织为模式中心（机制说明）、从业者档案（80 个带引用的团队记录）、周更洞察、行业全景与存档调研快照，覆盖 9 种拓扑模式、失败模式与 agent 安全主题。仓库另含参考实现，agents 可通过解析 docs/index.json 获取内容，以 MIT 许可发布，每周更新。
