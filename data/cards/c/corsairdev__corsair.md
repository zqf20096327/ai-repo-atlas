**面向开发者的产品集成平台，连接用户与应用**

Corsair 是一个产品集成平台，覆盖 agent 集成、后端服务与多租户 dashboard 场景。它基于 REST API 构建，使同一集成层可服务于 agents、后端服务与用户 dashboard；为每个集成提供统一语法，由官方维护适配器。可自托管，或使用 Hub 托管 OAuth 刷新与 webhooks。以 npm 包形式提供，含 MCP connector，Apache-2.0 许可。
