**西班牙语计算机视觉实践教学课程仓库（12 个主题）**

Hands-on Computer Vision 是一个由学生研究小组（semillero）维护的西班牙语教学仓库，包含每周课程使用的 notebook 与资源。课程规划 12 个主题：图像获取与处理、卷积神经网络深度学习、多光谱/高光谱成像、被动/主动深度估计、分割、凸优化、热成像、多模态 NLP 与最终项目。README 列出各主题简介，其中除导论课（Sesión 1）外多数标注'建设中'。使用方式为 git clone 源码、创建 venv、安装 requirements.txt 并在 VS Code 中打开 notebook。
