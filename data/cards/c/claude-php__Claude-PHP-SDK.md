# claude-php/Claude-PHP-SDK

⭐ 146 · PHP · MIT · 推送 2026-05-27 · [GitHub](https://github.com/claude-php/Claude-PHP-SDK) · [官网](https://dalehurley.com) · 个人维护

**非官方 Anthropic Claude API 的 PHP 客户端 SDK**

由个人开发者独立构建的 PHP SDK，封装 Anthropic Claude Messages API，功能覆盖流式输出、多轮对话、工具调用（含自动工具循环）、扩展思考三种模式、视觉与 PDF 输入、批量处理、结构化输出及服务端工具（代码执行/记忆/web fetch）。支持 Laravel/Symfony 框架集成，提供 Azure Foundry、AWS Bedrock、Google Vertex 云平台接入类，附 85+ 示例与 17 篇教程。需 PHP 8.1+、Composer 与 Anthropic API key，非 Anthropic 官方维护。
