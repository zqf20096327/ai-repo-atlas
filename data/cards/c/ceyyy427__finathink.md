**本地优先的金融研究与量化策略工作台**

Finathink 将用户自有数据、证据、因子、量化检验、风险检查、纸面组合和学习记录组织成可追溯研究流程，运行结果保存为结构化记录与可离线打开的 HTML 报告。机制上提供五类分析师并行的多代理研究、受控因子提案与回测/OOS 检验、确定性风险检查与纸面账本，每阶段带运行 ID、输入输出指纹与 checkpoint，相同 fixture 输入可重放。面向个人研究者与量化学习者，需 Python 3.11+，以本地 Web 服务运行。
