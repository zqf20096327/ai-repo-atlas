# Comfy-Org/ComfyUI

⭐ 148,295 · Python · GPL-3.0 · 推送 2026-11-24 · [GitHub](https://github.com/Comfy-Org/ComfyUI) · [官网](https://www.comfy.org/) · 组织维护

**给视觉创作者的节点图式扩散模型本地推理与生成引擎**

ComfyUI 是面向视觉创作者的 AI 内容生成引擎，通过节点图界面以无代码方式构建图像、视频、音频、3D 与文本生成工作流，原生支持 SD/Flux/Wan 等多系列开源模型，支持加载 checkpoint、VAE、LoRA、ControlNet 等格式，并提供局部重执行、VRAM/RAM 管理、异步权重流式等本地运行优化，可在低至 4GB 显存环境运行。另有 App Mode、API 端点、Comfy Agent 与 MCP 接入等形态，核心可完全离线运行，通过 ComfyUI-Manager 扩展自定义节点。
