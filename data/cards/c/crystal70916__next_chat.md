# crystal70916/next_chat

⭐ 22 · TypeScript · MIT · 推送 2026-03-17 · [GitHub](https://github.com/crystal70916/next_chat) · [官网](https://next-chat-crystal8.vercel.app) · 个人维护 · 中文 README

**支持多模型的 AI 聊天助手，可 Web 与桌面端部署使用**

NextChat 的社区 fork：一个面向终端用户的 AI 对话应用，支持 Claude、DeepSeek、GPT-4、Gemini Pro 等多模型接入；提供 Web 版、桌面版（Windows/macOS/Linux）与 iOS 版本，可一键部署到 Vercel、Zeabur 或在 Gitpod 中打开，另有企业版入口。支持 MCP 协议，构建前需设置环境变量 ENABLE_MCP=true，桌面端带自动更新功能。
