# ChannelCooperStart/capri-ai

⭐ 382 · 推送 2026-10-27 · [GitHub](https://github.com/ChannelCooperStart/capri-ai) · 个人维护

**赛博朋克风格桌面 AI agent 客户端：统一接入 Claude Code 等助手**

运行于 Windows 10+ 的桌面应用，作为 AI 助手的界面与 agent 层：用户以自然语言描述任务，Capri 通过引擎路由将任务交给所选 AI 引擎规划，再用本地工具执行文件整理、代码修改、项目搭建、定时自动化等桌面操作；敏感操作需用户批准。开箱支持 Claude Code、Codex、Antigravity，其他助手可经自定义适配器接入，首次启动用账号登录或 API key 连接。提供安装包与便携版，macOS/Linux 尚未发布（路线图中）。独立粉丝项目，与 CD PROJEKT RED 等无关联。

## 能力要点

- 可切换接入 Claude Code / Codex / Antigravity，其他助手经自定义适配器
- 自然语言驱动的桌面 agent：规划、用工具、执行前需用户批准
- 文件整理、代码修复、项目搭建、周期性自动化等桌面任务
- Windows 安装包与便携版两种分发格式

## 适用场景

- 不写命令行，用自然语言让 AI 助手操作我的电脑
- 在多个 AI 引擎之间随时切换执行任务
- 把重复的桌面杂务（如定期备份）变成一句话自动化
