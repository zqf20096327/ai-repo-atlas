**浏览器扩展：用自己的 API key 调 AI 总结网页正文**

面向普通用户的浏览器扩展，安装于 Chrome、Edge、Firefox，用于对当前网页文本内容生成 AI 摘要，用户需自行配置模型与 API key（BYOK）。支持自定义 AI 提供商、提示词模板、上下文长度限制，以及自动开始、悬浮球、右键菜单、快捷键等多种触发方式；无遥测、无后端服务。定位为浏览器内置 AI 工具之外的轻量替代选择，不提供 Tools、MCP、Skills 或记忆系统。

## 能力要点

- 自定义 AI 提供商（BYOK，用自己的 API key）
- 自定义提示词模板与最大上下文长度限制
- 多种触发方式：自动开始/悬浮球/右键菜单/快捷键
- 站点级定制（glob、选择器、白名单/黑名单）与 Token 用量显示

## 适用场景

- 浏览网页时快速生成正文摘要
- 用自己已有的 AI API key 总结指定网站内容
- 对特定站点设置白名单/黑名单并自动触发总结
