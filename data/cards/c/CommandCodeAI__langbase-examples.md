**Langbase 平台的 AI Agent 与 RAG 示例项目集合**

Langbase 官方维护的示例仓库，收录基于 Langbase 平台构建的 LLM AI 项目示例。Langbase 是 Serverless 的组合式 AI 基础设施，包含三项产品：AI Pipes（可作 API 部署的自定义 AI agent）、Memory（托管向量存储+RAG 的记忆检索服务）、AI Studio（构建、协作与部署 agent 的平台，含用量/成本/质量监控）。README 仅描述平台与示例定位，未给出具体示例列表或安装运行步骤，需注册 Langbase 账号并查阅官方文档使用。
