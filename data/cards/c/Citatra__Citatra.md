# Citatra/Citatra

⭐ 16 · TypeScript · NOASSERTION · 推送 2026-02-25 · [GitHub](https://github.com/Citatra/Citatra) · [官网](https://citatra.cloud) · 组织维护

**面向营销/SEO 人员的 AI 搜索可见性自托管监测平台**

开源自托管 Web 平台（Next.js + MongoDB），用于监测品牌在 Google AI Overviews 中的出现情况：支持提示词追踪、来源分析、竞品监控、反向链接分析、SoV 与情感分析、语义地图、GEO/HTML 审计、预测与关键词探索等功能。通过 SerpApi 抓取 AI Overview 数据，提供 REST API 与 cron 定时抓取；需自行配置 MongoDB、认证密钥与 SerpApi key。开源版限制 1 个工作区；许可为非商业再分发许可。
