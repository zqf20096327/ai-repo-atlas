# ck-ys/SmartDock

⭐ 322 · Java · Apache-2.0 · 推送 2026-11-23 · [GitHub](https://github.com/ck-ys/SmartDock) · 个人维护 · 中文 README

**给团队用的开源智能体工作台引擎，附用户画像引擎**

基于 Java 21/Spring Boot 3.5/Vue 3.5 与 RuoYi-Vue-Plus 底座的开源智能体工作台：按 agentId 注册多智能体，ReAct 工具循环、工具 SPI 扩展业务能力、写操作 HITL 确认、PII 脱敏与计费（19 家预置供应商）。技能为 SKILL.md 格式 Markdown 文件，可在管理台在线编辑。配套事件源用户画像引擎（事件→指标→快照）。提供本地开发与 Docker Compose 两种部署方式；基线不含模型 Key，需自行录入。

## 能力要点

- 多智能体注册与 ReAct 工具循环，AGUI/SSE 流式输出 28 类事件
- 工具 SPI（BizToolProvider）接入业务能力，写操作先确认再落库
- 技能为 SKILL.md 文件，管理台改完下一轮会话生效
- 事件源画像引擎：维度配置、评分、分群、快照回放

## 适用场景

- 给业务系统配一个能查真实数据、走真实流程的 AI 助手工作台
- 需要写操作确认、审计留痕与计费的内部智能体平台
- 想在业务动作上做用户画像评分与分群分析
- 以 RuoYi 底座为基础搭建带多租户权限的管理后台
