# ck-ys/SmartDock

⭐ 326 · Java · Apache-2.0 · 推送 2026-11-27 · [GitHub](https://github.com/ck-ys/SmartDock) · 个人维护 · 中文 README

**给企业团队的多智能体工作台：ReAct 工具调用+用户画像引擎**

基于 Java 21/Spring Boot 3.5/Vue 3.5 与 RuoYi-Vue-Plus 5.6.1 底座的开源智能体工作台：按 agentId 注册多智能体，走 ReAct 工具循环并经 AGUI/SSE 流式输出；业务能力通过工具 SPI（BizToolProvider）接入，写操作在落库前出 HITL 确认卡；技能为 SKILL.md 格式 Markdown 文件，支持三层装载与管理台在线编辑；配套事件源用户画像引擎（事件→维度→快照）。提供本地源码与 Docker Compose 两种部署方式，基线不含任何模型 Key，上线前需自配供应商 Key 并替换默认口令。

## 能力要点

- 多智能体注册 + ReAct 工具循环，AGUI/SSE 流式输出（28 类事件）
- 工具 SPI 扩展业务能力，写操作 HITL 确认、PII 出网脱敏、计费系统
- 技能为 SKILL.md 文件，管理台在线编辑无需发版
- 配套事件源用户画像引擎，快照可回放可对账

## 适用场景

- 给团队搭一个带权限、审计与计费的智能体工作台
- 把业务 SOP 写成技能文件让 AI 按步骤执行
- 定时用只读工具跑自动化任务并推送结果
- 用事件数据构建用户画像与行为分析
