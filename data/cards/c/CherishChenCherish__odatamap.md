# CherishChenCherish/odatamap

⭐ 10 · TypeScript · MIT · 推送 2026-04-04 · [GitHub](https://github.com/CherishChenCherish/odatamap) · [官网](https://odatamap.cherishchen2510.workers.dev) · 个人维护 · 中文 README

**面向中国科研人员的全球科研数据可视化地图**

交互式科研全景可视化工具，将 250M+ OpenAlex 论文映射为 7 大知识大陆、45 个研究方向的地图，支持缩放拖拽、中英文实时论文搜索、研究方向趋势/热度分析、学者 H-Index 主页。内置 DeepSeek 驱动的 AI 研究助手，用于分析研究方向、竞争格局与蓝海机会。基于 Next.js + D3.js 构建，部署于 Cloudflare Workers 以便中国直接访问，MIT 许可。
