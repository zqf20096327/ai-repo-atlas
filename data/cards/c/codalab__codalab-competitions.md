**举办与参与机器学习竞赛的开源 Web 平台**

开源的 Web 端竞赛平台，面向研究者、开发者与数据科学家，支持在线社区共享 worksheets、组织和参与以机器学习与高级计算为主的科学竞赛。参与或组织竞赛无需本地安装，注册平台实例即可；自行部署实例需 Linux、Docker 与 docker-compose，通过 git clone 仓库并启动容器在本地运行。README 提及下一代平台 Codabench 已发布，并附 JMLR 引用条目。
