**Cherry Studio 桌面客户端的自定义 CSS 主题（枫叶霓虹）**

面向 Cherry Studio v2.0+ 的自定义 CSS 主题，基于 v2 主题 API（语义化 CSS 变量与 data-ui 钩子）构建。提供三个变体：完整版（Maple Mono/DreamHan 字体 + 霓虹跑马灯动画 + 官方 token 映射）、仅字体精简版、仅流光边框动画版。使用方式为复制 CSS 内容粘贴到 Cherry Studio 的设置→显示设置→自定义 CSS，保存后即时生效。颜色集中在 :root 少量变量中，可自行改色；未安装指定字体时回退到 Fira Code / 微软雅黑。
