# CariSoftwareBR/OpenGitDesktop

⭐ 4 · TypeScript · GPL-2.0 · 推送 2026-11-23 · [GitHub](https://github.com/CariSoftwareBR/OpenGitDesktop) · [官网](https://github.com/CariSoftwareBR/OpenGitDesktop/releases/latest) · 组织维护

**带受监督 AI 助手的跨平台桌面 Git 客户端**

基于 Electron 的跨平台 Git 桌面客户端，提供变更与提交、历史分支图、分支同步、pull request、dashboard 等视图，本地优先存储。AI 部分为受监督的助手：用户以自然语言请求操作（如创建分支），经批准后执行；支持接入 OpenAI、Claude、OpenRouter、Ollama 或任意 OpenAI 兼容端点，也可完全不使用 AI。提供 Windows、Linux、macOS 预编译安装包，支持从源码构建，macOS 支持自动更新，许可证为 GPLv2。

## 能力要点

- 变更/提交、历史分支图、分支同步、pull request、dashboard 等 Git 客户端视图

- 在本地优先的工作流中查看 pull request 与仓库状态
