# CrawlScript/MMClaw

⭐ 151 · Python · GPL-3.0 · 推送 2026-10-25 · [GitHub](https://github.com/CrawlScript/MMClaw) · 个人维护 · 中文 README

**纯 Python 轻量多模态 Agent 内核，可接入多渠道聊天**

以 100% 纯 Python 实现的自主 Agent 内核，无 C 扩展、无 Node.js、无 Docker 依赖，Python 3.8+ 即可 pip 安装运行。提供 Agent 循环与工具调用、持久记忆、技能系统（含 SkillKG 技能知识图谱与安全检查）、定时任务、网页搜索与可选 Playwright 浏览器自动化。支持 Telegram/微信/飞书/QQ/WhatsApp 等连接器与多工作区隔离实例，同时定位为可读的 Agent 构建教程。

## 能力要点

- 100% 纯 Python，无 Node.js/Docker/C 扩展依赖
- 内置 SkillKG 技能知识图谱，激活技能前自动做依赖推理与安全检查
- 支持 Telegram、微信、飞书、QQ Bot、WhatsApp 等多渠道连接器
- 多工作区隔离运行多个独立 Agent 实例

- 通过微信/Telegram 等聊天工具远程指挥 Agent 执行命令和管理文件

- 阅读源码学习现代 AI Agent 的构建方式
- 同时运行个人、工作、写作等多个隔离 Agent 实例
