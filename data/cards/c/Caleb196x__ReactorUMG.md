⭐ 42 · C++ · MIT · 推送 2026-02-04 · [GitHub](https://github.com/Caleb196x/ReactorUMG) · [官网](https://caleb196x.github.io/ReactorUMGOnlineDoc) · 个人维护 · 中文 README

**用 React + TypeScript 构建 Unreal Engine UMG 界面的插件**

Unreal Engine 插件，基于 PuerTS 脚本桥接，让开发者用原生 React、TypeScript、React Hooks 与 TSX 语法编写 UMG 游戏 UI 与编辑器 UI，支持热重载与编辑器内实时预览，可导入 Spine 动画。配套 AI Coding 工作流，README 标明尤其适合用 AI 快速搭建编辑器扩展工具面板。当前为 Alpha 阶段，API 可能变动，运行时 UI 支持情况尚不能完全满足生产级游戏 UI 要求；开发环境需 UE 5.x、Node.js>=18 与 Windows 10/11。

## 能力要点

- 支持 React Hooks、函数/类组件、TSX 语法与 UMG 组件
- PuerTS 调用引擎与编辑器脚本接口，作为 Blueprint 替代
- 编辑器内实时预览与热重载验证
- 可导入 Spine 动画，配套初学到进阶示例

## 适用场景

- 前端团队用 React 技术栈开发 Unreal Engine 界面
- 配合 AI Coding 快速搭建编辑器扩展工具面板
- 构建可复用的 UI 组件库并热重载迭代
