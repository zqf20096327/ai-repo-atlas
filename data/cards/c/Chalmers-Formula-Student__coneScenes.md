**Formula Student 无人车锥桶 3D 标注 LiDAR 点云数据集**

面向 Formula Student Driverless 车队的协作式 LiDAR 点云数据集，包含锥桶的 3D 边界框标注，用于感知算法开发。仓库提供 CLI 与工具用于管理数据集、贡献标注与扩展、通过 GitHub Discussions 协作；附带自动标注工具，可对自有数据生成标注。完整数据访问需车队贡献自己的标注场景，仅提供示例场景。原维护者已停止积极开发，项目处于非活跃/需维护状态。
