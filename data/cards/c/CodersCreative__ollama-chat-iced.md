**Rust/iced 编写的 Ollama 本地模型聊天 GUI**

基于 iced 图形库与 Rust 编写的桌面聊天应用：通过 Ollama 与本地模型对话并可在应用内拉取/下载模型，也支持下载运行 Hugging Face 上可用的模型；提供模型参数调整、Markdown 渲染、语音通话、麦克风转写、多面板/多窗口、多模型并行会话。安装方式为 cargo install ochat，需先安装 Ollama 并拉取模型（如 orca-mini:3b）。支持 Linux/Windows/macOS。
