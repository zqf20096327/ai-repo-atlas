**给前端/Node.js 开发者的零依赖股票行情数据 SDK（含 CLI 与 MCP）**

面向浏览器与 Node.js 18+ 的 JavaScript/TypeScript 股票行情 SDK，无需 Python 与后端服务，读取 A 股/港股/美股/公募基金的实时行情、K 线、分时，以及期货/期权/资金流/龙虎榜/北向/基金净值等扩展数据，并在本地计算 14 个技术指标、筹码分布、信号/选股/回测。数据来自腾讯财经、东方财富等公开接口，带限流熔断与备用源切换。附带 CLI 命令行工具与内置 MCP server，可通过 npx 接入 AI 工具。实时行情有数十秒到数分钟延迟。
