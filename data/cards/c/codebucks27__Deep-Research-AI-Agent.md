# codebucks27/Deep-Research-AI-Agent

⭐ 162 · TypeScript · 推送 2026-08-07 · [GitHub](https://github.com/codebucks27/Deep-Research-AI-Agent) · 个人维护

**用 Next.js 和多 LLM 构建的深度研究 AI Agent 示例项目**

基于 Next.js 16、Vercel AI SDK v6、Tailwind CSS 的 Deep Research Agent 全栈项目：通过 OpenRouter 接入 GPT-4o、Gemini、DeepSeek 等模型，配合 Exa Search API 执行迭代研究循环——生成追问、构造搜索查询并汇编研究报告。项目源自教程并做过依赖刷新（迁移到 Bun 包管理器），需要自备 OpenRouter 与 Exa 的 API key，通过 git clone 后 bun install 运行开发服务器。
