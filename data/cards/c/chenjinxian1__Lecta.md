**面向英语学习学生的课件精读工具：AI 笔记+查词+间隔复习**

Lecta 把 .pptx/.ppt/.pdf 课件渲染为阅读页，为每页幻灯片生成 AI 笔记（摘要、要点、关键术语、考点提示），点击任意单词弹出释义、英式 IPA 与音频，并配套测验、生词本与间隔重复复习（1→60 天间隔），按课程组织。AI 生成不强制 API key：可通过网页聊天复制粘贴提示词、由 Claude Code/Codex 等 AI 助手在本目录内代为执行，或使用 Claude 订阅/Anthropic SDK、OpenAI 及 OpenAI 兼容端点。需 Python 3.10+，完全本地运行。
