**AI 编程竞赛游戏环境：供开发者编写机器人对战**

Coder One AI Sports Challenge 2020 的游戏环境，供参赛者用 Python 编写 Agent 机器人进行对战。提供交互模式（键盘参与）、自动对局与无图形 headless 锦标赛模式，支持热重载（--watch）、对局录制（--record）与 config.json 配置（迭代数、tick 步长等，锦标赛中固定）。安装途径为 GitHub 发布的安装包或源码（pip 安装 requirements）。README 声明 2020 赛季已结束，2021 年将发布新版本，本仓库可作练习使用；并附参赛机器人目录。

## 能力要点

- 三种运行模式：交互、自动对局、headless 锦标赛模式
- --watch 热重载支持边运行边改 Agent 代码
- --record 录制对局动作供回看
- 支持多文件 Python Agent（含 __init__.py）

## 适用场景

- 编写和调试对战机器人 Agent
- 本地以交互模式人机同场探索游戏规则
- 跑随机对局或锦标赛模式评估 bot 表现
