# chrisryugj/kordoc

⭐ 3,106 · TypeScript · MIT · 推送 2026-11-21 · [GitHub](https://github.com/chrisryugj/kordoc) · [官网](https://pubax.org/kordoc/) · 个人维护

**供 AI 读写韩国公文文档的转换库：HWP/HWPX/PDF↔Markdown**

面向韩国公共文档的解析与生成工具：将 HWP 3.x/5.x、HWPX、HWPML、PDF、Office 文件及扫描图片转换为 Markdown、IR、RAG 分块等结构化输出，并可将 Markdown 生成 HWPX/HWP 公文，支持表格结构还原、OCR（含手写）、格式保持编辑、新旧对照、模板填充。以库、CLI、MCP 服务器三种形式提供，需 Node.js 20+，支持 KORDOC_OFFLINE=1 离线运行，OCR 本地执行无需 API key。作者为韩国地方公务员。

## 能力要点

- HWP/HWPX/PDF/Office/扫描图片→Markdown 与 RAG 分块，Markdown→HWPX/HWP 公文生成
- 本地 OCR 含手写识别与检测模型选择，离线模式 KORDOC_OFFLINE=1
- MCP 服务器提供 22 个工具，`npx -y kordoc setup` 自动注册到已装客户端
- README 附固定语料验证结果：HWPX 10,342 表结构全一致、PDF 文字召回 99.887%

## 适用场景

- 把机构里的 HWP/HWPX 公文批量转成 Markdown 供 AI 读取
- 为 RAG 索引生成带标题路径的结构化文档分块
- 用 AI 代理自动填充公文模板并保持原有版式
- 断网内网环境中本地解析文档与 OCR
