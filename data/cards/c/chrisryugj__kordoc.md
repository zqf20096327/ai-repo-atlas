# chrisryugj/kordoc

⭐ 3,156 · TypeScript · MIT · 推送 2026-11-27 · [GitHub](https://github.com/chrisryugj/kordoc) · [官网](https://pubax.org/kordoc/) · 个人维护

**让 AI 读取和生成韩国公文：HWP/HWPX/PDF 解析与转换**

面向韩国公文场景的文档处理工具，以库、CLI、MCP 服务器三种形态提供。读取 HWP 3.x/5.x、HWPX、PDF、Office 文档与扫描图片并输出 Markdown、结构化数据与 RAG 分块；将 Markdown 生成 HWPX/HWP 公文，支持格式保留编辑、新旧对照、表单填写、印章、公文用语校对，并内置本地 OCR 与离线模式。面向需要接入 AI 客户端或批量处理公文的开发者与机构，需 Node.js 20 以上。

## 能力要点

- 读取 HWP/HWPX/PDF/Office/扫描图并输出 Markdown、IR、RAG 分块，扫描件自动启用本地 OCR
- Markdown 生成 HWPX/HWP 公文，支持格式保留补丁、模板套用、字段与按鈕框填写
- MCP 服务器提供 22 个工具，可注册到 Claude Desktop/Claude Code/Cursor 等客户端
- 支持离线封闭网络（KORDOC_OFFLINE=1）与 gVisor 沙箱运行

## 适用场景

- 把机构存量 HWP/HWPX/PDF 公文批量转成 Markdown 供 AI 或 RAG 检索使用
- 让 Claude/Cursor 等 AI 客户端通过 MCP 读取、比对、填写韩文公文
- 按机构模板生成公文并做新旧文对照与格式保留编辑
