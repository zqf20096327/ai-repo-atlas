**低代码/无代码全栈企业应用构建与自托管平台**

Convertigo Community Edition 是开源的 Low Code 与 No Code 平台，用于构建并自托管企业级 Web、移动与 PWA 应用。平台由三部分组成：Convertigo Server（后端连接器、微服务执行、离线数据同步，以 Docker 容器、HELM Chart 或 Tomcat WAR 提供）、基于 Eclipse 的 Convertigo Studio（Windows/macOS 桌面 IDE，编写后端微服务工作流与移动应用 UI）、面向非技术人员的 No Code Studio（表单类应用构建）。README 另列出 AI Knowledge Center 与 MCP Server、AI Agents 相关条目，采用 AGPL 许可。
