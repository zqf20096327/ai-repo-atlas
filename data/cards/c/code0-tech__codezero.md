**面向团队的开源可视化自动化/无代码后端平台，AI 辅助搭建流程**

CodeZero 提供可视化节点画布构建 flow，用于服务集成、暴露自有 HTTP API、定时任务与多步业务流程。AI 用于从自然语言生成、修改与重写流程，支持接入 OpenAI、OpenRouter 或兼容 provider 并自选工作区模型。可完全自托管或混合部署（云端 IDE + 自有硬件运行时），运行时组件可独立扩展，含组织/项目/角色与细粒度权限。通过 git clone 与 Docker Compose 部署，许可按组件各异。
