# Dereje1/Pinboard

⭐ 92 · TypeScript · MIT · 推送 2026-07-22 · [GitHub](https://github.com/Dereje1/Pinboard) · [官网](https://pclone.derejegetahun.com/) · 个人维护

**教学用途的 Pinterest 风格全栈图片收藏与分享应用（MERN）**

用 MERN 栈（MongoDB、Express、React、Node.js）加 TypeScript、Redux、Material UI 构建的全栈 Web 应用，作为学习项目开发：用户可通过网页链接生成图片、上传自己的图片，或使用 OpenAI 图像生成功能创建图钉（pin），支持 Google 与 GitHub 登录。README 声明普通图片上传与 pin 创建不依赖 AI 图像生成功能。提供 npm 本地开发流程与 Docker 构建，生产部署经 ECR/Elastic Beanstalk。
