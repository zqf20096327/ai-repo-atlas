**CLI 工具：用自然语言查回终端命令**

Zev 是一个终端 CLI 工具，用户以自然语言描述想做的事，工具调用 LLM 生成对应 shell 命令，支持交互模式与直接查询两种方式。提供危险命令警告提示，但不保证全部拦截。运行依赖 LLM API 后端，通过 zev --setup 配置 provider 与密钥；支持 OpenAI、Gemini、Ollama、Azure OpenAI、Anthropic 五种后端，其中 Ollama 可完全本地运行。macOS 经 Homebrew 安装，Linux 经 pipx 安装。Linux 下剪贴板功能需 xclip/xsel/wl-clipboard。

## 能力要点

- 自然语言输入生成终端命令，含交互与直查两种模式
- 支持 5 种 LLM 后端，可随时用 zev --setup 切换
- Ollama 后端支持完全本地运行
- 内置危险命令警告机制

## 适用场景

- 忘记某个 shell 命令时用自然语言查回
- 不熟悉终端操作时发现新命令
- 本地通过 Ollama 离线生成命令
