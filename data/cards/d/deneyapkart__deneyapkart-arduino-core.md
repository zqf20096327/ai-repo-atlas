**土耳其 Deneyap 开发板的 Arduino Core 板级支持包**

为土耳其设计制造的 Deneyap Kart / Kart 1A / Kart G / Mini 等系列开发板提供 Arduino Core 支持，基于 ESP32 架构。通过 Arduino IDE 的 Boards Manager 添加 JSON 索引链接即可安装并选择对应板型。README 提供各板型及 v2 版本的引脚图（标准版与扩展版），并说明通过 issue 模板报告问题。面向从初学者到专业用户的电子、IoT 与 AI 项目开发场景。
