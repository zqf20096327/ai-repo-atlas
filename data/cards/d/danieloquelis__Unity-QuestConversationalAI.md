**Unity 实时语音对话 AI 包，接入 OpenAI 与 ElevenLabs**

面向 Unity 项目（主要针对 Meta Quest 头显）的实时语音对话 AI 包集合：集成 OpenAI Realtime API 与 ElevenLabs 对话服务，跳过传统语音转文本→文本转语音流程，实现低延迟语音到语音交互。提供 OpenAI 与 ElevenLabs 两组文档，含安装、API key 配置、核心 Prefab、自定义工具与事件说明，以及多个示例场景。要求 Unity 6000.0.53f1 (LTS) 与 Meta SDK 77.0.0，支持 Meta Quest 与 Unity PC 平台；Meta SDK 78 存在麦克风权限问题。MIT 许可。
