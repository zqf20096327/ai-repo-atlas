**以太坊钱包交互的 Rivalz Fragmentz 自动领取机器人**

Node.js 编写的命令行机器人，面向参与 Rivalz 测试网空投的用户：读取 privateKeys.json 或 accounts.json 中的以太坊私钥/助记词，支持查询各钱包余额、一次性领取 Fragmentz，以及设置每 12 小时自动循环领取的定时任务，通过交互式 CLI 菜单（输入 0/1/2）操作。需 Node.js 16+，git clone 后 npm install 并 npm start 运行。仓库名含 'AI' 但 README 未描述任何 AI 功能。
