**电商数仓自然语言问数 AI Agent 实战项目与配套教程**

基于 LangGraph 编排的电商数据仓库问数系统：先从教学数仓抽取表、字段、指标与取值构建元数据知识库（MySQL/Qdrant/Elasticsearch 三路存储），查询时对字段、指标、取值做混合召回，再由 LLM 分步推理生成 SQL，经 EXPLAIN 校验与错误修正后执行，通过 FastAPI + SSE 流式返回到 React 前端。同时是 ai-agents-from-zero 教程体系的配套源码仓库，提供 17 个章节的图文讲义与对应 Git 分支，面向想学习 LangGraph 与 AI Agent 工程开发的学习者。
