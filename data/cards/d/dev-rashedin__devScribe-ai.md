**面向开发者与写作者的文本 AI 助手 Web 应用**

基于 React 19/TypeScript/Tailwind CSS 前端与 Node.js/Express/MongoDB 后端的全栈 Web 应用，通过 Nebius Studio 接入 AI，面向开发者与写作者提供简历助手、文档摘要、文章生成、代码解释、代码重构、邮件辅助等文本服务。支持 Firebase 认证（邮箱、Google、GitHub）、按服务分类的历史会话记录，Stripe 订阅与管理面板为规划中的功能。项目自述为作者的全栈开发能力展示作品。

## 能力要点

- 提供简历助手、文档摘要、代码解释/重构、邮件辅助等 6 类文本 AI 服务
- Firebase 认证（邮箱/Google/GitHub）与服务级聊天历史追踪
- 全栈 TypeScript 架构，后端使用 MongoDB/Mongoose 与 Nebius Studio AI 集成
