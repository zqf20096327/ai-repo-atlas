**让 AI 编程工具读取蓝湖需求与设计稿的 MCP 服务器**

面向蓝湖设计交付流程的 Model Context Protocol 服务器：下载并解析 Axure 需求页、截图与注释，提供开发/测试/探索三种分析视角与四阶段工作流；读取 UI 设计稿并返回尺寸/间距/颜色等参数与 HTML+CSS 参考，下载切图并语义化命名；内置团队留言板（normal/task/question/urgent/knowledge 五类），支持飞书 @提醒与按 Cookie 的多账号请求头隔离。支持 HTTP 与 stdio 两种启动方式，Docker 或 Python 3.10+ 源码部署，需配置蓝湖 Cookie。

## 能力要点

- 16 个 MCP 工具：需求页分析、设计稿局部读取、切图导出、留言板增删查改
- 团队知识库：所有接入的 AI 助手共享留言板与上下文，knowledge 类型永久保存
- HTTP 按请求隔离蓝湖 Cookie，多人共用同一服务
- 基于版本号的缓存与增量更新，长页返回带重叠区域的分块截图

- 批量下载设计切图并按项目类型输出到工程目录
- 团队踩坑经验沉淀为可搜索的知识库留言
