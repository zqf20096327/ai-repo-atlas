# DINKIssTyle/DINKIssTyle-Markdown-Browser

⭐ 43 · JavaScript · MIT · 推送 2026-10-21 · [GitHub](https://github.com/DINKIssTyle/DINKIssTyle-Markdown-Browser) · 个人维护 · 中文 README

**跨平台 Markdown 阅读/编辑器，内置本地 LLM AI 助手**

基于 Go/Wails 与 CodeMirror 的 Markdown 查看与编辑器：阅读端支持超链接导航、大纲侧栏、KaTeX 公式与 Mermaid 图表渲染、主题与打印；编辑端支持语法高亮、`/` 快捷工具栏、链接/图片插入、查找替换与 CJK 兼容模式。AI 功能通过本地 LLM 提供写作辅助（选中改写/翻译、FIM 补全、GFM 兼容、温度调节），不保存对话上下文，推荐 3B~4B 模型。提供 Windows/macOS/Linux 可执行文件下载，高级用户可从源码构建。
