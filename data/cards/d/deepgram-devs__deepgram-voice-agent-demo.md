**Deepgram Voice Agent API 的网页演示应用**

基于 Next.js 构建的语音助手演示网页，演示 Deepgram Voice Agent API 的能力。运行需自备 Deepgram API Key（需 usage:write 权限），通过环境变量注入；本地开发要求 Node v20+ 与 Yarn，安装依赖后以 yarn dev 启动，Next.js 提供 localhost 访问地址。提供在线 demo 链接，属于 bring-your-own-key 的开发者演示项目，未声明产品级部署支持。
