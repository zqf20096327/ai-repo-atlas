**面向 NLP 开发者的中文文本预处理与解析工具包**

JioNLP 是面向中文 NLP 开发者的 Python 工具包，覆盖预处理、解析与辅助建模环节：小工具集（时间语义解析、地址解析、身份证/车牌解析、拼音、繁简转换等）、文本数据增强（回译、同音替换等）、正则抽取与清洗、NER 辅助工具（词典 NER、tag 与实体互转、数据集切分）、文本分类与情感分析辅助、词典加载（成语、歇后语、中国地名、LLM 评测数据集等）。以 pip 包分发，另含 MELLM 自动评测算法示例，附 GitHub 引用格式与微信交流群。

## 能力要点

- 提供时间语义解析、地址解析、身份证/车牌/电话号码解析等中文特色功能
- 文本数据增强：回译、同音词替换、实体替换、随机增删字符
- 正则抽取与清洗：抽取/删除/归一化 E-mail、URL、电话、IP、身份证等
- 内置成语、歇后语、中国省市县地名、新华字典等多类词典加载器与 LLM 评测数据集

## 适用场景

- 为中文 NLP 任务做文本清洗、分句、停用词过滤等预处理
- 解析文本中的时间、地址、金额、身份证等结构化信息
- 用回译和实体替换扩充 NER/分类训练语料
- 加载中文词典资源辅助词典 NER 与情感分析
