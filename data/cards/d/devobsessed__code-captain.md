**面向 AI 编程助手的开发工作流系统：结构化需求/规划/实施**

Code Captain 是安装在 Cursor、GitHub Copilot+VS Code、Claude.dev 三类 AI 开发环境中的工作流与命令系统：提供产品规划、技术调研、特性规格、架构决策记录、测试驱动实施、项目状态等结构化命令，生成组织化的文档目录（.code-captain/ 及各 IDE 专属目录）。通过 npx 交互式安装器自动检测环境并完成集成，要求 Node.js 16+。命令语法随 IDE 不同而异，详见各平台文档。
