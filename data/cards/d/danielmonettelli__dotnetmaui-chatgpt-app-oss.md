**用 .NET MAUI 复刻 ChatGPT 的开源聊天应用**

基于 .NET MAUI 构建的开源跨平台聊天应用，接入 OpenAI API 生成文本与图像聊天回复，作者定位为复刻 ChatGPT 功能的 UI 挑战项目。使用前需自建 OpenAI 账号并将 API key 写入项目内的 OpenAIToken 常量，从源码构建运行。功能包括明暗主题切换动画、Lottie 空态动画、文本/图像聊天模式切换，支持多平台，部分界面适配仍在完成中。附有西语教程与系列文章。
