# Dodaios/Dodaios

**在本地桌面统一管理多个编码 agent 的 AI 助手工作台**

Dodaios（前身为 Personal Jarvis）是一个开源桌面应用，将 Claude Code、Codex 等多个编码 agent 并行放在一个工作区内，由一个助手统一运行；支持语音交互（唤醒词即助手名）、文档与 computer-use 能力，声明可自我改进。本地运行，使用用户自己的模型计划与 API key，采用 MIT 许可。安装脚本会自建 Python 环境并添加启动器；编码工作需至少安装一个编码 agent 并登录。
