**QQ 群聊/私聊 AI 机器人：多模型对话+Agent+插件+WebUI**

基于 NoneBot2 + OneBot V11 的 QQ 机器人，通过 NapCat 反向 WebSocket 接入 QQ。功能包括多模型对话（OpenAI/Claude/DeepSeek/Gemini/通义千问/Moonshot 等）、50+ 内置工具的 Agent 系统、置信度路由、音乐点播、联网搜索、B站/抖音等视频解析、图片生成、热插拔插件系统，以及 React 前端的 Web 管理面板。提供 Linux 一键部署脚本、Windows/macOS 手动部署与 yukiko CLI 运维命令；需 Python 3.10+、Node.js 18+、ffmpeg 与 OneBot V11 服务。
