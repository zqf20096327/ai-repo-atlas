**macOS PopClip 扩展：选中文本直接调用 ChatGPT 处理**

为 macOS 文本选中工具 PopClip 编写的 ChatGPT 扩展：选中文本后可与 ChatGPT 对话，内置改写、润色纠错、翻译、总结等预设动作，按应用维护 20 分钟过期的上下文历史；兼容任何 OpenAI chat completions 格式 API，并对 Microsoft Azure OpenAI 服务提供专门支持。结果可直接粘贴回当前应用，否则复制并预览。扩展未经官方签名，安装时会触发系统警告。

## 能力要点

- 选中文本直接与 ChatGPT 对话，支持按应用隔离的上下文历史（20 分钟过期）
- 内置改写、润色纠错、翻译、总结等预设动作，Shift 键切换次语言
- 兼容任何 OpenAI chat completions API，专门支持 Azure OpenAI
- 结果直接粘贴回当前应用，不可粘贴时复制并预览

## 适用场景

- 在任意应用中选中文本让 ChatGPT 改写、翻译或总结
- 写作时快速润色与语法纠错
- 使用自有 OpenAI 兼容 API 或 Azure OpenAI 服务处理选中文本
