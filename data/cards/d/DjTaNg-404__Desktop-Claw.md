⭐ 33 · TypeScript · MIT · 推送 2026-04-27 · [GitHub](https://github.com/DjTaNg-404/Desktop-Claw) · 个人维护 · 中文 README

**常驻桌面的悬浮球 AI 伙伴，带记忆与文件处理**

Electron + React + TypeScript 构建的桌面 AI Companion，以悬浮球形态常驻 macOS/Windows 桌面，提供双击快速提问、流式对话、本地文件读写（.pdf/.docx/.xlsx 文本提取）与轻记录。记忆体系包含 6 类结构化记忆对象、按天归档为 JSON、日历视图回顾、后台记忆提取与记忆纠错，SOUL.md 定义人格。接入 OpenAI 兼容 API，需支持 Function Calling 的 LLM API Key（README 推荐 DeepSeek）。GitHub Actions 自动构建双平台安装包，项目自述处于积极开发中。
