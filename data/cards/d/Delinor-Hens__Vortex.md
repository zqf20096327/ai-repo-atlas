# Delinor-Hens/Vortex

⭐ 14 · C++ · GPL-3.0 · 推送 2026-09-11 · [GitHub](https://github.com/Delinor-Hens/Vortex) · 个人维护

**Windows 桌面 AI 助手：本地离线模型与多家云端 API 聊天及代码生成**

C++ 后端加 Python GUI 的桌面应用。内置本地模型 qwen3.5:4b（经 Ollama 运行）可完全离线使用，也可配置 OpenAI、Anthropic、Gemini、Mistral、DeepSeek、OpenRouter、Groq、Together 等 API。功能含三档生成模式、代码生成/解释/修复/多语言运行、图像与文本附件、等待时的小游戏、多主题与流式输出，API 密钥经 DPAPI 加密。仅支持 Windows 10/11 64 位，通过 Setup.exe 安装。
