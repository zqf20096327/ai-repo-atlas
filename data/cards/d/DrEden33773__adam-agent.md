**Linux 终端本地编程 Agent：读改代码、审批命令、多代理协作**

TypeScript 编写的本地编程代理，面向 Linux 终端用户：读取/搜索/修改代码、审阅编辑、审批 shell 命令、跟踪 Todo，并可委派 Explore/Research 子代理处理探索与研究任务。支持会话历史（恢复/分叉/归档/回收站）、Skills 选择、Plan 模式与 MCP 集成。通过 DeepSeek API 密钥指定模型目标运行，提供可移动的本地安装包与 headless CLI。文件工具限制在项目路径内，命令与委派均需审批，且不提供 OS/进程/网络沙箱。
