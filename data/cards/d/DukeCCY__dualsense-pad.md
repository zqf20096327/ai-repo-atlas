# DukeCCY/dualsense-pad

⭐ 6 · Python · MIT · 推送 2026-11-04 · [GitHub](https://github.com/DukeCCY/dualsense-pad) · 个人维护 · 中文 README

**把 PS5 手柄触摸板变成给 AI 角色的触觉输入**

一个只做协议翻译的本地工具：以 250Hz 读取 DualSense 触摸板坐标，解析点/拍/划/抚摸等 8 类手势与 15 个键位，并通过 127.0.0.1 的 HTTP 端点暴露状态，上层程序可用 /pulse、/light 以震动与灯条回写反馈。零依赖，仅用 Python 标准库，无需驱动或管理员权限。仅支持 Windows 10/11 与 USB 报文形态（蓝牙不支持），定位是给本地 agent 角色补触觉通道。

## 能力要点

- 250Hz 原始坐标（1920×1080）与单指/双指读取
- 8 类手势识别与事件外推 webhook（默认关闭）
- 两路马达震动与 RGB 灯条回写，仅监听 127.0.0.1
- 零依赖：只用 Python 标准库 ctypes，不装驱动

## 适用场景

- 给桌面常驻的 AI 角色加触摸交互通道
- 本地 agent 通过 /state 轮询手柄触摸事件
- 网页 demo 或桌面挂件读取手柄输入做交互
