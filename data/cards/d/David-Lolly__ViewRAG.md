# David-Lolly/ViewRAG

⭐ 26 · Python · MIT · 推送 2026-02-27 · [GitHub](https://github.com/David-Lolly/ViewRAG) · 个人维护 · 中文 README

**图文并茂的 PDF RAG 问答系统：版式分块、图表理解与引用溯源**

面向终端用户的多用户 PDF 问答系统：上传 PDF 后经 PaddleX 版式解析、PyMuPDF 按 bbox 裁剪图片存入 MinIO、基于版式保留段落结构的智能分块，再调用视觉与文本 LLM 生成图表语义描述并向量化存入 pgvector；回答中内联引用图片并附带页码/片段/PDF 高亮定位溯源。支持多轮问题重写、知识库与会话文档、多用户多会话，所有模型经 OpenAI 兼容 API 接入。限制：依赖外部 PaddleX API 做版式解析，本地解析在后续计划中。

## 能力要点

- 基于版式识别的分块（保留段落结构，块大小 1024）
- 视觉 LLM 生成图表语义描述提升检索命中率
- 回答内联引用图片 + PDF 高亮定位溯源
- 多用户/多会话、知识库管理、任意节点编辑重生成

## 适用场景

- 上传含图表的 PDF 提问并获得图文并茂带溯源的回答
- 团队多用户各自维护知识库统一检索
- 多轮对话中追问并基于历史重写检索问题
