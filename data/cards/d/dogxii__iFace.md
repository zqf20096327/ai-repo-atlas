**工程师面试刷题工具，内置题库与自定义 AI 教练辅助**

面向前端、Golang、Java、AI Agent 等工程师的本地刷题工具：内置题库并支持 JSON/Markdown 导入与粘贴 AI 生成的题目，提供按模块/难度/状态组合练习、间隔复习、薄弱点分析与全局搜索。AI 面试教练功能（拆题、评分作答、追问、模拟面试、简历 JD 诊断）需用户自行填入 API Key 与 Base URL 接入模型。全部数据存于浏览器本地，支持导入导出备份与 GitHub Gist 同步，无需注册与服务器，可安装为 PWA 离线使用。
