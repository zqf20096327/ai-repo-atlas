**AI agent 与 LangGraph 示例项目集：多框架 agent 用法学习仓库**

收录多个 agent 示例工程的集合仓库：包括 YouTube 视频 RAG 问答 agent（Streamlit UI、FAISS 检索、LM Studio/Gemini 双后端）、CSV 数据分析九步顺序工作流、A2A 多 agent 演示、LangGraph 四个教学脚本（基础循环、线程记忆、人格分支、动态温度）、工具调用从零实现、Groq ReAct agent、MongoDB 自然语言查询、Ollama/Agno/Phidata/AgentScope/BeeAI 等框架示例。全英文文档，附截图与运行命令，面向学习 agent 框架用法的开发者，通过 git clone 后建虚拟环境并 pip 安装依赖运行。

## 能力要点

- YouTube 视频 RAG 问答 agent：转录提取+FAISS 向量检索+Streamlit UI
- LangGraph 教学脚本：线程记忆、人格分支对比、动态温度选择
- 工具调用从零实现：手动五步流程与 7 个可用工具（搜索/天气/汇率等）
- 覆盖 Ollama、LM Studio、Groq、Gemini、Agno、AgentScope 等多种框架与后端

## 适用场景

- 学习 LangGraph 状态图与多 agent 工作流写法
- 参考本地 LLM（Ollama/LM Studio）接入 agent 的示例
- 复用 YouTube 视频 RAG 问答或 CSV 分析 agent 的完整流程
