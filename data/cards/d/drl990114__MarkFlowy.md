**本地优先的 Markdown/通用文本编辑器，可选接入 AI**

基于 Tauri 与 Web 前端构建的跨平台桌面应用，支持所见即所得、Markdown 源码与阅读三种模式，覆盖表格、任务列表、数学公式、Mermaid 图、代码片段、本地历史、主题定制与工作区搜索。AI 为可选功能：用户自行配置 OpenAI 兼容服务、DeepSeek、Google 或本地 Ollama 后端后可用聊天、摘要、翻译与 Copilot；不配置 AI 也可完整使用本地编辑功能。通过 GitHub Releases 安装包分发，Linux 提供 Flatpak 与安装脚本。

## 能力要点

- 所见即所得/Markdown 源码/阅读三种编辑模式
- 可选 AI 功能：聊天、摘要、翻译、Copilot，支持本地 Ollama 端点
- 本地历史对比与草稿恢复
- 导出 HTML/图片/PDF，装 Pandoc 后支持 DOCX/ODT/EPUB

## 适用场景

- 在本地文件夹中组织和写作 Markdown 笔记

- 需要大型 Markdown 文档流畅编辑的场景
- 离线环境下的纯本地写作（无账号无 AI）
