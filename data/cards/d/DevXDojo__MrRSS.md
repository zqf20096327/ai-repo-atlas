**跨平台 AI RSS 阅读器：订阅、翻译、摘要与自动化**

用 Go + Wails + Vue.js 构建的跨平台 RSS/Atom 阅读器，Windows/macOS/Linux 提供安装包与便携版。核心功能包括订阅源管理（URL、XPath、脚本、邮件等多种订阅方式）、文章标题与内容的自动翻译和摘要生成、推荐、内置过滤与脚本自动化系统，以及与 Obsidian、Notion、FreshRSS、RSSHub 的集成。另提供 REST API 的本地接口与可 Docker 部署的无头服务器版本，支持 Codex 通过技能包操作本产品。
