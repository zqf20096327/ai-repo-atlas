# DevXDojo/MrRSS

⭐ 2,669 · Go · GPL-3.0 · 推送 2026-11-22 · [GitHub](https://github.com/DevXDojo/MrRSS) · [官网](https://mrrss.ch3nyang.top/) · 组织维护 · 中文 README

**面向个人用户的跨平台 AI RSS 阅读器，支持翻译与摘要**

基于 Go/Wails v3 与 Vue.js 构建的桌面 RSS 阅读器，支持 Windows/macOS/Linux 三平台。核心功能：自动翻译文章标题与内容、生成摘要、AI 推荐，并可通过技能（skills）读取和操作；订阅方式覆盖 URL、XPath、脚本、newsletter 等类型；提供插件生态对接 Obsidian、Notion、FreshRSS、RSSHub；内置过滤器与脚本系统实现自动化工作流。分发形式包括预构建安装包、便携版、源码构建以及 headless server 的 Docker 镜像（REST API 限定本机访问）。
