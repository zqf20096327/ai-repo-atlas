# dmMaze/BallonsTranslator

⭐ 5,321 · Python · GPL-3.0 · 推送 2026-11-26 · [GitHub](https://github.com/dmMaze/BallonsTranslator) · 个人维护 · 中文 README

**深度学习辅助的漫画翻译工具：一键机翻加图像文本编辑**

基于 PySide/PyQt 的桌面漫画翻译工具，流水线包含文本检测、OCR、图像修复（抹字）与机器翻译四个模块，支持日漫和美漫，译文回填参考原排版（颜色、轮廓、角度、对齐）。翻译器可选谷歌、彩云、papago、DeepL、Sugoi、m2m100、Sakura-13B 及 OpenAI 兼容 LLM 接口，LLM 翻译支持上下文翻译历史、可复用术语表、视觉上下文与摘要记忆机制，并提供 Token 预算与缓存费用估算。提供图形界面、无 GUI 命令行模式，Windows/macOS/Linux 均有安装脚本或免配置压缩包。

## 能力要点

- 一键机翻：文本检测、OCR、抹字、翻译四模块流水线
- LLM 翻译支持翻译历史、术语表、单页摘要与项目级记忆
- 支持掩膜编辑、修复画笔与所见即所得富文本嵌字
- 无 GUI 命令行批处理模式，设置从 config.json 导入
