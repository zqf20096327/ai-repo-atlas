# dmMaze/BallonsTranslator

⭐ 5,318 · Python · GPL-3.0 · 推送 2026-11-21 · [GitHub](https://github.com/dmMaze/BallonsTranslator) · 个人维护 · 中文 README

**面向漫画读者的深度学习辅助漫画翻译与嵌字工具**

基于深度学习的桌面端（PyQt）漫画翻译工具，串联文本检测、OCR、图像修复（抹字）、机器翻译四个模块，支持一键机翻、译文回填原文排版（颜色/轮廓/角度/对齐），并提供掩膜编辑、修复画笔、富文本编辑、Word 导入导出等编辑功能。内置 LLM 翻译支持翻译历史、术语表、视觉上下文与摘要记忆机制。提供 Windows/macOS/Linux 图形界面与无 GUI 命令行模式；文本检测目前仅支持日文和英文，机翻结果需注明方可公开分享。
