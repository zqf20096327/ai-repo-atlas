# debabrataswainiitp/VITREON

⭐ 20 · TypeScript · MIT · 推送 2026-09-28 · [GitHub](https://github.com/debabrataswainiitp/VITREON) · 个人维护

**多智能体 AI 编排平台：在统一界面路由任务给专职 agent**

基于 Next.js 14 与 Vercel AI SDK 构建的多智能体 AI Web 应用：提供 Prism、Lucent、Refract、Spectrum 四个面向编程、研究、创意与数据分析的智能体，通过 OpenRouter 拉取免费模型做路由推理，配流式输出与异步数据库缓存；含 Clerk 认证、Prisma/PostgreSQL 存储与 Razorpay 订阅付费集成。本地运行需 Node.js 18+，git clone 后 npm install 并配置 .env 环境变量。

## 能力要点

- 四个专职智能体（Prism/Lucent/Refract/Spectrum）按任务类型切换
- 通过 OpenRouter 动态拉取免费模型进行推理
- 异步数据库缓存与模型路由优化首 token 延迟
- Clerk 认证与 Razorpay 订阅付费集成

## 适用场景

- 在统一界面中按任务类型切换不同的 AI 智能体
- 使用免费模型完成编程、研究与创意写作任务
- 搭建带订阅付费层级的 AI 应用
