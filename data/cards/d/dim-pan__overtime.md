# dim-pan/overtime

⭐ 3 · Apache-2.0 · 推送 2026-10-18 · [GitHub](https://github.com/dim-pan/overtime) · 个人维护

**自托管服务器上的常驻 AI agent 舰队指挥中心（Mac/iOS 原生应用）**

开源自托管平台：在用户自有服务器上以现成 VM 模板部署多个 Claude Code 与 Codex agent，每个 agent 获得独立的计算机与浏览器，工作区相互隔离，可扩展至约 100 个 agent。通过 Swift 原生 Mac/iOS 应用以工作视图（步骤、diff、实时屏幕）而非聊天方式管理，可随时接管、批准或中断；支持 agent 间协作交接、定时任务、内存与 Telegram。数据与登录凭据保留在用户机器上。Apache-2.0 许可。

## 能力要点

- 每个 agent 独立计算机与浏览器，工作区隔离于自有服务器
- 工作视图管理：步骤、diff、实时屏幕，可随时接管或批准
- 现成 VM 模板，几分钟内创建新工作区
- Swift 原生 Mac/iOS 应用，支持 agent 间任务交接

## 适用场景

- 同时运行数十个营销、销售、工程类 AI agent 处理日常业务
- 在自有服务器上托管 agent 以保留登录与数据控制权
- 通过实时屏幕监控并随时接管 agent 的浏览器操作
