**面向 Java 开发者的引擎无关深度学习框架**

Deep Java Library 是一个引擎无关的高级 Java 深度学习框架，为 Java 开发者提供原生开发体验，可像普通 Java 库一样使用。用户无需深度学习专家背景，可在熟悉 IDE 中构建、训练和部署模型，并集成到 Java 应用。框架不绑定具体引擎，可随时切换，并依据硬件配置自动选择 CPU/GPU。提供模型加载推理与网络构建训练的 API；源码通过 Gradle 构建，采用 Apache-2.0 许可。
