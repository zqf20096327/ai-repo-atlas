# Dpro-at/Dpro-Bot

⭐ 70 · TypeScript · MIT · 推送 2026-10-24 · [GitHub](https://github.com/Dpro-at/Dpro-Bot) · [官网](https://agent-player.com) · 个人维护

**给个人与企业的 AI 员工桌面助手：请求路由到专属 agent 执行**

开源桌面应用（Windows/macOS/Linux 安装包，Tauri + Next.js + Fastify + SQLite）：用户发起一次请求，系统将其路由到角色、个性、长期记忆与权限各异的 agent，由其规划、拆分任务并在共享任务板上执行汇报。支持云端或本地模型按 agent 指定，通过 Claude Code/Codex 使用用户已有订阅而非另付 API 账单，轻量任务走本地小模型。集成 Telegram/WhatsApp/Discord/Slack 等渠道，含市场看盘与交易（纸面模式）扩展；3D 世界 GenVR、合规审查、手机端为开发中功能。

## 能力要点

- 请求路由到具备角色/记忆/权限的专属 agent
- 通过 Claude Code 与 Codex 复用用户已有 Claude/ChatGPT 订阅
- 本地小模型处理轻量任务以节省付费 token
- Telegram/WhatsApp/Discord/Slack/邮件/网页多渠道接入

## 适用场景

- 让一组 AI agent 员工在我的任务板上代为规划与执行工作
- 用已有 Claude/ChatGPT 订阅驱动 agent，不想另付 API 账单
- 通过 Telegram 或手机跟进 agent 团队的工作进度
