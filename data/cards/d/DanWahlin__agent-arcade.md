# DanWahlin/agent-arcade

⭐ 19 · TypeScript · MIT · 推送 2026-10-20 · [GitHub](https://github.com/DanWahlin/agent-arcade) · [官网](https://danwahlin.github.io/agent-arcade/) · 个人维护

**桌面透明覆盖层复古街机游戏合集，供等待 AI agent 时游玩**

基于 Tauri + Phaser + TypeScript 构建的复古街机游戏合集，包含 6 款游戏（太空入侵者、小行星、Galaga 风格射击、平台跳跃、Defender 风格、导弹防御），以透明覆盖层形式运行在桌面上，定位是供用户在等待 AI agent（Copilot CLI、Claude Code、Codex 等）完成工作期间游玩。附带 Copilot CLI canvas 扩展，agent 可在侧边面板打开游戏并调用列出/选择/重启游戏的动作。作者自述项目由 Copilot CLI 协助构建，仍处于实验阶段。提供 Windows 安装包（已签名）、macOS dmg 与 Linux AppImage/deb。
