**DeepSeek Harness 的社区插件市场插件，应用内浏览与一键安装插件**

以 DSH 插件形式安装进 DeepSeek Harness（网页版 dsh web 或桌面版），在「设置 → 插件市场」内提供社区插件的浏览、搜索、一键安装/升级/卸载与任务留痕。收录数据来自 dsh-plugin.org，主站收录 27,000+ 插件，其中 7,000+ 已发布 NPM 包并可一键安装，条目经人工审核并标注分类、Star/Fork 与来源仓库。安装仅提供 npm 一条命令方式，不提供源码/git 安装；需要 Node.js ≥ 22.6、pnpm 与可用 npm 源。声明为独立社区项目，与 DeepSeek Harness 官方无隶属关系。
