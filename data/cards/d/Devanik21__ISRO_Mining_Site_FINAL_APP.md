**面向太空采矿选址的 ML 分析 Streamlit 应用**

基于 Streamlit 构建的太空采矿勘探分析平台，针对天体采矿选址提供预测模型（预测潜在采矿点）、个性化推荐引擎、探索性数据分析（聚类与离群点检测）、交互式可视化与洞察模块。数据为合成数据集，特征包括矿物成分、估计价值、可持续性指数、距地距离等。技术栈含 Python、scikit-learn、TensorFlow/Keras、Plotly 等。通过 git clone 源码安装依赖后以 streamlit run 运行。曾参与 GSSoC Ext 2024 开源活动。
