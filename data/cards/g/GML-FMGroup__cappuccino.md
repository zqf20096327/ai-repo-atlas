**基于桌面屏幕纯视觉的本地 GUI 自动化 Agent**

卡布奇诺是一个通过操控电脑桌面执行任务的 GUI Agent：接收一条指令后生成任务规划并基于屏幕截图纯视觉方案执行操作，区别于解析图片元素或调用浏览器接口的方案。支持部署在 Windows/Mac 的被控计算机上，模型可通过供应商 API 或 OpenAI 兼容的本地部署（推荐 vLLM）接入；指令可经 Python 脚本或 Telegram 发送，2026 年更新加入 MCP 模块与 server 架构（暂不兼容客户端方式）。架构支持自定义执行器扩展与针对特定软件微调模型。
