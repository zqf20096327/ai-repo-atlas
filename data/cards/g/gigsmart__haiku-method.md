# gigsmart/haiku-method

⭐ 28 · TypeScript · Apache-2.0 · 推送 2026-05-29 · [GitHub](https://github.com/gigsmart/haiku-method) · [官网](https://haikumethod.ai/) · 组织维护

**Claude Code 插件：将 AI 辅助工作结构化为带质量门的生命周期框架**

H·AI·K·U 是一个 Claude Code 插件，将任意领域的 AI 辅助工作编排为 Studio>Stage>Unit>Bolt 四层生命周期：内置 12 个工作室（软件、数据管道、销售、营销、合规等），每个阶段经历分解、执行、对抗性审查、持久化、质量门五步循环。以单一二进制（TypeScript 编译）提供 MCP 服务器（16 个状态工具）、10 个 hooks 与编排器；状态存于提交的 markdown/json 工件中。支持六类双向 provider（Jira/Linear/Notion/Figma/Slack/Salesforce 等）由 Claude 中介集成。通过 /install 命令安装，无外部依赖；另配网站、论文与浏览器浏览功能。
