# GeekyWizKid/writing-helper

⭐ 645 · TypeScript · MIT · 推送 2026-02-06 · [GitHub](https://github.com/GeekyWizKid/writing-helper) · [官网](https://writing.chixitown.com/) · 个人维护 · 中文 README

**基于 Next.js 的 AI 写作助手与 AI 文本风格优化器**

基于 Next.js 构建的 Web 写作应用，面向作家、内容创作者、学生等需要文案的用户：根据主题、关键词与字数生成文章，支持多维度风格定制（语言、结构、叙述、情感），内置编辑器并支持导出 Markdown。另提供 AI 文本优化器，针对 GPTZero 等检测器的困惑度与突发性统计特征进行优化，含两种预设模式与自定义指令。兼容 OpenAI、Grok、Ollama、DeepSeek 等多种 API，需 Node.js 16.20.0+ 环境，通过 npm 安装源码运行。
