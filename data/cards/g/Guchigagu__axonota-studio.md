# Guchigagu/axonota-studio

⭐ 4 · TypeScript · MIT · 推送 2026-10-31 · [GitHub](https://github.com/Guchigagu/axonota-studio) · 个人维护 · 中文 README

**本地优先的 AI 学习笔记本：从主题生成结构化书籍**

面向 Windows 的本地优先学习笔记本应用：用户输入主题后先确认范围，生成可编辑大纲，再逐章逐节生成内容，产出可重读、可提问、可导出的结构化书籍。全部数据以 Markdown 与 JSONL 存于本机，无云同步与遥测；调用任意 OpenAI 兼容端点，API key 仅存本地。提供闪卡、词汇表、聊天与思维导图视图，支持 PDF 导出、zip 归档与双语界面。仅构建验证于 Windows。

## 能力要点

- 主题→范围→大纲→逐节生成的结构化书籍流程
- 闪卡、词汇表、聊天与思维导图等学习组件页
- 数据本地存储为 Markdown/JSONL，API key 不上传
- 兼容任意 OpenAI Chat Completions 端点，含连通性测试

## 适用场景

- 把一个学习主题生成可重读的结构化笔记本
- 阅读时选中文本向 AI 追问示例、类比或测验
- 为章节生成闪卡和词汇表用于复习
