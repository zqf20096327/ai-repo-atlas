⭐ 21 · Python · MIT · 推送 2026-04-29 · [GitHub](https://github.com/guybuk/bridge-ds) · [官网](https://bridge-ds.readthedocs.io/) · 个人维护

**Python 深度学习数据集统一操作框架：Pandas 式浏览与处理多模态数据**

轻量级 Python 框架，为不同模态的深度学习数据集提供统一接口：支持以 Pandas 风格语法执行全局操作、聚合与查询（赋值新列、排序、过滤），并可通过类与制表符补全方式处理单个样本与原始数据。功能包括数据集浏览、表格化查看、基于 Pandas Plotting API 的可视化，以及在流程内直接应用和可视化数据增广。面向深度学习研究者与工程师，从 PyPI 安装，提供 core 与 vision 两种安装口味，vision 包含图像数据集的额外功能。
