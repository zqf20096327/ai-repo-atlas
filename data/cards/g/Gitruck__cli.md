**给 AI Agent 用的视频剪辑 CLI：把口播毛片变成可精修工程**

gtrk 是为支持 Skills 的 AI Agent（Codex、Claude Code、Cursor、TRAE 等）准备的视频创作 CLI：用户在 Agent 里描述需求，Agent 调用 gtrk 完成口播粗剪、长剪短、解说配音、配画面、字幕等剪辑装配，产出可继续精修的视频工程。工程可在 Windows 桌面客户端预览精修，并导出剪映、Premiere XML、FCPXML 或 OTIO。CLI 代码 MIT 开源，但分析与渲染调用同合云，需 API Key 且按量计费。

## 能力要点

- 口播粗剪、长剪短、配音解说、配画面、字幕等多条工作流，可整体或单点调用
- 导出剪映/Premiere XML/FCPXML/OTIO 工程，保留精修时间线
- 配套 Skills 安装到 Claude Code/Codex 等Agent，无需写代码即可用自然语言创作
- 单点工具箱支持抠像、降噪、人声分离、超分、补帧、译制

## 适用场景

- 把口播或访谈毛片剪成结构完整、可二次精修的成片工程
- 从播客/课程/直播回放中挑出高光做成多条短片
- 给旅拍或探店素材写解说、配音并配画面
- 把成片导出到剪映或 Premiere 继续手工精修
