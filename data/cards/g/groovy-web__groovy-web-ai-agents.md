# groovy-web/groovy-web-ai-agents

⭐ 14 · MIT · 推送 2026-03-24 · [GitHub](https://github.com/groovy-web/groovy-web-ai-agents) · [官网](https://www.groovyweb.co) · 组织维护

**面向 Web 开发的预制 AI agent 配置与编排模板库**

由 Groovy Web 团队维护的 TypeScript npm 包，提供 ContentAgent、AnalysisAgent、CodeReviewAgent、SupportAgent 等预配置 agent 模板与提示词，用于内容生成、数据分析、代码审查和客服场景；内置 AgentOrchestrator 支持顺序、并行与层级式多 agent 协作，支持 ManagerAgent 决策策略，并可通过 createAgent 自定义 agent。集成 LangChain、OpenAI 与 Anthropic API，附带单元与集成测试。

## 能力要点

- 预配置 agent 模板：内容生成/数据分析/代码审查/客服
- AgentOrchestrator 支持顺序、并行、层级式多 agent 编排
- createAgent 自定义 agent 创建与 TypeScript 类型定义
- 与 LangChain、OpenAI、Anthropic API 集成

## 适用场景

- 在 Web 应用中快速接入内容生成或客服 agent
- 用多 agent 编排模式组织翻译、摘要、情感分析等流水线
- 作为团队 agent 配置与提示词工程的起点模板
