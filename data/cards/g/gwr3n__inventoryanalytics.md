**库存分析与预测的 Python 算法库（含 CLI）**

面向库存管理与运筹场景的 Python 库，实现预测与库存控制算法（如批量定价/库存优化），支持 Python 3.8–3.13，通过 pip 从源码安装。提供命令行接口：用 -list 列出算法目录，-method 选择具体算法，输入输出均为 JSON，也可通过 python -m 调用。附构建指引与引用条目，作者 Roberto Rossi。
