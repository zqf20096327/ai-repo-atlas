# giselles-ai/giselle

⭐ 560 · TypeScript · Apache-2.0 · 推送 2026-11-24 · [GitHub](https://github.com/giselles-ai/giselle) · [官网](https://giselles.ai) · 组织维护

**开源 AI agent 工作流构建工具，支持本地/自托管运行**

Giselle 是一个开源 AI 工作流工具，面向本地与自托管部署，提供可视化拖拽式 agent 构建器、多模型组合、知识库存储（含 GitHub 向量存储集成）、GitHub AI 操作（自动处理 issues、PR 与部署）及团队协作与模板中心（开发中）。运行需至少一个 AI 提供商 API key（OpenAI/Anthropic/Google AI）。托管云服务已停用，仅提供开源本地/自托管方式；仓库仍处于活跃开发中，公共路线图尚未定稿。

## 能力要点

- 拖拽式可视化 agent 构建器
- 多模型组合（GPT/Claude/Gemini 等，agent 按任务选择模型）
- 知识库统一访问与检索，支持 GitHub 向量存储集成
- GitHub AI 操作：自动化 issues、PR 与部署

## 适用场景

- 通过 GitHub 工作流自动进行 AI 代码审查
- 从代码库自动生成 PRD、规格文档和发布说明
- 串联多个 AI 模型处理复杂业务流程
- 从网页与内部文档自动收集信息的研究助手
