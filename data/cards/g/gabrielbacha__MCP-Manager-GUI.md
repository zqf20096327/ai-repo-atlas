**跨客户端统一管理 MCP 服务器配置的本地 GUI 工具**

一个本地运行的桌面实用程序，用于在各 MCP 客户端应用之间管理 MCP 服务器配置：通过指定客户端配置 JSON 路径添加客户端，以表单方式新增服务器配置，无需手动编辑 JSON；支持为 Claude、Cursor 等客户端一键启用/禁用 MCP，自动导入已有配置，并可导出/导入配置以切换环境。程序完全在本地运行，不收集数据、不与外部服务器通信。README 本身不含源码构建说明，安装包通过官网下载，仓库用于跟踪问题与功能请求。

## 能力要点

- 单一界面统一管理多个客户端的 MCP 服务器
- 为 Claude/Cursor 一键启用或禁用 MCP
- 自动导入已有 MCP 配置，表单方式新增配置免手写 JSON
- 本地运行，不收集数据、不与外部服务器通信

## 适用场景

- 在 Claude 和 Cursor 等多个客户端间统一管理 MCP 服务器开关
- 不想手动编辑 JSON 时用表单添加 MCP 服务器配置
- 导出/导入配置以在不同 MCP 环境间切换
