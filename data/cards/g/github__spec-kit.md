**为 AI 编码代理提供结构化流程与模板的工具包**

开源工具包，为 AI 编码代理提供结构化流程、可复用模板与文档化产物。内置规格驱动开发（SDD）流程，附带可选的 bug 修复与想法评估扩展，并提供扩展、预设、工作流、捆绑包、目录等组合机制用于定制或自建流程。以 CLI 形式安装，依赖 Python 3.11+ 与 uv，在代理聊天中以 /speckit-* 技能形式调用。MIT 许可。
