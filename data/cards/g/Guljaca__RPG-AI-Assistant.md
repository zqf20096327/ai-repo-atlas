# Guljaca/RPG-AI-Assistant

⭐ 19 · Python · 推送 2026-05-02 · [GitHub](https://github.com/Guljaca/RPG-AI-Assistant) · 个人维护

**用本地 LLM（LM Studio）玩文字 RPG 的 Python 程序**

基于 Python 的文字角色扮演游戏程序，通过 LM Studio 调用本地模型（如 Qwen 3.5 9B、Gemma-4 e4b）生成游戏内容。将一次玩家输入拆分为多个阶段处理：对象描述与场景生成、玩家陈述核实、玩家行动判定（d20 骰子）、随机事件判定（d100）、逐个 NPC 的计划生成与汇演。支持 spec-v3 角色卡导入（chub.ai）、对每个游戏对象的长期关联记忆、界面内创建游戏对象与编辑提示词、日志记录。要求模型支持 Tools 与 Thinking，通过 bat 脚本安装依赖并运行。

## 能力要点

- 多阶段处理：场景生成、玩家陈述核实、行动判定、随机事件、NPC 计划逐个生成后汇演
- spec-v3 角色卡导入，兼容 chub.ai 卡片
- 按游戏对象存储的长期关联记忆，仅当对象在场景中出现时提供
- 界面内创建游戏对象、编辑提示词并调整加载顺序，日志保留至多 30 条
