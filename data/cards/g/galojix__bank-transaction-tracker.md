**学习用户分类习惯的收支记录 Web 应用**

基于 Python 3 与 Flask 的收支记录 Web 应用：用户从网上银行下载交易 CSV 文件并上传，自行定义交易分类方式，通过图表跟踪收支情况。核心机制是观察用户的分类行为并逐步学习，自动完成后续交易分类。面向需要个人财务记录与统计的普通用户，以 Web 应用形式提供。
