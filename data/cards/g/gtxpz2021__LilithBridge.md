# gtxpz2021/LilithBridge

⭐ 4 · C# · MIT · 推送 2026-11-22 · [GitHub](https://github.com/gtxpz2021/LilithBridge) · 个人维护 · 中文 README

**《不/存在的莉莉丝》桌宠游戏的 LLM 伴侣 MOD，带长期记忆**

面向桌面伴侣游戏《不/存在的莉莉丝》的非官方 MOD：把游戏角色接入云端大语言模型（DeepSeek、OpenAI API、ChatGPT 账户登录），并提供本机长期记忆架构——对话原话归档、主观判断独立存储且可溯源修订，支持跨天记忆延续、打断气泡与按需看屏。以单文件 Windows 安装器分发，面向官方游戏 1.2.1（Windows x64）；记忆数据全部保存在本地，自有源码采用 MIT 许可。

## 能力要点

- 事实归档与主观演化双账本的记忆设计，判断可溯源、可修订（revises/qualify/settles）
- 可选本地 BGE-small-zh-v1.5 语义召回进程，基础聊天无需本地模型
- 支持 DeepSeek/OpenAI API Key 与 ChatGPT 浏览器账户登录三种接入方式
- 单文件安装器覆盖升级，保留记忆库、配置与凭据

## 适用场景

- 给桌宠游戏角色接上自己的大模型 API 长期聊天
- 让 AI 伴侣记住并延续跨天、跨周的对话内容
- 本地保存全部对话记忆、掌控数据归属
