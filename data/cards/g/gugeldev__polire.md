# gugeldev/polire

⭐ 14 · TypeScript · MIT · 推送 2026-05-27 · [GitHub](https://github.com/gugeldev/polire) · [官网](https://polire.app) · 个人维护

**桌面写作助手：语法润色、翻译与本地速记**

Electron 桌面应用，面向用非母语写作或需要快速润色文本的用户。通过全局快捷键唤出面板，粘贴或输入文本后可进行语法/拼写/清晰度改进（带前后对比视图）、六种语气改写与多语言翻译；笔记以 Markdown 文件本地保存。AI 部分采用自带 API key 模式，支持 OpenAI、Anthropic、Google Gemini 与 DeepSeek，key 使用 Electron 系统级安全存储加密，不运行接收用户文本的服务器。提供 Windows/Linux 安装包。
