**C# WPF 图像标注与训练工具：标注分类数据集并训练模型**

基于 C# WPF（Visual Studio 2022 / .NET 6）开发的免费图像标注与训练工具：支持对分类数据集进行人工标注（F1~F12 快捷键按索引打标）、训练模型，以及自动标注。标注信息以 target_info.json 与逐图 JSON 文件保存。运行需 .NET 6，GPU 训练可选 CUDA 11.3；以 Windows 桌面程序下载方式提供，附操作演示视频与 Notion WIKI。
