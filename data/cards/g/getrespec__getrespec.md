**让编程 agent 变身职业导师的转型课程文件夹**

面向想转入 AI 时代岗位（AI Engineer、AI Product Engineer 等）的开发者的实操课程，内容基于真实职位发布构建。产品形态是一个文件夹：用 Claude Code、Codex、Cursor 打开后，agent 承担导师、评估者与职业指导角色。流程覆盖画像建立、岗位推荐、课程生成、循环学习（课程→测验→补课→作业→评估）、进度仪表盘与面试档案生成；支持多语言回答，LLM 调用经本地代理记录 token 用量。需 Node.js 20+，作业需 API key 或本地模型。

## 能力要点
