# gufo-org/gufo

⭐ 1,250 · C++ · MIT · 推送 2026-11-22 · [GitHub](https://github.com/gufo-org/gufo) · [官网](https://gufo.blog) · 组织维护

**面向 AMD Strix Halo 单机的开源推理引擎，提供 OpenAI 兼容 API**

针对 AMD Strix Halo（Ryzen AI MAX+ 395 / Radeon 8060S，gfx1151，最高 128 GiB 统一内存）的推理引擎，以单二进制形式提供文本、嵌入、语音、图像与视频模型的推理服务，暴露 OpenAI 兼容 API，并针对该芯片调优内核。内置面向 coding agent 长对话重发场景的缓存机制，支持通过扩展接入自带模型；每个模型附带质量报告，与独立参考实现对比。仅支持单机、每个用例一个模型；仅面向 Linux 与 Windows。

## 能力要点

- 单二进制提供文本、嵌入、语音、图像、视频模型的 OpenAI 兼容 API
- 内核针对 Strix Halo（gfx1151，128 GiB 统一内存）调优

- 扩展注册表可安装额外模型（gufo extension install）

- 通过扩展注册表扩展可运行的自定义模型
