# gcjordi/aigraphstudio

⭐ 38 · JavaScript · MIT · 推送 2026-09-22 · [GitHub](https://github.com/gcjordi/aigraphstudio) · [官网](https://aigraphstudio.jordigarcia.eu/) · 个人维护

**浏览器内的 Agent AI 工作流图设计与分析工具**

免费开源的纯前端静态应用，用于设计、文档化、分析与模拟 Agent AI 工作流图：提供 18 种架构节点类型（LLM、Agent、Router、Guardrail、Human Approval、Loop 等）的可视化画布编辑器、启发式架构分析器、Token 与成本估算、结构化模拟、14 个内置模板与多格式导出（JSON/SVG/PNG/Mermaid/Markdown/PDF）。不执行真实模型或代码，厂商中立，本地优先：无后端、无 API key，项目存于浏览器 IndexedDB。UI 支持加泰罗尼亚语/西班牙语/英语。

## 能力要点

- 18 种架构节点类型的可视化图编辑器与 14 个工作流模板
- 本地启发式架构分析器与节点/工作流级 Token 及成本估算
- 结构化模拟模式：不执行真实模型即可遍历工作流并估算调用与成本
- 纯静态浏览器应用，无后端/无 API key，数据存于 IndexedDB，支持 JSON/SVG/Mermaid/Markdown 等导出

## 适用场景

- 在实现前设计与推演 Agent AI 系统架构
- 估算工作流的 LLM 调用次数、Token 消耗与成本
- 生成工作流架构文档与可视化图表用于评审或教学
- 学习 Agent、RAG、guardrail、human-in-the-loop 等架构概念
