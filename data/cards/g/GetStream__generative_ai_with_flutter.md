**Flutter 示例应用：在聊天中演示 Gemini API 与 Stream Chat SDK**

GetStream 维护的示例工程，演示 Google Generative AI SDK（google_generative_ai）在 Flutter 上的使用，并与 Stream Chat Flutter SDK 集成实现实时聊天事件处理，覆盖该包当时全部能力的示例代码。运行需在 Stream 控制台创建应用并获取 API key、在 Google AI Studio 创建 Gemini API key，写入配置文件后构建运行。README 顶部声明该示例已过时：使用 google_generative_ai 0.2 与 Stream Chat Flutter 7，模型 id 与 SDK 版本不再最新，可能无法直接运行。给 Flutter/AI 应用开发者参考。
