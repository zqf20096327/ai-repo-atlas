**基于麦当劳中国 MCP 的点餐前热量/复购/用券体检器**

纯 Python（仅标准库，3.10+）的命令行工具，调用麦当劳中国 MCP 的只读工具读取菜单营养、历史订单与券信息，用确定性规则引擎在下单前算五项体检（热量、钠、脂肪、重复下单、深夜/无券情境）并输出 0–15 分判决与同品类替换建议；附消费账本、营养查询、可脱敏的 HTML 分享卡片。判决不使用 LLM，同样输入结果可复现。可独立运行，也可作为 MCP 客户端的 skill 配置。属麦当劳程序员节大赛参赛作品，非官方产品；重复体检依赖账号历史订单，无历史时如实标注不扣分。

## 能力要点

- 五项体检的确定性规则引擎，结果可复现，运行数百毫秒
- 零依赖：仅 Python 标准库，手写 Streamable HTTP + JSON-RPC + SSE 兼容的 MCP 客户端
- 支持 --share 门店脱敏与单文件 HTML 分享卡片（无外部资源）
- 单元测试 29 条全部离线运行、不需要 Token

## 适用场景

- 点麦当劳前用 30 秒判断这单热量和钠是否超标
- 查看近 7 天是否重复点同一单品，避免复购
- 在同类餐品间找热量更低但蛋白不降的替换搭配
- 生成脱敏后的消费体检卡片分享
