**带 AI 助手的跨平台 Markdown 桌面编辑器**

基于 Tauri 2 + React + TypeScript 的 Markdown 编辑器，功能包括 CodeMirror 6 大文件编辑、多标签页、实时预览、自动保存、KaTeX 公式、Mermaid 图表、思维导图、内置 PDF 阅读器、媒体嵌入与导出 PDF/HTML/Word。AI 部分：可配置 Dify、OpenAI 兼容 API 等提供商，提供文档对话、选区问答、图片分析与全局记忆，需用户自配 API Key。开发环境要求 Node.js 18+ 与 Rust stable，从源码构建运行。
