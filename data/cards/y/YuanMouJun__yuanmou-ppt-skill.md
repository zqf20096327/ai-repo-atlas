# YuanMouJun/yuanmou-ppt-skill

⭐ 5 · JavaScript · Apache-2.0 · 推送 2026-11-27 · [GitHub](https://github.com/YuanMouJun/yuanmou-ppt-skill) · [官网](https://ppt.resourcehub.dpdns.org) · 个人维护 · 中文 README

**装进 agent 的一句话生成可编辑 PPTX 的技能**

以 agent skill 形式分发的 PPT 生成工具：输入一句主题即策划大纲并匹配 1.6W+ 商业版式库，输出原生 OOXML 格式的 .pptx，文字、图片、表格均可在 PowerPoint/WPS 中直接编辑，图表内嵌 .xlsx 工作簿支持双击改数。另支持将图片、截图、PDF 1:1 还原为可编辑矢量，以及对既有 .pptx 模板原位改版并瘦身。零第三方 npm 依赖，仅需 Node.js ≥22.5；本地渲染审图依赖可选安装 LibreOffice 与 poppler。通过 npx 安装到多种 agent 中使用。

## 能力要点

- 生成原生 OOXML .pptx，图表内嵌 .xlsx 工作簿双击改数
- 图片/截图/PDF 转可编辑 PPT，旧 .pptx 模板原位改版
- 1.6W+ 免登录商业版式库按槽位指纹同构匹配
- 内置 6 组 15 项自动代码门禁，零 npm 依赖

## 适用场景

- 给商业提案快速产出一份可直接改数的完整 PPT
- 把公司的旧 .pptx 模板原位升级并瘦身
- 把截图或 PDF 还原成可编辑的演示文稿
