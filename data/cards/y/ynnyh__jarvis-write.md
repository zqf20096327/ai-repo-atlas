# ynnyh/jarvis-write

⭐ 15 · Python · Apache-2.0 · 推送 2026-10-30 · [GitHub](https://github.com/ynnyh/jarvis-write) · [官网](https://ynnyh.github.io/jarvis-write/) · 个人维护 · 中文 README

**面向长篇网文作者的 AI 小说创作系统：控制层包裹 LLM，管事实、伏笔、大纲与文风**

自部署的 Web 应用（FastAPI+React，Tauri 桌面版，Windows 安装包开箱即用），生成文字的环节交给用户自带 key 的 LLM，本体做 LLM 外的控制层：时序故事圣经绑定事实生效章节区间、伏笔四态调度（埋设/强化/回收/弃用）、大纲级联更新（改动分级、下游影响分析、级联重生成）、标签化倾向系统与去 AI 味门禁（套话规则+句式统计打分，超标定向重写复测）。六步生成流水线从种子到逐章正文。另含漫剧、宣传片、剧本等衍生工坊，只产提示词、不接生成模型。支持 Docker 单容器部署与多用户 JWT 数据隔离。

## 能力要点

- 时序故事圣经：每条事实绑定生效章节区间，可查第 N 章时角色状态
- 大纲级联更新：改动分级、下游影响分析、用户勾选后级联重生成、版本化可回退
- 去 AI 味门禁：9 类套话规则 + 句式统计打 AI 味指数，超标定向重写复测收敛
- 漫剧/宣传片/剧本等工坊：产三轨绘图提示词、SRT、剪映草稿.zip，不接生成模型

## 适用场景

- 写几十万字长篇网文时保持人设、伏笔、设定不自相矛盾
- 随时改任意一章大纲并自动级联更新下游章节
- 把已定稿小说改编成竖屏漫剧拍摄手册，拿去即梦/可灵/剪映出片
- 导入旧书 TXT/DOCX 跑翻新引擎重构旧章节
