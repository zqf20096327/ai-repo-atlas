**网页标注工具栏：帮开发者向 AI 编码 agent 精确传达 UI 修改需求**

面向使用 AI 编码 agent 的前端开发者的开发工具库：点击页面元素、添加备注，导出包含元素标识、CSS 选择器、框架组件路径与上下文的结构化 markdown，供 AI agent 定位代码中的元素。提供 Vanilla JS、Web Component 及 React/Vue/Svelte/Angular 适配层；支持四级输出详略、localStorage 持久化（7 天）、i18n（英文与简体中文）。README 提示应在开发环境条件引入，避免打包进生产。
