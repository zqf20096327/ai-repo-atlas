# yaratul2005/StreamFlix

⭐ 20 · TypeScript · 推送 2026-10-22 · [GitHub](https://github.com/yaratul2005/StreamFlix) · [官网](https://streamflix-coral-six.vercel.app/) · 个人维护

**基于 Next.js 的影视流媒体浏览与播放平台（Netflix 风格）**

用 Next.js 13+（App Router）、TypeScript、Tailwind CSS 与 shadcn/ui 构建的响应式影视浏览播放应用：通过 TMDB API 获取影片元数据、VidSrc API 聚合第三方流媒体链接，提供搜索（按标题/类型/演员）、深浅色主题、HD 播放、用户账户（观看历史与收藏）等功能。运行需 Node.js 18+ 与 TMDB API Key，从源码克隆安装。README 声明仅供教育用途、不托管内容。主题标签含 ai 但 README 内未见 AI 功能描述。
