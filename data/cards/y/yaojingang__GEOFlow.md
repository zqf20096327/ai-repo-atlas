# yaojingang/GEOFlow

⭐ 4,219 · PHP · AGPL-3.0 · 推送 2026-11-13 · [GitHub](https://github.com/yaojingang/GEOFlow) · [官网](https://www.geoflow.me) · 个人维护 · 中文 README

**面向企业内容团队的 GEO 内容生产与多站点分发平台**

GEOFlow 将企业知识导入、AI 文章与专题生产、智能配图、AI 质量门禁、人工审核、多站点分发和 AI 可见性分析串联为一条运营链路。团队可在同一后台管理资料来源、内容版本与发布结果，支持 TXT/Markdown/DOCX/PDF/PPTX 知识导入、向量检索、签名更新与回滚。技术栈为 Laravel + PostgreSQL(pgvector) + Redis，通过 Docker Compose 部署，另提供 CLI、Chrome 运营助手与 Agent Skill。采用 AGPL-3.0，闭源集成需另行商业授权。

## 能力要点

- 知识导入支持 TXT/Markdown/DOCX/PDF/PPTX，带向量检索与智能配图
- AI 质量门禁按知识证据、引文、广告规则检查文章并记录评分与修改建议
- 多站点交付支持托管站点、WordPress REST、通用 HTTP API 与自动生成 sitemap/llms.txt
- 独立 Updater 提供签名更新、完整备份与恢复点回滚

## 适用场景

- 围绕产品与行业知识持续运营企业官网 GEO 内容
- 从一套后台管理多品牌、多站点的栏目与发布
- 以 AI 质检加人工审核把关内容质量后分发
- 建设行业信源站并输出 sitemap 与 llms.txt
