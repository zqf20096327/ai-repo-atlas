**为中文用户汉化 Google Antigravity 桌面客户端与 VS Code 扩展**

社区开源的本地化套件，通过对客户端 ASAR preload、原生菜单和弹窗打补丁实现中文化，覆盖 Antigravity App 桌面端与 VS Code 扩展，提供备份还原、安装副本校验和可选的社区中文交互插件；不修改 CLI 二进制，独立 IDE 不声明适配。以 Node.js CLI（cli.js）与 install.sh/install.bat 脚本分发，配套词库构建、自动化测试与前端文本扫描工具。官方更新后需重新执行安装，扩展更新会覆盖汉化。
