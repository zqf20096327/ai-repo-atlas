# yeahhe365/PowerAgent

⭐ 23 · Python · MIT · 推送 2026-05-22 · [GitHub](https://github.com/yeahhe365/PowerAgent) · 个人维护 · 中文 README

**结合 AI 聊天、命令行执行与键盘自动化的桌面助手**

基于 PyQt5 的桌面应用，将可配置多模型的 AI 聊天界面与本地命令行（CLI）集成：AI 可生成 <cmd> 标签的 Shell 命令，自动在 CLI 窗口回显并执行；也可生成 <function> 标签模拟按键、热键、粘贴等键盘动作。支持通过 API URL/密钥/模型 ID 配置接入自选 AI 服务，可选将近期 CLI 输出作为上下文发送，实验性支持多步骤连续操作。运行方式为 python main.py，无打包安装说明，面向需要在本机执行命令与自动化操作的用户。

## 能力要点

- AI 生成 <cmd> 命令并在内置 CLI 自动回显执行
- AI 生成 <function> 键盘动作（模拟按键/热键/粘贴）并自动执行
- 可配置任意 API URL/密钥与多模型列表
- 可选将 CLI 输出作为上下文，实验性多步骤连续执行

## 适用场景

- 通过自然语言让 AI 在本机执行 Shell 命令
- 让 AI 模拟键盘操作实现桌面自动化
- 在同一窗口内聊天、执行命令并用 Tab 切换焦点
