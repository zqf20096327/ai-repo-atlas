# ystemsrx/smart-shop

⭐ 21 · JavaScript · Apache-2.0 · 推送 2026-10-25 · [GitHub](https://github.com/ystemsrx/smart-shop) · 个人维护 · 中文 README

**集成 AI 购物/管理助手的在线商城系统**

基于 Next.js + FastAPI + SQLite 的电商系统，覆盖购物车、订单、多角色权限（超管/管理员/代理商）、预约下单（商品级/时间截止/打烊预约）、销售周期、抽奖与营销活动。AI 部分为 OpenAI 兼容助手：用户端提供商品推荐与咨询（4 个工具），管理端提供对话式运营工具（6 个管理工具，SSE 流式、多模型切换、图片上传）。部署支持 Docker Compose 本地验证与 GitHub Actions + Kubernetes 生产链路；默认 SQLite 限制后端单副本。

## 能力要点

- AI 管理助手通过自然语言调用 6 个管理工具（商品/订单/抽奖/满赠/优惠券/用户）
- 三种预约触发方式：商品级、时间截止、打烊预约
- 多角色权限（超级管理员/管理员/代理商）与代理商区域数据隔离
- Docker Compose 本地验证与 GitHub Actions + Kubernetes 生产发布链路

## 适用场景

- 搭建带 AI 咨询与推荐的小型在线商城
- 管理员/代理商通过对话完成商品、订单与营销管理
- 社区团购或宿舍场景错峰配送与打烊预约接单
