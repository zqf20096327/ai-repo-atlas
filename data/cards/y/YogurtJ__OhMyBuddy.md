# YogurtJ/OhMyBuddy

⭐ 61 · JavaScript · ISC · 推送 2026-10-29 · [GitHub](https://github.com/YogurtJ/OhMyBuddy) · [官网](https://github.com/YogurtJ/OhMyBuddy#readme) · 个人维护 · 中文 README

**自托管个人 AI 助理：带可见长期记忆，浏览器/手机/微信可用**

基于 Pi coding agent 构建的自托管 Web 应用，分两部分共享同一运行时：Buddy 个人助理（长期记忆、笔记本、习得技能，记忆变更以回执展示且可编辑撤销）与 Workspace 编码代理工作区（线程、流式工具调用、diff、子代理、定时任务）。自带模型接入 Claude/GPT/Gemini/DeepSeek/Qwen 等多家 API key 或 OpenAI 兼容端点，可选装微信连接器收发消息与文件，密钥与历史留在本机。需 Node.js 22、bash 与 ripgrep，从 Releases 下载 tar.gz 安装，无需 GPU。

## 能力要点

- Buddy 长期记忆与技能，变更以回执展示、可审查编辑撤销

- 多提供方接入：Anthropic/OpenAI/Gemini/DeepSeek/Qwen/Kimi 等，含 OpenAI 兼容端点
- 微信连接器可对话、收发文件与定时通知
