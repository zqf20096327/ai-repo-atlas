**为 GitHub 仓库添加 Code Wiki 按钮的浏览器扩展**

Chrome/Firefox/Edge 浏览器扩展，在 GitHub 仓库页面上添加跳转 Code Wiki 的按钮。Code Wiki 是 Google 的 AI 文档平台，为公开仓库自动生成文档，包含自动更新、Gemini 问答、交互式导航与自动生成架构图等功能，扩展本身不收集数据。开发需 Node.js 24+，通过 git clone 与 npm 安装依赖，npm run dev/build 构建各浏览器版本。

## 能力要点

- 在 GitHub 仓库页面添加 Code Wiki 入口按钮
- 支持 Chrome/Firefox/Edge 三种浏览器
- 入口指向 Google Code Wiki（Gemini 驱动的仓库文档平台）

## 适用场景

- 在浏览 GitHub 仓库时快速跳转查看其 AI 生成文档
- 向 Code Wiki 文档提问并导航到具体代码文件
