**Obsidian 提示工程研究插件：对话、记忆与上下文实验**

面向 Obsidian 用户的 Prompt Engineering 研究插件：在笔记软件内与 AI 模型对话，自动或手动保存对话为可搜索、可标签、可链接的笔记；提供 Memory Manager 实时编辑上下文（Core Memory/Remembered/Forgotten/Default 四种记忆状态），可中途切换模型（当前支持 gpt-4 与 gpt-3.5-turbo）对比同一输入的输出，并可查看每次请求的 Prompt 与原始 JSON。桌面端经 Electron safeStorage 存储 API Key，不支持移动端。自称 Beta 软件尚未稳定。

## 能力要点

- 对话自动保存为可搜索、可标签的 Obsidian 笔记
- Memory Manager 实时编辑每条消息的上下文记忆状态（四种）
- 对话中途切换模型，对比不同模型对同一输入的输出
- 可查看每次请求的 Prompt/Context 与响应的原始 JSON

## 适用场景

- 在笔记工作流中研究 Prompt 与上下文设计
- 对比不同模型对同一输入的回答
- 整理、检索并归档与 AI 的历史对话
