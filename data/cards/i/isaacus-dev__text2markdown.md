**Python 库：调用 Isaacus API 将纯文本智能转换为 Markdown**

text2markdown 是一个 Python 库，通过 Isaacus enrichment API 将非结构化文档转换为 Markdown：识别并格式化标题、切分嵌套小节、为交叉引用添加超链接、斜体化引用文献与定义术语、格式化块引用、删除线标记垃圾文本。使用需 Isaacus API key，提供同步与异步两个函数，各能力可用可选布尔参数开关。以 pip 安装，MIT 许可。
