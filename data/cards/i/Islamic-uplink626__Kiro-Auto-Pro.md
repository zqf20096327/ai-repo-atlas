# Islamic-uplink626/Kiro-Auto-Pro

⭐ — · [GitHub]() · 个人维护

**Windows 桌面自动化工具：自动执行点击、输入与表单填写**

以 .exe 安装包形式分发的 Windows 桌面自动化程序，用户创建任务序列（鼠标点击、文本输入、屏幕坐标定位）后由程序按顺序执行，可用于数据处理、表单填写与系统设置管理等重复操作。程序本地运行，README 声明不向外部服务器发送数据。仅支持 Windows 10/11，需 4 GB 内存与 50 MB 存储空间，下载地址为仓库内 zip 文件直链。仓库描述另称其可自动化 Kiro IDE 账号注册与 Pro 升级（Google OAuth/Stripe/隐身浏览器），但 README 正文未涉及此内容，两者描述不一致。
