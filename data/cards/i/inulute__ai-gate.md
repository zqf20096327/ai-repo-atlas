# inulute/ai-gate

⭐ 220 · TypeScript · GPL-3.0 · 推送 2026-08-16 · [GitHub](https://github.com/inulute/ai-gate) · [官网](https://aigate.inulute.com) · 个人维护

**桌面聚合客户端：在一个应用内同时使用多个 AI 网页工具**

基于 Electron + Vite + React 的跨平台桌面应用，将 ChatGPT、Claude、Gemini、Perplexity、Qwen、Grok 等以网页视图嵌入同一窗口，无需 API key。支持最多 3 面板并排布局、同步/独立标签模式、布局切换保留 webview 状态、可自定义键盘快捷键（含 tmux 式前缀模式）、Wayland 支持、系统托盘与 GitHub Releases 自动更新，声明无遥测。提供 Windows/macOS/Linux 安装包，GPL-3.0-only 许可。

## 能力要点

- 最多 3 面板并排查看多个 AI 工具，同步或独立标签模式
- 切换布局保留 webview 状态（URL、滚动位置、会话）
- 无需 API key，通过网页视图访问各 AI 服务
- 可自定义键盘快捷键，含 Original/iTerm/tmux 三套预设

## 适用场景

- 把常用的多个 AI 对话工具集中到一个桌面窗口管理
- 并排对比多个 AI 的回答
- 用键盘快捷键快速切换 AI 工具
