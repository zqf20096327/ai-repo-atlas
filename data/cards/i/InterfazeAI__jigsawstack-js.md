# InterfazeAI/jigsawstack-js

⭐ 27 · TypeScript · MIT · 推送 2026-10-27 · [GitHub](https://github.com/InterfazeAI/jigsawstack-js) · [官网](https://jigsawstack.com) · 组织维护

**调用 JigsawStack 各类 AI 服务的 TypeScript/JavaScript SDK**

JigsawStack 官方的 JS/TS 客户端库，通过单一 API key 接入其托管 AI 服务，覆盖翻译、摘要、情感分析、AI 网页抓取与搜索、语音转文本、OCR、目标检测、图像生成（Flux/SD 等）、邮件与 NSFW 校验等。SDK 提供全类型化参数与响应、Webhook 长任务支持、内置文件上传，基于原生 fetch 构建；可在 Next.js、React、Vue、Node.js、Bun、Deno 等环境运行，需 Node.js 18+ 与 JigsawStack API key。
