# iurp/livevideoprocessor

⭐ 18 · TypeScript · MIT · 推送 2026-01-02 · [GitHub](https://github.com/iurp/livevideoprocessor) · [官网](https://ikamobile.cn/projects/livevideoprocessor) · 个人维护 · 中文 README

**给主播与创作者：AI 分析直播回放，一键提取精华片段**

Electron 桌面应用：导入直播回放视频与 SRT 字幕（可用剪映生成），调用通义千问/OpenAI API 分析字幕内容，生成摘要、核心要点并标记精华时间段；用户可在时间轴上预览并调整片段范围，一键导出为独立视频文件，视频处理由本地 FFmpeg 完成、无需上传。适用视频号/抖音主播、知识博主、培训讲师与内容运营人员。首次使用需配置 AI 服务 API Key。macOS 与 Windows 提供下载版本。
