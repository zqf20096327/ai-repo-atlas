# intelligent-iterations/ii-content-engine

⭐ 15 · HTML · MIT · 推送 2026-08-08 · [GitHub](https://github.com/intelligent-iterations/ii-content-engine) · 组织维护

**面向内容创作者的 AI 视频与轮播图生成及自动发布引擎**

在 Claude Code 或 Codex 中打开仓库后，用自然语言描述需求，由 agent 完成选题研究、模板选择、素材生成、配文与排期发布。生成由 Grok 驱动，支持 xAI API key 或复用 Chrome 浏览器会话 Cookie，可无 API key 生成；发布到 TikTok/Instagram/X 依赖各平台已保存 Cookie。模板优先设计使创意可复用，另有 xAI 花费追踪、月度预算与硬上限，以及 Docker 构建辅助命令。MIT 许可。

## 能力要点

- Grok 生成图片与视频，支持 API key 或浏览器 Cookie 会话两种认证
- 模板优先：创意沉淀为可复用格式而非一次性 prompt
- 排期发布队列覆盖 TikTok、Instagram、X
- xAI 花费记录、月度预算告警与硬上限

## 适用场景

- 批量制作短视频、轮播图并自动发布到多个社媒平台
- 将爆款内容格式沉淀为可复用模板持续产出
- 控制 AI 生成与发布的月度 API 支出
