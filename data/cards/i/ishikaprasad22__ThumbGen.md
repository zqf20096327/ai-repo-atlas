# ishikaprasad22/ThumbGen

⭐ 19 · TypeScript · 推送 2026-03-25 · [GitHub](https://github.com/ishikaprasad22/ThumbGen) · [官网](https://thumbgen-two.vercel.app) · 个人维护

**用 AI 从标题生成 YouTube 风格缩略图的 Web 工具**

ThumbGen 是一个 Web 应用：用户输入标题后借助 Imagen 图像生成能力产出缩略图，支持预定义风格提示与调色板、自定义宽高比，输出 1280x720 的导出尺寸，图像经 Cloudinary 云存储。内置 Botpress 聊天机器人，用于 FAQ、账户与账单咨询。技术栈为 React+Vite+Tailwind 前端、Node.js+Express 后端、MongoDB 数据库，部署于 Vercel，提供在线 Demo，也可 git clone 后本地运行。面向需要快速制作视频封面的内容创作者。

- AI 生成缩略图（Imagen）
