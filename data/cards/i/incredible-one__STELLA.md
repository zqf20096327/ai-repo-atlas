**面向开发者的多 Agent 对话框架，用 LLM 构建可扩展智能体**

基于服务器架构的多 Agent 框架，用于以 LLM 构建会话型智能体。提供 CLI（stella configure / serve / 交互 shell）、Socket 实时通信、多用户支持、Agent 间通信以减少 Token 用量、单提示方法及社区驱动的 Agent 包管理器。面向希望将 LLM 能力集成到应用中的开发者，通过 pip 源码安装并启动本地服务器使用。注意：README 声明该项目自 2024 年 1 月 beta 后未再更新，旧文档站点已下线；采用双许可模式。
