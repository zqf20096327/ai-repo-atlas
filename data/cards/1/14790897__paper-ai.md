# 14790897/paper-ai

⭐ 1,760 · TypeScript · MIT · 推送 2026-11-05 · [GitHub](https://github.com/14790897/paper-ai) · [官网](https://paperai.sixiangjia.de) · 个人维护 · 中文 README

**面向写作者的检索真实文献并生成带引用论文的AI写作工具**

基于 Next.js 的网页论文写作工具：用户输入关键词后在 Semantic Scholar、arXiv、PubMed 中检索论文，将文献信息整合进 AI 生成的论文文本，编辑器基于 Quill，支持直接修改 AI 生成内容与调整样式布局。通过环境变量或设置界面配置上游 AI 模型地址与 API Key，支持 GitHub/Google OAuth 登录（Supabase）。提供 Vercel 一键部署、Docker 镜像与本地源码运行三种方式，README 另含开发踩坑记录与 API 参考文档。

## 能力要点

- 在 Semantic Scholar / arXiv / PubMed 检索真实文献并整合到论文中
- AI 写作对话交互，根据输入提供写作建议
- Quill 编辑器内直接修改 AI 生成内容
- Docker 镜像与 Vercel 部署，支持自定义上游模型地址

## 适用场景

- 根据关键词快速生成带真实文献引用的论文草稿
- 在编辑器中结合 AI 建议撰写和修改学术文本
- 自部署一个可配置上游模型的论文写作站点
