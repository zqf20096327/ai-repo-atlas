**本地 AI 编程 Agent 控制台：通过桌面/Web/微信等远程操控**

面向使用 Codex、Claude Code、CodeBuddy 的开发者，将这些编程 Agent 集中到本地控制台，并通过 Web UI 及飞书、钉钉、QQ、Telegram、个人微信等渠道远程访问。支持为各 Provider 配置自定义上游与模型映射（含 Ollama/llama 本地后端），提供 MCP 服务器与技能管理、项目工作区、变更审查、定时自动化任务等。桌面应用覆盖 macOS/Windows，也可用 Node.js 22 从源码运行。

## 能力要点

- 通过 Web UI 与飞书/钉钉/QQ/Telegram/微信等渠道远程操控本地编程 Agent
- 支持 Codex / Claude Code / CodeBuddy 三种 Provider，运行时组件按需下载
- 自定义上游与模型映射，兼容 Ollama / llama 本地模型后端
- MCP 服务器与技能统一管理、项目工作区、变更 diff 审查、Cron 定时自动化任务

## 适用场景

- 在手机上通过微信或飞书远程调用电脑上的 Claude Code / Codex 编程 Agent

- 定时运行本地代码分析、文档生成等 Agent 任务并推送到聊天渠道
