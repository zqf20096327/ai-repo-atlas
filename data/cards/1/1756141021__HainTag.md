**给 AI 绘画用户的 Danbooru TAG 生成与管理 Windows 桌面工具**

面向 Stable Diffusion / NovelAI 等 AI 绘画工作流的 Windows 桌面应用（PyQt6）：通过用户自备的 OpenAI 兼容 API 将自然语言描述转为 Danbooru 标签 TAG，流式输出。提供 TAG 编辑（分类着色、权重拖拽、15 万词自动补全）、提示词管理、画师库与 OC 角色库、图像管理器、四种格式 Metadata 查看/编辑/销毁、图像反推（本地 cl_tagger ONNX 离线识别或多模态 LLM）等工具链。所有数据存储本地，不依赖云服务。Windows 提供免安装发行包，macOS/其他从源码运行。

## 能力要点

- LLM 驱动 TAG 生成，连接任意 OpenAI 兼容 API，流式输出
- Danbooru 自动补全（15 万词典）与分类着色、权重拖拽编辑
- 图像反推：本地 cl_tagger ONNX 离线识别或多模态 LLM 两种方式
- 支持 A1111/Forge、ComfyUI、NovelAI（含 LSB 隐写）、Fooocus 四种 Metadata 格式

## 适用场景

- 把脑中的画面描述转成 AI 绘画可用的 Danbooru TAG
- 管理画师名、LoRA 触发词与原创角色（OC）多套服装 TAG
- 查看/编辑/批量抹除生成图片的 Metadata
- 对已有图片离线反推 Danbooru 标签
