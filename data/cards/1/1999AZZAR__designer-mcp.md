**面向 AI 客户端的 UI 设计 MCP 服务器：46 个设计工具**

一个 Design-Theory-as-a-Service 的 Model Context Protocol (MCP) 服务器（TypeScript，MIT 许可），把 OKLCH 色彩数学、动效物理、排版缩放与可访问性等设计原则编码为可执行算法。提供 46 个工具：35 项反模板化质量门禁与 6 轴自评、WCAG 2.1 项静态审计、OKLCH 令牌生成（19 套主题、自动深色模式）、React/Vue/HTML 组件输出、CSS/SCSS 生成、motion.dev 与 anime.js 动效片段、logo 设计（1,432 个参考商标库）及 9 个 Stitch 画布集成工具。属于 HeLa MCP 生态，面向使用 MCP 客户端的开发者与设计师。

## 能力要点

- 35 项反模板化质量门禁与 6 轴自评（低于 3 分触发修订）
- WCAG 2.1 共 25 项检查的静态审计，返回 0-100 分与修复说明
- OKLCH 令牌系统：19 套主题、自动深色模式推导
- 组件输出支持 HTML/Tailwind、React TSX、Vue 3 SFC；logo 设计含 1,432 个商标 SVG 参考库

## 适用场景

- 让 Claude 等 MCP 客户端按设计系统规范生成组件与令牌
- 对现有页面跑 WCAG 2.1 审计与反模板化质量检查
- 生成匹配设计风格的 motion.dev / anime.js 动效片段
- 基于真实商标参考库进行 logo 设计与交付变体导出
