**评测 LLM 编写 1С 代码能力的基准工具（147 题）**

面向 1С（俄罗斯企业级平台）生态的 LLM 代码生成评测基准：内置 147 道任务，先用 generate_for_bench.py 调用 LLM（Anthropic 或 OpenRouter 通道）生成 1С 解决方案，再用 run_bench.py 在本地 1С:Предприятие 平台上编译执行并验证，输出编译率与正确率两项指标，附在线排行榜与原始结果 CSV。任务以 .epf 处理文件形式提供，需含解题、校验与启动三个函数。要求 Python 3.11+、本地 1С 平台或预构建 Docker 容器（经 HTTP 对接）。

## 能力要点

- 147 道 1С 编码任务，双指标评测：编译执行率 +  эталон 校验正确率
- generate_for_bench.py 支持 Anthropic / OpenRouter 双通道生成解答

- 附模型排行榜与原始结果 CSV 文件
