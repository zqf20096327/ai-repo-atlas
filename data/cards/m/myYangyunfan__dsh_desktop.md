# myYangyunfan/dsh_desktop

⭐ 765 · JavaScript · MIT · 推送 2026-11-23 · [GitHub](https://github.com/myYangyunfan/dsh_desktop) · [官网](https://github.com/myYangyunfan/dsh_desktop/releases) · 个人维护 · 中文 README

**给 Windows/macOS/Linux 用户的 DeepSeek Harness 开箱即用桌面客户端**

把官方 @deepseek-ai/dsh（DeepSeek Harness CLI）与 33 个精选伴随插件打包成 Tauri 2 桌面客户端：内置独立 Node 运行时，双击启动原生窗口，无需预装 Node.js。功能覆盖插件统一启停/更新、会话归档与会话地图、Bot 团队群聊协作、文件工作台、桌面通知、余额费用显示、崩溃自愈守护与双源（GitHub/Gitee）客户端更新。提供安装版与便携版；便携 Lite 版不含内置 Node，需本机 Node ≥ 22。项目本体不注入 Agent 预设，只携带内核出厂模式集。

## 能力要点

- 内置独立 Node 运行时与官方 dsh 内核，零环境依赖、离线可用
- 33 个精选插件随包交付，标注来源仓库、版本与许可证
- boot 守护瀑布与 supervisor 探活：坏插件修复、坏配置重建、崩溃自动重启
- Tauri 2 原生窗口，托盘常驻、原生通知、文件工作台

## 适用场景

- 不想手动装 Node.js 和逐个配置插件，希望一键使用 dsh
- 把 DeepSeek agent 当成长期协作工作台，用 Bot 群聊管理多个会话
- 在无网或离线机器上安装使用完整 dsh 运行时
- 用 U 盘便携版在临时机器上运行 dsh
