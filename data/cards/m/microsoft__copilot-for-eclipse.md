**微软官方的 Eclipse IDE GitHub Copilot 插件**

Microsoft 维护的 Eclipse IDE 插件，将 GitHub Copilot 的 AI 辅助编码能力带入 Eclipse：提供行内代码补全、下一处编辑建议、Ask/Agent 对话模式（解释代码、生成代码、自主完成项目任务）、MCP 集成以及 Custom Agents、Subagents、Plan Agent、SKILL.md 技能等代理能力。需要 Eclipse IDE 与有效的 GitHub Copilot 订阅方可使用；0.23.0 起最低环境要求为 Eclipse 2025-12（4.38）与 Java 21 运行时。通过 Eclipse Marketplace 或 update site 安装，插件收集使用数据并回传 Microsoft。

## 能力要点

- 行内代码补全与 Next Edit Suggestions
- Agent/Ask 对话模式，支持自主项目级任务
