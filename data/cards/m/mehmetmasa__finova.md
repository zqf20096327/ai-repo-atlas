# mehmetmasa/finova

⭐ 34 · PHP · MIT · 推送 2026-09-15 · [GitHub](https://github.com/mehmetmasa/finova) · [官网](https://finans.mikpa.com) · 个人维护

**面向自由职业者与中小企业的 Laravel 财务管理与 CRM 平台，含 AI 助手**

基于 Laravel 11 + Livewire 3 + Filament 3 的开源财务管理 Web 应用，功能覆盖多币种账户与收支追踪、客户/供应商/线索管理、看板式项目管理、储蓄投资与债务规划、角色权限体系，以及 Telegram 通知。AI 部分包括财务洞察聊天助手、文档分析与建议，通过 OpenAI 或 Google Gemini API 接入，需在 .env 配置 API key。安装需 PHP 8.2+、Node.js 18+ 与 MySQL/PostgreSQL，经 git clone、composer、npm 与 artisan 命令部署，提供在线 Demo（每 30 分钟重置）。
