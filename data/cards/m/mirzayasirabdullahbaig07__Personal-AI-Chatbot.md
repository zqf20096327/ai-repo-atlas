**基于 Gemini API 的网页版个人聊天机器人前端项目**

用 HTML、CSS 与原生 JavaScript 实现的浏览器端聊天机器人，通过 Google Gemini API 生成实时回复。功能包括逐词打字效果、上传图片/PDF/CSV/文本并预览、明暗主题切换（localStorage 保存偏好）、建议提示面板、清空聊天记录与中断回复，界面响应式适配多设备。使用方式为直接打开 index.html；README 声明仅用于教育目的，不供商业使用。
