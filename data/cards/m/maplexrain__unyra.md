# maplexrain/unyra

⭐ 147 · TypeScript · MIT · 推送 2026-11-27 · [GitHub](https://github.com/maplexrain/unyra) · 个人维护 · 中文 README

**本地优先的 AI 探索式学习桌面应用，把知识拆成拓扑节点学习**

基于 Electron + React 的本地优先桌面学习应用：从学习目标生成 DAG 知识拓扑，AI 导师在沙箱中编排生成教学文档、节点与试卷，输出为本地 Markdown/YAML/JSON 明文文件。内置三层讲解细粒度调节回路（模型推演、表单提问、网络检索 RAG）、用户画像与双层记忆系统、代码沙箱本地编译执行、独立考试窗口与错题追因，以及选词裂变子节点等交互。数据全在本地，模型请求由主进程端到端直连所配置服务商。仅提供 Windows 安装包与便携版；使用需自备 API Key。

## 能力要点

- DAG 知识拓扑画布与一份活的教学文档，支持分屏与行号跳转
- 超级导师通过 JavaScript 沙箱直接读写文档、编排试卷与批注
- 本地代码沙箱执行、PaddleOCR 划词与 SenseVoiceSmall 离线语音输入
- 本地优先存储：纯 Markdown/YAML/JSON 文件，AI 请求端到端直连服务商

## 适用场景

- 从高数这类学科目标出发，生成依赖分明的路线图并逐层学习
- 阅读讲义时选词裂变子节点，深潜前置概念
- 随堂小测客观判分，由 AI 导师批阅主观题并写错题讲解
- 导入 PDF 教材后划词提取、提问与作答
