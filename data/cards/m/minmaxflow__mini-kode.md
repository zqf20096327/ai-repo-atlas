# minmaxflow/mini-kode

⭐ 305 · TypeScript · MIT · 推送 2026-11-03 · [GitHub](https://github.com/minmaxflow/mini-kode) · 个人维护 · 中文 README

**教学用 AI 编码代理 CLI，帮助开发者理解 Coding Agent 架构**

Mini-Kode 是一个教育性质的项目，以约 1.4 万行 TypeScript 代码实现完整 Coding Agent：基于 OpenAI SDK 的 LLM 调用、覆盖文件操作/搜索/命令执行的工具系统、MCP 集成、流式输出的 Agent 循环、人在回路的权限审批、React/Ink 终端 UI，并自动读取项目根目录 AGENTS.md 维护上下文记忆。面向希望理解与魔改现代 AI 编码助手的开发者，附架构文档与代码分析资源。开发需 Bun 与 pnpm。

## 能力要点

- 教育优先设计：OpenAI SDK 之上的清晰架构与完整注释
