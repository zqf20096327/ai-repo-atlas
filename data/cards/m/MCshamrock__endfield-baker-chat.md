⭐ 20 · TypeScript · MIT · 推送 2026-11-27 · [GitHub](https://github.com/MCshamrock/endfield-baker-chat) · [官网](https://chat.peilika.beer) · 个人维护 · 中文 README

**终末地同人的 AI 角色聊天模拟器，35 名干员可对话**

基于《明日方舟：终末地》世界观的非营利同人项目，提供 AI 角色聊天服务：单聊、多角色群聊、世界书检索、干员记忆、AI 推荐回复、图片消息与 SSE 流式输出。仓库含 FastAPI 后端、Vue 3 网页前端、管理后台（密钥池/用量）与 Electron/Capacitor 客户端，一套后端同时服务网页版与客户端；客户端支持自定义 API 模式直连任何 OpenAI 兼容端点。部署需 Python 3.14、MySQL 8.4 与 Node 20+，Releases 提供 Windows 安装器与 Android APK。
