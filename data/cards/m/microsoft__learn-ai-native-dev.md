**微软的 agentic coding 实践课程站：学 AI 原生开发直觉**

社区共建的 AI 原生开发教学网站，主题为 agentic coding 的实践与直觉培养。内容分三类：Path（体系化路径）、Recipe（5-15 分钟单一问题示例）、Project Shape（项目形态），并按 researcher/developer/business/creative 四类受众过滤。学习者直接在浏览器打开网站，无需安装；贡献者通过 git clone 与 npm 运行本地站点（React 19 + Vite 7）。仓库自身用 Copilot Chat 的 slash-prompt 与自动 agent 流程辅助内容贡献。代码 MIT、内容 CC BY 4.0 双许可分列。
