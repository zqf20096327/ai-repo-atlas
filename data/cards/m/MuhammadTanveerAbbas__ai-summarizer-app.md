**网页应用：粘贴文章 URL 生成 GPT-4 摘要**

面向研究者、营销人员与内容读者的全栈 Web 应用：用户输入文章 URL，应用通过 RapidAPI 平台调用 OpenAI GPT-4 接口生成简短摘要，支持一键摘要、本地保存历史记录与剪贴板复制。前端用 React、Redux Toolkit + RTK Query、Tailwind CSS、TypeScript 与 Vite 构建，后端为 Node.js/Express。README 未给出安装运行命令或 API key 配置细节，属个人项目。
