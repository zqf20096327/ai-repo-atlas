# mindmuxai/mindmux

**本地优先的 AI 项目记忆工作台，面向开发者的"项目大脑"**

MindMux 是一款 Electron 桌面应用，用于持久化项目记忆：与 AI 讨论项目，将已确定的内容提炼为可移植的 brain/ 目录（本地 Markdown 文件），并将可执行部分分派给编码 agent，使上下文在会话、模型与 agent 之间延续。目前处于早期测试阶段，仅提供 macOS（Apple Silicon 与 Intel）构建，从 Releases 页面下载，首次安装后自动更新；Windows 与 Linux 支持已列入计划但尚未提供。仓库为其发布与产品更新的公开主页，应用源码正在逐步发布。

## 能力要点

- 讨论内容可沉淀为本地 Markdown 文件构成的 brain/ 目录
- 支持将明确的决策分派给编码 agent 执行
- 本地优先存储，上下文跨会话、模型与 agent 存续
- macOS 构建从 Releases 分发，首次安装后自动更新

## 适用场景

- 让项目讨论与决策在会话之间留存，避免重复交代上下文
- 以可移植的 Markdown 文件管理项目知识，不锁定在数据库
- 把已确定的执行事项交给编码 agent 处理
