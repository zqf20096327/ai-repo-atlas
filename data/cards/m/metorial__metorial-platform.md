**面向开发者的开源 MCP 集成平台，一次函数调用接入数千工具**

Metorial Platform 是基于 Model Context Protocol（MCP）的开源集成平台，供开发者将 AI 应用连接到外部 API、数据源与工具。核心机制：单函数调用式 SDK（JavaScript/TypeScript、Python）、收录 5000+ MCP server 的可搜索目录、Dashboard 内嵌 MCP Explorer 测试调试、按会话记录并生成错误报告的监控。自托管基于 Docker 容器运行 MCP server，技术栈含 Bun、Go、PostgreSQL、Redis、MongoDB；同时提供托管服务。采用 FSL-1.1 许可，明确面向开发者而非终端用户。
