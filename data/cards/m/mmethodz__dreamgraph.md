# mmethodz/dreamgraph

⭐ 127 · TypeScript · NOASSERTION · 推送 2026-10-09 · [GitHub](https://github.com/mmethodz/dreamgraph) · 个人维护

**面向开发者的图治理架构认知层：把项目知识固化为持久认知图**

DreamGraph 是一个 MCP 项目治理与架构认知环境，由实例级 daemon、dg CLI、浏览器 Architect、VS Code 扩展、仪表盘与持久知识图组成。它将源码、ADR、工作流、测试与运行时观察沉淀为图结构，支持单仓、monorepo 与多仓系统跨仓推理。认知输出在获得治理证据或明确评审前仅为建议性；提供插件 SDK 文档、示例插件与用户指南，由个人开发者独立维护并接受赞助。
