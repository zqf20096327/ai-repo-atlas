# mindolph/Mindolph

⭐ 202 · Java · GPL-3.0 · 推送 2026-09-13 · [GitHub](https://github.com/mindolph/Mindolph) · 个人维护 · 中文 README

**跨桌面平台的个人知识管理软件，支持思维导图等格式编辑与 Gen-AI 生成**

基于 JavaFX 的开源桌面应用，运行于 macOS、Windows 与 Linux。以工作区形式在本地存储中管理文件树，支持思维导图(.mmd)、Markdown、PlantUML、CSV 与纯文本格式的编辑与预览，思维导图可从 Freemind、XMind 等格式导入并导出为 Markdown、图片等。Gen-AI 功能通过 LLM 的 API 在思维导图、Markdown、PlantUML 与纯文本编辑器中生成或总结文本。提供 .dmg/.msi/.deb/.rpm 安装包与 Java 可执行 .jar，PlantUML 功能需先安装 graphviz。
