# Muyu-Chen/Auto-Essay-Grader

⭐ 23 · Python · GPL-3.0 · 推送 2026-05-08 · [GitHub](https://github.com/Muyu-Chen/Auto-Essay-Grader) · [官网](https://muyyy.link/programs/Web-Frontend/client/mainpage.html) · 个人维护 · 中文 README

**基于 LLM API 的英语作文批量自动评分与评语生成工具**

面向英语作文评分场景的客户端-服务端应用：用户上传作文放在单列的 Excel 文件（.xls），配置通义千问 API Key，选择模型档位（max/plus/turbo），填写作文题目与评分标准（任务回应、连贯性、词汇多样性、语法准确性等），后端调用大语言模型 API 批量生成分数与评语，评分与评语分两列输出。包含 Tk 桌面客户端与网页端，共用同一后端；后端另含用户管理、余额与卡密充值等计费功能。通过 pip 安装依赖并运行 Python 脚本启动。

## 能力要点

- Excel 单列作文批量导入，自动生成评分与评语
- 支持 max/plus/turbo 三档模型选择与自定义评分标准
- 桌面端（Tk GUI）与网页端共用同一后端接口
- 后端含用户管理、余额充值与 token 统计功能

## 适用场景

- 教师或辅导者批量给英语作文打分并生成评语
- 按自定义评分标准（任务回应、连贯性等）自动化评分流程
- 自部署后端并通过网页端或桌面端提交评分任务
