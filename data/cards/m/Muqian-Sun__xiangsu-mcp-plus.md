**给像塑（抖音 AR）用户的 MCP 服务：让 agent 操作编辑器与运营流程**

非官方的像塑（Douyin AR，macOS）MCP 扩展，由编辑器插件加 stdio MCP 服务两部分组成：原样转发像塑官方 MCP 工具并处理连接、超时与截图降级，另通过编辑器内部模块提供官方 MCP 之外的能力，包括官方素材库、添加对象菜单、AI 妆容/AI 3D/AR 视频任务、首页作品下载学习、特效提交送审、音源制作、运营数据读取等。依赖像塑版本（9.7.2 起实测），像塑升级后可能失效；仅限学习与个人制作。按客户端能力自动在扁平强类型与精简目录两种暴露模式间协商。

## 能力要点

- 一个 MCP 服务同时转发官方工具并扩展编辑器能力
- 支持素材库 AI 妆容、AI 3D（图生 3D、动作迁移、高斯点云）、AR 视频等任务提交与导入
- 首页作品下载打开，供 agent 读取场景、脚本和资源学习
- 对接运营平台只读接口，提供作品流水线、开工简报与赛道数据

## 适用场景

- 让 MCP 客户端（如 Claude Code）直接操作像塑编辑器制作特效
- 下载别人的首页作品供 agent 分析学习做法
- 在会话中完成图标设置、特效检测到提交审核的交付流程
- 读取运营数据跟踪作品审核状态、收益与选题方向
