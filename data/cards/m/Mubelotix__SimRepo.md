# Mubelotix/SimRepo

⭐ 477 · TypeScript · NOASSERTION · 推送 2026-11-17 · [GitHub](https://github.com/Mubelotix/SimRepo) · [官网](https://simrepo.dera.page) · 个人维护

**为开发者提供 GitHub 星标历史图表与相似仓库发现**

SimRepo 是一个 GitHub 仓库可视化与发现工具：生成星标历史图表（支持按日期/时间线多种视图、一键导出高质量图片、嵌入 README 或网页），并通过浏览器扩展在仓库侧边栏展示相似项目，帮助开发者发现可替代/相似的开源仓库。无需 API token 即可使用，支持 Firefox、Chrome、Edge 等多款浏览器。项目由 Star History 代码分叉而来，分叉点前代码为 MIT，扩展及之后的修改为 GPL-3.0。

## 能力要点

- 无需 API token 生成实时星标历史图表
- 浏览器扩展在 GitHub 仓库侧边栏展示相似项目
- 支持将图表嵌入 GitHub README 或其他网站
- 支持多种图表视图与多仓库对比输入

## 适用场景

- 给开源项目 README 嵌入实时星标历史图表
- 发现与某仓库相似的备选开源项目
- 对比多个仓库的星标增长趋势
