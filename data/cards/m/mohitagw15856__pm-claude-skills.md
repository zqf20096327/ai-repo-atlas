**面向 Claude/ChatGPT 等助手的专业 Agent 技能 markdown 库**

开源的 1,390 个 Agent Skills 库，每个技能是一个 SKILL.md 纯 markdown 文件，内含工作框架、输出模板、质量检查与反模式，让 AI 助手按专业标准完成具体任务（写 PRD、解读租约、复盘等）。支持 Claude、ChatGPT、Gemini、Cursor、Codex 等工具，提供 npx 安装器、Claude Code 插件目录、MCP 服务器、REST API 与离线包多种分发方式；含 21 个面向 Claude Duet 类常驻 agent 的技能；MIT 许可。
