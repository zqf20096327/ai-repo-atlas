# midas-research/audino

⭐ 1,148 · TypeScript · NOASSERTION · 推送 2026-02-03 · [GitHub](https://github.com/midas-research/audino) · 组织维护

**开源音频标注工具：为语音任务制作转写与标签数据**

由 Human Protocol 赞助的开源音频标注工具（v2.0，main 分支），提供转写与标注功能，适用于 VAD、说话人分离、说话人识别、ASR、情绪识别等任务的数据制作。功能包括多语言支持、emoji 标注、用户级项目/任务/作业管理、灵活标签创建与多格式导出。基于 CVAT 构建，通过 git clone 与 docker compose 部署运行，浏览器访问 Web 界面；开发环境需 Python 3.10+、Node.js 20 与 Docker。采用 CC BY-NC 4.0 非商业许可。
