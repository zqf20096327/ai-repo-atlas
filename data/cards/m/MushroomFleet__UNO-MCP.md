# MushroomFleet/UNO-MCP

⭐ 14 · TypeScript · ISC · 推送 2026-04-07 · [GitHub](https://github.com/MushroomFleet/UNO-MCP) · 个人维护

**面向写作者的 MCP 服务器：叙事分析与散文扩写增强**

UNO 是一个 Model Context Protocol 服务器，以三个 MCP 工具提供服务：analyze_text 输出叙事位置、人物焦点、场景类型、语气与重复模式的报告；enhance_text 默认将文本扩至 200% 并自动应用五种技术；custom_enhance_text 可选技术组合与 100%-500% 扩写目标。五种技术包括 Golden Shadow 扩展、环境描写扩充、动作场面增强、行文平滑与重复消除。面向使用 Claude Desktop 或 VS Code 的创作用户，通过 Smithery npx 一键安装或源码构建（Node.js ≥14，TypeScript 编译）。

## 能力要点

- 三个 MCP 工具：文本分析、自动增强、自定义增强
