**Momentic 官方 CLI：用自然语言构建与运行端到端测试**

Momentic 公司发布的官方命令行工具：用户以自然语言提示词编写、运行和管理端到端测试。使用需先在 Momentic 控制台登录并生成 API key，再通过 npm 安装 CLI、安装浏览器、初始化项目后启动应用；测试运行依赖 Momentic 云端服务。另提供 momentic skills 命令，为编码 agent 安装 Momentic 的 agent 技能与 MCP 服务器。支持 Node 20/22/24，覆盖 Windows/macOS/主流 Linux 发行版。
