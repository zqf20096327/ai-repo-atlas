# minthcm/minthcm

⭐ 438 · PHP · AGPL-3.0 · 推送 2026-10-08 · [GitHub](https://github.com/minthcm/minthcm) · [官网](https://minthcm.org/) · 组织维护

**开源 AI 原生 HCM 平台：面向企业用 AI agent 管理 HR 流程**

基于 SugarCRM CE 与 SuiteCRM 代码重建的开源人力资本管理（HCM）系统，覆盖招聘、入离职、考勤、休假、绩效、组织架构等完整 HR 功能，提供 Open API 与移动端应用。AI 部分提供内置 agent、MCP/WebMCP、A2A 多 agent 编排与自定义 agent 支持，LLM 可接入 OpenAI、Anthropic、Mistral、本地 Llama 等任意模型。部署支持本地、云端与混合环境；系统要求 Apache2、PHP 8.2、MySQL/MariaDB 与 ElasticSearch。AGPL v3 许可，安装步骤见官网指南。
