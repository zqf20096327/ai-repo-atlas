**VS Code 扩展：在编辑器内用 Azure ML 构建、训练与部署模型**

Azure Machine Learning for Visual Studio Code 扩展（早期名称 Visual Studio Code Tools for AI），让用户在 VS Code 界面中通过 Azure Machine Learning 服务完成模型构建、训练与云端或边缘部署。功能覆盖本地实验后向云上 GPU 集群扩展、自动化机器学习与超参数调优、实验跟踪与模型管理及 CI/CD 集成部署。支持 TensorFlow、PyTorch、Jupyter 等开源技术。运行于 Windows、macOS、Linux Ubuntu（64 位）。仓库仅提供文档指引，未见直接安装命令。
