# microsoft/mcp-dotnet-samples

⭐ 201 · C# · MIT · 推送 2026-10-23 · [GitHub](https://github.com/microsoft/mcp-dotnet-samples) · [官网](https://aka.ms/mcp/dotnet/samples) · 组织维护

**微软官方的 .NET MCP 服务器/客户端示例集**

由 Microsoft 维护的 Model Context Protocol .NET 示例仓库，演示在 .NET 应用中创建与使用 MCP 服务器和客户端，覆盖从自建 MCP 实现到集成 Azure 服务。含四个 MCP 服务器示例：Awesome Copilot 定制文件检索、Markdown 转 HTML、通过 Outlook 发送邮件、待办事项管理，各示例可在 VS Code / VS Code Insiders / Visual Studio 中安装。具体设置与运行说明位于各示例目录。
