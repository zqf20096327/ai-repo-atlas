# Maimuzamilhu/toondirector

⭐ 3 · Python · MIT · 推送 2026-11-04 · [GitHub](https://github.com/Maimuzamilhu/toondirector) · 个人维护

**在普通 PC 上把一个主题生成完整 2D 动画视频的开源 Windows 应用**

ToonDirector 是 Windows 桌面应用（PySide6/Qt），流程覆盖选题检索（Wikipedia 与可选 Tavily）、脚本撰写、角色与场景绘制、11 种语言配音或用户自录声音转换、逐帧动作演出，到合成音乐、音效与逐词字幕，输出 30 秒至 60 分钟的宽屏或 Shorts 视频；也可把用户已有视频重绘为 2D 卡通并保留原声。LLM 作为创作大脑，可接入 16 个提供方并按优先级自动切换，无需显卡，普通笔记本即可运行。

## 能力要点

- 主题→脚本→绘制→演出→剪辑的全流程自动生成，每步结果可断点续作
- 16 个 AI 提供方可配置排序，额度用尽自动切换下一个
- 无需显卡，实机演示在无 GPU 的 i5/8GB 笔记本上运行
- 本地绘制、语音转换与导出，配音支持 11 种语言

## 适用场景

- 输入一个话题自动生成带解说的 2D 动画科普视频
- 把自己的视频转成保留原声的 2D 卡通
- 在无显卡的普通笔记本上离线绘制和导出动画
