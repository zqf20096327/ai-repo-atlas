**微软官方 MCP 服务器集合与目录：让 AI 应用接入 Azure 等服务**

## 能力要点

- 从本仓库构建 Azure MCP 与 Fabric MCP 服务器
- 目录收录 20 余个微软系 MCP 服务器，按类别与 Local/Remote 类型标注
- 每个条目给出 VS Code/Visual Studio/IntelliJ/Claude Code 等安装入口
- 提供核心库、测试框架与工程系统供 MCP 服务器贡献者复用
