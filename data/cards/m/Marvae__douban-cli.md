**豆瓣命令行工具与 AI Agent Skill，查影书并备份标记记录**

提供豆瓣数据的命令行查询与账号记录管理：查询电影、剧集、图书的评分、短评、榜单和相似推荐（无需登录），一条命令导出观影/读书记录为 JSON、CSV 或 Markdown，并支持标记、评分、写短评（登录后，改动前预览、按 ISBN 核对、保留原有评分标签）。同时以 Agent Skill 形式接入支持 Agent Skills 的 AI agent，用自然语言完成上述操作。npm 分发，需 Node.js 22.13+，仅 2 个依赖，无 API key。非官方工具，需控制请求频率。

## 能力要点

- 查询豆瓣影书评分、榜单、相似推荐与播放平台，公开查询不用登录
- 一条命令导出观影/读书记录为 JSON、CSV 或 Markdown，含评分与短评

- 把微信读书读完的书按 ISBN 同步标记到豆瓣
