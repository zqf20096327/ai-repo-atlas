**面向科研人员的 LangGraph 从零到多智能体教程**

为有 Python 基础但无 LangGraph/LangChain 经验的博士生与研究者编写的渐进式教程仓库。内容以 langgraph_examples/ 文件夹中的可运行 Python 示例为主：从无 LLM 的 Hello World 图、带对话记忆的聊天机器人，到实现 ReAct 模式的工具调用 Agent。讲解 State、节点、边、条件路由、START/END 等核心概念，并覆盖环境搭建、API key 管理与 OpenAI/Anthropic/Ollama 三种模型接入选项。
