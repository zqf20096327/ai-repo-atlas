**SEObot 博客 API 的 TypeScript 客户端库：拉取并渲染 SEO 博客内容**

为 SEObot（app.seobotai.com）的 Blog API 提供的 npm 客户端库：通过 API key 初始化 BlogClient，支持按分页获取文章、按分类或标签筛选、按 slug 获取单篇文章，内置缓存机制，并导出 IArticle 等 TypeScript 类型。面向需要在自己网站（如 Next.js 项目）中实时渲染 SEObot 生成的 SEO 博客内容的开发者，需要 SEObot 账号与 API key 才能使用。另提供面向 AI 编程代理（Lovable、Cursor、Copilot、Claude）的 Next.js SSR 集成指令指南。
