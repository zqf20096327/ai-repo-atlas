**微软面向 M365/Teams 的企业级 Agent 开发 SDK（Python）**

Microsoft Agent 365 SDK 在 Microsoft 365 Agents SDK 之上扩展企业级能力，覆盖四个方向：可观测性（追踪/缓存/监控）、通知服务、运行时工具与开发工具链。以多个 microsoft-agents-a365 前缀的 PyPI 包分发，含 notifications、observability、runtime、tooling 等库，并为 Agent Framework、LangChain、OpenAI、Semantic Kernel、Azure AI Foundry 提供观测与工具扩展，面向构建部署到 M365、Teams、Copilot Studio 和 Webchat 的生产级 Agent 的开发者。项目处于活跃开发阶段，构建需 Python 3.10+ 与 uv。
