**为 Dragon Copilot 开发扩展与临床连接器的示例和 CLI 工具集**

Microsoft 维护的 Dragon Copilot 产品家族扩展开发资源库：包含 Physician Workflow、Radiologists Workflow 两类扩展示例与最佳实践，以及对接 EHR 与企业 API 的 Clinical Application Connector 文档；提供 dragon-copilot CLI 用于初始化、生成、校验和打包扩展与连接器；各产品配独立 QUICKSTART 指南，从开发环境搭建到在 Dragon Copilot 内测试。面向为医疗场景集成该产品的开发者与合作伙伴，MIT 许可。
