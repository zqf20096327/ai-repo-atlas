**面向 .NET 开发者的生成式 AI 应用实战课程（5 课）**

微软维护的 .NET 生成式 AI 入门课程，包含五节课：生成式 AI 介绍、生成式 AI 技术与 Microsoft.Extensions.AI 调用、语义搜索/RAG 等模式、基于 Microsoft Agent Framework 的 Agent 开发、负责任 AI。每课提供可运行的完整代码示例、视频与分步指南，覆盖 28+ 个 Agent Framework 示例及本地决策模型、Milvus 向量检索等新增样本。运行需 .NET 11 SDK，AI 侧可在 Ollama/Foundry Local（本地）或 Azure OpenAI/Microsoft Foundry（云）之间选择，本地路径无需 Azure 账号。
