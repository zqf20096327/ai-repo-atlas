**基于 Vercel AI SDK 的 ACP 客户端界面模板，连接本地/远程 agent**

Web 前端模板，使用 Vercel AI SDK 与 AI Elements 构建 Agent Client Protocol（ACP）界面，可连接 Claude Code、Gemini CLI、Codex CLI 等 ACP 兼容 agent。技术栈为 React Router V7、shadcn/ui、Tailwind CSS、TypeScript、Vite。使用流程：从下拉列表选择 agent，在设置对话框中配置 API key 环境变量，即可以聊天界面与 agent 交互。面向想快速搭建 agent 前端界面的开发者，以模板形式提供，通过 pnpm 安装依赖运行。
