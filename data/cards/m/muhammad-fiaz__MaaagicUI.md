# muhammad-fiaz/MaaagicUI

⭐ 16 · TypeScript · GPL-3.0 · 推送 2026-07-25 · [GitHub](https://github.com/muhammad-fiaz/MaaagicUI) · 个人维护

**给开发者的桌面 AI 应用 UI 框架（LLM/Stable Diffusion）**

基于 Next.js 与 Tauri 的开源 UI 框架/模板，用于构建在 Windows、macOS、Linux 原生运行的 LLM 与 Stable Diffusion 桌面应用界面。内置 CivitAI 下载商店、明暗主题、可拖拽标题栏、侧边导航等组件化 UI 要素。技术栈含 Node.js、Rust/Tauri、Next.js、Tailwind、Chakra UI、shadcn/ui，并包含 Python 后端目录（Flask/FastAPI）。通过 git clone 后 npm 安装并以 Tauri CLI 开发与构建。README 顶部声明项目已停止维护、不再更新，风险自负。
