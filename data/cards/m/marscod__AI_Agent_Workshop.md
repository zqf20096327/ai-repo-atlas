**AI agent 构建与部署的上手教程仓库**

提供构建和部署 AI agent 的分步上手指南：通过 GROQ 或 xAI Grok2 的 API 调用 LLM（也可选用 ollama、LM Studio 本地运行），配套 Colab Notebook；流程包括 fork 仓库、配置 .env 填入 API key、在 GitHub Codespaces 中打开、运行 setup.sh 与 run.sh 启动服务，并可选择将端口公开。面向参加动手实践的初学者，本体是文档与脚本集合，不含模型实现。
