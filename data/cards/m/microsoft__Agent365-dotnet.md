# microsoft/Agent365-dotnet

⭐ 29 · C# · MIT · 推送 2026-10-29 · [GitHub](https://github.com/microsoft/Agent365-dotnet) · 组织维护

**微软面向企业级 Agent 开发的 C#/.NET 扩展 SDK**

Microsoft Agent 365 SDK 在 Microsoft 365 Agents SDK 之上提供企业级能力扩展，覆盖四个方向：可观测性（tracing/缓存/监控）、通知服务、运行时工具与开发工具，面向在 M365、Teams、Copilot Studio 和 Webchat 上构建生产级 Agent 的 .NET 开发者。项目处于活跃开发中，包以 Microsoft.Agents.A365 前缀发布到 NuGet；源码包含 DevTools、Notification、Observability、Runtime、Tooling（含 MCP 集成）等模块，需 .NET 8.0 SDK 或更高版本编译。
