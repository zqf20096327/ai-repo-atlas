# machinelearnjs/machinelearnjs

⭐ 540 · TypeScript · MIT · 推送 2026-02-07 · [GitHub](https://github.com/machinelearnjs/machinelearnjs) · [官网](https://machinelearnjs.github.io/) · 组织维护

**面向浏览器与 Node.js 的 TypeScript 机器学习库**

用 TypeScript 编写的机器学习库，供 Web 与 Node.js 环境使用，覆盖随机森林、SVM、概率模型等结构化数据算法。提供统一的模型 API（fit 训练、predict 推理、toJSON/fromJSON 保存加载模型状态），并声称通过教学式 API 帮助用户理解算法原理。默认使用纯 JavaScript 版 tfjs，可安装 machinelearn-node 或 machinelearn-gpu 包启用 C++ 绑定或 GPU 加速；浏览器端经 jsDelivr 分发。
