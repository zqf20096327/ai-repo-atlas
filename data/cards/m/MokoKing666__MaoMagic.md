# MokoKing666/MaoMagic

⭐ 3 · Kotlin · MIT · 推送 2026-10-24 · [GitHub](https://github.com/MokoKing666/MaoMagic) · 个人维护 · 中文 README

**完全离线的传统术数排盘 Android 应用，内置端上模型生成解卦白话**

面向 Android 用户的传统术数工具箱：六爻起卦、八字排盘、梅花易数、今日黄历四大模块，排盘与断卦由确定性规则引擎在本机完成，147 个单元测试加全输入空间集成测试覆盖算法。解卦文案可选端上模型（README 写明为 Qwen3.5 0.8B，约 920 MB 按需下载，经 LiteRT-LM 运行时走 OpenGL ES GPU）转述既定结论，模型不参与判断；也支持用户自填地址的云端 AI，两者均不可用时回落规则引擎。默认完全离线，MIT 协议开源。
