**微软官方的 M365 Copilot 智能体开发学习系列（含视频与配套材料）**

微软维护的实践学习系列，围绕 Microsoft 365 Copilot 上的声明式智能体，分 Extend、Ground、Connect、Evaluate 四条主线：通过 Skills 和 actions 扩展智能体、用 WorkIQ 注入企业上下文、连接 MCP apps 提供交互式体验、用 M365 Copilot Evals 评估质量。每节含录播直播视频与补充材料。面向在 M365 上构建智能体的开发者，前置条件包括 M365 开发者沙盒订阅、Copilot 许可证、Node.js 22 与 Agents Toolkit VS Code 扩展 5.0.0+ 或 CLI。
