**用 GitHub Copilot 构建社交媒体网站的实践教程**

微软提供的自定节奏动手教程（workshop）：以虚构公司 Contoso 开发微型社交媒体网站 MVP 为情境，指导参与者用 GitHub Copilot Agent Mode 在 Python、JavaScript、Java、.NET 四种技术栈中构建后端与前端应用，并进行容器化。内容涵盖自定义指令、MCP 服务器接入等 Copilot 功能，提供 7 种语言的教程文本、分步指引文档与各语言的完整示例代码（FastAPI、React、Spring Boot、Blazor）。推荐通过 GitHub Codespaces 运行，也可本地准备环境。
