# pdsuwwz/nextjs-nextra-starter

⭐ 318 · TypeScript · MIT · 推送 2026-09-17 · [GitHub](https://github.com/pdsuwwz/nextjs-nextra-starter) · [官网](https://nextra.likemashang.com/zh) · 个人维护 · 中文 README

**面向独立开发者与小团队的 Next.js 博客/文档/AI SaaS 落地页模板**

基于 Next.js 16、React 19、Nextra 4、TypeScript 的前端启动模板，集成 Tailwind CSS 4、Shadcn UI、Radix UI、Aceternity UI、Sass、ESLint 10、Iconify 与 i18n 中英文多语言，覆盖博客、文档站、AI SaaS 落地页等场景，提供暗黑模式、登录页与前端鉴权示例，支持 Vercel / Netlify 部署。仓库另在 .agents/skills/ 下提供项目蒸馏 Skill（架构、功能地图、扩展指南等文档）供二次开发者参考。前置要求 Node >= 20.x 与 Pnpm 9.x，通过 pnpm 命令安装运行。
