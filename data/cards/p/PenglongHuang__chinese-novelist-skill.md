**让 AI Agent 从零生成 10-50 章中文小说的 Skill**

一个面向 Coding Agent / Personal Agent 的中文长篇小说创作技能包：通过三层递进式问答收集题材、视角与文风，确认规划后以串行、子 Agent 并行或 Agent Teams 三种模式逐章生成 10-50 章内容；内置偏好记忆（跨项目共享）、中断检测续写、逐章审读与字数校验修复，并附带本地"小说书房"界面浏览书架、正文与审读报告。以 Skill 形式经 npm 安装，适配多种主流 Agent Harness。
