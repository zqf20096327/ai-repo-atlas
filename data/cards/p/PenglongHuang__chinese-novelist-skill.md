**让 coding agent 从零写完整中文长篇小说的 Skill**

一个面向 Claude Code 等 coding agent 的技能包：通过四阶段流程（初始化→三层问答→规划确认→连续写作→自动校验）生成 10-50 章的中文小说。内置偏好记忆（user-preferences.json 跨项目共享）、中断续写、串行/子Agent并行/Agent Teams 三种写作模式，每章 3000-5000 字并经润色与字数校验（不合格自动修复最多 3 轮）。附带流程文档与 10 份写作指南（悬念钩子、对话、情节结构等模板）。通过 npx skills add 安装，MIT 许可。

## 能力要点

- 四阶段流程生成 10-50 章中文小说，每章 3000-5000 字
- 三层递进式问答与偏好记忆，支持跳过/随机生成/默认值
- 三种写作模式：串行、子Agent 并行、Agent Teams
- 中断续写与自动字数校验（不合格章节最多修复 3 轮）
