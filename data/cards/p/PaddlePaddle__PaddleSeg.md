# PaddlePaddle/PaddleSeg

⭐ 9,413 · Python · Apache-2.0 · 推送 2026-02-05 · [GitHub](https://github.com/PaddlePaddle/PaddleSeg) · [官网](https://arxiv.org/abs/2101.06175) · 组织维护 · 中文 README

**飞桨图像分割开发套件：45+模型全流程训练到部署**

基于 PaddlePaddle 的端到端图像分割套件，内置 45+ 模型算法与 140+ 预训练模型，覆盖语义分割、交互式分割、图像抠图、全景分割、3D 医疗分割等任务。支持配置化驱动与 API 调用两种开发方式，打通数据标注（EISeg）、训练、压缩（量化/蒸馏/裁剪）与多端部署（服务化/端侧/JS）。模型按高精度/轻量级/超轻量级分档，给出 V100 与骁龙855 的精度与速度数据；另接入 PaddleX 低代码全流程开发，支持英伟达 GPU、昆仑芯、昇腾、寒武纪、海光等硬件间切换。

## 能力要点

- 45+ 分割模型与 140+ 预训练模型，四大分割能力
- 数据标注→训练→压缩→部署全流程，多种部署方式（Serving/Lite/JS/ONNX）
- 模型按部署目标（服务器 GPU/Jetson/CPU/移动端 ARM）分档并给出实测精度与速度
- 支持多标签分割、量化蒸馏压缩、多卡并行训练与显存优化
