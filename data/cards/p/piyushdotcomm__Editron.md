# piyushdotcomm/Editron

⭐ 67 · TypeScript · MIT · 推送 2026-10-31 · [GitHub](https://github.com/piyushdotcomm/Editron) · [官网](https://editron.in) · 个人维护

**浏览器内全栈开发环境：模板起步、在线编辑运行与协作**

基于 Next.js、WebContainers 与 Monaco Editor 的浏览器端开发环境：用户从 React、Vue、Next.js、Express 等多种起步模板创建项目，在浏览器内编辑代码、通过 xterm.js 终端在 WebContainer 中运行、实时预览并导出 ZIP，无需本地工具链。内含 AI 聊天与代码补全层，可在 Gemini、Groq、Mistral 之间切换，支持用户自备 API key。另提供 NextAuth 认证、Prisma+MongoDB 持久化与独立 Yjs 协作服务器实现实时协同编辑。README 声明部分 AI 流程仍在演进中。

## 能力要点

- WebContainer API 在浏览器内运行全栈项目，xterm.js 终端与实时预览
- 覆盖前端/后端/全栈/工具型的起步模板目录
- AI 聊天与补全层，支持 Gemini/Groq/Mistral 切换与应用内 API key
- 独立 Yjs 协作服务器支持实时协同编辑

## 适用场景

- 不装本地工具链直接在浏览器里跑全栈项目
- 用起步模板快速创建和分享代码试验场
- 多人实时协同编辑同一项目
