# pbek/QOwnNotes

⭐ 5,974 · C++ · GPL-2.0 · 推送 2026-11-24 · [GitHub](https://github.com/pbek/QOwnNotes) · [官网](https://www.qownnotes.org/) · 组织维护

**本地 Markdown 笔记与待办管理器，支持 Nextcloud 同步**

QOwnNotes 是开源纯文本记事本与待办清单管理器，运行于 GNU/Linux、macOS 和 Windows，笔记以 Markdown 纯文本文件存储，可经 Nextcloud/ownCloud 文件同步访问，移动端可通过配套 Android 应用或 WebDAV 客户端查看。功能包括多笔记文件夹、笔记版本与回收站恢复、脚本系统与在线脚本仓库、CalDAV 任务管理、AES-256 加密、便携模式与 Vim 模式。内置 AI 支持（OpenAI、Groq 脚本集成）与 MCP 服务器。安装走发行打包渠道或从源码构建，构建需 Qt 与编译工具链。
