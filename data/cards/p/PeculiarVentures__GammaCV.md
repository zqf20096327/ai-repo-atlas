**面向 Web 应用的 WebGL 加速计算机视觉库**

基于 WebGL 在浏览器 GPU 上运行的计算机视觉库，采用与 TensorFlow 相似的数据流范式构建与执行计算图，用于图像处理与特征提取。提供线条检测、HOG、Canny 边缘检测、高斯模糊、色彩分割、直方图均衡等操作示例，通过 npm 安装，供需要在现代 Web 应用中集成计算机视觉能力的开发者使用。由 PeculiarVentures 团队维护。
