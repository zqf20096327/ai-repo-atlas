**用机器学习预测股价的桌面 GUI 应用**

基于 Python 的股票价格预测桌面应用：通过 yfinance 从 Yahoo Finance 拉取历史行情，计算 RSI、MACD、SMA、EMA 等技术指标作为特征，用 SVM（scikit-learn）预测下一交易日收盘价，并自动跳过周末与市场假日。提供 GUI，支持股票代码自动补全、90/180/360 天训练周期选择和 matplotlib 交互图表。需 Python 3.8+ 与网络连接，提供 Windows 批处理和 Mac/Linux shell 启动脚本。声明仅用于教育目的，预测不保证准确。
