# pathpy/pathpyG

⭐ 60 · Python · AGPL-3.0 · 推送 2026-10-07 · [GitHub](https://github.com/pathpy/pathpyG) · [官网](https://www.pathpy.net) · 组织维护

**面向时序网络数据的 GPU 加速图学习与网络分析库**

pathpyG 是基于高阶 De Bruijn 图模型对时序数据进行因果结构建模的 Python 库，提供 GPU 加速的新一代网络分析与图学习方法，用于时间网络上的时序图和路径数据建模。研究背景来自 ETH Zürich、苏黎世大学、普林斯顿大学及维尔茨堡大学，NeurIPS、LoG、Nature Physics 等处发表多篇论文。支持 Python 3.10+，依赖 numpy、scipy、torch 与 torch-geometric，通过 pip 从 GitHub 安装开发版，在线文档含教程与 API 参考，测试用 pytest 运行。
