**JetBrains IDE 的 AI 编程 Agent 语言，用 LLM 自动化开发任务**

以 IntelliJ 插件形式提供的 AI Coding Agent 语言，通过 .shire 脚本让 LLM 与 IDE 交互实现自动化编程。内置右键菜单、Inline Chat、终端、提交面板等多种交互入口，覆盖需求分析、代码生成、CRUD、单元测试（Java/Python/Golang）、E2E 测试、Git 提交信息、数据库 Schema 设计、WireMock mock 服务等 SDLC 场景，并集成 Jira、Confluence、Jenkins 等工具链。源自 UnitMesh 旗下 AutoDev 项目的 DevIns 语言。开发构建基于 Gradle 与 IntelliJ Platform 252，发布于 JetBrains Marketplace。
