# PromptMixerDev/prompt-mixer-app-ce

⭐ 85 · TypeScript · MIT · 推送 2025-11-28 · [GitHub](https://github.com/PromptMixerDev/prompt-mixer-app-ce) · [官网](https://www.promptmixer.dev) · 组织维护

**测试与管理提示词链的桌面应用，供对比多个 LLM 输出**

开源桌面应用（TypeScript/Node 构建），面向做提示词工程的开发者和用户：支持构建传递上下文的提示词链、通过表单界面编排多步工作流、经 connectors 接入自定义模型与第三方 API，并在投入生产前对提示词进行实验与评估。提供 macOS（arm64/Intel）、Windows、Linux 预编译包下载；开发环境需 Node.js 与 Yarn，从源码克隆后用 yarn 安装依赖、启动与构建。MIT 许可。

## 能力要点

- 提示词链构建：序列内传递上下文以实现复杂对话
- 表单式界面编排多步提示词工作流
- 通过 connectors 接入自定义模型与第三方 API
- 提供 macOS/Windows/Linux 预编译安装包

## 适用场景

- 在投入生产前持续实验和评估提示词效果
- 对比不同 LLM 对同一提示词的输出
- 构建和测试多步提示词链与分析工作流
