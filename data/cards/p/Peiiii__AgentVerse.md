# Peiiii/AgentVerse

⭐ 318 · TypeScript · MIT · 推送 2026-01-27 · [GitHub](https://github.com/Peiiii/AgentVerse) · [官网](https://agent.dimstack.com) · 个人维护 · 中文 README

**多 AI 专家协作对话的开源平台：多角色自主讨论解决问题**

一个支持多 AI 智能体协作对话的 Web 平台：多个具有不同专业领域与个性的 AI 专家在群聊中自主交流讨论，向用户提供多角度见解。内置 14 个预设专家团队（思维探索、创作、商业等类别），支持对话式创建自定义 Agent、MCP 协议工具集成、基于 LightningFS 的文件系统与多讨论管理。面向终端用户，以头脑风暴、产品评估、决策辅助、学习辅导、代码开发为应用场景。本地运行需 Node.js >= 18 与 pnpm >= 8.0，通过 git clone 源码安装并配置 AI 服务商 API Key，MIT 许可证。

## 能力要点

- 14 个预设专家团队，覆盖思维探索、创作、商业等类别
