**面向 AI DAO 的多智能体框架：工厂式生成并管理专用 agent 团队**

PolyGPT 是一个开源框架与技术栈，用于在 AI 驱动的去中心化自治组织（DAO）中构建和管理智能体网络：由 Global Factory 与 Specialized Factories 的层级结构生成具备特定技能的 agent，部署后自主执行软件开发、客服等运营任务；配备中央知识库供 agent 读取与回写，形成自改进循环。README 声称模块化、可扩展。项目通过 git clone 与 Poetry 安装、以 poetry run python main.py 运行；README 两次声明项目为 work in progress，功能与结构可能变动，且相当篇幅为愿景叙事而非已实现细节。
