**从零实现的 Hadoop MapReduce 机器学习算法集（Java）**

用 Java 从零实现（不依赖机器学习库）的一系列 MapReduce 机器学习程序：线性/逻辑回归（迭代版）、K-Means 聚类、KNN 分类、购物篮分析、共同好友计算等。开发环境为 Eclipse IDE 与 HDT 插件，Hadoop 版本为 1.2.1。作者自述代码为初学时期所写、效率低且待优化，并指出可通过自定义 Secondary Sort 改善 shuffle-sort 阶段的耗时与内存占用。以 Eclipse Public License 2.0 授权（附 GPL v2 附带 Classpath Exception 的次级许可选项）。
