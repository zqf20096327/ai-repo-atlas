**面向个人的长期 AI 伙伴：本地优先的桌面 Agent 工作台**

NextClaw 是开源、本地优先的个人 AI 助手应用：用户以目标发起请求，Agent 组织工具与步骤，完成资料整理、数据分析可视化、文档起草、本地文件处理、搭建小工具与定时任务，结果保留在同一工作区。支持为每个任务选择 Agent 运行时（Native/Codex/Claude Code/OpenCode/Hermes），内置模型供应商并支持自定义 OpenAI 兼容端点，可接入微信/飞书/QQ 等消息渠道。1.0 目标（理解用户、主动分析、自我改进）为规划中，验收未完成、无发布日期。提供桌面安装包、npm 与 Docker 部署。

## 能力要点

- 任务上下文与结果（对话、文件、文档、后续工作）集中在同一工作区
- 每任务可选 Agent 运行时（Native/Codex/Claude Code/OpenCode/Hermes）
- 支持 OpenRouter/OpenAI/Anthropic/Gemini/DeepSeek/vLLM 等模型供应商及自定义端点
- 定时任务、消息渠道（微信/飞书/QQ 等）与技能/MCP 支持

## 适用场景

- 让 Agent 把资料整理成报告、对比表或可视化结果
- 通过飞书/微信等渠道接收定时简报并继续对话
- 在本地或自管服务器上运行专属 Agent 处理文件与重复性工作
