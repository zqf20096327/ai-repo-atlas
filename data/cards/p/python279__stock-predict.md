# python279/stock-predict

**自动抓新闻并用大模型分析股市投资机会的邮件报告系统**

Python 编写的全自动系统：每日从 News API、RSS、GDELT DOC API 与 Google News 抓取新闻，经白名单过滤后送入大模型，结合美股/A股/韩股行情、宏观与官方披露数据，生成含黑天鹅预警、宏观传导、四大市场分析等 7 章报告，以 JSON/Markdown/HTML 邮件输出。支持定时调度与 Cron，运行依赖用户自备 LLM API 密钥和邮箱 SMTP 配置，报告内容为模型输出，README 未提供投资准确性的验证方式。
