# pluveto/daan

⭐ 283 · TypeScript · AGPL-3.0 · 推送 2025-11-25 · [GitHub](https://github.com/pluveto/daan) · [官网](https://daan.one) · 个人维护 · 中文 README

**浏览器中的轻量 LLM 聊天客户端，支持 MCP 与角色设定**

Daan（答案）是一个轻量级大语言模型客户端，兼容 OpenAI GPT 系列及其他 OpenAI 兼容 API，用户可自定义 API 端点与模型。功能包括 MCP（Model Context Protocol）接入外部工具与知识、角色（Character）自定义聊天人设、将常用功能转为 miniapp 并在迷你窗口使用、通过 GitHub Issues 发布与一键安装 miniapp/角色，以及 miniapp 以 MCP 服务形式运行。提供在线 Demo 或本地部署两种使用方式，API 密钥存储在浏览器本地。支持系统提示词、历史长度、主题、对话置顶与 Token 估算等个性化设置。采用 AGPL-3.0 许可证。
