**把提示词草稿改写为生产级提示词的 AI 技能（SKILL.md）**

以 Claude Code 插件/技能形式提供的提示词优化工具：粘贴草稿后，按五阶段流程（诊断→选技术→改写→自检→交付）产出优化提示词及变更说明。技术规则按模型族（Claude 4.x、GPT/o 系列、Gemini）自适应调整，技术来源可追溯到 Anthropic/OpenAI/Google 指南与 The Prompt Report 的 58 种技术分类。除 Claude Code 外，提供 GitHub Copilot CLI、OpenAI Codex、Gemini CLI、OpenCode、Cursor/Windsurf/Cline 等工具的安装适配方式。仅改进提示词，不执行提示词。

## 能力要点

- 五阶段改写流程，产出优化提示词+逐条变更说明
- 技术按任务类型与目标模型族自适应选择
- 收录 The Prompt Report 全部 58 种技术及厂商后续补充
- 支持 8 种以上编码助手/CLI 工具的安装通道

## 适用场景

- 把随手写的提示词草稿改写成结构化生产级提示词
- 针对不同模型族（Claude/GPT/Gemini）调整提示词写法
- 在 Claude Code 等工具中用斜杠命令或自然语言触发优化
