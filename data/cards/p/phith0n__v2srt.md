# phith0n/v2srt

⭐ 50 · Python · 推送 2026-10-17 · [GitHub](https://github.com/phith0n/v2srt) · 个人维护 · 中文 README

**本地 whisper.cpp 识别视频语音并可用 Gemini 翻译的字幕生成 CLI**

命令行工具 v2srt：调用本机 whisper-cli 将任意视频的语音识别为 SRT 字幕，长视频按静音点自动分段、多进程并行识别；可选接入 Gemini API 将字幕翻译为目标语言（默认 gemini-3.8-flash，可输出双语字幕），翻译与识别流式并行。提供补漏识别、VAD 降噪、失败重试与日志。依赖 uv、FFmpeg、whisper.cpp 与 whisper 模型文件；不配置 Gemini 密钥时仅生成原文字幕。面向需要本地语音识别不出网、再按需翻译的终端用户。

## 能力要点

- whisper.cpp 本地识别，支持 GPU 加速，音频不上传云端
- 流式翻译：分段识别完立即进入翻译队列，识别与翻译并行
- 基于 VAD 的补漏识别：找出有人声却无字幕的片段二次识别
- 双语字幕、批量处理、翻译已有 .srt 文件

## 适用场景

- 为长视频批量生成 SRT 字幕并翻译成目标语言
- 在本地完成语音识别、音频不出网的环境下做字幕
- 输出双语字幕或对已有字幕文件做翻译
