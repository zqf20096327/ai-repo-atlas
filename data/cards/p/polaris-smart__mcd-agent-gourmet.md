**帮个人用户算清麦当劳点单的 MCP Skill：一句话得核价餐单**

一个只读的麦当劳中国 MCP 客户端 + Agent Skill，接受「35 元，不辣，去冰，带走」式的一句话需求，按价格、钠含量、口味三个标准比较完整餐单（主食+小食+饮料），金额只认官方 calculate-price 返回的整数分，最终产出一张可照着点的点单卡；无方案时直说并给出预算阶梯。不领券、不兑换、不下单、不支付。提供网页（历史快照）、CLI（Python 3.9+ 仅标准库）与 WorkBuddy Skill 三种入口，实时核价需本机配置官方 MCP Token。
