# PaperHammer/VirtualPaper

⭐ 16 · C# · GPL-3.0 · 推送 2026-10-30 · [GitHub](https://github.com/PaperHammer/VirtualPaper) · 个人维护

**Windows 桌面壁纸管理软件，含 AI 风格迁移与超分**

面向 Windows 10+ 用户的开源免费轻量壁纸管理软件，基于 XamlNexus 和 Lively 构建。支持静态图片、动图、视频与网页交互壁纸，提供实时预览、效果定制、3D 视差跟随鼠标、独立屏保服务、锁屏背景设置与主题样式。AI 功能包括图像风格迁移与超分辨率增强（清晰度恢复、无损放大）。运行时要求 .NET 8.0，通过 GitHub release 提供安装包下载，采用 GPL-3.0 许可。
