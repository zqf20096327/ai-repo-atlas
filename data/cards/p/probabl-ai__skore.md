**加速 ML 模型开发的 Python 库：结构化实验与自动评估报告**

skore 是面向数据科学工作流的开源 Python 库，定位为将零散的 ML 开发过程转化为结构化工件：一行代码生成模型评估与洞察报告，内置方法学警告提示常见陷阱，减少样板代码，并维护清晰的项目组织。与 pandas/polars/skrub/scikit-learn 等 generic 工具搭配使用，要求 python>=3.11.4，通过 pip 或 conda-forge 安装，可选安装 hub 与 mlflow 扩展。项目由 Probabl 维护，另提供协作平台 Skore Hub 的集成。
