**30 天软件模拟硬件工程的每日构建挑战，无需硬件**

面向已掌握 Python 基础的开发者的 30 天每日构建挑战：每天约 1 小时完成一个项目，用软件在笔记本上实现真实硬件概念（PWM、I2C、ADC、PID 控制、中断处理等）。核心模型为 sensor → process → output，用摄像头/麦克风作为传感器、屏幕作为执行器。四周期结构：第一周身体输入、第二周经 ollama 运行本地 LLM、第三周信号与系统、第四周系统集成。全部本地运行，无云依赖与 API key。每天缺席即出局，项目须按模板提交 README。v2.0 计划引入 Raspberry Pi Pico W 等真实硬件。
