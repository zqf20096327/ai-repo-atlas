**纯 Python 构建数据应用与仪表盘的 Web 框架**

基于 Plotly.js、React 和 Flask 的 Python 框架，将下拉框、滑块、图表等 UI 元素与 Python 分析代码绑定，无需编写 JavaScript 即可构建 ML 与数据科学 Web 应用；支持约 50 种图表类型，应用代码为声明式响应式写法。开源版在本地运行，另设 Dash Enterprise 提供部署、Kubernetes 扩缩、认证、任务队列与企业级模板等付费功能。
