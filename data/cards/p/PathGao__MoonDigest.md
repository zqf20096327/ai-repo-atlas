# PathGao/MoonDigest

⭐ 284 · JavaScript · GPL-3.0 · 推送 2026-11-24 · [GitHub](https://github.com/PathGao/MoonDigest) · [官网](https://chromewebstore.google.com/detail/bnjihpbocpimaipifanfkjjpfdbigggd) · 个人维护 · 中文 README

**用 AI 帮用户读完整理 B站/YouTube 收藏视频的 Chrome 扩展**

一个 Chrome MV3 扩展，围绕收藏的视频和网页做三类事：读——查看 B站/YouTube 字幕并复制下载 SRT/TXT，AI 侧边栏生成一句话总结、带时间戳要点并支持追问；理——分拣台按标题和字幕对收藏夹视频给出保留/清理判断，支持打标签与观看进度；记——对话存入摘读记录，导出 Markdown 或写入 Obsidian。AI 调用走用户自配的 API Key（DeepSeek、智谱 GLM、Kimi、MiniMax、OpenRouter 及任意 OpenAI 兼容接口），数据全部存在浏览器本地，无作者服务器。另提供 MCP 服务与 skill，让外部 agent 借浏览器登录态读取字幕并经授权后管理收藏夹。

## 能力要点

- AI 视频总结与追问：一句话总结、带时间戳要点，无字幕时用简介和热门评论兜底
- 分拣台 AI 判断收藏夹视频留/清/拿不准，取消收藏可撤销
- 支持多个 AI 平台配置与切换，兼容任意 OpenAI 接口
- 提供 MCP 服务与 skill 两种接入方式供 AI agent 读取视频内容

## 适用场景

- 批量清理 B站收藏夹里囤积没看的视频
- 看视频前先读 AI 要点决定是否值得看
- 把视频笔记导出 Markdown 归档到 Obsidian
- 让 AI agent 借浏览器登录态读视频字幕做资料调研
