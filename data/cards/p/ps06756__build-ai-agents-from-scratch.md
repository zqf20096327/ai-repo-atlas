**从零构建 AI Agent 的渐进式教程仓库（LangGraph/LangChain）**

面向学习者的 14 章渐进式教程仓库，基于 LangGraph 与 LangChain 讲解 AI Agent 构建：工作流图、条件路由、LLM 调用、工具调用、结构化输出，以及 ReACT、Plan-and-Execute、Reflection 等 Agent 模式实现。每章配 Jupyter Notebook 与可运行 Python 示例，需 Python 3.11+ 与 Anthropic API key，通过 git clone 后 pip 安装依赖运行。课程目前止于第 14 章，后续多 Agent 章节为规划中；示例以学习优先，接入真实数据前需自行核对生产清单。
