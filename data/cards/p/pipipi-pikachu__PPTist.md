# pipipi-pikachu/PPTist

⭐ 9,513 · Vue · AGPL-3.0 · 推送 2026-11-27 · [GitHub](https://github.com/pipipi-pikachu/PPTist) · [官网](https://pipipi-pikachu.github.io/PPTist/) · 个人维护 · 中文 README

**给开发者的在线演示文稿编辑/放映 Web 应用**

基于 Vue 3 与 TypeScript 的 Web 端幻灯片编辑与放映应用，复刻 Office PowerPoint 常用功能：文本/图片/形状/线条/图表/表格/音视频/公式等元素编辑、页面管理、模板、切换与元素动画、演讲者工具、移动端基础编辑，支持导入导出 PPTX/JSON/图片/PDF。AI 相关功能为基于模板的 AIPPT 生成、AI 文本改写，并提供供 AI 直接生成页面数据的结构定义。面向有 Web 幻灯片开发需求的开发者，非开箱即用工具。

## 能力要点

- 浏览器内编辑与放映，支持文本/图片/形状/图表/表格/音视频/公式等元素
- 导入导出 PPTX（导入保真约85%+，导出约95%+）及 JSON/图片/PDF
- 模板化 AIPPT 生成，并提供 AI 直接生成页面数据的 schema 定义（AI_PPT_SCHEMA.md）
- 文本 AI 改写/扩写/缩写

## 适用场景

- 在此基础上定制开发在线演示/编辑产品
- 业务系统中在线预览与轻量审阅本地 PPTX 文件
- 接入 AI 生成结果后进行编辑与再加工
