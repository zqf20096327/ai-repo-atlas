# PeakScripter/Neural-Visualizer

⭐ 13 · TypeScript · GPL-3.0 · 推送 2026-04-26 · [GitHub](https://github.com/PeakScripter/Neural-Visualizer) · [官网](https://neural-visualizer-ruby.vercel.app/) · 个人维护

**在浏览器中构建、训练并可视化神经网络的教学 Web 应用**

React + FastAPI 架构的交互式深度学习可视化 Web 应用：支持搭建 ANN、CNN、RNN、LSTM、GAN、Transformer 与 Diffusion 七种模型，配置层数、神经元数、激活与正则化参数；提供 2D/3D 架构图、前向/反向传播动画、决策边界、损失曲面、注意力热力图、网络剪枝等 15+ 可视化标签页。训练支持服务端 PyTorch 与浏览器内 TensorFlow.js 两种方式，附 4 种合成数据集与 CSV 上传，可导出 PyTorch/Keras 代码。面向深度学习教学与自学场景，需分别启动前后端服务运行。

## 能力要点

- 七种模型类型（ANN/CNN/RNN/LSTM/GAN/Transformer/Diffuser）的交互式架构搭建
