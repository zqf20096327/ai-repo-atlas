# puzige/random-interview-platform

⭐ 25 · TypeScript · MIT · 推送 2026-04-21 · [GitHub](https://github.com/puzige/random-interview-platform) · [官网](https://devinterview.org/) · 个人维护 · 中文 README

**AI 驱动的技术面试练习平台：生成八股文题目并给出反馈**

基于 Next.js 15 与 Monaco 编辑器的 Web 面试练习应用：通过 OpenAI API 生成编程题或概念题，用户答题后获得 AI 生成的评分与改进建议（覆盖正确性、效率、可读性）。支持中英文界面、12 种编程语言、错误追踪与优先练习、答题历史与自动保存；可在设置中配置 API 端点、模型（README 推荐 gpt-4o）与密钥。内置贡献功能可从文本或 URL 添加题目并自动创建 PR 合入题库，另有在线站点可直接使用。

## 能力要点

- OpenAI API 生成题目并评估答案，输出评分与详细反馈
- Monaco 编辑器支持 12 种编程语言、多主题与实时代码预览
- 错误追踪与优先安排、历史记录、答题进度自动保存
- 文本/URL 贡献题目并自动创建 PR 合入题库

## 适用场景

- 通过 AI 生成的编程题与概念题练习技术面试
- 提交答案后获得代码正确性、效率、可读性的反馈
- 自定义技术类别与难度，针对性强化薄弱知识点
