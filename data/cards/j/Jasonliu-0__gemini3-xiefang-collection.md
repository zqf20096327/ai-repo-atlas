**展示与分享 Gemini 3.0 AI 作品的 Web 社区平台**

基于 Next.js 14 + Supabase 的作品展示平台，面向分享通过 Gemini 3.0 创作的作品（HTML/SVG）。支持粘贴代码上传（Base64 存储）、首页 iframe 沙盒实时预览、Linux DO 与 GitHub OAuth2 登录、访客浏览、5 星评分评论、点赞收藏、高级搜索、统计图表与管理员后台（审核/隐藏/删除作品）。部署需自行配置 Supabase 数据库与 OAuth 应用，提供 Vercel/Netlify 与 Docker 部署方式。平台本身不调用模型，AI 作品是展示内容。

## 能力要点

- HTML/SVG 代码粘贴上传，Base64 存储，无需文件存储服务
- 首页 iframe 沙盒实时预览与全屏预览
- Linux DO / GitHub OAuth2 登录，访客可浏览
- 管理员后台支持审核、隐藏、编辑与删除作品
