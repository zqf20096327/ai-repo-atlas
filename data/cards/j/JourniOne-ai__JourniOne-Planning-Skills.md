**面向旅行者的规划 Skill：逐日路线、酒店比价与可分享旅行指南**

以 agent Skill 形式分发的旅行规划工具：从出行想法生成逐日路线，按兴趣与节奏安排景点、餐饮与休息；确认后生成含 Journal 视图与 Map 视图的交互式 Travel Journal，可分享链接免登录查看。按需接入 TourMind 酒店搜索（聚合 100+ 渠道比价）与 Kiwi.com 机票搜索；默认连接 journione.ai 云端服务，无需本地 token 或 MCP 服务。需 Node.js 22+，客户端需支持 web 搜索、文件访问、HTTPS 请求与远程 MCP。

- 逐日路线规划，支持导入既有行程、照片与笔记
