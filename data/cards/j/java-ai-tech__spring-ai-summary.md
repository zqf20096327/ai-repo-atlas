**Spring AI 框架的模块化示例工程与学习资源集合**

基于原生 Spring AI 框架的模块化示例工程集合，覆盖聊天应用、工具调用、向量数据库集成、MCP/RAG/Agent 等功能，配套推荐学习路径与运行说明。面向 Spring AI 的初学者与有经验的 Java 开发者，要求 SpringBoot 3.3.6、Spring AI 1.0.0、JDK 21+ 与 Maven 3.6+，部分模块需 Docker 运行 Milvus、Nacos 等依赖。另汇总国内学习资源（博客、视频、论文列表），README 声明仅供学习研究、不适用于生产环境，由 glmapper 独立维护，MIT 许可。
