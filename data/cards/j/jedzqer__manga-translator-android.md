**给安卓用户的 LLM 驱动漫画即时翻译与阅读应用**

Android 平台的漫画翻译与阅读应用：自动检测气泡与游离文字，提供本地 OCR、API OCR、低置信度 AI OCR 补充、VL 视觉直译与全文速译五种翻译方式，译文覆盖回原图。翻译 API 需用户自备，支持 OpenAI 兼容 Chat、OpenAI Responses 与 Gemini 接口配置。附带漫画库管理、条漫阅读、跨页上下文译名表、悬浮窗跨应用翻译、备份导出。本地分割模型随仓库分发，OCR 模型需自行下载。提供 APK 下载，也可从源码构建（需 JDK 17 与 Android SDK）。

## 能力要点

- 五种翻译方式：本地 OCR、API OCR、AI OCR 补充、VL 直译、全文速译
- 支持 OpenAI 兼容 Chat、OpenAI Responses 与 Gemini 三种接口格式
- 悬浮窗截屏翻译与半透明穿透模式
- 随仓库分发基于 YOLO26s-seg 的 TFLite 分割模型

## 适用场景

- 批量翻译本地漫画文件夹并生成可阅读的译文版
- 阅读条漫时滚动获取连续剧情上下文的翻译
- 在其他应用中通过悬浮球截屏翻译屏幕上的漫画
- 从 CBZ/ZIP/PDF 导入漫画并按文件夹设置源语言与文风
