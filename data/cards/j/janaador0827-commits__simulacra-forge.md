**多智能体对话模拟平台：观察自主 Agent 演化出共同语言协议**

基于 Python/FastAPI/WebSocket 的分布式多智能体对话模拟环境：部署一群自主 Agent，通过递归自交互协商构建共享符号语言与语义网格（图数据库）存储对话、概念与信念；支持本地与云端模型混合编排（Ollama、llama.cpp、OpenAI、Anthropic）、持久化叙事记忆（Redis）与冲突自动消解，附 React 观测面板。定位为研究工具，供学术研究、游戏叙事设计、语言涌现观察等场景使用。需 Python 3.12+ 并至少接入一个语言模型。
