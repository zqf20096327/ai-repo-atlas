# jayli/vim-easycomplete

⭐ 435 · Vim Script · MIT · 推送 2025-12-16 · [GitHub](https://github.com/jayli/vim-easycomplete) · [官网](https://github.com/jayli/vim-easycomplete/wiki) · 个人维护 · 中文 README

**Vim/Neovim 开箱即用代码补全插件，含 LSP 与 Tabnine AI 补全**

面向 vim/nvim 用户的补全插件：兼容 Vim（vimscript）与 Neovim（lua），macOS 上提供 Rust 编写的高性能模块。功能覆盖 LSP 补全（一条命令安装各语言 LSP server，支持 20+ 语言）、关键词/路径/片段/命令行补全、诊断跳转、重命名等。AI 部分：内置 Tabnine 补全（含 inline suggestion，可免 APIKey 使用），并说明可与 copilot.nvim 配合使用。无需安装 Node 及一堆 Node 模块即可运行。

## 能力要点

- Vim/Neovim 双兼容，开箱即用
- 一条命令安装 LSP server，支持 20+ 编程语言
- 内置 Tabnine AI 补全（含 inline suggestion，无 APIKey 可用）
- macOS 提供 Rust 高性能模块，无需 Node 依赖

## 适用场景

- 在 vim/nvim 中获得开箱即用的多语言代码补全
- 一条命令安装并使用各语言的 LSP server
- 用 Tabnine 获得 AI 行内补全建议
