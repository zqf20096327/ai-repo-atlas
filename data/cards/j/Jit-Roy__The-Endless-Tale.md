**AI 互动小说引擎：目标驱动的角色对话叙事游戏**

基于 Python 的 AI 互动小说与叙事引擎，面向想要目标驱动剧情体验的玩家与故事创作者。系统通过 Google Gemini API 生成对话与叙事，角色拥有独立人格并自主决策进出场景，世界状态随时间动态变化；玩家行动会依据故事目标被评估以推进剧情。使用两个 API key 分离前台角色响应与后台叙事任务的并行处理，官方说明平均约 40 秒生成一条新消息。支持以 JSON 文件自定义故事与角色，运行 python app.py 启动图形界面。
