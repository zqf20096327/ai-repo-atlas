# Jevon-Zhong/agent-trip-planner

⭐ 22 · Python · MIT · 推送 2026-02-04 · [GitHub](https://github.com/Jevon-Zhong/agent-trip-planner) · 个人维护 · 中文 README

**面向用户的 AI 旅行规划助手（微信小程序+FastAPI）**

面向旅行者的问答式规划应用：前端为 Uniapp/微信小程序，后端 FastAPI+PostgreSQL；通过 LangGraph/LangChain 框架调用阿里云百炼 MCP 工具（攻略、天气、高铁票等），结合通义千问（默认 qwen3-max）生成流式回复，并自动生成腾讯地图驾车路线，支持腾讯云实时语音识别输入。包含账号登录、历史对话管理与推荐提问。运行需自备通义千问 API key、腾讯地图 key、腾讯云语音凭据及 PostgreSQL。

## 能力要点

- MCP 工具调用 + 大模型总结生成旅行攻略回答
- Websocket 流式输出与工具调用列表展示
- 腾讯云实时语音识别切换语音提问
- 自动生成腾讯地图驾车路线规划

- 向 AI 助手提问获取目的地旅游攻略与天气、车票信息

- 在微信小程序中管理多个账号的规划对话记录
