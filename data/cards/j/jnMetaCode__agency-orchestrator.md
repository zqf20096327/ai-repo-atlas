# jnMetaCode/agency-orchestrator

⭐ 2,506 · TypeScript · Apache-2.0 · 推送 2026-11-26 · [GitHub](https://github.com/jnMetaCode/agency-orchestrator) · [官网](https://ao.aiolaola.com) · 个人维护 · 中文 README

**一句话组队多 AI 专家自动协作，交付完整方案**

一个多智能体工作流编排工具：输入一句话自动拆解任务，从 276 个中文/184 个英文专业角色中匹配组队，按 DAG 并行执行并保存产物。以 YAML 定义工作流，零代码运行；支持 20+ 家 API 与 10 种免 key 方式（复用已登录的编码 CLI 或本地 Ollama），提供 `ao compose`/`ao run` 命令行、`ao web` 图形 Studio、Electron 桌面端与 Docker 部署。产物可导出 docx/pdf 等格式，支持断点续跑、带意见返工与 webhook 结果推送。面向个人创业者、开发者与内容创作者。

## 能力要点

- 一句话自动从 276 个角色中组队并按 DAG 并行执行
- 20+ 家 API 接入，10 种免 key 方式（复用已登录 CLI / 本地 Ollama）
- `ao web` 图形 Studio：拖拽画布、可视化工作流编辑与分享报告页
- 70 个内置工作流模板，支持 `--resume` 续跑与 `--feedback` 返工

- 输入一句创业想法，自动产出可行性分析或商业计划书

- 方案到代码：PRD 喂给编码 Agent 并核对偏差
- 用 --notify 接 webhook 让 AI 团队定时交活
