**基于 AI 大模型的 Web 应用防火墙，检测恶意流量**

开源的 Web 应用防火墙，实时分析检测 Web 应用流量，清洗恶意流量后转发正常流量至业务服务器。核心机制包括多维稀疏注意力与在线蒸馏的 AI 安全模型（继承大模型检测能力至本地推理引擎，纯 CPU 运行）、语义分析引擎（防御 SQL 注入、XSS、命令执行等）、SSL 行为分析与 WebTDS 毫秒级实时威胁分析。提供标准版（单机 Docker 编排）、专业版（控制台/节点/日志分离部署）与 WebTDS 三条产品线；防护模式支持模型训练、日常防护、重保防护与离线防护切换。

- AI 安全模型支持 0day 自动检测与误报自动处理，纯 CPU 运行
