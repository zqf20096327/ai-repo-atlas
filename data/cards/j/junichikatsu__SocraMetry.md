# junichikatsu/SocraMetry

⭐ 16 · TypeScript · MIT · 推送 2026-08-15 · [GitHub](https://github.com/junichikatsu/SocraMetry) · 个人维护 · 中文 README

**企业向け：AI 用苏格拉底式提问锻炼并测评调试能力**

面向 B2B 场景的调试能力培养与测评系统。使用者不能直接向 AI 提问，只能提交错误并选择 AI 生成的阶段性选项；通过 3 个 Gate（仅提示→选项→答案）渐进开示，解决所在的 Gate 构成评价值。以观察、切分、假说、验证、修正 5 轴计算调试评分，作为育成与人事评估依据。技术栈为 enebular 云执行环境 + Hono/TypeScript + enebular 数据存储，LLM 访问统一经 OrcaRouter（OpenAI 互兼容），采用两段 LLM 防止答案泄露。限制：本地 MOCK 模式无法通全 3 Gate（需 enebular 数据存储连接），v0.2 组织功能（演习题库/仪表板）未实现，实跑需 OrcaRouter API key。

## 能力要点

- 3 Gate 渐进开示机制，Gate 到达位置即评价主轴
- 5 轴调试评分（观察/切分/假说/验证/修正）
- 两段 LLM 构成：廉价模型仅着眼点，设计上防止答案泄露
- MOCK 模式下 326 件自动测试，无需 LLM 与数据存储

## 适用场景

- 组织在业务中培养成员的调试能力而非直接给答案
- 以 5 轴评分作为人事评估与育成的客观依据
- 将实际发生的错误匿名化后沉淀为内部演习题库
