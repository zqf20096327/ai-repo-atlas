# jiabaobei/memory-bridge

**给 AI 助手提供跨设备共享记忆层的 MCP 服务**

基于 CDSMP 架构的 AI 共享记忆层：以 SQLite 存储记忆条目、语义向量与关联边，通过网盘同步加密差分包实现手机/PC/平板间的记忆连续性，支持边缘预加载与内容冻结（不改写原始记忆）。经 MCP 协议接入 Claude Code、Cursor、Cline 等客户端，并支持网关基站模式供手机浏览器读写。核心零依赖、纯标准库实现，检索为向量+关键词+图谱三路混合，写入依赖用户显式提交而非 LLM 自动蒸馏。

## 能力要点

- 跨设备增量差分同步（DSS），网盘只传输端到端加密包
- MCP Server 供任意 MCP 客户端接入，支持 HTTP 远程模式
- 向量+关键词+SAN 图谱三路混合检索与 RRF 融合
- 内容冻结原则：只提取语义关联，不改写原始记忆内容

## 适用场景

- 在手机上开始的 AI 对话上下文，回到 PC 继续使用
- 多个 MCP 客户端（Claude Code/Cursor/Cline）共享同一份记忆库
- 用旧手机搭建零云端的本地记忆+推理个人 AI 栈
- 需要记忆内容可审计、可导出为 Markdown 存档的场景
