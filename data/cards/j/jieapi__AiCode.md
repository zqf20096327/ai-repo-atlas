**给 Android 用户的移动端 AI 编程 Agent，内置 Linux 终端**

运行在 Android 上的通用 AI Coding Agent，内置基于 Termux 与 PRoot 的 Alpine Linux 容器、终端与代码编辑器，AI 可读写文件、执行 Shell 命令、运行构建工具，开发全程可在手机本地完成；也支持远程 SSH 服务器作为执行后端。不内置模型、不绑定供应商，兼容 OpenAI / Anthropic / Gemini 三类协议，模型与密钥自行配置。支持 MCP 协议扩展、子代理并行、三种权限模式、检查点回滚与插件系统。需 Android 8.0+（arm64-v8a / x86_64），从 GitHub Releases 下载安装包使用。

## 能力要点

- 内置 Alpine Linux 容器与多标签终端，AI 可执行 Shell 命令与构建工具
