**面向非程序员的本地优先 AI agent Markdown 编辑器**

Ritemark 是 macOS/Windows 桌面 Markdown 编辑器，三窗格布局：中央可视化编辑（实时预览、斜杠命令、Mermaid、50+ 语言离线语音听写），右侧与 Claude、Codex、Gemini 三种 agent 对话。Agent 可读取、编辑、新建项目文件，支持切换提供商、Plan 模式、流程编排（Flows）。文件为本地纯 Markdown，编辑器可离线工作，AI 功能需各自的 API 连接。面向产品经理、创始人、技术写作者、顾问等非编程用户，由爱沙尼亚公司 Productory 开发，MIT 许可。
