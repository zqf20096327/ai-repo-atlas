# JoelDeonDsouza/Win-ielts

⭐ 16 · TypeScript · MIT · 推送 2026-10-12 · [GitHub](https://github.com/JoelDeonDsouza/Win-ielts) · [官网](https://win-ielts.vercel.app) · 个人维护

**借助 AI 的雅思备考 Web 应用：练习材料与个性化反馈**

基于 React 19、TypeScript 与 Vite 构建的雅思备考 Web 应用，面向雅思考生。通过 Vercel AI SDK 与 Google Generative AI（Gemini）提供智能练习材料与个性化反馈，并含进度跟踪功能；练习数据以 IndexedDB 在本地存储。安装方式为 git clone 源码后 npm install 并运行 Vite 开发服务器，需在 .env 中配置 GOOGLE_API_KEY，另有 Vercel 在线部署的 Demo。
