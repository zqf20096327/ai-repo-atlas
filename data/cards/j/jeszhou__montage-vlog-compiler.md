# jeszhou/montage-vlog-compiler

⭐ 11 · Python · MIT · 推送 2026-08-28 · [GitHub](https://github.com/jeszhou/montage-vlog-compiler) · 个人维护 · 中文 README

**给 Vlog 创作者：把口播与素材编译成逐镜剪辑执行单**

一个面向情绪混剪 Vlog 的剪辑方案编译器（Claude skill 形式）：输入参考片、文案/口播与授权素材目录，产出风格档案、语义锚点表与逐镜剪辑执行单。核心机制是口播作时间主轴、画面服从口播语义的四层联动规则，并区分已验证/待验证结论；用户修改先存候选偏好，需明确确认才写入长期风格。不产出成片，需配合能读指令的剪辑 Agent 或手动在剪辑软件执行。工具脚本依赖 ffprobe。目前仅在母婴题材上验证过。

## 能力要点

- 从参考片提炼跨样本重复的风格档案，区分单片特征与未验证假设
- 口播语义决定画面的四层联动剪辑规则（语义/速度/卡点/声场）
- 修改存为候选偏好，需用户明确确认才进长期风格
- 提供 media_inventory.py / verify_inventory.py 媒体清单脚本

## 适用场景

- 给母婴/旅行/亲子类情绪混剪 Vlog 生成逐镜初剪方案
- 让 AI 剪辑工具按工具无关的执行单指令搭建可编辑时间线
- 沉淀个人剪辑审美偏好供后续项目复用
