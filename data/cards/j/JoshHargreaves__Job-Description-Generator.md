# JoshHargreaves/Job-Description-Generator

⭐ 14 · TypeScript · 推送 2026-02-10 · [GitHub](https://github.com/JoshHargreaves/Job-Description-Generator) · [官网](https://job-description-generator-gamma.vercel.app) · 个人维护

**招聘者用 AI 生成职位描述的 Next.js 网页应用**

基于 Next.js 与 Tailwind CSS 的网页应用，调用 OpenAI API 生成结构化职位描述，供招聘人员与 HR 使用。支持选择语气（Story/Formal/Fun），提供实时预览与一键复制。运行需自备 OpenAI API Key 写入 .env.local，通过 git clone 源码安装、npm/yarn/pnpm 安装依赖后本地启动开发服务器。项目致谢 github.com/shnai0/linkedin-post-generator。
