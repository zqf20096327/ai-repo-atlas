**面向 LLM 研究者收录 RAG 前沿论文与学习资源的策展清单**

该仓库以清单形式记录 LLM 中检索增强生成（RAG）方向的论文，按综述与基准、检索增强 LLM、指令微调、上下文学习、嵌入等主题分区组织，每条含作者、会议/期刊与链接；另收录工作坊与教程、书籍（Manning 出版物、免费电子书）以及开源工具条目，并鼓励研究者通过 pull request 提交自己的论文信息。仓库本身不含可运行代码，MIT 许可。
