**面向失读症学习者的浏览器多感官阅读教学工具**

基于 Orton-Gillingham 方法的阅读教学应用，面向失读症学习者及其教育者。在浏览器中同时呈现视觉、听觉与触觉通道：展示字母并播放读音，学习者屏上描摹字母，设备震动提供触觉反馈；正确后的庆祝环节重播刚学的字母、读音与形状。概念按固定顺序引入，教学回应学习者的具体错误。README 声明未做过有效性研究，不能替代专业评估。技术栈为 JavaScript，通过 git clone 与 npm 本地运行。
