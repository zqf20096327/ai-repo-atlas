# amanda-burgos/Nuggit

⭐ 3 · TypeScript · MIT · 推送 2026-11-06 · [GitHub](https://github.com/amanda-burgos/Nuggit) · 个人维护

**面向需要开始任务并保持专注者的桌面效率应用，带 AI 助手 Dip**

基于 Electron 的桌面效率应用：提供可拆放的桌面小组件面板（任务、笔记、时钟、日历、音乐、图片）、专注计时、提醒与每日问题。AI 部分 Dip 将大任务拆解为小步骤（Tenders）、生成日常例程并整理 brain dump，需配置 Gemini API key、本地 Ollama 或 OpenAI 兼容服务器其中之一；不配置 AI 时应用其余功能仍可运行。数据仅存本地。提供 Apple 芯片 Mac 的 .dmg 安装包，Windows/Linux 标注未测试。

## 能力要点

- Dip 将大任务拆解为小步骤（Tenders）、生成 Dailies 例程并整理 brain dump
- AI 后端可选 Gemini API key、本地 Ollama 或 OpenAI 兼容自建服务器
- 桌面小组件面板支持任务、笔记、时钟、日历、音乐等并可拖出到桌面
- 本地语音经由 whisper.cpp（仅 Mac）

## 适用场景

- 把大任务拆成小步骤来克服拖延
- 用桌面小组件管理任务、笔记与专注计时
- 用本地 Ollama 离线使用 AI 助手
