**给 Claude Code 用户提供西西里语终端 spinner 动词预设**

一个面向 Claude Code CLI 的配置预设仓库：提供 140+ 条西西里语（卡塔尼亚方言）的动词与习语，替换或追加终端等待时的默认 spinner 文案（Thinking/Working 等）。包含完整替换集、纯动词集与戏剧性习语集三个 JSON 文件，通过 settings.json、--settings 标志或 settings.local.json 三种方式安装。README 附动词释义表、自定义规则（须用动名词形式、保持简短）与故障排查说明。要求 Claude Code ≥ 2.1.23。
