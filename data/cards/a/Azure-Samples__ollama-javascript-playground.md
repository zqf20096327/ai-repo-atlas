**浏览器中体验生成式 AI 模型的 JavaScript Playground**

基于 GitHub Codespaces 与 Ollama 的生成式 AI 演练场：在预配置的 Codespace 环境中运行 Phi-3 等小语言模型，通过 ollama.ipynb 交互式笔记本对话，无需本地安装。附带 samples 文件夹，用 OpenAI Node.js SDK 演示生成式 AI 用法，部分示例需先启动 Azure OpenAI 模拟器（ollamazure -d）。面向学习生成式 AI 与 JavaScript 的开发者，属于 Azure-Samples 教学样例项目。
