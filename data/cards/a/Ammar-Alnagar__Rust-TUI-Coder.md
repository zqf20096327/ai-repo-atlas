# Ammar-Alnagar/Rust-TUI-Coder

⭐ 14 · Rust · Apache-2.0 · 推送 2025-11-26 · [GitHub](https://github.com/Ammar-Alnagar/Rust-TUI-Coder) · 个人维护

**终端 AI 编程助手：在 TUI 中对话、执行代码与操作文件**

用 Rust 编写、基于 ratatui 的终端 AI 编程助手：以自然语言与 LLM 对话，AI 可直接执行工具操作，包括文件读写/搜索替换/删除、目录操作、Python/Bash/Node.js/Ruby 代码执行、计划管理与 Git 状态检查，并可实时查看工具执行过程。LLM 通过 config.toml 配置（示例为 OpenAI API，README 提及支持 OpenAI、Anthropic 或本地模型）。以 cargo install 安装，运行 rct 命令启动；详细文档移至 docs/ 目录。
