# apt-oss/libro

⭐ 402 · Jupyter Notebook · MIT · 推送 2026-02-25 · [GitHub](https://github.com/apt-oss/libro) · [官网](https://apt-oss.github.io/libro) · 组织维护 · 中文 README

**可定制、易集成的 Notebook 方案，含 AI 辅助开发能力**

基于 Python 的 Notebook 产品，提供完整 Notebook 能力与周边功能，各层次内容支持内核级二次开发定制。AI 功能包括代码补全、错误修复、AI 对话、代码解释与优化，以及直接与大模型交互的 Prompt Cell（支持文本对话与多模态，内置 OpenAI 系列模型，可通过 langchain 或 libro-ai 扩展模型）；另有 Sql Cell 支持连接数据库在 notebook 中写 SQL。pip 安装后运行 libro 命令启动 Web 服务器并自动打开浏览器，要求 Python 3.10-3.12。
