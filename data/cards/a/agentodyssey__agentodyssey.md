# agentodyssey/agentodyssey

⭐ 56 · Python · Apache-2.0 · 推送 2026-10-19 · [GitHub](https://github.com/agentodyssey/agentodyssey) · [官网](https://agentodyssey.github.io/) · 组织维护

**长时程文字游戏生成引擎：评测测试时持续学习 Agent**

轻量级交互环境，支持开放式长时程文字游戏生成、统一 Agent 接口与多维评测，用于评估测试时持续学习 Agent 的探索、世界知识获取、情节记忆、技能学习与长时程规划五类能力。游戏生成经实体、规则、任务三阶段完成；内置 6 类范式的 Agent 实现（基线/长上下文/固定记忆/RAG/SFT/潜在记忆），并托管 NeurIPS 2026 TTCL Workshop 社区挑战。以 pip 包、CLI 与 Python API 提供，可选配 OpenAI/Gemini/Claude 等 LLM 提供方。
