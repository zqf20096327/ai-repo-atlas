**免 root 的离线优先 Android 自动化应用，支持本地/云端 LLM 驱动任务**

一款 Android 自动化应用，基于无障碍服务、端上 ML（TFLite + ML Kit）、屏幕捕获与系统事件接收器实现手势录制回放、可视化节点工作流、地理位置/电量/时间/Wi-Fi 触发器，无需 root。所有核心功能在设备上运行；可选接入云 API（GPT-4o、Gemini、Groq、DeepSeek 等）执行 LLM 智能体任务。面向希望自动化手机操作的用户；需通过 Android Studio 从源码构建，许可证为 PolyForm Noncommercial，禁止商用。

## 能力要点

- 通过 AccessibilityService 录制并回放手势宏，无需 root
- 可视化节点工作流编辑器，支持条件分支与多节点执行
- 端上 ML 屏幕理解：OCR、UI 元素识别、图像模板匹配
- LAN 多设备同步（手机↔PC↔平板）与桌面 agent 控制

## 适用场景

- 录制手势宏自动完成重复的 App 操作
- 按位置/时间/Wi-Fi 事件自动触发手机任务
- 通过自然语言将指令转换为自动化流程
- 在局域网内多设备协同执行自动化
