⭐ 15 · JavaScript · MIT · 推送 2026-03-02 · [GitHub](https://github.com/alicetinkaya76/microgpt-academy) · [官网](https://microgpt-academy.vercel.app) · 组织维护

**逐行讲解 Karpathy 243 行 GPT 的双语交互教学平台**

基于 React 的交互式网页教学平台，逐行讲解 Andrej Karpathy 的 243 行纯 Python GPT 实现（microgpt.py）。提供 10 周课程加一篇 Attention Is All You Need 论文精读、78 个带滑块与动画的交互可视化、90 道双语测验、3 门前置课（线性代数/概率与信息论/反向传播）、85 页双语幻灯片与 17 段逐行注释的 Python 代码。每周配有零配置的 Google Colab 实验。内容为土耳其语+英语双语，由 Selçuk 大学计算机系助理教授维护。通过 git clone 与 npm 本地运行，或访问 Vercel 在线演示。
