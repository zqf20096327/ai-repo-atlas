**多智能体博客生成器：基于 Agno 框架生成带引用的博文**

基于 Agno 框架的多智能体系统，面向需要生成博文的用户：由研究、内容提取、写作等专职 agent 协作，检索并评估权威来源、抓取与摘要文章内容，最终生成带引用的博客文章。支持在 OpenAI、Gemini、Claude、Grok 之间切换模型，使用时需自行输入对应 API key。提供 Gradio Web 界面，通过 git clone 克隆源码后用 uv 创建 Python 3.12 虚拟环境安装依赖并运行，另有 Hugging Face Spaces 在线演示。采用 MIT 许可证。
