**面向开发者的 AI Agent 目录与注册平台：收录、部署与变现**

DeepNLP 运营的 AI Agent 市场与索引服务：从 GitHub/HuggingFace/ProductHunt 等来源收录 10K+ AI Agent，按 30+ 类别组织，提供 Web 目录与搜索 API。开发者可用 agtm CLI（pip/npm 安装）提交 Agent 元信息，将 python/nodejs Agent 或 MCP 代码部署到免费子域名获得 Live URL，并通过 OneKey Gateway 用单一 access key 调用商业 API，配合统一积分体系实现流量统计与收费提现。另支持域名验证（ChatGPT App/微信/钉钉等）并定期在 HuggingFace 发布全量数据集快照。

- 10K+ AI Agent 索引，30+ 类别，含 CLI/Skills/MCP 子注册表
