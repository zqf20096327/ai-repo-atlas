**用开源 LLM 构建函数调用 Agent 工作流的框架**

AgentForce 是一个构建生产级 AI Agent 的 Python 框架：通过函数调用与工具集成组装 Agentic 工作流，支持接入 OpenAI、Cohere Command (R/R+) 与 LlamaCPP 多种 LLM，可添加网页搜索、天气数据、图像分析等工具，并支持文本与图像的多模态输入。提供简单 API 用于扩展自定义工具与 LLM 提供方，以 pip 包形式从 PyPI 安装，附基础用法与多模态 Agent 示例。采用 Apache 许可证。
