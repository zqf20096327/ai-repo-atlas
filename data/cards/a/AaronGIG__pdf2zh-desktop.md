**面向学术用户的 PDF 翻译桌面应用：保留公式排版、支持 AI 引擎**

基于 PDFMathTranslate 的 PDF 学术翻译桌面程序，Windows 与 macOS 双平台提供独立打包的二进制，内置 Python 运行时，无需安装 Python。核心流程为拖入 PDF、选择翻译服务、生成纯译文/双语对照/左右并排三种 PDF。保留公式与排版，提供扫描件 OCR（内置 RapidOCR）、表格翻译管线、分块翻译、断点续传，以及 Zotero 联动（译文自动回写为附件）。翻译服务需自行配置 API Key（Google/Bing 免费可直接使用），本身不包含模型。

## 能力要点

- 支持 35 种语言、20+ 翻译服务预设，含 OpenAI 兼容格式自定义接口
- 输出单语/双语对照/左右并排三种 PDF，保留公式与排版
- 内置 RapidOCR 处理纯图片扫描件，独立表格翻译管线
- Zotero 深度联动：拖入翻译后译文自动回写为 Zotero 附件

## 适用场景

- 翻译学术论文并保留公式和排版

- 在 Zotero 文献工作流中直接翻译并回写附件
