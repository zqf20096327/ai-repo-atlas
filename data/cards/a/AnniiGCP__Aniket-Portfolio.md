# AnniiGCP/Aniket-Portfolio

⭐ 4 · TypeScript · MIT · 推送 2026-11-17 · [GitHub](https://github.com/AnniiGCP/Aniket-Portfolio) · [官网](https://aniketyadav.tech) · 个人维护

**开发者的个人作品集网站模板：展示项目、经历与技能**

基于 Next.js 15（App Router、静态生成）、TypeScript 与 Tailwind CSS v4 构建的个人开发者作品集，页面包括主页（技术栈、经历、GitHub 贡献日历、访客计数）、项目展示、经历时间线、成就、简历 PDF 浏览、阅读清单、命令面板（⌘K）、深色模式、音乐播放器与光标宠物等。内容可通过 src/config/ 下的配置文件与 MDX 文件编辑，部署方式为 Vercel。运行需 Node.js v20+ 与 npm v10+。
