# acquahsamuel/ai-resume-builder-frontend

⭐ 13 · TypeScript · 推送 2025-12-10 · [GitHub](https://github.com/acquahsamuel/ai-resume-builder-frontend) · [官网](https://cleansheet-resume.vercel.app) · 个人维护

**面向求职者的隐私优先开源简历构建器（Angular 前端）**

基于 Angular 与 TailwindCSS 的简历/CV 构建前端：提供多模板选择、实时预览、章节增删排序、输入校验、响应式界面与 PDF 导出，生成符合 ATS 筛选的简历。数据仅存浏览器本地存储，可选账户保存，无第三方存储。以源码方式提供，需 Node.js、npm 与 Angular CLI 后从 GitHub 克隆运行。README 未描述具体的 AI 功能机制，仅项目名称与主题标签含 AI。
