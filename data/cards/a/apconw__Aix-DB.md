⭐ 2,268 · JavaScript · 推送 2026-11-06 · [GitHub](https://github.com/apconw/Aix-DB) · [官网](https://db.aixhub.top/) · 个人维护 · 中文 README

**对话式数据分析（ChatBI）系统，自然语言转 SQL 与可视化**

基于 LangChain/LangGraph 与 MCP Skills 多智能体架构的智能数据分析系统：用户以自然语言提问，经 LLM 意图理解、Embedding+BM25 混合检索（结合 Neo4j 图谱）获取表结构知识，Text2SQL 引擎生成并校验 SQL，在目标数据源执行后自动生成 ECharts/AntV 图表。提供 Web 界面与 CLI，支持 8+ 种数据库；Docker 部署需配置 JWT_SECRET_KEY，本地开发需 Python 3.11。另提供面向企业场景的 Aix-DB Pro 商业版（看板、报告中心）。
