# akshayaggarwal99/nodenest

**可视化 AI 学习平台：把 AI 对话变成知识图谱**

基于 Next.js 的开源 Web 应用，面向学习者。用户提问后 AI 以苏格拉底式引导回答，对话内容不随时间线滚走，而是生成画布上的永久节点，概念按逻辑连接并自动布局成广度优先树，形成可视化知识图谱。默认接入 Google Gemini API（需自配 API key）。提供 Vercel 在线演示，本地运行需 git clone 后 npm install，支持一键部署到 Vercel，不能托管在 GitHub Pages。
