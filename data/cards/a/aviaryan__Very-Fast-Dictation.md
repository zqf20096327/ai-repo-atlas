# aviaryan/Very-Fast-Dictation

⭐ 70 · Python · MIT · 推送 2026-06-04 · [GitHub](https://github.com/aviaryan/Very-Fast-Dictation) · 个人维护

**Mac 系统级实时听写工具：快捷键触发语音转文字**

面向 M 系列 Mac 的系统级听写应用：连按两次 Control 键启动录音，语音经 Parakeet MLX 模型实时转录，结果自动复制到剪贴板并粘贴到当前活动窗口，可在任意应用中使用。界面用 PySide6 提供"Recording..."视觉指示。安装方式为 git clone 源码后用 uv 安装依赖并运行 main.py，需在系统隐私设置中授予终端辅助功能权限。
