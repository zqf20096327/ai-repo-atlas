# aikeyaorg/aikeya

⭐ 24 · Svelte · MIT · 推送 2026-02-14 · [GitHub](https://github.com/aikeyaorg/aikeya) · [官网](https://aikeya.org) · 组织维护

**开源 AI 虚拟伴侣平台：VRM 形象+记忆成长+恋爱模拟机制**

面向终端用户的本地优先 AI 伴侣平台，自称 Grok Companion 的开源替代。基于 SvelteKit/Three.js 构建：加载 VRM 3D 形象、3D 语音气泡、唇形同步与 VRMA 动画；支持 7 个 LLM 供应商（含 Ollama/LM Studio 本地方案）、2 个 TTS、Groq Whisper 与 Web Speech 语音输入。伴侣系统含多轴关系追踪、8 阶段进度与视觉小说事件，语义记忆经 Transformers.js 在本地做向量检索。数据以 IndexedDB 本地存储，可导出导入。桌面版为 beta 且仅限 macOS。README 声明项目处于很早期阶段，存档可能不向后兼容。

## 能力要点

- VRM 3D 形象加载、3D 语音气泡、TTS 唇形同步与 VRMA 动画
- 7 个 LLM 供应商（OpenAI/Anthropic/Gemini/DeepSeek/xAI/Ollama/LM Studio）
- Transformers.js 本地语义记忆与记忆图谱可视化
- 多轴关系追踪与 8 阶段恋爱模拟进度系统，数据 IndexedDB 本地存储

## 适用场景

- 养一个有 VRM 形象、会记事和成长的 AI 虚拟伴侣
- 本地运行：数据不出设备，用 Ollama 等本地方案免 API key
- macOS 桌面透明悬浮模式让伴侣常驻桌面
