**展示 ML 与软件工程项目的个人作品集网站**

基于 React 18、TypeScript、Vite 和 Tailwind CSS v3 构建的个人作品集网站，使用 HashRouter 以兼容 GitHub Pages 部署。页面包含主页简介、实习经历、ML 研究项目、软件项目（含截图画廊）、案例研究与技能展示；支持暗色模式与系统偏好检测，响应式布局。内容以 TypeScript 对象形式存放于 src/data/，通过 npm 安装依赖并构建部署。注意：网站本身不含 AI 功能，仅展示 AI/ML 相关项目内容，且页面底部声明保留所有权利（© 2026）。
