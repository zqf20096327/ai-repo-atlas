**浏览器端免费 AI 文生图工具，无需 API key**

基于 Vanilla HTML/CSS/JavaScript 的浏览器端文生图应用，通过 Puter.js 在客户端调用 DALL·E 3、Gemini 2.5 Flash、Grok 2 Image 与 GPT Image 等模型生成图像，无需注册、订阅或 API key。附带 AI 提示词增强、负向提示词、图像下载/复制到剪贴板、本地保存画廊历史、深浅色模式与响应式 UI。可部署到 Vercel/Netlify/GitHub Pages，本地开发只需 git clone 后运行。
