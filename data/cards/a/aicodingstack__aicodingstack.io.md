**AI 编码工具目录站：社区维护的元数据仓库与对比平台**

AI Coding Stack 是一个收录 AI 编程工具、模型与平台的目录网站与元数据仓库，覆盖 IDE、CLI、扩展、模型、Provider、厂商六类条目，提供并排对比、搜索、GitHub 星标追踪与精选合集，支持 12 种语言。元数据以 JSON manifest 文件形式存储在 manifests/ 目录，各类别有 JSON schema 做自动校验，通过 PR 提交更新；站点基于 Next.js 16 构建，部署于 Cloudflare Workers。
