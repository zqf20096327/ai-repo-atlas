# anfoss/PCprophet

⭐ 14 · Python · MIT · 推送 2025-11-21 · [GitHub](https://github.com/anfoss/PCprophet) · 组织维护

**蛋白质复合物预测与共分级质谱数据差异分析工具包**

PCprophet 是面向蛋白质组学研究的 Python 软件工具包，用于从共分级质谱（cofractionation MS）数据中系统性预测蛋白质复合物并进行差异分析。依赖 Sklearn、NetworkX、Pandas、Scipy、Dask 等库，推荐通过 Anaconda 环境安装，命令行版本需使用 git-lfs 克隆仓库并解压 GO 注释文件。由 UCSF 与 Monash 大学的研究人员（Andrea Fossati、Chen Li）开发，采用 MIT 许可证，详细用法见 PCprophet_instructions.md。
