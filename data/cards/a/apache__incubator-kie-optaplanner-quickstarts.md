**OptaPlanner 约束求解器官方快速上手示例集（8 类用例）**

Apache KIE 孵化项目维护的 OptaPlanner quickstarts 仓库，以 8 个运筹优化用例（学校排课、设施选址、维护排程、呼叫中心、疫苗接种排班、订单拣选、员工排班、车辆路径）演示约束求解，每个用例提供 Quarkus、Spring Boot、ActiveMQ、Kotlin、Python 等多种技术栈实现，多为 Java/Maven/Gradle 工程并配 H2 数据库。上手需安装 JDK 11 及以上，通过 git clone 后运行 runQuickstartsFromSource.sh 构建展示工程；另附桌面版示例下载入口。
