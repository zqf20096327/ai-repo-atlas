**遗传算法 Python 库：优化问题与机器学习训练**

PyGAD 是一个 Python 3 库，用于构建遗传算法并优化机器学习算法，支持 Keras 与 PyTorch，可处理单目标与多目标问题。提供多种交叉、变异与父代选择方式，用户通过自定义适应度函数优化各类问题。核心安装仅依赖 numpy 与 cloudpickle，绘图等功能以可选 extras 提供。当前版本 3.9.2，要求 Python 3.8+，文档托管于 Read the Docs，另提供云端运行工具 Vilvik。
