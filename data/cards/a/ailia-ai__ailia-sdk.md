# ailia-ai/ailia-sdk

**跨平台 ONNX 推理引擎 SDK，含模型库与多语言绑定**

ailia SDK 是支持跨平台运行的推理引擎：读取 ONNX 模型，经 Metal 与 Vulkan 执行 GPU 推理；附带 400 余类模型的模型库，并提供高级前处理与后处理。以 Python、C++、C#、Flutter 绑定形式交付，同系列还包括分词、语音识别、语音合成、本地 LLM 推理（GGUF）、目标追踪与 TFLite 推理等组件。面向在应用中集成神经网络推理的开发者，提供免费评估版下载。
