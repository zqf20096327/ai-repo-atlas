**浏览器本地生成 YC 风格创业名的字符级神经网络应用**

基于字符级小型神经网络生成 YC 风格创业公司名的 Web 应用，模型从 6,194 个 YC 公司名上从零训练，数据经 Context.dev 抓取。模型在浏览器本地运行，无 LLM 与后端。前端用 React/Vite 构建，运行方式为 npm install 与 npm run dev；另提供 Python venv 训练模型的流程，并用 npm run export-models 导出模型。声明为非官方项目，与 Y Combinator 无关联。
