# autonomys/autonomys-agents

⭐ 30 · TypeScript · NOASSERTION · 推送 2026-02-18 · [GitHub](https://github.com/autonomys/autonomys-agents) · 组织维护

**构建自主 AI agent 的实验性框架，支持社交媒体交互与永久记忆**

TypeScript/yarn 构建的实验性 AI agent 框架，支持自主社交媒体互动（Twitter）、内置编排系统、可扩展工具系统与 YAML 角色人格配置。通过 Autonomys Network 实现永久记忆存储、可验证交互历史与跨 agent 记忆共享（需 Auto Drive API key 与 Taurus EVM 钱包）。包含上下文裁剪摘要机制管理 LLM 窗口；提供 Web CLI 界面与 Docker 多 agent 部署。README 声明处于早期开发阶段，主分支可能有破坏性变更。
