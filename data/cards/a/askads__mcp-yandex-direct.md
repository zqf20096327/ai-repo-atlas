**把 Yandex Direct 广告账户接入 AI 应用的 MCP 服务器**

以 MCP 协议将 AI 应用（Claude Desktop/Code、Codex、Cursor、VS Code）连接到 Yandex Direct 广告后台，提供 46 个工具，覆盖广告系列、组、广告、关键词与否定关键词、出价调整、余额与统计的查询和修改。提供两种接入方式：远程 URL 服务器只读、无需手动取 token；本地 npx 运行可完全读写。通过聊天内 OAuth 授权连接，支持沙箱环境、CI 环境变量配置与遥测开关；仅支持创建文字类广告系列，受 API Units 配额与报表限制。

## 能力要点

- 46 个工具覆盖广告系列/广告/关键词/出价/统计/余额
- 聊天内 OAuth 连接，无需预先创建 token；支持约一年的访问有效期
- 远程只读与本地 npx 全读写两种接入方式，支持沙箱
- 工具向客户端传递读/写/不可逆操作标记，raw_request 需 confirmWrite=true

## 适用场景

- 用自然语言查看广告预算花到了哪些系列和分组
- 找出花费预算但不产生点击/转化的关键词和已停止的广告
- 在对话中准备并应用出价、否定词、新广告系列等修改
- 代理商在一台服务器上切换查看多个客户账户
