# aleksa-codes/astro-portfolio

⭐ 30 · HTML · MIT · 推送 2026-10-29 · [GitHub](https://github.com/aleksa-codes/astro-portfolio) · [官网](https://aleksa.codes) · 个人维护

**带 AI 聊天助手与博客的个人作品集网站模板**

基于 Astro 7、Tailwind CSS 4 与 TypeScript 构建的个人作品集与博客站点，集成 Groq 驱动的流式 AI 聊天助手（含追问与每日限流）、AI 生成的单文件浏览器小游戏页面、Markdown 内容集合、Decap CMS（/admin 路径）、Netlify Forms 联系表单与自动 OG 图生成。通过 git clone 源码安装，使用 Bun 作为包管理器，需设置 GROQ_API_KEY 环境变量，部署面向 Netlify。去掉 AI 聊天后仍可作为常规作品集站点使用。
