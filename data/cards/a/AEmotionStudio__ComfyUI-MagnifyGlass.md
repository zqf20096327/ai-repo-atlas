**ComfyUI 画布放大镜扩展：缩放查看图像与节点细节**

ComfyUI 的自定义节点扩展，提供 WebGL 渲染的放大镜工具：跟随或固定位置缩放画布（最高 10x），可配置形状、尺寸与边框；附带检查器面板悬停查看节点参数（Seed/CFG/Steps）、文本与图像详情；支持多显示器弹出视图、主题自适应与可访问性选项（反色、灰度、文字描边/发光、减少动画）。面向 ComfyUI 用户，用于检查生成图像与工作流细节。通过 ComfyUI Manager 或 git clone 安装，GPL-3.0 许可，由 Æmotion Studio 开发。

## 能力要点

- WebGL 渲染放大镜，缩放 100%-1000%，形状/尺寸/边框可配置
- 检查器面板悬停显示节点参数、文本与图像详情
- 多显示器弹出视图与主题自适应（Dark/Light/Solarized/Nord 等）
- 可访问性选项：反色、灰度、文字缩放/加粗/发光/描边、减少动画

## 适用场景

- 放大查看 ComfyUI 画布中生成图像的细节
- 悬停快速查看节点参数与执行顺序导航
- 高对比度或低视力场景下更清晰地阅读节点内容
