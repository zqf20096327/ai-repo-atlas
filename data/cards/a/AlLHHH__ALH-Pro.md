⭐ 297 · C# · GPL-3.0 · 推送 2026-11-26 · [GitHub](https://github.com/AlLHHH/ALH-Pro) · [官网](https://alhpro.cn/) · 个人维护 · 中文 README

**本地运行的图片/视频/音频 AI 增强桌面工具**

Windows 桌面应用，将多种开源引擎封装为本地处理流水线：图片超分（waifu2x/Real-ESRGAN）、AI 抠图（U²-Net/ISNet/BiRefNet）、视频超分（Real-CUGAN）、RIFE 补帧、重复帧去除，以及音频升采样/人声分离（Demucs）/增强。全部处理在本机完成，不上传数据；启动时自动检测 GPU 并在不兼容时降级 DirectML 或 CPU，无独立显卡也可运行。普通用户下载安装包即可，开发者可用 .NET 8 SDK 从源码构建。

## 能力要点

- 集成 waifu2x、Real-ESRGAN、RIFE、Demucs 等多个开源引擎
- 全部处理在本机完成，不上传、不收集用户数据
