# ApmeM/BrainAI

⭐ 55 · C# · MIT · 推送 2026-05-28 · [GitHub](https://github.com/ApmeM/BrainAI) · 个人维护

**为游戏添加 AI 的 .NET 辅助类库（寻路/影响图/模拟）**

面向游戏开发者的 C#/.NET 库，提供向游戏加入 AI 行为的辅助类集合，功能模块包括 AI、寻路（Pathfinding）、影响图（InfluenceMap）与模拟（Simulations）。通过 GitHub NuGet 源以 dotnet add package 安装，提供基于 Godot 的在线动态示例。寻路部分源自 StrightEdge 项目的重写适配，基础寻路与 AI 技法参考自 Nez 引擎。README 未展示各模块的算法细节与平台支持范围。
