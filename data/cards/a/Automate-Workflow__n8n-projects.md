# Automate-Workflow/n8n-projects

⭐ — · [GitHub]() · 个人维护

**n8n 自动化工作流学习目录：50 个分类项目与四阶段路径**

该仓库将 data/n8n_list.csv 中的公开 n8n 工作流与集成仓库整理为 9 个类别（WhatsApp、LinkedIn、HR、文本分类、语音、图像、计算机视觉、视频、论文），共 50 个项目，并按触发器/凭证、聊天机器人、文档视觉、多 Agent 四个学习阶段排序。面向自动化工程师、开发者、技术运维团队与学生。每个类别附带前置条件与风险说明，另提供 Docker/npx 本地运行 n8n、导入工作流 JSON、配置测试凭证与样例数据测试的使用步骤；CSV 校验与链接检查由脚本和 GitHub Actions 自动执行。
