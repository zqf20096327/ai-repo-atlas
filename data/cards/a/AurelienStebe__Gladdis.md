# AurelienStebe/Gladdis

⭐ 46 · TypeScript · MIT · 推送 2026-03-26 · [GitHub](https://github.com/AurelienStebe/Gladdis) · 个人维护

**Obsidian 内的 AI 聊天机器人插件：在笔记中对话、转录与读档**

Obsidian 社区插件，把任意打开的 Markdown 文件作为对话窗口，流式追加 LLM 回复；自动转录音频 WikiLinks（Whisper），加载文本/PDF/网页链接，支持向视觉模型发送图片；可用 FrontMatter 命名与切换多个 system prompt 人格。模型接入：OpenAI 付费 API（o3-mini/gpt-4o 等），或经 Ollama/LocalAI 本地运行开源模型（llama3、qwen2.5 等）。提供 Demo Vault 与三种 Obsidian 命令。

## 能力要点

- 以 Markdown 文件为对话窗口，流式追加 LLM 回复
- Whisper 音频转录、文本/PDF/网页链接自动加载
- FrontMatter 命名多个 system prompt 人格并切换
- 支持 OpenAI API 与 Ollama/LocalAI 本地开源模型

## 适用场景

- 在 Obsidian 笔记库中直接与 LLM 对话并留档
- 录音后自动转写为文字笔记
- 通过不同人格配置与多种模型对话
