**纯 JavaScript 的教育向 ML 算法库，浏览器内运行**

面向开发者与学生的教学用途纯 JavaScript 机器学习库：实现 400 余种算法，覆盖聚类、分类、回归、降维、异常检测、强化学习、时间序列预测、图像分割与边缘检测等任务，全部在浏览器客户端运行。算法部分不依赖外部库（仅 ONNX 文件加载除外），多数模型单文件实现。附在线 demo、演示数据（MNIST/Titanic/UCI 等）与十余个强化学习环境。文档声明代码在速度与内存方面不具备实用性。
