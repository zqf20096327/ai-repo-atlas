⭐ — · [GitHub]() · 个人维护 · 中文 README

**网页版 AI 照片编辑器：用 Gemini 实现文生图与局部修图**

基于 React 19 的网页版 AI 图像编辑器（webui），通过 Google Gemini API 与 Imagen 4 模型提供文生图、点击式局部编辑、风格滤镜、多图融合（最多 4 图）、一键抠图、纹理叠加、Past Forward 年代肖像生成及随音乐节拍生成视频短片等功能，并内置可搜索的 NB 提示词库。面向终端用户，可在 AI Studio 上作为 APP 使用，也支持自部署并配置环境变量中的 API 密钥；自带 Gemini API 密钥的调用会产生费用。

## 能力要点

- 点击式局部编辑：指定图片位置后用文字指令修改
- 多图融合（最多 4 图）与 AI 灵感建议
- 一键抠图生成透明 PNG、纹理叠加与专业调整
- 内置可搜索分页的 NB 提示词模板库

## 适用场景

- 用自然语言对照片做局部修改或移除物体
- 从文本生成图片并套用艺术风格滤镜
- 把多张图片的人物、背景、风格融合成新图
- 上传肖像生成 1950s-2000s 各年代样貌
