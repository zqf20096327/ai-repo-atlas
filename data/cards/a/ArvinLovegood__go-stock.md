# ArvinLovegood/go-stock

⭐ 8,275 · Go · GPL-3.0 · 推送 2026-11-26 · [GitHub](https://github.com/ArvinLovegood/go-stock) · [官网](https://go-stock.sparkmemory.top) · 个人维护 · 中文 README

**面向个人投资者的 AI 股票分析与选股桌面工具**

基于 Wails 和 NaiveUI 开发的股票分析桌面应用，支持 A股/港股/美股行情、ETF 基金搜索与 K 线分析。AI 侧内置三种模式的智能体（React/PlanExecute/DeepAgents）、150+ 数据工具、技能系统、MCP 扩展、视觉理解（截图问股/K线图分析），并提供涨跌报警与飞书/钉钉推送。数据保留在本地，支持 OpenAI 接口格式、Ollama、LMStudio、DeepSeek、硅基流动等平台。开发环境主要基于 Windows10+，其他平台未测试或功能受限；README 声明分析结果仅供学习研究。
