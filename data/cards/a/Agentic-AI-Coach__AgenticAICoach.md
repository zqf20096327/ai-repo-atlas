# Agentic-AI-Coach/AgenticAICoach

⭐ 32 · Python · MIT · 推送 2026-03-01 · [GitHub](https://github.com/Agentic-AI-Coach/AgenticAICoach) · 组织维护

**面向 AI 创业者的多智能体教练系统（CrewAI 实现）**

基于 CrewAI 构建的开源多智能体教练项目，将 AI 创业旅程绘制为'AI Coaching Atlas'，在客户痛点决策、AI 伦理与合规（含 AI Act 合规检查器）、UX 与产品验证、精益创业、创业心态等环节提供教练式对话支持。采用模块化架构：YAML 配置定义 agents 与 tasks，支持自定义工具扩展，社区可提交 Agents、Tasks 与 Crews。通过 git clone 源码运行，每个 coach 为独立目录（含 poetry 配置与 .env 示例）。
