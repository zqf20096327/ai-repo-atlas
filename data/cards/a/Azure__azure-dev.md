**面向开发者的 Azure 应用构建部署运维 CLI**

Azure Developer CLI（azd）是面向开发者的命令行工具，用于构建、部署和运维 Azure 应用，命令对应工作流关键阶段：code、build、deploy、monitor。提供 Windows（winget）、macOS（Homebrew cask）、Linux（curl 安装脚本）安装渠道，并配套 VS Code 扩展；内置遵循 Azure 开发规范的模板，支持 bash/zsh/fish/powershell 补全，默认收集遥测数据、可通过环境变量关闭。
