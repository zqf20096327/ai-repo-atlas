# AntheaLaffy/dsh-plugin-tomato-todo

⭐ — · [GitHub]() · 个人维护 · 中文 README

**DSH 插件形态的番茄钟专注工具，带本地学习助手**

作为 DeepSeek Harness 的插件提供专注与学习管理：九页主视图、番茄计时、任务/项目/循环任务、每周课表阻塞时段与统计；Node 本地 runtime 承担领域逻辑与数据，Rust 原生守卫通过各桌面窗口接口实现应用白名单、全屏锁机与通知，随 systemd user service 登录自启。学习助手复用 DSH 对话，经插件自带的 tomato_* 工具读写计划与白名单，改动需经待审阅文件批准。数据全部存本机 JSON，不联网不要账号；专注保护依赖桌面会话（以 Wayland 为主），部分桌面后端尚待验收。

## 能力要点

- 学习助手经 tomato_* 工具读写计划，改动先出待审阅文件
- Rust 守卫按桌面提供应用白名单与 1–720 分钟定时锁机
- 任务/课表/循环规则针对多科目长线备考场景设计
- runtime 亦暴露为 MCP 服务器，可接入任意客户端

## 适用场景

- 备考多科目时按科目建项目并配置各项目应用白名单
- 专注时把白名单外应用自动切回专注界面
- 用每周课表与阻塞时段安排复习节奏并回看统计
