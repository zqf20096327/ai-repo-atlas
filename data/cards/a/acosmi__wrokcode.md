**个人 AI 工作台：从需求生成页面、文档与海报**

wrok Code（原 CrabCode）是运行在终端与桌面的 AI 工作台，提供 Code 与 Work 双模式：编程方面从需求生成页面与代码、复杂任务交由子智能体分工；工作方面整理资料、提炼重点并保留出处。内置 104 个设计模板，可导出图片、PDF 和视频；支持跨会话记忆、MCP 工具接入、经授权的浏览器与电脑操作。提供 TUI 与 GUI 两种形态，覆盖 macOS/Linux/Windows；模型请求经 Acosmi 网关转发，可用模型由 SDK 动态下发。仓库仅承载发布包与用户文档。

## 能力要点

- Code × Work 双模式，同一助手串联整理、编程、设计与记忆
- 104 个内置设计模板，支持导出图片、PDF 和视频
- TUI 与 GUI 双形态，覆盖 macOS/Linux/Windows
- 支持 MCP 工具接入与经授权的电脑/浏览器操作

## 适用场景

- 从一个需求直接生成页面、文档和海报交付物
- 在终端中完成代码理解、排错、重构与测试生成
- 整理项目资料并保留出处，跨会话延续项目记忆
