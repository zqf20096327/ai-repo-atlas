**用 Java 1.8 分 12 课从零拆解 AI Agent 原理的教程项目**

shareAI-lab/learn-claude-code（Python 版）的 Java 重写，把 Claude Code 式 Agent 的核心机制拆成 12 节递进课程：从 while 循环、工具调用逐步讲到子 Agent、多 Agent 协作与 Git Worktree 隔离。面向想理解 Agent 底层原理的 Java 开发者，非框架。依赖仅 Gson 与原生 HttpURLConnection，不引入 AI SDK；每课含独立 main() 可直接运行，配套 14 张交互式 SVG 架构图与中英双语注释，需自行配置 Anthropic 兼容 API Key。
