**开源的团队 Agent 工作台：对话式构建 AI 同事与自动化**

Agenta 是一个开源（MIT）的 Agent 工作区，用户通过对话描述工作来构建专职 Agent，可连接应用并按反馈迭代；Agent 可通过 Slack、Telegram 或 WhatsApp Business 被团队使用，并支持按计划或事件触发的自动化。机制上：每个 Agent 在独立沙箱会话中运行、支持按 Agent 设置工具权限、每次运行有追踪与成本记录、Agent 具备记忆与自建技能。可通过 Agenta Cloud 使用或自行托管；部署说明通过安装一个自托管技能来引导完成。

## 能力要点

- 对话式构建 Agent，支持 Slack/Telegram/WhatsApp 中的使用
- 自动化运行：按计划或连接应用的事件触发，可查看每次运行记录
- 会话级沙箱隔离、工具读写权限控制、运行追踪与成本记录
- 接入 MCP 与 Composio（1,000+ 应用），支持 Ollama 自托管模型

## 适用场景

- 为 IT 运维、GTM、HR、法务、财务等团队构建共享的自动化 Agent
- 在 Slack 等团队工具中直接与 Agent 协作
- 无需代码构建潜客调研与外联回复的自动化流程
- 自托管并用自己的模型与数据运行 Agent 平台
