# ALucek/deep-competitive-analyst

⭐ 51 · Python · Apache-2.0 · 推送 2025-11-25 · [GitHub](https://github.com/ALucek/deep-competitive-analyst) · [官网](https://lucek.ai) · 个人维护

**自动化生成公司档案与竞争分析的 deep agent 助手**

基于 deepagents、LangGraph Platform 与 Perplexity Search 构建的 LLM 深度代理：自主执行商业调研，动态生成子代理并行拆分研究任务，长时间运行后产出公司档案与竞争分析报告。安装方式为克隆仓库后用 uv sync 安装依赖，配置 OPENAI、PERPLEXITY、LANGSMITH 的 API key，通过 langgraph dev 在本地运行并可接入兼容界面，推荐用 LangSmith Studio 做本地测试。面向需要批量产出商业调研报告的用户。
