# Arthur-Miyano/recall-memo

⭐ 16 · Python · MIT · 推送 2026-09-06 · [GitHub](https://github.com/Arthur-Miyano/recall-memo) · 个人维护 · 中文 README

**本地运行的八股背诵训练工具：AI 出题、判分、面试模拟与复盘**

面向面试准备的本地单用户背诵训练应用：内置 229 题题库，支持导入 md/txt/json/pdf 由 LLM 提取补全题目；提供记忆训练、限时面试模拟、回忆三种模式，AI 按准确性/逻辑/自然度三维度即时判分，逐字重合会被压低自然度分；答错题自动进待补答队列优先重背。答案可展开为层级"记忆树"辅助记忆，另有智能助手代理操作题库、仪表盘统计 token 费用。后端 FastAPI+SQLite 仅监听 127.0.0.1，多 Provider（DeepSeek/Kimi/智谱/豆包）失败自动切换，云端多用户能力未实现。

## 能力要点

- 三种模式：记忆训练、限时面试模拟、按到期度挑题的回忆模式
- AI 三维度即时判分，逐字重合判背诵痕迹并压低自然度
- LLM 从导入文档提取面试题，缺答案自动补全、重复跳过
- 答案拆成层级大纲的记忆树，多 Provider 失败自动切换
