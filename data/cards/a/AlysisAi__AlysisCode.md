# AlysisAi/AlysisCode

⭐ 233 · Python · Apache-2.0 · 推送 2026-11-27 · [GitHub](https://github.com/AlysisAi/AlysisCode) · [官网](https://alysiscode.com/) · 组织维护

**面向桌面用户的 AI agent 应用：写代码、做文档、托管例行任务**

Alysis 是一个桌面 AI 助手应用，内置三类 agent：Code owls 在用户项目中构建、修复并测试软件，支持变更检查点回滚；Work owls 将笔记、文件与研究内容生成文档、表格、幻灯片和 PDF；Owls 可在本地、云端或 Android 上携带记忆与例程持续执行任务。引擎以 Apache-2.0 开源在本仓库，含 CLI、VS Code 扩展与 JetBrains 预览。模型可选 Claude、GPT、Gemini、DeepSeek 或通过 Ollama/LM Studio 使用本地模型，可自带 API key。Shell 命令默认在沙箱中运行，对外发布类操作需用户批准。
