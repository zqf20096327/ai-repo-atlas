**面向家长与教师的学习障碍早期筛查平台（多语言+语音）**

面向学龄儿童及其家长、教师的多语言 Web 平台，通过结构化互动测评辅助读写障碍、计算障碍、书写障碍的早期识别：AI 模式检测筛查、语音交互与语音模式分析、面向教师/家长的角色化仪表盘（筛查、分析、进度追踪、干预建议）。前端为 React+TypeScript+Vite，后端用 Supabase 提供数据库/认证，AI 部分为 Python/TF 集成的模式检测模型。提供在线演示账号，可本地用 npm 或 Python 方式运行。
