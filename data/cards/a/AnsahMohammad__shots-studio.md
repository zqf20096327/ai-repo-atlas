**Android 截图管理应用：AI 搜索、自动打标签与整理**

面向 Android 用户的截图管理应用，用 Flutter 构建。提供按文本、对象、主题的截图内容搜索、AI 自动标签建议、合集分组整理。AI 部分支持两种模式：云端 Gemini 2.0 Flash / 2.5 Pro（需 API key，默认将截图数据发送至 Gemini API），或设备端 Gemma 模型离线处理（无需 API key、不联网）。通过 GitHub Releases、Play Store、F-Droid 分发 APK，安装后授予存储权限即可使用。

## 能力要点

- 按截图内容（文本/对象/主题）搜索，无需预先标注
