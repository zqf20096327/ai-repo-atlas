**嵌入 textarea 的 AI 文本编辑器，基于 Next.js 与 Groq**

使用 Next.js 与 Vercel AI SDK 构建的 AI 文本编辑器，推理通过 Groq 提供，定位为将 AI prompting 能力内置到文本输入框中。运行方式：克隆仓库，配置 .env.local 中的 Vercel AI Gateway API key（或通过 vercel link 与 vercel env pull 以 OIDC token 认证），用 pnpm install 安装依赖、pnpm dev 启动开发服务器。README 仅 13 行，功能细节未展开。
