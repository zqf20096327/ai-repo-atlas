# asaotomo/FofaMap

⭐ 770 · Python · Apache-2.0 · 推送 2026-11-02 · [GitHub](https://github.com/asaotomo/FofaMap) · [官网](https://www.hx0.store/products/fofamap) · 组织维护 · 中文 README

**给安全人员用的AI资产测绘工具：串联FOFA查询、验证与报告**

FofaMap 将 FOFA 资产查询、AI Agent 反思分析、Nuclei 授权扫描与 Markdown/HTML 报告交付整合进同一命令行工作流，覆盖语法入门、字段选择、分页额度控制、CSV/JSONL/XLSX 导出与定时快照对比。普通查询仅需 FOFA API Key，无需配置模型；AI 调查需另配模型 Key。提供 31 个 MCP 工具、Skill 与 REST API 供宿主 AI 助手或程序调用，主动扫描需用户确认方案。

## 能力要点

- 31 个 MCP 工具 + Skill + REST API 多入口接入
- Agent 规划查询并按命中反思，输出可回看证据的资产简报
- 内置 691 条、166 类本地指纹规则库（含核验状态标记）
- 主动扫描需展示目标与方案并经用户确认

## 适用场景

- 用一句话让 Agent 完成域名资产调查并生成简报
- 对授权范围资产做周期盘点与快照对比
- 在 Codex/Cursor/Claude 等宿主中通过 MCP 调用资产查询
- 导出 CSV/XLSX 资产清单交给团队继续分析
