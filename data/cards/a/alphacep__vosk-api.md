**离线语音识别工具包：面向 20+ 语言的开发者 API**

Vosk 是一个离线开源语音识别工具包，支持 20 多种语言和方言的语音识别。模型体积小（50 MB），提供连续大词汇量转写、流式 API 零延迟响应、可重配置词汇表与说话人识别。为 Python、Java、Node.js、C#、C++、Rust、Go 等语言提供绑定，可从树莓派、Android 手机扩展到大型集群，安装文档位于官网。
