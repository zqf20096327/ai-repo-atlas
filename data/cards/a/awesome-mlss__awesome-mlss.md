社区项目 awesome-mlss，以网站 awesome-mlss.com 与 GitHub 仓库形式追踪全球机器学习及相关领域暑期学校的报名截止日期。README 列出即将举办与截止日期临近的学校条目（含主题、地点、日期），过往学校数据存于网页存档；接受社区以 issue 或 pull request 方式增改条目，组织者可通过邮件提交学校信息。项目基于 aideadlin.es 与 pythondeadlin.es 的成果构建，MIT 许可。
