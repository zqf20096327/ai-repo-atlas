**面向种植者的叶片病害识别全栈 Web 应用**

AI Crop Doctor 是一个 Flask 全栈 Web 应用，服务农民、园艺爱好者与农业专家：用户上传叶片照片并回答症状相关问题，系统结合机器学习图像识别（CNN/TFLite/Keras，据仓库标签）与 Gemini 生成置信度评分的病害诊断与处理建议。使用流程为上传图片、回答补充问题、获得诊断结果；通过 git clone 源码、pip 安装依赖并运行 app.py 启动，浏览器访问本地 5000 端口。README 未披露模型训练数据与准确率细节。
