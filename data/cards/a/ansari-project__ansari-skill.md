**回答伊斯兰教义问题的 Agent Skill，基于 Quran/Hadith 权威来源**

符合 Agent Skills 规范的技能包：安装到 Claude Code、GitHub Copilot、OpenAI Codex CLI、Cursor、Gemini CLI、OpenClaw 等平台后，指示 AI agent 调用 Ansari API，输出以 Quran、圣训集与古典伊斯兰学术为依据的回答。API 无需认证与 API key。安装方式包括上传 zip 至 Claude 设置、复制目录到各平台 skills 目录、clawhub 安装器及 npx openskills 通用安装器。MIT 许可。
