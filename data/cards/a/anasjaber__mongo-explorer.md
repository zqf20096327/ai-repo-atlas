# anasjaber/mongo-explorer

⭐ 35 · JavaScript · MIT · 推送 2025-11-24 · [GitHub](https://github.com/anasjaber/mongo-explorer) · [官网](https://mongo-explorer.onrender.com) · 个人维护

**带 AI 辅助的 MongoDB 网页版管理与查询优化工具**

Web 应用，提供多实例 MongoDB 连接、库与集合浏览、查询执行与保存、索引管理界面、Schema 浏览、查询日志与剖析等数据库管理功能。AI 部分：自然语言生成 MongoDB 查询、AI 索引建议（一键创建）与查询优化建议，通过 OpenAI 集成实现。架构为 React 前端加 ASP.NET Core 8 后端 API，通过 Docker Compose 一键部署，前端 7072、后端 7073 端口访问。MIT 许可。
