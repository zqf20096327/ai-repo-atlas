**构建 AI SaaS 的 Next.js 全栈启动模板（免费开源版）**

基于 Next.js 与 Tailwind CSS 的全栈 AI SaaS 应用启动模板，包含认证、Stripe 支付、数据库管理、仪表盘等页面与集成，以及 AI API 接入层和文本、图像、代码等生成示例。面向希望快速搭建 AI SaaS 产品的开发者。免费版组件与集成有限（AI 功能仅演示），Pro 付费版包含完整集成与全部示例；支持一键部署到 Vercel 等平台。

## 能力要点

- 预置认证、Stripe 支付、数据库管理等 SaaS 集成与页面
- AI API 即插即用，附文本/图像/代码/视频/邮件生成示例
- 基于 Vercel AI SDK 统一接口，默认支持 OpenAI 及其他模型提供商
