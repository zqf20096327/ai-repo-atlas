**面向个人/开发者/团队的 IM 平台 Agent 聊天机器人框架**

开源一体化 Agent 聊天机器人平台，接入主流即时通讯应用，为个人、开发者与团队提供对话式 AI 基础设施。核心机制包括：多平台适配层（QQ、Telegram、Slack 等 20 余平台）、多模型服务接入（LLM/语音转文字/文字转语音三类约 40 项服务）、1000+ 插件一键安装、带会话级资源复用的 Agent 沙箱、知识库与人设配置、WebUI 与 Web ChatUI 管理。部署提供 uv 一键安装、Docker、桌面应用、Launcher 及多种面板方式。
