**Android 记账应用：自动读取银行短信并用 Gemini 分类支出**

面向个人用户的 Android 记账应用：读取本机银行短信通知，经 Google Gemini API 自动分类与生成支出洞察，配合 Material Design 3 界面、图表分析、订阅与账单提醒。数据经 Firebase 同步，Room 数据库提供离线存储，认证由 Firebase Authentication 承担。限制：短信分析目前仅支持 5 家卡塔尔银行（QNB/QIB/CBQ/Doha Bank 等）。需从源码构建：Android Studio、JDK 17+、Android SDK API 24+，并自行配置 Firebase 与 Gemini API key。
