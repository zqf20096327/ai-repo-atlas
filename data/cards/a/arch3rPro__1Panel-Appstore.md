**1Panel 用户的第三方应用商店：脚本化安装约百款开源应用**

面向 1Panel 面板用户的应用仓库，收录约百个开源项目的部署配置，覆盖 AI 应用、LLM 免费逆向 API、文档管理、安全网络、多媒体、运维监控与 NAS 工具等类别。使用方式是把仓库提供的 Shell 脚本加入 1Panel 计划任务，实现应用的自动化安装与更新。另提供 Skill 配置，可在 Cursor、Windsurf、Claude Code 等 AI 客户端中根据 GitHub 项目地址自动生成 1Panel 应用配置（data.yml、docker-compose.yml、双语 README、图标）。仓库为非官方第三方项目，声明不对镜像有效性作保证。
