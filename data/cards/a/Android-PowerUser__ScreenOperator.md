**Android 应用：用视觉 LLM 的指令操作手机屏幕**

Android 端应用，接收视觉 LLM 下发的指令并执行屏幕操作，可通过 API 在 Termux 中直接执行命令；每次更新后需点击 Restore System Message 获取新工具。以 APK 安装包分发（GitHub 版本更新快于 Play Store），并支持用户分享自定义 Skill Set。README 提示 Google 账号若被识别为未满 18 岁将无法获取 API key，可用 Freedom 订阅作为替代方案。
