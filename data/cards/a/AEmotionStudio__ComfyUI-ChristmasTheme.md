# AEmotionStudio/ComfyUI-ChristmasTheme

⭐ 45 · TypeScript · GPL-3.0 · 推送 2026-04-09 · [GitHub](https://github.com/AEmotionStudio/ComfyUI-ChristmasTheme) · [官网](https://aemotionstudio.org/) · 组织维护

**为 ComfyUI 添加圣诞节视觉主题的自定义节点扩展**

面向 ComfyUI 用户的界面主题扩展（custom node），提供动态星空背景（6 种氛围主题）、雪花效果（8 种 SVG 雪花、自定义雪花图片与混搭模式）、节点连线的彩灯动画（6 色方案 × 6 动画样式）、21 种鼠标粒子效果与跨年倒计时烟花。性能方面支持自适应降质、渲染时暂停动画、GPU 加速渲染与对象池。代码以 TypeScript 重写并配套 Vitest/Playwright 测试。通过 ComfyUI Manager 或 git clone 到 custom_nodes 目录安装，GPL-3.0 许可。
