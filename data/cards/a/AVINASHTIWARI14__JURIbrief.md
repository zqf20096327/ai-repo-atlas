⭐ 18 · JavaScript · 推送 2026-10-28 · [GitHub](https://github.com/AVINASHTIWARI14/JURIbrief) · [官网](https://legal-ease-ai-sand.vercel.app) · 个人维护

**面向消费者的法律文档 AI 助手：摘要、风险识别与问答**

React + Node.js 的 Web 应用，用户上传 PDF/DOCX/TXT 法律文档或粘贴文本，通过 Google Gemini API 生成摘要，识别风险条款、义务与关键期限，支持就文档内容追问、对比两个版本差异、按管辖区从自然语言描述起草文档，并可将分析内容翻译为多语言。提供邮箱/Google 登录与管理员面板。自部署需 Node.js、Supabase、PostgreSQL 与 Gemini API key，本地运行需分别启动前后端并应用 schema.sql。README 声明仅为信息工具、不构成法律意见。
