# Alice5412/wechat-message-completion

⭐ 3 · Rust · MIT · 推送 2026-11-22 · [GitHub](https://github.com/Alice5412/wechat-message-completion) · 个人维护 · 中文 README

**Windows 微信输入框的 AI 消息补全托盘工具**

面向 Windows 64 位桌面微信的 Rust 托盘程序：在微信输入框按 Ctrl+Alt+空格调用自定义模型接口生成灰色建议，Tab 填入草稿；输入框为空时写回复、有文字时续写。聊天历史默认用内置 OCR 模型读屏获取，可选配合仓库自带的 weflow-local 本机服务直接解密读取微信 4.x 数据库以取完整历史。仅支持 OpenAI 兼容流式 Chat Completions 接口，只读单聊会话，需从源码构建。

## 能力要点

- 快捷键触发灰字建议、Tab 填入，空框写回复/有字续写两种模式
- 内置 PP-OCRv6 Tiny OCR 读屏获取聊天历史，无需额外服务
- 可选 weflow-local 本机服务解密读取微信 4.x 完整历史
- 支持任意 OpenAI 兼容流式接口与从本人历史生成回复风格提示词

## 适用场景

- 在微信私聊中快速生成或续写回复草稿
- 用本人历史消息让补全贴合个人回复风格
- 不启动额外服务时靠 OCR 读屏提供上下文
