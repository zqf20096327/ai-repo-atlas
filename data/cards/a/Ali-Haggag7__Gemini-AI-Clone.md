**仿 Google Gemini 界面的 React 对话应用，接入 Gemini API**

使用 React.js 构建的 Google Gemini 界面复刻 Web 应用，通过官方 Google Generative AI SDK（@google/generative-ai）调用 Gemini Pro 模型，提供流式实时对话、多会话聊天历史侧边栏与响应式布局。状态管理采用 React Context API，处理 prompts、结果与加载状态。运行需从 Google AI Studio 获取 API Key 并配置到 gemini.js 或环境变量，通过 npm 启动开发服务器。面向学习 React 与生成式 AI API 集成的前端开发者。
