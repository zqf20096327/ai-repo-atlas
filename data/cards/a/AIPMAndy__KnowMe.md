# AIPMAndy/KnowMe

⭐ 19 · Python · Apache-2.0 · 推送 2026-10-25 · [GitHub](https://github.com/AIPMAndy/KnowMe) · 个人维护 · 中文 README

**从 AI 对话与飞书聊天记录做 MBTI 行为分析的本地工具**

Python 命令行分析器，读取 ChatGPT/Claude/OpenClaw 导出的长期对话或飞书群聊/私聊/复制文本，每次只分析一个指定发言人，输出 E/I、S/N、T/F、J/P 四维倾向、置信度、原话证据片段与沟通建议。分析器仅依赖 Python 3.8+ 标准库，本地运行、不调用外部 AI API；直读飞书需另装 lark-cli。报告标注样本限制，并列出禁止的高风险用途（招聘、解雇等）。亦可作为 Agent Skill 使用。

## 能力要点

- 支持 ChatGPT/Claude/OpenClaw 导出、飞书 lark-cli 直读与 JSON/复制文本导入
- 每次只分析一个发言人，输出四维 MBTI 倾向、置信度与原话证据
- 分析器本地运行、仅依赖 Python 标准库，不调用外部 AI API
- 按消息量分级标注置信度（<20 条低置信度，50+ 条跨日期话题更稳定）

## 适用场景

- 用一年期 AI 对话记录核对自己的思维与表达模式
- 分析飞书里老板/同事的沟通风格，定位协作错位
- 在汇报冲突场景下回到可核对的原话证据做归因检查
