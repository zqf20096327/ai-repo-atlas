# adongwanai/adong-media-desk

⭐ 9 · JavaScript · MIT · 推送 2026-11-22 · [GitHub](https://github.com/adongwanai/adong-media-desk) · 个人维护 · 中文 README

**给自媒体创作者的本地个人 IP 内容生产工作台**

运行在 DeepSeek Harness（DSH）中的本地创作插件：把选题、成稿、图文排版、口播视频与账号运营接入同一工作流。选题雷达聚合 RSS、热榜与内置源，结合方向词提炼选题；成稿走 DSH 原生 Agent 会话，按用户配置的风格卡与素材生成正文，支持局部改稿与版本快照；本地排版提供 30 套主题，卡片导出 PNG/ZIP；视频部分覆盖录制、粗剪、字幕与成片，MP4 导出依赖本机 ffmpeg。稿件与数据保存在本机，模型由用户在 DSH 中自行配置，插件不带任何密钥。

## 能力要点

- DSH 原生 Agent 创作：同一会话内生成、检索、加图与改稿
- 选题雷达聚合 RSS、热榜与内置源，提炼每日选题
- 30 套排版主题，图文卡片导出 PNG/ZIP，长文支持外链脚注
- 口播录制、停顿粗剪、字幕与模板成片，MP4 导出用本机 ffmpeg

## 适用场景

- 从一条资讯或灵感直接生成图文卡片与公众号长文
- 把一篇稿子改编成小红书、X、B 站等多个平台版本
- 录制口播并完成粗剪、字幕与视频发布包
- 汇总各平台粉丝与收入数据做内容复盘和对标
