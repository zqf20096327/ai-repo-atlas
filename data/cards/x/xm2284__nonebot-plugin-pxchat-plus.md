# xm2284/nonebot-plugin-pxchat-plus

⭐ — · [GitHub]() · 个人维护 · 中文 README

**为 nonebot-plugin-pxchat 聊天插件提供稳定性修复补丁的工具**

以构建期/运行期补丁脚本形式存在的项目：对经 pip 安装的 nonebot-plugin-pxchat 包做精确字符串替换，修复调用超时、并发限制、模型故障切换、输出容错解析、发送限速等稳定性问题，并新增按群独立人设、主动插话冷却、多引擎搜索兜底、表情包语义挑选等行为。补丁带 assert 保证上游结构变化时报错，脚本幂等可重复执行。依赖 Python 3.10+、NoneBot2 2.4+ 与 pxchat 1.0.x，上游大版本升级后需同步更新匹配目标。

## 能力要点

- 补丁脚本幂等，对已打补丁文件重复执行会跳过
- 基于字符串精确匹配并带 assert，上游结构变化即报错
- 支持 Dockerfile 构建期打补丁与容器内热补丁两种方式
- 按群独立人设：get_system_prompt 支持 group_id 回退全局人设

## 适用场景

- 为部署 pxchat 的 QQ 机器人修复调用超时与上下文污染
- 为不同群配置独立人设
- 在 Docker 部署流程中自动化打补丁
