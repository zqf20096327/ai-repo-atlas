**可私有部署的多租户企业智能体基座，含 RAG 与多智能体**

面向团队的私有部署智能体平台：将企业资料建成知识库（支持混合检索、Neo4j 知识图谱、RAG 评估），智能体可拆分子智能体、调用工具并在沙盒中执行命令，产物以文件形式交付到工作区。提供 Skills 编写、MCP 工具接入、Agents API 供业务系统调用，管理员可按部门划分权限并查看 Token 用量。安装依赖 Docker Compose 与模型 API Key，本体以 MIT 许可发布。

## 能力要点

- 知识库支持解析、分块、向量与关键词混合检索，引用可回溯原文

- 多租户权限管理与模型用量看板

- 通过 Agents API 把智能体嵌入现有业务系统
- 让外部助手经知识库 MCP 检索企业资料
