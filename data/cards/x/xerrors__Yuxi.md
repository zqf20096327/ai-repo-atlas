**企业自托管智能体基座：统一 RAG、知识图谱与多智能体**

Yuxi 是可私有部署的多租户企业智能体平台：团队将内部资料建成知识库（支持解析、分块、向量与关键词混合检索），可从索引文档块构建 Neo4j 知识图谱，并支持 RAG 评估与问答集生成；智能体可将任务分给子智能体、调用工具与 MCP/Skills 扩展、在沙盒中执行命令并交付文件。管理员按用户与部门划分权限、配置模型供应商与凭据、查看 Token 用量看板；业务系统通过 Agents API 接入，外部助手经知识库 MCP 检索。通过 Docker Compose 部署，需 SiliconFlow API Key 初始化。

## 能力要点

- 自建 Milvus 知识库支持混合检索，可构建 Neo4j 知识图谱
- 多智能体编排：子智能体分工、沙盒执行命令、人工审批
- Skills 与 MCP 工具扩展，知识库 MCP 供外部助手检索
- 多租户权限管理、模型供应商凭据配置与用量看板

## 适用场景

- 把企业制度、产品手册建成可溯源引用的知识库问答
- 把多步调研分析任务交给智能体并取回报告文件
- 为部门共享配置专用智能体并按权限管控资源
- 让外部助手通过 MCP 在授权范围内检索企业知识
