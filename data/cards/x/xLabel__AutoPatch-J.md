**面向 Java 仓库的代码修复 Agent：审阅问题并生成补丁**

AutoPatch-J 是针对 Java 仓库的代码修复 Agent，读取静态扫描产生的 finding，由 LLM 生成补丁，经独立证据（重扫原规则）与人工审核后交付。关键机制包括：以 finding 附近源码为起点的按需上下文扩展与 focus scope 路径限制、按任务类型授权的工具系统（拦截未授权工具与绕过审核的写入）、对话之外保存 finding 队列与补丁状态、编译/测试等独立验收证据。可在本地 CLI 使用，也可接入 CI/CD 以 MR/PR 形式交付补丁。README 未给出安装命令与支持的 LLM 提供商清单。

## 能力要点

- 扫描 finding 驱动的逐项补丁生成，补丁绑定当前 finding 并限定修改范围
- 工具系统按任务类型授权，拦截未授权工具与绕过审核的文件写入
- 补丁应用后重扫原规则，以扫描结果作为独立验收证据
- 支持本地 CLI 与 CI/CD 集成，以可评审的 MR/PR 交付

## 适用场景

- 在 CI 流水线中把静态扫描结果转成可评审的修复补丁
- 开发者对 Java 仓库问题做人工在环（human-in-the-loop）的补丁审核
- 跨项目复用代码风格与提交规范等工程偏好记忆
