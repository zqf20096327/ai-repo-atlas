**面向个人投资者的 Claude Code/Codex 价值投研 Skill 合集**

一套同时兼容 Claude Code 与 Codex 的投资研究 Skill 合集（22 个入口），将巴菲特、芒格、段永平、李录四人的方法论结构化为可执行流程，覆盖深度研究、财报分析、行业筛选、持仓管理与思维工具五类。核心机制包括：多 Agent 并行研究（Team Lead 调度 4 个大师视角 Agent）、信息丰富度评级、芒格式逆向检验、快速否决清单、财务数据多源交叉验证与手算校验脚本。依赖 npm 安装的 Claude Code 或 curl 脚本安装的 Codex，仓库提供各平台的克隆安装脚本；README 另附作者实盘收益记录与公众号、阅读站等渠道声明。

- 22 个 Skill 入口，覆盖深度研究/财报/行业筛选/持仓管理/思维工具
- /investment-team 以 4 个并行 Agent 独立搜索与打分后综合研判
- 财务计算用 decimal.Decimal 并要求至少 2 个独立来源交叉验证

- 跟踪持仓投资论文是否被后续事实证伪
