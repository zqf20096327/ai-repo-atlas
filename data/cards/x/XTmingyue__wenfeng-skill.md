**从单本小说提炼叙事与文风规则、生成可复用写作 Skill 的蒸馏器**

面向 agent 框架的写作类 Skill：用户提供一部小说文本或路径，skill 指导 agent 从叙事模型、语言指纹、母题意象、人物塑造、情节技法、风格边界六个层维提炼规则，规则需满足复现性、生成力与排他性三条准入标准，最终输出可安装调用的目标 SKILL.md。提供 agent 自动安装、npx CLI、git clone 手动安装与直接粘贴四种安装方式。仅处理单本作品，不含受版权保护文本，生成物限定为抽象技法与边界，不包含原文句子或情节复述。
