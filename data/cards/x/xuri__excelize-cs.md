**C# 读写 Excel（XLSX/XLSM 等）文件的开源库**

Go 语言 Excelize 库的 C# 移植版，提供对 XLAM/XLSM/XLSX/XLTM/XLTX 格式文件的读写能力，兼容 Microsoft Excel 2007 及之后生成的文档。支持创建与读取电子表格、基于工作表数据生成图表、插入图片，并提供流式 API 用于处理大体量数据的工作表。以 NuGet 包（ExcelizeCs）分发，要求 .NET 6 与 C# 10 或更高版本，采用 BSD 3-Clause 许可证。

## 能力要点

- 读写 XLAM/XLSM/XLSX/XLTM/XLTX 五种格式
- 流式 API 处理大数据量工作表
- 基于工作表数据生成图表，也可无数据生成图表
- 向工作表插入图片

## 适用场景

- 在 .NET 应用中生成带图表和图片的 Excel 报表
- 程序化读取与解析 Excel 文件数据
- 处理大体量数据工作表的流式读写
