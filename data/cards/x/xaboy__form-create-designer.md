# xaboy/form-create-designer

⭐ 2,380 · Vue · MIT · 推送 2026-11-05 · [GitHub](https://github.com/xaboy/form-create-designer) · [官网](https://view.form-create.com/) · 个人维护 · 中文 README

**Vue 低代码可视化表单设计器，拖拽生成表单并支持 AI 助理**

基于 @form-create 系列与 Element Plus、Ant Design Vue、Vant 实现的表单设计器组件，支持 Vue2/Vue3 与 PC、移动端。核心机制是以 JSON 数据生成表单，内置 40+ 表单与布局组件，提供表单操作 API、验证、子表单、事件与样式配置、多语言等能力。另提供已开源的 AI 表单助理，根据自然语言描述自动生成和修改 FormCreate 表单规则。README 描述其在政务、OA、ERP、电商、流程管理等系统中使用。安装通过 npm 或 CDN 引入。
