# xuanyustudio/LocalMiniDrama

⭐ 2,569 · JavaScript · MIT · 推送 2026-11-27 · [GitHub](https://github.com/xuanyustudio/LocalMiniDrama) · [官网](https://83zi.com/) · 个人维护 · 中文 README

**面向内容创作者的本地离线 AI 短剧/漫剧一站式生成工具**

基于 Electron + Vue 3 + Node.js/SQLite 的本地短剧制作平台：从故事梗概生成多集剧本，自动提取角色/场景/道具并生成形象图，再逐镜生成分镜脚本、静帧与视频片段，最后合成完整剧集。数据存储于本地 SQLite 与本地文件，通过用户自有的 AI API Key 调用多家图片/视频/文本服务商。提供列表与画布双视图、一键流水线、失败自动重试与工程 ZIP 导出导入。Windows 提供 exe 安装包，也可从源码运行。

## 能力要点

- 全流程：故事→角色/场景→分镜→视频合成，支持一键流水线与整组重跑
- 列表+画布双视图编辑，画布支持节点生成与工作流框选
- 多服务商接入：通义/火山/可灵/Gemini/Vidu 及 OpenAI 兼容接口
- 本地优先：SQLite + 本地文件存储，支持 16:9/9:16/1:1 画幅
