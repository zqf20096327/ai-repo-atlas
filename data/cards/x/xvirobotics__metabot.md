**从飞书/Telegram 手机端运行 Codex/Kimi Code 的个人 Agent 工作台**

可自托管的个人 Agent 工作台，由 XVI Robotics 开发、MIT 开源：通过一行安装脚本部署本地 Core、Web 控制台、IM Bridge 与 CLI，从飞书/Lark、Telegram、Slack、微信或 Web 使用 Codex、Kimi Code 等编码引擎，Claude Code 作为兼容引擎保留。提供 Agent Teams 并行分工、MetaMemory 跨会话记忆同步到飞书知识库、T5T/Goal 持久执行、Skill Hub 与 Agent Bus 消息机制。前置条件为 Node.js ≥ 22.19、Git 及引擎与渠道凭证。

## 能力要点

- 三引擎接入：Codex 默认、Kimi Code 一级可选、Claude Code 兼容保留
- 飞书/Lark、Telegram、Slack、微信、Web 五种聊天渠道接入
- MetaMemory 跨会话记忆并可同步到飞书知识库
- 带签名校验的一行安装器，约五分钟部署完整个人版

## 适用场景

- 在飞书或 Telegram 手机端分派和跟进编码任务、合并 PR
- 搭建多 Agent 团队并行分工并保留持久任务状态
- 让 Agent 记忆跨会话留存并同步到飞书知识库
