**Android 原生 Agent：读屏控机、跨应用完成任务**

运行在 Android 手机上的智能 Agent，具备 Phone Use 能力：读取屏幕、点按、滑动、输入文字、打开应用，跨 App 完成操作。可用 Python 封装工具实现网络搜索、文件下载、网页阅读等能力，支持记忆、Skills、MCP 与设备端 Python 运行时，并可通过 SSH 对接远程开发机。通过 LSPosed 接管系统语音助手（目前适配小布助手，即 OPPO/OnePlus/Realme Breeno）实现语音唤醒；接管不支持时可用内置对话界面。本仓库为迁移后的存档页，下载、文档与源码已迁至主仓库 niki914/zafiro。

## 能力要点

- 完整 Phone Use：读屏、点按、滑动、输入、打开应用、跨 App 操作
- 设备端 Python 运行时，可自行封装工具（网络搜索、文件下载、网页阅读）
- 支持记忆、Skills、MCP，可通过 SSH 对接远程开发机
- 通过 LSPosed 接管系统语音助手（目前适配小布助手）

## 适用场景

- 用语音唤醒自己的 Agent 代替系统语音助手
- 让 Agent 看懂屏幕并跨 App 自动完成手机操作
- 在手机上运行带记忆与 Skills 的个人 Agent，并通过 SSH 连接开发机
