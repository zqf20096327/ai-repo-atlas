# xgwangdl/AI-Interview

⭐ 264 · Java · Apache-2.0 · 推送 2026-11-20 · [GitHub](https://github.com/xgwangdl/AI-Interview) · 个人维护 · 中文 README

**面向求职开发者的 AI 模拟面试训练系统：录答、追问、逐题评分**

输入目标岗位、JD 与简历后生成面试题目，通过真人形象数字人语音提问并依据回答质量追问，浏览器逐题录制回答并转写，报告按内容相关性、STAR、逻辑、语速等维度评分；低于 75 分的题进入错题本重练，另含 Docker 沙箱判题笔试（Java/Python/C++/JavaScript/Go）与简历解析优化导出。技术栈为 Java 21 + Spring Boot + Spring AI Alibaba + Vue 3 + PostgreSQL/pgvector + Redis，提供本机开发与 docker compose 两种启动方式，无 API Key 时可用 stub 模式体验界面。

## 能力要点

- 数字人面试官语音提问，追问按回答质量决定，每题最多两轮
- AI 出题先在沙箱运行参考解自检，通过才交给用户
- Docker 一次性容器判题：禁网、只读文件系统、限制 CPU/内存/进程数
- 报告维度含 STAR、逻辑、语速、停顿、口头禅，转写可人工校正后单题重评

## 适用场景

- 准备校招、社招、转岗面试，练开口回答并复盘
- 进行带 Docker 判题的上机笔试练习
- 上传简历按 JD 优化并导出 Markdown/Word/PDF
- 组织学习小组作业布置与同伴互评
