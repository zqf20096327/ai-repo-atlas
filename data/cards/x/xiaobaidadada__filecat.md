# xiaobaidadada/filecat

⭐ 104 · TypeScript · Apache-2.0 · 推送 2026-10-24 · [GitHub](https://github.com/xiaobaidadada/filecat) · 个人维护 · 中文 README

**自托管 Web 文件服务器与轻量服务器管理工具，集成 AI Agent**

基于 Node.js 的自托管 Web 文件服务器与服务器管理工具，UI 采用 filebrowser，支持移动端访问。文件功能覆盖在线预览、编辑（Markdown 所见即所得）与云盘挂载（百度网盘/SFTP/S3/WebDAV/SMB）；另提供内网穿透、Web SSH 终端、Windows 远程桌面（RDP）、系统监控、CI/CD 命令流水线、大文件日志查看与多用户权限管理。AI Agent 为可选功能，需配置大模型 API，可接入 QQ、企业微信、飞书、钉钉等平台机器人。提供 npm、一键脚本、二进制包、Docker 与源码构建五种安装方式。

## 能力要点

- 在线文件浏览/上传/编辑/预览与 Markdown 所见即所得编辑
- 挂载百度网盘/SFTP/S3/WebDAV/SMB 为本地文件夹
