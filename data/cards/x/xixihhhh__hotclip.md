# xixihhhh/hotclip

⭐ 517 · TypeScript · AGPL-3.0 · 推送 2026-11-20 · [GitHub](https://github.com/xixihhhh/hotclip) · [官网](https://xixihhhh.github.io/hotclip/) · 个人维护 · 中文 README

**本地运行的 AI 切片工具：长视频与直播回放一键切竖屏短视频**

Electron 桌面应用，将长视频、直播回放、播客导入后经本地逐字转写（SenseVoice/Paraformer/FireRedASR2 三档本地引擎）与 LLM 爆点分析，生成带爆款分、推荐理由与逐字对齐切点的候选片段，导出 9:16 竖屏成片并自动加动态字幕、封面与发布文案。弹幕文件、响度、镜头与表情峰值作为爆点判断信号；另提供 CLI、MCP server 与录播监听自动出片。全程本地处理、不上传素材，AGPL-3.0 开源，Windows/macOS/Linux 提供安装包。

## 能力要点

- 本地转写三档引擎（SenseVoice/Paraformer/FireRedASR2），普通 CPU 可运行
- 弹幕热度（B站录播姬 .xml / 抖音 .jsonl）进爆点判断
- 横屏转竖屏智能取景 + 词级时间戳动态字幕
- 提供 CLI、MCP server 与 7×24 录播监听自动切片

## 适用场景

- 下播后把几小时直播回放自动切成高光短视频
- 播客纯音频转成竖屏视频发布
- 带货直播按商品讲解模式批量切片并生成发布文案
- 通过 MCP 让 Agent 一句话完成切片交付
