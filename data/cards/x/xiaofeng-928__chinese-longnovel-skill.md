**给网文作者的可安装 Skill：让 Codex/Claude Code 长篇连载不写崩**

一套面向中文长篇网络小说的 Claude Code / Codex 写作 Skill（工程化协议），覆盖从扫榜选题、大纲与分阶段细纲到逐章生成、总结、双审查与 EPUB 导出的工作流。核心机制：按固定证据层级分层组装上下文、事实锁（绑定来源路径与 SHA-256）阻断与已发生事实冲突的续写、每 50 章分阶段细纲、伏笔与因果债追踪、章节事务链与正文哈希绑定的审查失效。通过 install.sh / install.ps1 一键安装，确定性校验脚本需 Python 3。声明适合数百章以上长篇，短篇场景流程偏重。

## 能力要点

- 分层上下文组装：固定证据层级读取，避免整书入上下文
- 事实锁绑定来源路径与 SHA-256，冲突时流程停止而非改写历史
- 每 50 章分阶段细纲与伏笔/因果债追踪回收
- 逐章提交、双独立审查、正文哈希变更后旧审查自动失效

## 适用场景

- 连载数百章的系统流/经营流网文，保持数值与角色认知连续
- 规划第 51-100 章等后续阶段，避免提前透支剧情
- 审查最近若干章的一致性与伏笔状态并自动修复
- 长篇范文拆书、文风蒸馏后进行原创仿写
