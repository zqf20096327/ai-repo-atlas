# 0xPlaygrounds/rig

⭐ 9,240 · Rust · MIT · 推送 2026-11-23 · [GitHub](https://github.com/0xPlaygrounds/rig) · [官网](https://rig.rs) · 组织维护

**Rust 库：统一接口构建模块化 LLM 应用，附终端编码 Agent**

Rig 是用于构建大语言模型应用的 Rust 库，将 20 多个模型提供商和十余种向量存储收敛到统一接口，提供带工具、流式输出与类型化钩子的 Agent，覆盖补全、嵌入、转录、音频与图像模型，遵循 OpenTelemetry GenAI 规范，rig-core 与 rig-agent 可构建为浏览器 WASM。库同时附带同名终端编码 Agent：工具、命令、会话、登录与终端视图均以插件形式组织，可用 Bevy 插件关闭、替换或扩展，/reload 可重建 Agent 并保留会话。Agent 需 Rust 1.97.1 或更新版本，运行于 Linux 与 macOS。
