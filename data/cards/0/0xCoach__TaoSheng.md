**用安卓手机全天收音并 AI 整理成待办与记忆的 lifelog 应用**

面向个人用户的安卓 lifelog 应用：手机后台全天收音，按 Silero VAD 只录人声，本机声纹区分说话人，通过本地 SenseVoice 或云端转写服务转文字，再交给大模型整理成事件、待办、约定与记忆，提问答案附原话出处。支持夜间睡眠记录、环境音识别、足迹与屏幕时间等线索。数据留在本机，无需注册账号；模型可配任意 OpenAI 兼容接口，支持主备容灾。安装方式为 APK 下载，源码编译需 JDK 21 与 Android SDK 36。

## 能力要点

- 离线转写（SenseVoice + 骁龙 NPU）与本机声纹认人可选
- 自动生成待办、每日/每周回顾，问问功能答案附原话
- 记忆可推送到 10 种通道并复制给 Claude Code 等 Agent
- 无官方服务器，密钥存系统安全区，原录音默认 3 天自动删

## 适用场景

- 开会答应的事自动变待办，防止遗忘
- 把日常对话整理成可搜索的个人记忆库
- 夜间自动记录睡眠、鼾声与梦话
- 把每天的记忆增量推送给自己的 AI Agent 再加工
