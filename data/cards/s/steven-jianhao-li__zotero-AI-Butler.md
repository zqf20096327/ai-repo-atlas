**Zotero 插件：自动精读论文并生成 Markdown 笔记**

以 Zotero 插件形式（.xpi 安装）运行的文献阅读助手：自动扫描新添加的 PDF，调用用户自配的大模型 API 生成 Markdown 精读笔记并保存到条目下。支持右键即时分析、自动巡航、批量回溯三种触发方式，多轮对话精读、多文献综述、思维导图（PNG/OPML 导出）、一图总结、侧边栏追问与 LaTeX 公式渲染。插件本身不提供模型服务，需用户自行申请并配置 API Key，不收集上传用户数据。

## 能力要点

- 自动扫描新 PDF 并生成 Markdown 精读笔记，支持右键、自动巡航、批量三种触发方式
- 支持 Base64 多模态上传与文字提取两种 PDF 处理模式
- 多文献综述生成与思维导图（PNG/OPML 导出）
- 内置多种提示词模板，支持自定义与多轮对话精读

## 适用场景

- 文献拖入 Zotero 后自动生成精读笔记
- 批量补充总结文献库中积压的旧论文
- 对整个分类的多篇论文生成文献综述报告
- 阅读论文时在侧边栏向大模型追问公式与细节
