# stockedge/manga-generator

⭐ 171 · JavaScript · MIT · 推送 2026-11-17 · [GitHub](https://github.com/stockedge/manga-generator) · 个人维护

**与 Codex 协作、从原作文本生成漫画到 PDF 的制作工具**

面向漫画创作者的制作工具：以小说或文章原作为输入，在 Codex 代理驱动下推进脚本、分镜（ネーム）、图像生成、文字排版、检品到 PDF 输出的完整流程。台词与气泡和画面分层配置，便于后期修改台词。制作分 quality 与 economy 两种模式，后者限制资料引用、使用独立评审与较短输出。支持 Claude Code 作为替代代理，图像生成依赖外部 ComfyUI 且需另行准备 GPU 环境；制作历史以 gzip 压缩保存以控制容量。

## 能力要点

- 原作文本到脚本、分镜、图像生成、排版、PDF 的全流程制作
