# SWUSTcyt/langchain-travel-agent

⭐ 39 · Python · MIT · 推送 2026-10-22 · [GitHub](https://github.com/SWUSTcyt/langchain-travel-agent) · 个人维护 · 中文 README

**一句话生成多日行程并用地图按天标点的旅游助手**

基于 LangChain 1.x、通义千问 Qwen 与高德地图 MCP 的旅游助手，提供 Gradio 聊天页面：输入城市与天数即生成按天的行程卡片，右侧地图用高德 JS API 按天标点连线。机制上每次提问仅调用一轮工具（地点搜索与天气各最多一次），地点坐标由页面补查最多 12 次；高德查询失败时模型收到并声明「没查到」。需配置 DashScope API Key 与高德相关 Key，源码方式运行，面向普通用户做本地演示使用。
