**Supadata 数据抓取 API 的官方 Python SDK**

Supadata API 的官方 Python 客户端库，供开发者通过 API key 调用 Supadata 的网页抓取与媒体数据处理服务：支持获取 YouTube/TikTok/Instagram/Twitter 平台的媒体元数据与转录文本、翻译 YouTube 转录、抓取网页内容并输出 Markdown，以及用 AI 从视频中提取结构化数据。使用自定义 SupadataError 异常提供结构化错误信息。MIT 许可，pip 安装，需在 supadata.ai 注册获取 API key。
