**构建 AI Agent 团队以自动化高层任务的开源平台**

开源平台，供用户创建由多个 AI Agent 组成的团队来执行高层任务，目标是无需复杂配置即可从 prompt 得到解决方案。核心形态是节点编辑器（node editor）可视化界面，既支持复杂团队也兼容小规模用例。基于 Autogen 框架构建，并计划吸收 ChatDev、CrewAI 等多智能体项目中的部分能力。用户需提供 API key 与任务上下文等信息；另有云端版本 Aitino Web（SvelteKit/Supabase/Stripe 技术栈，免费计划标注 coming soon）。README 未给出本地安装与运行命令。
