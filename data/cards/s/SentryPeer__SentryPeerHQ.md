# SentryPeer/SentryPeerHQ

**管理 SentryPeer 节点数据的 Web 应用与 API（VoIP 欺诈检测）**

Elixir/Phoenix 编写的 Web 应用与 RESTful API，用于管理和查询用户自运行 SentryPeer 节点产生的数据；也可订阅官方云端服务消费其托管的节点数据。自运行节点数据的使用保持免费。自托管需自备邮件服务、PostgreSQL/timescaledb 数据库与 OAuth 2.0 提供方。面向使用 SentryPeer 做 VoIP 欺诈与网络侦察检测的用户。
