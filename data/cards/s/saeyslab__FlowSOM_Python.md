**流式细胞术数据的 SOM 聚类与可视化 Python 库**

将 R/Bioconductor 的 FlowSOM 包完整移植到 Python，并集成 scverse 生态。基于自组织映射（SOM）对流式细胞术（及单细胞）数据做无监督聚类与可视化，用于区分细胞群体，服务于免疫学与肿瘤学研究。要求 Python 3.9+，提供 PyPI、Conda（conda-forge）与 GitHub 源码三种安装途径，附带示例 notebook、API 文档与速查表。
