**浏览器扩展：用 NLP 分析网页并建议书签标签与文件夹**

浏览器扩展，读取当前标签页内容，生成建议的标签与文件夹供保存书签，也可作为网页扫描器输出内容整体情绪与情感概览。分析能力来自 IBM Watson Natural Language Processing API。与 Pocket、Mix 等使用独立存储空间的书签管理器不同，它作为浏览器书签 API 的接口，使书签在扩展外也可访问和编辑。项目已声明停止开发，安装与使用章节标注即将推出或尚未提供。

## 能力要点

- 分析当前标签页内容并返回建议标签与文件夹
- 可作为网页扫描器输出内容情绪与情感概览
- 基于浏览器书签 API 而非独立存储空间
- 分析服务由 IBM Watson NLP API 提供

## 适用场景

- 保存网页时自动获得标签和文件夹建议
- 快速查看一个网页内容的整体情绪与情感
- 在扩展之外继续管理由扩展保存的书签
