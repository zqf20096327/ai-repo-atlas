# sligter/LandPPT

⭐ 3,650 · Python · NOASSERTION · 推送 2026-11-20 · [GitHub](https://github.com/sligter/LandPPT) · [官网](https://landppt.com) · 组织维护 · 中文 README

**基于大语言模型的 PPT 生成平台：文档/主题转演示文稿**

以「主题或文档 → 大纲 → HTML PPT → 讲稿/配音/导出」为工作流的 Web 平台。用户输入主题或上传 PDF/Word/Excel/PPT/Markdown/图片，经大纲编辑、可选深度研究、AI 配图与并行生成产出幻灯片，支持侧边栏 AI 对话编辑、Edge-TTS 讲解音频、1080p 讲解视频，以及 PDF/HTML/PPTX/图片/DOCX/Markdown 多格式导出。本地默认 SQLite 即可运行；标准可编辑 PPTX 导出需商业许可的 Apryse License Key；FastAPI 实现，提供 Docker 单容器与 Compose 部署及 OpenAI 兼容 REST API。

## 能力要点

- 主题/文档到完整 PPT 一键并行生成，四阶段工作流（需求确认→大纲→任务追踪→生成）
- 按角色（大纲/幻灯片/编辑/模板/讲稿）路由不同模型以控制成本
- 三源配图：本地图库/网络图库（Pixabay、Unsplash）/AI 生成
- 多格式导出与一键公开分享链接（含讲解音频与字幕）

## 适用场景

- 把长文档或报告快速转成结构化演示文稿
- 教学课件与工作汇报的自动化制作
- 接入 API 在脚本/CI 中批量生成 PPT
