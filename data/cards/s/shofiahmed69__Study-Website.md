**集成 AI 学习助手的全栈学习进度追踪平台**

基于 React + Node.js/Express + MongoDB 的全栈 Web 应用：收录数百个 YouTube 学习课程，提供学习进度追踪、管理员后台手动添加与管理课程、管理员身份认证，以及通过 Groq API 驱动的 AI Study Buddy 学习助手；课程数据经 YouTube Data API 获取。安装方式为克隆仓库后分别在后端与前端目录 npm install，配置 MongoDB/Groq/YouTube 三项 API key 后运行。计划中的功能包括个性化推荐与课程完成证书，尚未实现。
