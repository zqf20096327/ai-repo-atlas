# seehiong/md-editor-pro

⭐ 172 · TypeScript · MIT · 推送 2026-07-10 · [GitHub](https://github.com/seehiong/md-editor-pro) · [官网](https://seehiong.github.io/md-editor-pro/) · 个人维护

**React Markdown 编辑器组件：分屏预览、LaTeX、可选 AI 辅助**

基于 React 18/TypeScript/Tailwind CSS 的 Markdown 编辑器，提供 CodeMirror 6 分屏实时预览、多文档标签页浏览器自动保存、通过 File System Access API 原生打开/保存本地 .md 文件、KaTeX 数学公式、Mermaid 图表、GitHub 风格 Markdown、导出独立 HTML 或打印 PDF，可安装为离线 PWA。AI 为可选功能（BYOK）：用用户自有 API key 接入 OpenRouter、OpenAI 或本地 Ollama，做改进、校对、摘要或续写。以 npm/源码方式集成到 React 应用，需 Node.js 18+。
