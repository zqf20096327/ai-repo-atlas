# signerlabs/ShipSwift

⭐ 3,283 · Swift · MIT · 推送 2026-11-12 · [GitHub](https://github.com/signerlabs/ShipSwift) · [官网](https://shipswift.app) · 组织维护 · 中文 README

**为 iOS 开发者提供 AI 编码代理可调用的 SwiftUI 组件库与技能包**

面向 iOS 开发的 SwiftUI 组件库，附带的 agent skills 与 MCP server 让编码代理按需获取组件源码与实现步骤。内容分四块：44 个动画组件（含 Metal shader 背景）、9 种图表、UI 组件，以及多文件模块（认证、相机、订阅付费墙、聊天等）。安装走 npm 安装技能包、连 MCP server、或直接复制文件进 Xcode 工程；另提供 Showcase App 预览全部组件。iOS 客户端代码 MIT 开源，Pro 技能（后端、合规模板等）为付费内容，仓库同时宣传定制开发服务。

## 能力要点

- 44 个动画组件含 Metal shader 程序化背景与视图特效
- SWModule 提供认证、相机、StoreKit 2 付费墙、聊天等多文件框架
- MCP server 提供三个工具：listSkills、getSkill、searchSkills
- 技能包可离线安装，AI 本地读取组件源码

## 适用场景

- 用 Claude Code/Cursor 等 AI 工具快速往 iOS 工程添加动画、图表组件
- 搭建带认证、订阅付费墙的 iOS 应用原型
- 在 Xcode 中按需复制自包含的 SwiftUI 组件文件
