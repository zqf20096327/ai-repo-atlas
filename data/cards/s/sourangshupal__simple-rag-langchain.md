# sourangshupal/simple-rag-langchain

⭐ 24 · Jupyter Notebook · 推送 2025-11-30 · [GitHub](https://github.com/sourangshupal/simple-rag-langchain) · 个人维护

**面向初/中级学习者的 LangChain RAG 七讲 Jupyter 课程**

基于 LangChain 1.0.5+ 的 RAG 动手课程，由 7 个递进式 Jupyter Notebook 组成（约 6 小时），覆盖 LCEL 基础、文档加载（PDF/CSV/JSON/HTML）、文本分割策略、OpenAI/Gemini 嵌入、FAISS/Chroma/InMemory 向量库、检索策略与完整 RAG 流水线。每个 Notebook 附练习，随附 4 个示例数据文件与 requirements.txt。运行需 Python 3.9-3.11 与 OpenAI API key（Gemini key 为可选），课程全程 API 成本估计 $0.50-1.00。
