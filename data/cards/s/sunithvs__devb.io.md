# sunithvs/devb.io

⭐ 354 · TypeScript · MIT · 推送 2026-06-16 · [GitHub](https://github.com/sunithvs/devb.io) · [官网](http://devb.io/) · 个人维护

**面向开发者的 AI 作品集生成器：从 GitHub 活动自动生成个人主页**

Web 平台，读取用户 GitHub 档案、项目与贡献记录，自动生成开发者作品集页面，并用 AI（经 Groq API）生成个人简介；支持动态追踪 GitHub 活动使作品集保持更新，设定一次后无需手动维护。技术栈为 NextJS 前端、FastAPI 后端、Redis 数据库。自部署需配置 GitHub API Token 与 Groq API Key 等环境变量，通过 pip 安装依赖并以 uvicorn 运行。
