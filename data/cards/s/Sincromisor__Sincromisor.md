# Sincromisor/Sincromisor

⭐ 25 · TypeScript · Apache-2.0 · 推送 2026-10-27 · [GitHub](https://github.com/Sincromisor/Sincromisor) · 组织维护 · 中文 README

**自托管 Web 服务基盘：浏览器中与 3D 角色语音对话/变声直播**

可在本地/自建服务器上全部运行的 Web 服务基盘：用户在浏览器中让 VRM 1.0 角色朗读自己的发言（シンクロモード，NeMo 约 4GB VRAM）或与角色对话（チャットモード，LLM 合计需 16GB 以上 VRAM）。提供语音识别固有名词词典、管理画面编辑角色话风、VictoriaLogs 日志记录与检索、多服务器分布式部署、OBS 浏览器源接入、360 度相机与 Looking Glass 画面，以及命令行语音识别/合成 CLI。服务端需 x86_64 Linux + NVIDIA GPU + CUDA 13 驱动（580 系以上），通过 Docker Compose 启动，首次自动构建镜像并下载模型。

## 能力要点

- 两种模式：发声转角色语音朗读 / 角色对话（LLM）
- 支持任意 VRM 1.0 模型替换角色，模型仅存浏览器缓存不上传服务器
- 全部组件可オンプレ（本地）运行，Docker Compose 一键启动并自动下载模型
- 含 OBS 接入、日志检索、分布式部署与语音 CLI

## 适用场景

- 用可爱 3D 角色做语音直播，把自己的话转成角色声音
- 在自家服务器上运行角色对话服务并在局域网多端使用
- 给语音识别添加名字、作品名等固有名词读音词典
