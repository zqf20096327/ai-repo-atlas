# simeonradivoev/electron-dam

⭐ 17 · TypeScript · 推送 2026-05-19 · [GitHub](https://github.com/simeonradivoev/electron-dam) · 个人维护

**面向游戏素材包的桌面数字资产管理器，带语义搜索**

基于 Electron + React + TypeScript 构建的本地数字资产管理（DAM）应用：以 bundle 为单位管理来自素材包的 3D 模型、音频、图片、视频与文本文本文件，提供多格式 3D 预览、音频可视化试听、HTML5 视频播放、标签、统计排序与导出。AI 相关功能为可选的 Ollama 元数据获取与生成，以及语义搜索。数据依赖文件系统与人类可读 JSON 数据库，便于迁移与外部存储。支持从 Humble Bundle 导入 bundle。

## 能力要点

- 多格式 3D 模型预览（obj/fbx/gltf/stl）与音频可视化试听

- 通过语义搜索发现符合需求的素材
