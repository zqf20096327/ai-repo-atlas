**面向开发者的 SAP BTP 代码式 AI Agent 开发教程（三套技术栈）**

SAP Developer Advocates 维护的 CodeJam 培训材料仓库：指导学员用 Python+LiteLLM 搭配 CrewAI 或 LangGraph，或 TypeScript+LangGraph+SAP Cloud SDK for AI 三种技术栈构建 AI Agent。内容覆盖自定义 agent 工具、多 Agent 系统、SAP Grounding 服务、SAP-RPT-1 模型使用，并练习部署到 SAP BTP（Cloud Foundry/Kyma）与集成 SAP Joule。课程期间由讲师提供 SAP BTP 子账号与开发环境，学员仅需带 Chromium 系浏览器的笔记本电脑；每套技术栈含 10 个递进练习。仓库采用 Apache 2.0 许可。
