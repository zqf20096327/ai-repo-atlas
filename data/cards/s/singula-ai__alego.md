**插件式架构的 AI agent 应用构建框架（agent harness）**

Singula AI 开源的 agent harness，为构建 AI agent 应用提供基础底座，采用 everything-is-a-plugin 架构，基于 Cordis（其设计见《A Programming Paradigm for Spatiotemporal Composability》）。项目是 DeepSeek Harness 的独立 fork，与 DeepSeek 无隶属关系。当前处于 developer preview 阶段，声明将有不兼容的破坏性变更，并要求运行前阅读安全须知。通过 npx 启动 Web UI，或从源码安装构建，支持插件仓库以 alego-plugin 话题标记便于发现。
