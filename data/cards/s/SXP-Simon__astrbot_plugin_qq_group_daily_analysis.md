**AstrBot 群聊分析插件：LLM 总结群聊并生成报告海报与连环漫画**

作为 AstrBot 宿主的插件运行，自动定时或手动分析群聊消息，用 LLM 提取话题、金句、用户画像并生成图片/HTML 报告，还可将分析结果改编为 14 种内置风格的连环漫画。支持 QQ 官方机器人、Telegram、Discord、OneBot v11、Satori 平台；内嵌 WebUI 管理面板，提供任务可观测、历史报告重绘、Token 消耗看板、模型熔断与多级回退机制。分析依赖宿主配置的 LLM Provider，漫画生图需自行配置服务商 API Key。

## 能力要点

- 定时/手动/增量三种分析模式与黑白名单继承判定
- 漫画分镜支持 14 种内置风格及自定义提示词，多绘图供应商条目按优先级切换
- WebUI 提供运行链路、熔断状态、Token 消耗与数据审计
- LLM 原生函数调用工具，支持自然语言只读检索历史报告

## 适用场景

- 群主想在群里自动产出每日聊天总结与活跃度报告
- 给机器人社区生成趣味群聊连环漫画活跃气氛
- 管理员想查看分析的 Token 消耗与运行日志做运维
