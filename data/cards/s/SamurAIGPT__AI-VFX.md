**面向创作者的 AI 视频特效生成 Web 应用**

基于 Next.js 15 的 Web 应用，将静态图片转换为带电影级运镜与视觉特效的视频：提供 50+ 种运镜、30+ 种特效及 AI 变换效果（合计 80+ 效果），支持多种宽高比、时长与分辨率配置，生成通常需 1-3 分钟。视频生成能力依赖 MuAPI 云端 API（需 API key），本产品不内置模型，仅做前端交互与 API 代理。安装方式为 git clone 源码后 npm 运行，支持 Vercel 一键部署。
