# skillhub-club/skillhub-desktop

⭐ 599 · TypeScript · 推送 2026-03-07 · [GitHub](https://github.com/skillhub-club/skillhub-desktop) · 组织维护 · 中文 README

**管理 AI 编程工具技能的桌面应用：浏览、安装与多工具同步**

基于 Tauri v2（Rust 后端 + React 前端）的桌面应用，用于管理 Claude Code、Cursor、OpenCode、Windsurf 等 10 种 AI 编程工具的技能：从 SkillHub 目录浏览搜索技能、一键安装到多个工具、在工具间同步、组织技能集合，并提供 AI 辅助的技能生成与文本增强（扩展/简化/改写/翻译）。界面支持英文与中文。需通过 npm + Tauri CLI 从源码构建，依赖 SkillHub.club 平台 API。
