# SSShooter/ebook-to-mindmap

⭐ 1,436 · TypeScript · MIT · 推送 2026-11-10 · [GitHub](https://github.com/SSShooter/ebook-to-mindmap) · [官网](https://app.mind-elixir.com/ebook-to-mindmap) · 个人维护 · 中文 README

**面向读者的电子书 AI 总结工具：EPUB/PDF 转思维导图**

将 EPUB 与 PDF 电子书解析为章节结构后调用 AI 生成三种输出：文字总结（章节总结、章节关联、全书总结）、章节思维导图与整书思维导图。支持 BYOK 模式由浏览器直连 AI 供应商，或登录 Mind Elixir 账号使用托管模型；可自定义提示词、智能检测章节、按章节分组合并处理，AI 结果自动缓存以支持中断续跑与离线查看。网页版与 Tauri 桌面端共用一套代码，导出的思维导图可导入 Mind Elixir 编辑器二次编辑。

## 能力要点

- EPUB/PDF 解析并生成章节/整书思维导图与文字总结
- BYOK 模式浏览器直连 Google/OpenAI，不经第三方代理
- 自定义提示词可完全覆盖系统默认（文字总结模式）
- AI 结果缓存支持中断续跑与离线查看

## 适用场景

- 把教材或工具书转成结构化思维导图便于复习
- 为小说生成章节总结与全书脉络分析
- 用自有 API Key 批量拆书并导出脑图二次编辑
