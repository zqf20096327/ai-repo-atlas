# SDNNetSim/FUSION

⭐ 16 · Python · MIT · 推送 2026-10-29 · [GitHub](https://github.com/SDNNetSim/FUSION) · 组织维护

**面向科研者的 SD-EON 光网络离散事件仿真框架，支持强化学习集成**

FUSION 是一个开源的软件定义弹性光网络（SD-EON）离散事件仿真框架，供研究人员与工程师对光网络进行建模、分析与优化，内置强化学习集成支持和网络生存性实验。要求 Python 3.11.X，支持 macOS（需手动编译）、Ubuntu 20.04+、Fedora 37+ 与 Windows 11；提供自动安装脚本、Python 打包安装与 requirements 文件三种安装方式，依赖 PyTorch 2.2.2 与 PyTorch Geometric，官方提示 legacy 方式可能在 PyTorch Geometric 上失败。项目配套 IEEE ANTS 2024 论文与在线文档。
