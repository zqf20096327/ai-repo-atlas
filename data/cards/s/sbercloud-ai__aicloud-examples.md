⭐ 38 · Jupyter Notebook · MIT · 推送 2025-11-18 · [GitHub](https://github.com/sbercloud-ai/aicloud-examples) · [官网](https://cloud.ru/mlspace) · 组织维护

**Cloud.ru Distributed Train 平台的分布式 ML 示例与教程集**

面向使用 Cloud.ru AICloud Distributed Train 平台的用户，提供从入门到进阶的机器学习示例：在 Jupyter Server 直连 GPU 训练、通过 client-lib 在 PyTorch/TensorFlow 2/CPU 上训练、Horovod 与 PyTorch Distributed 分布式训练、Hugging Face LLM 的 LoRA/PEFT 与 DDP 训练、PyTorch Lightning 图像分类及 Elastic Learning 断点续训。另含 S3 数据上传下载、Rapids GPU 数据处理、Spark 预处理笔记本及 Public API v2 交互示例。以笔记本与代码示例形式提供。
