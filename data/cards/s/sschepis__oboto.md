**运行于本机与云端的多 agent 个人 AI 助理**

基于 Node.js 的桌面/CLI 个人 AI 助理：多并行会话与后台任务的多 agent 架构，支持 OpenAI、Anthropic Claude、Gemini、Vertex AI、LM Studio、WebLLM 等多模型接入与按任务类型路由；包含 30 个内置插件（浏览器自动化、文档解析、语义搜索、TTS、工作流等）、MCP 与 OpenClaw 集成、Chrome 扩展与 Electron 托盘应用；具备“意识处理器”（事实推理、人格管理）与按工作区的本地 HTTP 内容服务器。提供 npm 安装与 macOS DMG/Windows 安装包，也可作为库嵌入。
