# SupratimRK/Ai-rewrite

⭐ 22 · JavaScript · MIT · 推送 2026-09-02 · [GitHub](https://github.com/SupratimRK/Ai-rewrite) · [官网](https://smrk.in) · 个人维护

**Chrome 扩展：在任意网页输入框中右键或一键 AI 改写文本**

面向普通网页用户的 Chrome 扩展，在任意网页文本框与富文本编辑器内提供 AI 改写：右键菜单选 15 种写作模式（Retone、Humanize、Professional、Grammar 等）、输入框内一键 AI 气泡、行内预览确认工具栏、温度滑杆（0.0–2.0）与自定义模式。兼容 WhatsApp Web、Reddit、ChatGPT、Notion 等站点。通过用户自备 API key 直接从浏览器请求 OpenAI 或 OpenAI 兼容接口，内置 OpenAI、OpenRouter、Groq、DeepSeek、Gemini、Ollama、LM Studio 等一键预设；API key 存于 chrome.storage.sync。安装方式为开发者模式加载解压目录，尚未上架 Chrome Web Store。

## 能力要点

- 15 种内置改写模式并支持自定义提示词模式
- 右键菜单、输入框一键气泡与快捷键三种触发方式
- 多 Provider 一键预设，支持 OpenAI 兼容接口及 Ollama/LM Studio 本地模型
- 兼容 WhatsApp Web、Reddit、ChatGPT、Notion 等富文本场景，含撤销与用量统计

## 适用场景

- 写邮件或文档时快速调整语气（专业/礼貌/随意）
- 在 WhatsApp Web、Reddit 等网页应用里直接改写消息
- 用本地 Ollama/LM Studio 模型做免费私密的文本改写
