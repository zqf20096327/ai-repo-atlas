# Sylinko/Everywhere

⭐ 6,368 · C# · AGPL-3.0 · 推送 2026-11-25 · [GitHub](https://github.com/Sylinko/Everywhere) · [官网](https://everywhere.sylinko.com) · 组织维护 · 中文 README

**屏幕感知桌面 AI 助手：就地调用 LLM 处理当前上下文**

基于 .NET/Avalonia 的桌面 AI 助手，通过底层辅助功能 API 与 UI 自动化提取当前屏幕与活动应用的结构化上下文，用户按快捷键即可在原地对可见内容提问、摘要、翻译、改写或核实信息。支持多家 LLM 云服务、Ollama 本地部署与自定义 API 端点，Agent 系统提供浏览器、本地文件系统、终端脚本、MCP 工具与子 Agent 调度。提供 Windows/macOS 安装包，Linux 由社区维护。

- 屏幕感知：无需截图/复制/切换应用，快捷键就地获取 AI 帮助

- 对可疑信息做快速检索核实
