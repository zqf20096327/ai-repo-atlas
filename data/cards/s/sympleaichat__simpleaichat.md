# sympleaichat/simpleaichat

⭐ 23 · Dart · MIT · 推送 2026-06-02 · [GitHub](https://github.com/sympleaichat/simpleaichat) · [官网](https://github.com/sympleaichat) · 个人维护

**Windows 本地优先的多模型 AI 聊天客户端，支持六大 LLM API**

面向 Windows 用户的本地优先 AI 聊天桌面客户端（原生 .exe，非 Electron）：通过用户自备的 API key 接入 Claude、ChatGPT、Gemini、Grok、DeepSeek、Mistral。默认将 LLM 视为无状态引擎，消息历史、记忆与个性化数据全部存储在本地并可自由编辑、删除；支持多线程对话、外部文件自定义系统提示、Gemini API 附件上传。API key 仅保存在设备上，不从本地上传。作为独立非官方客户端，与各家提供商无附属关系。

- 支持 Claude/ChatGPT/Gemini/Grok/DeepSeek/Mistral 六种后端
