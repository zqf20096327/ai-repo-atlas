# shanliuling/dsh-image-gen

⭐ 1,772 · TypeScript · Apache-2.0 · 推送 2026-11-24 · [GitHub](https://github.com/shanliuling/dsh-image-gen) · [官网](https://github.com/shanliuling/dsh-image-gen#readme) · 个人维护 · 中文 README

**DeepSeek Harness 对话内批量生图/改图的插件**

以插件形式运行于 DeepSeek Harness 的图像创作工具：在对话中由 Agent 规划 Prompt 并批量生成图片（单次最多 10 张）、读取画布草图与圈选做局部编辑、按角色一致性做图生图、生成 GIF 与 SVG 输出。内置 500+ Prompt 灵感库与本地缓存，提供 Studio 参数工作台、多模型对比与图库管理。依赖宿主 DeepSeek Harness 与 Node.js ^22.19.0/>=24.0.0；通过 pnpm 安装插件，Provider 需自备 API Key 或订阅登录；tldraw 画布在 HTTPS 部署需另行填写 License Key。

## 能力要点

- 对话批量生图：Agent 规划一组 Prompt 逐张生成，单次最多 10 张
- AI 画布读取草图与圈选，支持局部编辑与草图转成图
- 内置 500+ Prompt 灵感库，Agent 检索后自动套用模板
- 支持本地 ComfyUI 多命名工作流与多模型并发对比

## 适用场景

- 给文章或小红书笔记一键配一组风格统一的插图
- 在画布上圈出图片局部并要求替换
- 同一 Prompt 用多个模型出图对比挑选
- 用本地 ComfyUI 工作流在对话里生图
