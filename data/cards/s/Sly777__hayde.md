# Sly777/hayde

⭐ 26 · TypeScript · GPL-3.0 · 推送 2026-02-15 · [GitHub](https://github.com/Sly777/hayde) · [官网](https://docs.haydejs.com) · 个人维护

**面向 React 开发者的 CLI 组件代码生成器，支持 AI 生成**

基于 Node/TypeScript 的命令行工具，通过 npx hayde 或 .hayde.json 配置生成 React 组件，支持 Chakra UI、Material UI、Storybook、Builder.io、Emmet 等库，并可接入 OpenAI（GPT-3.5/GPT-4/GPT-4 Vision）与 Ollama 用 AI 生成组件。提供配置 Profile、NPM 脚本前后钩子、自动导入组件及基于 Handlebars 的自定义插件机制；无配置即可使用，可用于 create-react-app、Next.js、Astro 等项目。GPL-3.0 许可。

## 能力要点

- npx 一键运行，无需预先安装
- 支持 Chakra UI / Material UI / Storybook / Builder.io 等组件库
- AI 集成：OpenAI（GPT-3.5/GPT-4/GPT-4 Vision）与 Ollama
