**地震学深度学习 Python 包：检测地震、估震级、拾取相位**

面向地震学研究者与科研用户的开源 Python 包，整合多个已发表的深度学习模型（CREIME、DynaPicker、PolarCAP）及升级版本（如 CREIME_RT），完成地震检测、震级估计、地震相位拾取与极性识别等任务。提供 API 简化与 STEAD、INSTANCE 基准数据集的集成；v1.2.0 支持单台站分析，并可选用地震台网数据库做多台站结果分析。安装方式为 git clone 后 pip install，文档以 PDF 与示例代码形式提供。

## 能力要点

- 整合 CREIME、DynaPicker、PolarCAP 等已发表模型
- 覆盖地震检测、震级估计、相位拾取、极性识别四类任务
