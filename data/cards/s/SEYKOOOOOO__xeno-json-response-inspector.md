**Chrome 扩展：捕获并检视浏览器 HTTP/JSON 流量用于调试与安全测试**

面向工程师、QA 与协议研究者的 Chrome 扩展，提供实时请求/响应捕获与过滤、嵌套 JSON 结构化浏览与路径复制、请求重放与参数变体对比、可组合规则集、会话存档、Header 解码面板与 WebSocket 帧查看。捕获数据仅保存在浏览器本地，无遥测外发。README 声明为开发与研究工具，仅限在拥有或获得授权的系统上使用；采用 MIT 许可。

## 能力要点

- 实时请求捕获与按方法/状态/域/MIME/自定义签名过滤
- 请求重放引擎：修改 header/查询串/请求体后对比服务端行为
- 会话保险库：保存并恢复整个捕获会话
- 捕获数据仅存于浏览器本地，不向外部端点发送遥测

## 适用场景

- 调试 API 时追踪认证流程与未文档化端点
- 对比线上响应与预期 schema 以发现契约漂移
- 审查第三方脚本实际传输的数据内容
- 逐帧观察 WebSocket 通道的收发过程
