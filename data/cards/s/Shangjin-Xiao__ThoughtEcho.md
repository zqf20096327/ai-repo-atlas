# Shangjin-Xiao/ThoughtEcho

⭐ 49 · Dart · MIT · 推送 2026-10-29 · [GitHub](https://github.com/Shangjin-Xiao/ThoughtEcho) · [官网](https://note.shangjinyun.cn) · 个人维护 · 中文 README

**本地优先的跨平台 AI 灵感笔记与摘录应用**

基于 Flutter/Dart 的跨平台（Windows/Android/iOS）灵感笔记与阅读摘录应用，数据以 SQLite 与 MMKV 本地存储，支持生物识别保护隐藏笔记。AI 功能以 OpenAI 兼容协议接入多提供商（OpenAI、DeepSeek、Ollama、Gemini、Claude、OpenRouter、SiliconFlow 等），提供 Thoughter agent（含跨会话长期记忆）、周期性洞察报告、AI 卡片生成。同步走 LocalSend 局域网直传与 WebDAV 云备份。Windows 经 Microsoft Store 分发，Android 从 GitHub Releases 下载 APK。
