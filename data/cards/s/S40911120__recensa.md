# S40911120/recensa

⭐ 73 · TypeScript · MIT · 推送 2026-10-11 · [GitHub](https://github.com/S40911120/recensa) · [官网](https://hub.docker.com/r/s40911120/recensa) · 个人维护

**自托管 Web 查看器：读取、搜索、回放、审计 Claude Code 会话记录**

面向 Claude Code 用户的本地会话记录阅读器。Claude Code 将每次会话以 JSONL 写入 ~/.claude/projects/，Recensa 将其索引进本地 SQLite（FTS5 全文检索、支持 CJK），在 localhost:7788 提供三栏阅读界面。功能包括：折叠工具调用与思考块的对话视图、按文件渲染 Edit diff、每会话的工具/文件/模型/token 与估算费用统计、多 agent 名册与子会话深链、压缩(compaction)点标记与压缩前对话重建、置顶/标签/备注。读取不修改原文件，无账号与遥测；单机单用户设计，明确不支持云端与多主机聚合。通过 Docker 预构建镜像或源码 Compose 部署。

## 能力要点

- SQLite FTS5 全文检索全部历史会话（CJK-aware）
- Edit 渲染为逐文件 diff，会话级工具/文件/token/费用统计
- 多 agent 运行审计：名册、跳转调用点、子会话深链
- 标记压缩点并跨 fork/resume 链重建压缩前完整对话
- 只读设计：索引为可重建缓存，用户标注存于独立数据库

## 适用场景

- 回查此前会话中如何解决某个 bug 或 agent 实际改了什么
- 审计长时间 agent 运行的工具调用、文件变更与费用
- 检索并复盘某个走入歧途的提示词会话
- 在多 agent 运行中跟踪各子 agent 的行为与产出
