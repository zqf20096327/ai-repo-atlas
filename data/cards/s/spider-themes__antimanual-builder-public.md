**WordPress 可视化页面构建插件，AI 辅助生成与迁移页面**

WordPress 插件，作为主 Antimanual 插件的附加组件运行：提供全屏 React 编辑器，编辑原生 WordPress 页面，支持自然语言提示生成/修改布局、拖拽手动编辑、可复用组件库、AI 或直接两种方式的页面迁移、单个 HTML 文件与 ZIP 项目导入。AI 提供商、模型与 API key 设置不独立管理，运行时从 Antimanual 插件读取（支持 OpenAI 与 Google Gemini）；手动编辑、直接迁移和 HTML 导入不需要 AI key，但 Antimanual 插件必须处于激活状态。

## 能力要点

- 自然语言提示生成/修改页面布局的 AI 聊天编辑器
- AI 迁移与直接迁移两种页面转换方式，可替换原件或生成草稿副本
- HTML 单文件与 ZIP 项目导入
- 可复用组件库与响应式预览（桌面/平板/大小手机）

## 适用场景

- 用自然语言生成或改版 WordPress 页面，再手动微调
- 把现有 WordPress 页面迁移为 Builder 页面进行重新设计
- 从 HTML 文件或 ZIP 项目批量导入并生成页面
