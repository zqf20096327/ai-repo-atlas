# Sunona-AI-labs/sunona

⭐ 16 · Python · NOASSERTION · 推送 2026-10-30 · [GitHub](https://github.com/Sunona-AI-labs/sunona) · [官网](https://sunona-twilio.onrender.com) · 组织维护

**语音 AI 平台：编排 STT+LLM+TTS 构建电话/语音助手**

Python 语音 AI 平台，将实时语音转写、LLM 与语音合成串联为对话流水线，提供 7 类专用 Agent（上下文/抽取/流程图/知识库/Webhook/摘要/自适应）、通用知识库构建器（网站/PDF/DOCX 等）与智能转人工机制。接入 11 家 STT、11 家 TTS、经 LiteLLM 的 100+ LLM 及 7 家电话运营商（Twilio/Plivo 等），支持 WebRTC 双向浏览器通话、20+ 语言与 30+ 语言脏话检测。内置按量计费、多租户与 Redis AgentStore。面向开发者，需配置外部 API key。
