⭐ 16 · Kotlin · GPL-3.0 · 推送 2026-10-13 · [GitHub](https://github.com/shibry88-netizen/TalkTact) · [官网](https://modules.lsposed.org/module/io.github.shibry88_netizen.talktact/) · 个人维护 · 中文 README

**微信 Xposed 模块：聊天页悬浮 LLM 候选回复卡片，只填输入框不发送**

LSPosed/Xposed 模块，注入微信聊天页读取最近消息，调用 OpenAI 兼容接口生成 3 条不同策略候选回复并标出最推荐与理由，点选即填入输入框（不自动发送）。支持多套提示词 skill 导入、按联系人的角色关系档案、直通/模型分级双路模式。隐私机制包括只绑 127.0.0.1 的本地代理（API Key 不出 App 进程）、会话白名单 fail-closed、ML Kit 本机离线 OCR（不上传不落盘）。限制：仅单聊可靠、依赖特定微信版本（8.0.78 验证）、修改微信客户端有风控风险。需 Android 12+ 与 libxposed API 102 框架。

## 能力要点

- 3 条策略候选回复 + 最推荐标注 + 单条改写
- 本地代理使 API Key 只留在 App 进程，微信进程仅见回环地址
- ML Kit 中文离线 OCR，不上传不联网不落盘
- 会话白名单 fail-closed：未勾选会话不读内容不调接口

## 适用场景

- 聊天时快速获得多条风格不同的候选回复并填入输入框
- 通过本地代理在不把 Key 交给微信进程的前提下使用 LLM 接口
- 用离线 OCR 把对方截图长图文转成文字送给模型
