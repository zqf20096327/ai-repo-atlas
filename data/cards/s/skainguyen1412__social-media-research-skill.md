**面向 AI 助手的社媒舆情分析技能：实时抓取 Reddit/X 讨论**

以 npm CLI（sc-research）与 agent 技能形式提供的社交媒体与公众舆论分析工具：抓取 Reddit 与 X 的实时讨论，生成排名、情感、趋势、争议、新兴话题五类结构化 JSON 结果，附本地可视化仪表盘。需至少一个 API key（OPENAI_API_KEY 用于 Reddit，XAI_API_KEY 用于 X），要求 Node.js>=20。可安装为 Claude Code、Cursor、Windsurf 等助手的技能，也可直接用 CLI 运行。
