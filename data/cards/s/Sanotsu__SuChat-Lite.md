# Sanotsu/SuChat-Lite

⭐ 31 · Dart · 推送 2026-10-14 · [GitHub](https://github.com/Sanotsu/SuChat-Lite) · 个人维护 · 中文 README

**个人跨平台 AI 聊天与生活工具集成应用**

Flutter 开发的跨平台（Windows/Linux/Android）应用，核心为接入云端大模型 HTTP API 的 AI 聊天：预设阿里、百度、腾讯、智谱、DeepSeek 等多个 OpenAI 兼容平台，也支持手动填写请求地址、模型名与 API Key。附加 AI 功能包括语音合成、图片/视频生成、录音识别、快速翻译，以及训练助手、饮食日记等轻度 AI 扩展，并聚合新闻热榜、Bangumi、TMDB 等第三方 API 的生活娱乐功能。桌面端与移动端部分功能适配不一致，密钥通过本地存储缓存。
