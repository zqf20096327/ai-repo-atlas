**自托管的职业档案/简历创作工作室，多语言多格式导出**

CraftMyProfile 是一个可自托管的职业档案精修环境：以 YAML 结构化数据描述角色、技能与经历，经核心引擎解析、组合器生成渲染树，输出 HTML、PDF 与纯文本；支持版本快照与 diff、12 种语言区域包（含 RTL）、WCAG 2.2 AA 无障碍目标及 CLI 与 API 访问方式。面向独立职业人士、职业教练、技术编辑及需要统一档案格式的组织。协助层为规则式结构问题分诊与建议，非 AI 模型推理；README 未给出具体安装命令，仅描述浏览器/终端/API 三种使用入口。

- YAML 结构化档案数据，经渲染树导出 JSON/YAML/PDF
