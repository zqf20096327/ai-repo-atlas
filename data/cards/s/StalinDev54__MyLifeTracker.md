**面向个人的 24/7 数字生活监控与 AI 数字生命陪伴系统**

由 Vue3/Express/Socket.io 构建的自我量化与 AI 陪伴应用：通过 Android 自动化应用（AutoTask/Tasker）上传手机活动、锁屏与电池状态，TypeScript 服务读取网易云音乐客户端本地 SQLite 数据库同步播放状态，并集成行者运动 API、B站与百度统计 API 聚合运动和网站数据。AI 部分基于小智 AI 提供 24 小时语音通话、主动播报与文本对话（chat.jiclub.site 暂未开源）。支持监控他人设备（需知情同意）。当前数据以 JSON 文件存储，一键部署方案（XODN）处于内测开发中，macOS/iOS 客户端在开发或规划中。

## 能力要点

- Android（AutoTask/Tasker）与 Windows 端活动数据实时采集上报
- TypeScript 服务直接读取网易云音乐客户端本地 SQLite 数据库同步播放状态
- 集成行者运动、B站、百度统计等第三方 API 聚合数据

- 在对方知情同意下实时了解伴侣、家人的日常活动状态
- 监控长辈活动状态，异常行为及时预警
