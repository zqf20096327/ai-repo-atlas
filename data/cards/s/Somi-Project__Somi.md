# Somi-Project/Somi

⭐ 27 · Python · 推送 2026-03-20 · [GitHub](https://github.com/Somi-Project/Somi) · [官网](https://x.com/SomiProject) · 组织维护

**本地自托管的桌面 AI agent 工作站：聊天/记忆/编码/语音/OCR**

面向日常用户与开发者的本地优先、自托管 AI agent 框架，提供 PySide6 桌面工作台（控制室、编码/研究工作室、语音控制、节点管理）。功能覆盖本地聊天与持久记忆、编码工作区与受保护执行、网页/文档研究与证据图导出、OCR 结构化抽取、本地 TTS/STT、工具/技能系统与自动化运行时。通过本地 Ollama 运行模型，审批感知执行与审计日志，面向消费级硬件。安装方式为 git clone 源码 + pip 依赖 + Ollama 拉取模型。主要在 Windows 上开发，架构面向三平台。
