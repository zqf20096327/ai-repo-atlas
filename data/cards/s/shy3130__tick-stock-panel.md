**自托管 A 股量化研究工作台：策略+监控+回测+AI 助手**

面向本地量化学习与研究的自托管工作台，覆盖看板、因子与策略筛选、回测验证、盘中监控与模拟盘。内置 Tivelo Data 数据引擎与 Tivelo Backtest 回测引擎（后者按 T+1、涨跌停、费用约束模拟撮合），计算内核基于 Polars 的 Rust 列式引擎。日 K、分钟 K、实时行情可分别配置第三方数据源，页面、策略、插件通过 SDK 与资源包扩展。工作台 AI 助手可取数、起草策略与运行回测，并经 Open API/MCP 供外部脚本与 AI 客户端调用。Docker、桌面安装包与源码三种运行方式；Tivelo 组件采用 PolyForm 非商业许可。

## 能力要点

- 日 K/分钟 K/实时行情/除权因子可分别选择数据源，扩展表支持定时拉取与历史回补
- Tivelo Backtest 按 A 股 T+1、涨跌停和费用约束模拟撮合，支持滚动样本外验证
- AI 助手在面板内取数、起草策略与运行回测，Open API 与 MCP 按 Token 权限开放
- Page Pack SDK 与插槽机制支持页面、策略、图表指标及后端插件扩展

## 适用场景

- 在本地自建 A 股策略并做参数筛选与滚动样本外回测
- 设置价格、信号和策略告警，把策略绑定模拟账户跟踪成交
- 把日 K 与复权因子固定为快照，供策略复跑和归档研究
- 通过 MCP 让本机 AI 客户端按权限查询行情和提交回测
