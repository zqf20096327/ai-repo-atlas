**自托管 A 股量化工作台：策略、监控、回测与 AI 助手一体化**

面向本地量化学习与研究的工作台，功能覆盖数据源切换、因子与策略筛选、回测验证、盘中监控与模拟盘。内置 AI 助手可查询本地行情、起草策略、运行回测，并通过 Open API 与 MCP 供外部脚本和 AI 客户端按权限调用。数据经 Tivelo Data 引擎采集与版本化，回测由 Tivelo Backtest 按 A 股 T+1、涨跌停和费用约束模拟。工作台采用 MIT 许可，Tivelo 组件按 PolyForm 非商业许可授权。

## 能力要点

- 日 K、分钟 K、实时行情与除权因子可分别切换数据源
- AI 助手在面板内取数、起草策略和运行回测，工具调用记录可核对
- Open API 与 MCP 按 Token 权限开放行情、策略与回测接口
- 回测按 A 股 T+1、涨跌停与交易费用约束模拟成交

## 适用场景

- 在本地搭建 A 股策略筛选、回测与盘中监控工作流
- 通过 AI 助手查询行情并起草策略
- 把工作台接入自己的脚本或 AI 客户端做策略研究
- 用快照数据固定行情做策略复跑与归档
