# sagiyaacoby/TeamHero

⭐ 38 · JavaScript · MIT · 推送 2026-04-03 · [GitHub](https://github.com/sagiyaacoby/TeamHero) · 个人维护

**给 Claude Code 开发者的多 Agent 编排与项目管理平台**

自托管的 AI agent 编排平台，以项目管理方式管理 agent 团队：提供 Web 仪表盘、与编排 agent 对话的 Command Center、带计划/版本/审批/交付物跟踪的任务系统、跨会话持久记忆、知识库、可选技能集成（浏览器自动化、GitHub）及基于文件范围声明的冲突预防。面向使用 Claude Code 并希望对 agent 施加结构化管理的开发者，需熟悉 CLI 与 Node.js。依赖 Node.js 18+ 与 Claude CLI 作为 agent 的 AI 后端，MIT 许可，由个人开发者开源发布。

## 能力要点

- 任务全生命周期管理（计划、版本、审批、交付物跟踪）
- 每个 agent 具备跨会话的持久短期与长期记忆
- 文件范围声明防止多 agent 相互覆盖
- Web 仪表盘与集成终端 Command Center

## 适用场景

- 多个 agent 协作同一项目时做计划与交付物跟踪
- 通过仪表盘统一查看和管理 agent 团队状态
- 将 agent 交付成果沉淀为可检索的知识库
