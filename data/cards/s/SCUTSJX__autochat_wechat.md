# SCUTSJX/autochat_wechat

⭐ 4 · Python · MIT · 推送 2026-10-19 · [GitHub](https://github.com/SCUTSJX/autochat_wechat) · 个人维护 · 中文 README

**Linux 桌面微信 AI 自动回复机器人：多窗口上下文回复与识图**

面向 Ubuntu 图形桌面的微信自动回复工具，通过 Frida 接收运行中微信的新消息，经 AT-SPI 识别聊天控件、X11 虚拟光标完成发送。支持多会话独立窗口、上下文回复、窗口截图识图、表情包回复与群聊 @ 策略；文字与图片接口可分别配置兼容 Chat Completions 的模型地址、模型与密钥。仅适配已实测的 Ubuntu 20.04.6 与 Linux 微信 4.1.13.26 构建（SHA256 指纹核对），Xorg 会话下运行，README 标注存在账号封禁风险。

## 能力要点

- Frida 挂接 + AT-SPI 控件识别 + X11 虚拟光标发送
- 多会话独立窗口各自维护上下文，支持引用提问与截图识图
- 文字与图片识别接口可分别配置不同服务商、模型与密钥
- 按会话配置表情包分组库与发送间隔

## 适用场景

- 在 Ubuntu 桌面为微信好友或群聊生成上下文相关的自动回复
- 通过引用消息让识图模型描述或评价收到的图片、链接卡片
- 为不同聊天配置不同人设提示词与表情包策略
