# ShivaBhattacharjee/WasteEasy

⭐ 27 · TypeScript · NOASSERTION · 推送 2026-01-31 · [GitHub](https://github.com/ShivaBhattacharjee/WasteEasy) · [官网](https://wasteeasy.theshiva.xyz/) · 个人维护

**垃圾分类与处置应用：拍照分类垃圾并奖励积分/优惠券**

Envision 黑客松开发的垃圾管理 Web 应用：用户通过应用对垃圾进行分类投放，系统借助 Gemini（Vision）进行图像垃圾分类，鼓励正确分类，用户使用应用投放垃圾可获得积分或优惠券。技术栈为 Next.js 14、Bun、TailwindCSS、MongoDB，集成 Google Maps 与 EmailJs。本地运行需先安装 Bun，配置 .env 中的 GoogleMaps/Gemini API key 等字段后以 bun dev 启动，可部署到 Vercel/Netlify/Render。采用 Apache 2.0 许可。
