**SAP HANA 预测与机器学习场景的示例代码集（教学用）**

SAP 官方提供的教学性示例代码仓库，覆盖 SAP HANA 预测分析与机器学习场景：包含 Predictive Analysis Library (PAL) 的 SQL 示例、完整的设计时 ML scenario 应用内容，以及 HANA-ML Python Notebook 示例。运行示例需要带 AFL 组件（含 PAL）的 SAP HANA 数据库环境，部分示例文件会标注额外要求。示例文件本身无需安装，下载后在 SQL 控制台或相应编辑器中打开使用。面向使用 SAP HANA 的开发者和数据科学家。
