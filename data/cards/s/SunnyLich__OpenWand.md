# SunnyLich/OpenWand

⭐ 15 · Python · MIT · 推送 2026-10-18 · [GitHub](https://github.com/SunnyLich/OpenWand) · [官网](https://sunnylich.github.io/OpenWand/) · 个人维护 · 中文 README

**桌面端 AI 协作工具：快捷键唤起，自动取上下文问答**

跨平台（Windows/macOS/Linux）桌面覆盖层应用，通过全局热键唤起，自动收集选中文本、浏览器/应用上下文或屏幕截图区域，配合预设或自定义 prompt 发送给用户自选的模型（云厂商、本地模型或任意 OpenAI 兼容服务），以气泡流式显示回答。支持就地改写并回贴、语音输入输出、本地可选记忆、隐私脱敏提示。可通过 Codex CLI 与 Claude Agent 运行 agent，支持插件与 MCP 扩展。提供打包版本下载，亦可从 Python 3.12 源码运行。

## 能力要点

- 热键唤起 + 自动上下文收集（选中文本/浏览器/应用/屏幕截图区域）
- 支持多种云厂商、本地模型及任意 OpenAI 兼容服务，自带 20+ 免费试用 API 源
- 就地改写选中文本并回贴；语音输入（F9）与听写（F8）、TTS 朗读
- 可通过 Codex CLI 与 Claude Agent 运行 agent；插件与 MCP 客户端/服务端扩展

## 适用场景

- 工作中不切窗口，用快捷键对当前内容提问或改写
- 对屏幕指定区域截图发给视觉模型提问
- 口述 prompt 并语音听取回答
- 通过 Agent Team 委派多角色的较长工作区任务
