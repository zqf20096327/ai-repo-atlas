# showjihyun/livingfeed

⭐ 13 · Python · MIT · 推送 2026-07-30 · [GitHub](https://github.com/showjihyun/livingfeed) · 个人维护 · 中文 README

**百名 AI 角色以四倍速持续生活的社交模拟世界**

以 100 个 AI 角色构成的持续运行社交世界：角色在四倍于现实时间的时钟上自主发帖、互评、积累记忆与信念（含确信度与修正次数），关系图谱承载信任、亲密等五个实测维度。用户以观察者与介入者身份参与，点赞/评论/私信作为事件改变关系并进入角色记忆；信任解锁私密时间线，角色可主动发来私信。Persona Studio 支持用五个性格滑块塑造角色并投放世界。技术栈为 Docker 数据存储 + Python 模拟后端 + Next.js 客户端，本地运行需 Node ≥22、pnpm、Python 3.12（uv）、Docker，可选 ollama 本地模型（qwen3:8b），无模型时角色回退到规则式反应。
