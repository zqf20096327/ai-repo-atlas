# 6figr-com/jobgpt-mcp-server

⭐ 26 · TypeScript · MIT · 推送 2026-10-26 · [GitHub](https://github.com/6figr-com/jobgpt-mcp-server) · [官网](https://6figr.com/jobgpt-ai) · 组织维护

**连接 AI 助手与求职平台的 MCP 服务器：搜索、自动投递、简历生成**

由 6figr 维护的 JobGPT 平台官方 MCP 服务器，将 Claude、Cursor、Windsurf、Cline、ChatGPT 等 MCP 兼容工具接入 JobGPT 求职平台，提供 34 个工具覆盖职位搜索、职位导入（LinkedIn/Greenhouse/Lever/Workday 等 URL）、自动投递、AI 定制简历生成与匹配评分、申请追踪、招聘者/内推人查找与外联邮件。支持浏览器 OAuth 登录或 API key 两种接入方式，也可通过 Node.js 18+ 本地运行。部分操作（自动投递、简历生成）消耗平台积分。

## 能力要点

- 34 个工具覆盖职位搜索、申请管理、简历、外联
- 支持从 LinkedIn/Greenhouse/Lever/Workday 等 URL 导入职位
- 浏览器 OAuth 登录接入，无需手动配置 API key（部分客户端）
- 支持 Claude Desktop/Code、Codex CLI、ChatGPT、Cursor、Windsurf、Cline、Continue 等客户端

## 适用场景

- 在 AI 助手中用自然语言搜索并筛选职位
- 让 AI 助手自动投递职位并跟踪申请状态
- 为特定职位生成定制简历并计算匹配分
