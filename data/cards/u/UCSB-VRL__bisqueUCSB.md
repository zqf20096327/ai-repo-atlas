**面向科研人员的 5D 生物图像存储、分析与可视化 Web 平台**

BisQue 是 UCSB 视觉研究实验室开发的 Web 平台，为研究者提供最高 5 维图像数据的组织、标注与定量分析工具，支持 100+ 生物图像格式与 100+GB 大图处理。用户可通过自建模块接入机器学习算法，存储兼容本地、iRODS 与 S3，分析语言支持 MATLAB、Python、Java+ImageJ。本地通过 Flox 环境安装启动，另有 Docker 与 Kubernetes 部署示例。应用于生物医学、神经科学、野生动物保护、海洋与材料科学领域，由 NSF 资助。
