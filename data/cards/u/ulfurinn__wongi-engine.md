**面向 Ruby 开发者的纯 Ruby 前向链推理规则引擎**

基于经典 Rete 算法实现的前向链（forward-chaining）规则引擎库，以纯 Ruby 编写。支持 Ruby >= 2.7 与 JRuby，Rubinius 未获积极支持。库未提供 API 文档，因多数接口仅供内部使用，作者建议跟随教程并仅使用其中描述的构造。1.0 发布前所有次版本均可能破坏兼容。Rete 实现主要遵循 Doorenbos 1995 年论文的框架。
