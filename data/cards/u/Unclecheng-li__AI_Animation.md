**给 AI Agent 用户的一套 HTML 动画生成 Skills 集合**

基于 WorkBuddy / Claude Code / Cursor 等 AI Agent 的动效 Skill 集合，每个 Skill 为自包含文件夹（SKILL.md 指令、README 文档、references 提示词、assets 模板 HTML）。安装后 Agent 依据用户描述自动激活对应 Skill，生成完整的单文件 HTML 动画，覆盖 PPT 演示、流程图、网络协议可视化、动态架构图、手写笔记、卡片剧场、视频分镜、手机 UI 与 Win11 仿真等类别；另含 GSAP 动效镜像库、HTML→MP4 渲染底座与视频 QA 工具。

## 能力要点

- 每个 Skill 自包含 SKILL.md + 模板 HTML，Agent 按描述自动激活
- 覆盖 PPT、流程图、协议可视化、架构图等 17 类动效场景
- dynamic-archify 支持 Mermaid 输入与 PNG/SVG/GIF/WebM 导出
- HyperFrames 底座将 HTML/CSS/动画渲染为确定性 MP4

## 适用场景

- 用 Claude Code 生成可录屏成片的技术科普演示动画
- 为系统设计评审生成带流动动画的架构图
- 制作手机 UI 风格或仿 Win11 的产品演示视频素材
