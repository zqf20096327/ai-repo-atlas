# USC-ICT/vhtoolkit

⭐ 23 · ShaderLab · NOASSERTION · 推送 2026-09-23 · [GitHub](https://github.com/USC-ICT/vhtoolkit) · [官网](https://vhtoolkit.ict.usc.edu) · 组织维护

**面向研究者的具身对话虚拟人创建平台（Unity，多厂商 AI）**

USC ICT 开发的研究平台，基于 Unity 构建具身对话智能体：集成语音识别、视听感知、语言模型、语音合成与非语言行为生成，原生支持 20+ 云端与本地厂商，运行时可切换云端或全本地（Docker 容器）部署。提供 URP/HDRP/AR 多个 Unity 工程、内置角色库与 Reallusion Character Creator 自定义角色流程，部署覆盖 Windows/macOS/Linux/WebGL/Android/iOS/Quest。需 Unity Hub 与 git，云端服务使用自己的 API key，限制为 USC-RL 许可仅限学术与个人使用。
