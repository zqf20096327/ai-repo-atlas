# URUWorks/TeroSubtitler

⭐ 474 · Pascal · MPL-2.0 · 推送 2026-11-27 · [GitHub](https://github.com/URUWorks/TeroSubtitler) · [官网](https://uruworks.net) · 组织维护

**跨平台免费字幕编辑软件，含自动转录与翻译**

面向 Windows、macOS 与 Linux 的开源字幕编辑软件：支持 45+ 字幕格式、SMPTE 与 Media 模式编辑、翻译记忆与术语库、波形时间线与内置镜头变化检测、蓝光 SUP 导入导出、文本转语音与视频配音、批量转换等。AI 相关能力以外部引擎集成形式提供：whisper.cpp / Faster-Whisper 用于音频自动转录为字幕，Google Translate 用于自动翻译，ElevenLabs TTS 用于配音。提供 Windows 安装包与便携版、macOS 与 Linux 下载；源码需 Lazarus 5.0 与 FPC 3.2.4 编译。

## 能力要点

- 支持 45+ 字幕格式（SubRip、WebVTT、ASS、TTML、EBU STL 等）
- 集成 whisper.cpp / Faster-Whisper 自动转录音频为字幕
- 时间线波形可视化与内置镜头变化检测
- 翻译记忆、术语库与 Google Translate 自动翻译

## 适用场景

- 为视频制作与本地化团队编辑、校验多格式字幕
- 用自动转录把音频/视频生成字幕初稿再人工修正
- 导入蓝光 SUP 字幕并用 OCR 提取文本
