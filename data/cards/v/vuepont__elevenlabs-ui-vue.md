# vuepont/elevenlabs-ui-vue

⭐ 200 · Vue · MIT · 推送 2026-10-11 · [GitHub](https://github.com/vuepont/elevenlabs-ui-vue) · [官网](http://elevenlabs-ui-vue.com) · 个人维护

**构建多模态语音 agent 的 Vue UI 组件库**

基于 shadcn-vue 的 Vue 组件库与自定义注册表，为 agent 与音频应用提供预构建可定制组件，包括 orb、波形、语音 agent、音频播放器等。配套 CLI 支持通过 npx 一键安装全部组件或按需添加单个组件，也兼容 shadcn-vue CLI 从注册表安装。面向使用 Vue/Nuxt 并已配置 shadcn-vue 与 Tailwind CSS 的开发者，要求 Node.js 18 及以上。MIT 许可。

## 能力要点

- 面向 agent 与音频应用的 Vue 组件（orb、波形、语音 agent、音频播放器等）

- 提供 shadcn-vue 注册表，兼容 shadcn-vue CLI 安装
- 支持 Vue 与 Nuxt 项目
