**本地/VPS 运行的个人 AI 助理，可切换模型大脑做业务自动化**

NAOTA 是由个人开发者 Hoàng Ngọc Vương 开发的 AI 助理，运行在本地电脑或自有 VPS 上。它执行代替用户的任务：读写文件、调用销售/广告/日历/邮件/Zalo 等连接、运行技能、后台执行任务与自动排期，通过可对话的控制面板操作并支持语音。模型大脑可切换（Claude、ChatGPT、Grok、Gemini 或单个 API key）；记忆、wiki 与技能以文本文件保存在本地并带历史。安装脚本会安装 Python 与依赖，服务在 localhost:7777 提供。

## 能力要点

- 可切换模型大脑（Claude/ChatGPT/Grok/Gemini 或 API key），工具能力不随模型切换丢失
- Second Brain：记忆/wiki/技能以本地文本文件存储并带历史，可迁移
- 支持文件读写、业务连接调用、后台任务与自动排期
- 支持语音交互的控制面板，数据可留在本机或部署到 VPS
