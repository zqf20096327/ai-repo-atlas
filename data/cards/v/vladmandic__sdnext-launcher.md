# vladmandic/sdnext-launcher

⭐ 14 · TypeScript · Apache-2.0 · 推送 2026-10-29 · [GitHub](https://github.com/vladmandic/sdnext-launcher) · [官网](https://vladmandic.github.io/sdnext-docs/) · 个人维护

**Windows 一体化安装启动器：免配置安装运行 SD.Next**

面向 Windows 10/11 用户的应用程序，将 SD.Next 的安装与运行打包为图形界面流程：内置便携版 Python 与 Git，无需额外安装依赖；用户下载 EXE/ZIP 后经 Bootstrap 解包、选择 GPU 后端（CUDA/ROCm/Zluda/IPex/DirectML/OpenVino）与安装路径，再执行安装与启动，全程无需命令行。安装过程不修改自身目录以外的文件，无需管理员权限，需 6GB 以上磁盘空间与网络连接。

## 能力要点

- 内置便携版 Python 与 Git，无需额外安装依赖
- 支持选择 CUDA/ROCm/Zluda/IPex/DirectML/OpenVino 六种 GPU 后端
- 图形化 Bootstrap→Configure→Install→Launch 流程，无需命令行
- 不修改自身目录以外的文件，无需管理员权限

## 适用场景

- Windows 用户免命令行一键安装并启动 SD.Next
- 按自己显卡选择 GPU 后端完成部署
- 希望安装过程不影响系统环境的用户
