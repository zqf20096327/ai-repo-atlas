**面向中学学习的 Android AI 辅导应用，滑动交互式拍照问答**

Kotlin + Jetpack Compose 编写的 Android 学习应用：拍照/相册上传题目图片进行 AI 问答，渲染 Markdown 与 LaTeX 公式，支持录音转写的语音追问、AI 学习教练复盘、题目归档与 Anki 记忆卡片延展。核心交互为左滑继续表达、右滑展开详解与精细追问链。模型服务通过 local.properties 配置 ARK API 与语音服务密钥接入，需克隆源码经 Android Studio 或 Gradle 构建安装（Min SDK 26）。README 自述为持续迭代中的学习型项目。
