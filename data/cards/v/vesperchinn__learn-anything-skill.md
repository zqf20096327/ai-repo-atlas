# vesperchinn/learn-anything-skill

⭐ 15 · Python · MIT · 推送 2026-07-28 · [GitHub](https://github.com/vesperchinn/learn-anything-skill) · 个人维护 · 中文 README

**把 AI agent 变成引导式学习教练的多语言技能包**

面向个人学习者的开源 Agent Skill Pack：告诉 agent 学习目标、背景与时间，即生成结构化学习仓库（领域图、课程、练习、测验、结业项目、来源记录），并在对话中按 I do→We do→You do 模式开始 Day 1 教学，通过 progress.md 等文件跨会话保存进度。支持导入 PDF/幻灯片/笔记等自有材料作为主要来源，未证实内容标记 unverified。兼容 Codex、Claude Code、Cursor、Coze、ChatGPT 等平台，英文与简体中文界面完整，v0.2.4-beta。

## 能力要点

- 一个学习目标生成结构化学习仓库（领域图/课程/练习/测验/结业项目）
- 对话内引导式 Day 1 教学与回复检查的进度循环
- 基于自有材料学习，外部知识标记 Supplemental，无来源内容标 unverified
- 多平台适配：Codex/Claude Code/Cursor/Coze/ChatGPT，en-US 与 zh-CN 完整

## 适用场景

- 让 AI agent 为我定制某领域的 7 天学习计划并逐日陪我学
- 用自己的 PDF、笔记和课件生成以我材料为主的学习路径
- 跨会话续学，从上次进度继续当日课程
