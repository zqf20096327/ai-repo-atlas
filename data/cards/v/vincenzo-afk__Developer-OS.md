# vincenzo-afk/Developer-OS

⭐ 26 · TypeScript · MIT · 推送 2026-08-27 · [GitHub](https://github.com/vincenzo-afk/Developer-OS) · [官网](https://developer-os-sage.vercel.app) · 个人维护

**Windows 11 风格的交互式开发者作品集网站**

为开发者 Bharani Kumar S 构建的网页作品集，以 Windows 桌面交互形态呈现：解锁屏、任务栏、开始菜单、可拖拽窗口、Explorer、终端别名与 Edge 风格浏览器工作区，内容锚定于本地验证数据与公开 GitHub 检索，外部源不可达时显示诚实的加载/不可用状态。内含基于本地证据与公开检索、带引用的回答的 Portfolio Assistant，生成回复依赖可用的 provider，未配置时回退到验证的本地答案。技术栈为 React 19 + TypeScript + Vite 前端与 Express 4 + tRPC 11 后端，需 Node.js 22+ 与 pnpm 10+，支持 Vercel 部署。

## 能力要点

- 桌面外壳：可拖拽/最小化/最大化的窗口、任务栏、开始菜单、Ctrl/Cmd+K 搜索
- Portfolio Assistant 基于本地证据与公开 GitHub 检索，回答带引用并在 provider 不可用时回退
- 安全终端别名仅路由到验证项目，不执行访客提供的 shell 命令
- Resend 驱动的联系人投递，含验证与速率限制

## 适用场景

- 以桌面系统交互方式浏览开发者的项目、技能与成就
- 通过内置助手以对话方式查询作品集相关信息
- 作为可自托管的桌面风格作品集模板进行部署
