**复刻《西部世界》Rehoboam 界面的 React 网页项目**

pnpm monorepo，包含 React 19 + Vite 网页 UI、Cloudflare Worker API 与定时任务 Worker 三个工作区。网页以 Rehoboam 风格动画展示重大世界事件时间线，并可通过同步标注检视活跃信号。技术栈为 TypeScript、oxlint、Prettier、Vitest、Turborepo；本地通过 pnpm install/dev 运行，提供构建、类型检查、Playwright 截图工具与 GitHub Actions CI 流水线。README 未描述任何实际 AI 模型或推理功能，仅以影视剧中的 AI 系统为界面主题。
