**Zotero 论文问答与双语 PDF 翻译的开源插件**

面向 Zotero 7–10 的免费开源阅读助手插件：对 PDF/EPUB 中的段落提问，回答带定位引用，可跳转到对应 PDF 页或 EPUB 章节，并能保存为 Zotero 笔记；支持划词翻译、批量生成单语/双语 PDF（含 OCR 方向校正）、对话导出导入、通讯作者档案生成。接入 ChatGPT 与 GitHub Copilot 账号（OAuth）、OpenAI 兼容 API 及本地模型；历史与记忆本地存储；界面支持 13 种语言。AGPL-3.0-or-later 许可，基于 llm-for-zotero 项目。
