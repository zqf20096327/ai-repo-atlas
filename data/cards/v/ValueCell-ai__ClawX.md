**为 OpenClaw AI Agent 提供图形化桌面界面，免去命令行操作**

基于 Electron 与 React 构建的桌面应用，内嵌 OpenClaw 运行时，将命令行方式的 AI Agent 编排转为图形界面操作。功能覆盖多会话聊天、Agent 创建与生命周期管理、多渠道管理（含内置微信与钉钉插件）、Cron 定时任务、本地技能管理、模型提供商统一配置（凭据存入系统钥匙串）、语音听写与本地计算机操作。提供安装包与源码构建两种方式，最低 4GB 内存。另提供面向企业的商业版本联系方式。

## 能力要点

- 内嵌 OpenClaw 运行时，一键安装与向导式配置，无需终端命令
- 多渠道管理：内置腾讯个人微信插件与钉钉连接器
- Cron 定时任务与可本地管理的技能系统（pdf/xlsx/docx/pptx 技能）
- 凭据存入系统钥匙串的提供商集成与 macOS/Windows 本地计算机操作

## 适用场景

- 在桌面上配置和管理多个专用 AI Agent
- 定时让 Agent 监控信息源并把结果推送到微信/钉钉等渠道
- 把 Agent 接入开发流程做代码审查与文档生成
- 为不熟悉命令行的用户搭建 AI Agent 工作流
