**疫情微博文本情感分析与可视化的机器学习项目**

基于 Python 3.6 与 scikit-learn 0.24.2 的分析项目：手动爬取疫情背景下微博文本与评论，经数据清洗、jieba 分词、textRank 关键词分析后，分别用 SO-PMI 情感词典扩展、K-means/DBSCAN/层次聚类、多维情感词典三类方法做情感与心态分析，用 pyecharts 和 matplotlib 可视化。面向数据分析和 NLP 学习者，需自行 clone 源码并配置环境运行。
