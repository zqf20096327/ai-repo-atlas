**拼豆图纸生成网站：AI 辅助优化图片并一键生成拼豆底稿**

基于开源项目 Zippland/perler-beads 二次开发的拼豆图纸生成网站（Next.js 静态导出 + Cloudflare Pages Function）。核心流程：上传图片→浏览器端 Canvas 像素化（主导色映射+欧氏距离匹配调色板、BFS 相似色区域合并、洪水填充移除背景）→导出带 Key 图纸、颜色统计图与 CSV 采购清单。支持 MARD/COCO/漫漫/盼盼/咪小窝五种色号系统、自定义调色板与手动编辑。AI 优化为可选功能，通过火山引擎即梦 AI API 将普通图片转换为适合拼豆的像素风格，需配置 API 密钥，不配置则跳过。另提供 no-backend 静态部署分支与免费微信小程序。

## 能力要点

- 像素化+颜色映射+BFS 相似色合并+背景移除的浏览器端处理流程
- AI 优化功能调用火山引擎即梦 AI，将普通图片转为适合拼豆的像素风格
- 导出带 Key 图纸、颜色统计图与 CSV 采购清单
- 支持 5 种拼豆色号系统与自定义调色板编辑器

## 适用场景

- 把照片或插画一键转成拼豆拼装图纸

- 用 AI 先把普通图片转成低颜色数、白底像素风再生成图纸
