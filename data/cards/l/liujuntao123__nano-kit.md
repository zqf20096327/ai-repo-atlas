**基于 Nano Banana Pro 的图片生成工具箱，含模板配图与本地图片管理**

面向图片生成用户的 Web 工具箱：基于 Nano Banana Pro 模型，通过自定义 API 接入，提供文章配图（22 个模板）、小红书配图（10 个模板）、单页信息图（17 种风格）、提示词拉取收藏与一键应用、图片切片制作表情包，以及生成作品的本地化管理。图片局部编辑功能为 TODO 状态。技术栈为 React 18 + TypeScript + Vite，通过 npm 安装依赖并开发构建，提供在线网站预览。
