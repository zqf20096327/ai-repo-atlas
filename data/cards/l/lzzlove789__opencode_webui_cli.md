# lzzlove789/opencode_webui_cli

⭐ 24 · TypeScript · Apache-2.0 · 推送 2026-02-10 · [GitHub](https://github.com/lzzlove789/opencode_webui_cli) · 个人维护 · 中文 README

**为 OpenCode CLI 提供 Web 聊天界面的封装工具**

基于 npm 分发的 Web UI 封装，包裹 OpenCode CLI：提供流式响应的聊天界面、生成文件面板与预览、会话历史查看、通过 CLI 参数选择模型。支持配置监听端口与主机地址（默认 127.0.0.1:8080）、指定 opencode 可执行文件路径与默认模型、调试模式。面向需要在浏览器中使用 OpenCode CLI 的开发者，需本机已安装 OpenCode CLI。项目基于 anomalyco/opencode 与 sugyan/claude-code-webui，采用 Apache-2.0 许可。
