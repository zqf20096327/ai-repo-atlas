**LangChain 生态流式能力的可运行示例与文档集**

由 langchain-ai 维护的流式功能示例库（cookbook）：围绕 LangGraph、LangChain agents、Deep Agents 的事件流 API 及 React/Angular/Svelte/Vue 前端 SDK 收集可运行示例，覆盖事件流、消息投影、子代理发现、A2UI 生成式 UI、多模态故事书、断线重连、人工干预中断等主题。每个概念提供 TypeScript 和/或 Python 包，TypeScript 用 pnpm、Python 用 uv 运行；API 处于 preview 阶段可能变动，运行示例需在 .env 中填写 provider key。

## 能力要点

- 覆盖事件流、消息投影、子代理/子图发现、自定义 StreamTransformer 等流式主题
