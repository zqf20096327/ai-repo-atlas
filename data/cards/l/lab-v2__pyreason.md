**面向研究者的可解释图逻辑推理库**

PyReason 是一个可解释的推理软件包：用户定义逻辑规则与事实（初始条件），在图结构上进行推理，支持标注逻辑、实数值、图结构与时序逻辑。以 Python 库形式发布（pip 安装，支持 Python 3.8–3.13），提供论文、视频、网站、PyReason Gym 与 ReadTheDocs 文档及代码示例。关联论文发表于 AAAI Spring Symposium 2023，采用 BSD-2-Clause 许可，商标归属亚利桑那州立大学。
