**开源个人 AI 助手，本地运行并提供 Web 应用**

由 Louis Grenard 自 2017 年起开发的开源个人 AI 助手，目标是在用户日常生活中记住重要事项并代为完成事务。当前处于 2.0 alpha 开发阶段，提供 Web 应用预览与计划的桌面应用。核心机制包括持续 agent 循环、隔离 worker 中的工具执行、渐进式上下文管理、多层记忆（临时上下文、持久偏好、每日摘要等按 profile 隔离）、原生技能与 agent 技能双体系。支持本地与远程模型，可在自己的机器上运行。Node.js >= 24，从源码安装，下载在中国机器上使用国内镜像。旧版文档与 2.0 实际状态存在差异。
