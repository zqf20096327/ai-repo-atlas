# licon/ez-translate

⭐ 49 · JavaScript · NOASSERTION · 推送 2026-10-12 · [GitHub](https://github.com/licon/ez-translate) · [官网](https://chromewebstore.google.com/detail/ahlibmildbganmkdhokbkfanpaakpgfd?utm_source=github) · 个人维护 · 中文 README

**基于 LLM 的浏览器划词/截图/弹窗翻译扩展**

面向普通用户的浏览器翻译扩展，调用 LLM（Google Gemini、Silicon Flow、OpenRouter、OrcaRouter、Ollama 等）完成网页划词悬停翻译、右键菜单翻译、截图取词翻译（AI 视觉识别图内文字）与弹窗快捷翻译，支持 100+ 语言、主/次目标语言智能切换、朗读与一键复制，API key 仅存于本地浏览器。安装方式为 GitHub Releases 下载 zip 后以开发者模式加载（Chromium/Firefox）。README 附与 Google Translate API 的译文对比示例，并声明译文质量随所选模型与提供商而异。

## 能力要点

- 五种 LLM 提供商可选，含 Ollama 本地部署路径
- 截图翻译利用 AI 视觉能力识别图中/PDF/截图内文字
- 划词悬停、右键菜单、弹窗、快捷键四种触发方式
- API key 仅本地浏览器存储，不上传

## 适用场景

- 浏览外文网页时划词或右键即时翻译
- 翻译图片、PDF、截图中的文字
- 通过 Ollama 本地模型离线隐私翻译
- 双语用户在主/次目标语言间自动切换
