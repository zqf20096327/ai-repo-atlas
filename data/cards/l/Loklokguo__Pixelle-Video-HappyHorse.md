# Loklokguo/Pixelle-Video-HappyHorse

⭐ 56 · Python · Apache-2.0 · 推送 2026-05-14 · [GitHub](https://github.com/Loklokguo/Pixelle-Video-HappyHorse) · [官网](https://dashscope.aliyuncs.com) · 个人维护 · 中文 README

**输入主题一键全自动生成短视频的 AI 引擎（含云端文生视频）**

面向无剪辑经验的内容创作者的 Web 应用：输入主题后自动完成文案撰写、AI 配图/视频生成、TTS 语音合成、BGM 与视频合成，流程为文案→配图规划→逐帧处理→合成。基于 ComfyUI 架构，图像生成可接本地 ComfyUI 或云端 RunningHub，LLM 可选通义千问/GPT/DeepSeek/Ollama，TTS 支持 Edge-TTS、Index-TTS 等。本仓库在 Pixelle-Video 基础上新增 HappyHorse（DashScope）云端文生视频，无需 GPU。提供 Windows 一键整合包，macOS/Linux 从源码运行，依赖 uv 与 ffmpeg。另含数字人口播、图生视频、动作迁移等扩展模块。
