**面向 React/React Native 应用的 340+ AI/LLM 品牌 Logo 图标库**

Lobe Icons 收录 340+ AI 模型、服务商与应用品牌的 Logo，以 React 与 React Native 组件形式提供，同时发布静态 SVG/PNG/WEBP 资源。组件支持 mono、color、text、avatar 四种样式适配明暗主题，可传入模型或服务商 id（如 gpt-4o、openai）获取对应 Logo，按需导入以减小包体积，也可不经框架直接通过 CDN URL 引用图片。另提供 skills.md、llms.txt 与技能文件供编码代理读取使用。安装依赖 React 19，@lobehub/ui 为 peer dependency。

## 能力要点

- 340+ AI/LLM 品牌图标，覆盖模型、服务商与应用品牌

- 让编码代理按 skills.md 自动接入图标组件
