**多人大葱 AI 编程对战游戏 Leek Wars 的网站前端**

Leek Wars 是一款多人网页端 AI 编程游戏，玩家编写代码训练自己的大葱进行对战。本仓库是该项目网站的 Vue 3 + TypeScript 前端，同时包含整个项目的概览信息；后端生成器与 LeekScript 语言为独立仓库。前端通过 git clone 加 npm i/npm start 部署，运行于 localhost:8080，但会连接生产服务器，登录即使用真实账号。使用 Vue 3、Vuetify、Pinia、Monaco Editor 等库，GPL3 许可。
