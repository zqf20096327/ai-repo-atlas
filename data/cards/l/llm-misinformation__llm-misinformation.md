**ICLR 2024 论文数据集与检测代码：LLM 生成虚假信息可否被检测**

论文《Can LLM-Generated Misinformation Be Detected?》的官方仓库，提供 LLMFake 数据集与检测实验代码：数据集覆盖 7 类生成器（ChatGPT、Llama2、Vicuna 各规模）与 7 类生成方法产出的虚假信息，基于 Politifact/Gossipcop/CoAID 三个人写虚假信息数据集构建。检测实验以 ChatGPT-3.5/GPT-4 API 及 Llama2 为检测器，提供复现脚本（需自备 OpenAI API key，实验环境为单张 RTX A6000、CUDA 11.7、vllm==0.1.4）。不提供虚假信息生成代码以避免滥用。
