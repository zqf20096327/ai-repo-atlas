**面向开发者的 DeepSeek 优化终端 AI 编码助手**

以 npm 全局包发布的终端 AI 编码助手，专为 DeepSeek 模型调优。提供 agent skills 扩展机制（扫描项目/用户级目录，兼容 .agents/skills 跨客户端互操作）、思考模式与推理强度控制、MCP 外部服务集成、细粒度权限确认、斜杠命令与会话管理，并支持读取本地图片与可选的联网搜索。CLI 与官方 VSCode 插件共享同一配置文件；另有可选的 DeepCode Plus 订阅套餐，不订阅也可使用。

## 能力要点

- Agent Skills 支持，扫描 .deepcode/skills 与跨客户端 .agents/skills 目录
- 专为 DeepSeek 优化的思考模式与推理强度控制
- MCP 集成可连接 GitHub、浏览器、数据库等外部服务
- 细粒度权限控制与 /undo 状态回退

## 适用场景

- 在终端中用 DeepSeek 模型进行代码对话与修改
- 通过 skills 与 MCP 扩展助手的工具能力
