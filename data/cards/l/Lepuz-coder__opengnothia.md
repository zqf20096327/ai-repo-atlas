# Lepuz-coder/opengnothia

⭐ 32 · TypeScript · MIT · 推送 2026-08-25 · [GitHub](https://github.com/Lepuz-coder/opengnothia) · [官网](https://opengnothia.com/) · 个人维护

**本地优先的 AI 自助心理疗愈桌面应用：对话、日记与梦境分析**

基于 Tauri 2 + React 19 + Rust 构建的隐私优先自疗桌面应用：提供 AI 疗愈对话（流式输出、会话计时与收尾建议）、临床问卷、日记与可选 AI 分析、梦境记录与 AI 解读、情绪追踪、呼吸练习和结构化疗愈计划。内置六个流派（精神分析、CBT、意义疗法、ACT、图式疗法、斯多葛）的系统提示词。支持自带 API key 接入 Anthropic Claude、OpenAI 或任意 OpenAI 兼容端点；全部数据存于本地 SQLite，无云同步与遥测，支持 Touch ID 与密码锁。附注说明本工具不替代专业心理治疗。
