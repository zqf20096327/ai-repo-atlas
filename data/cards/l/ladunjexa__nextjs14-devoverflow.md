# ladunjexa/nextjs14-devoverflow

⭐ 71 · TypeScript · MIT · 推送 2025-12-14 · [GitHub](https://github.com/ladunjexa/nextjs14-devoverflow) · [官网](https://nextjs14-devoverflow.vercel.app) · 个人维护

**开发者问答平台模板应用，类 StackOverflow 功能复刻**

基于 Next.js 14、TypeScript、Tailwind CSS、Clerk、MongoDB/Mongoose、Shadcn-UI、TinyMCE 构建的开发者问答平台，功能覆盖提问、回答与知识分享，支持通过 Clerk 认证与 Webhook 同步用户、TinyMCE 富文本编辑、Prism 语法高亮，并接入 OpenAI API 与 RapidAPI 的 JSearch API 作为外部服务。本地运行需配置 Clerk、MongoDB、TinyMCE、OpenAI、RapidAPI 五组凭据到 .env，可用 npm run dev 启动开发服务器，支持 Vercel/Netlify 部署。属 JavaScript Mastery 课程配套项目。
