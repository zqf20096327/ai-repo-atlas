**自托管家庭资产管理：全家资产全局图+真实年化+AI体检**

Spring Boot + MySQL 的自托管 Web 应用，按「月度快照」方式记录散落在银行/支付宝/券商/房产/房贷中的家庭资产，输出净资产趋势、XIRR/TWR 真实年化、CPI/M2 财富水位线与多维透视（含基金穿透到股/债/行业）。AI 部分：截图上传后由视觉大模型识别持仓名称与市值、AI 推荐资产打标、AI 解读四维体检结果（数字由工程计算，LLM 只解读，不荐产品不预测）。以 Docker compose 或 systemd 直装部署，支持 iOS PWA。

## 能力要点

- 月度快照记账：每月一次填报，自动算家庭级 XIRR 与资产 TWR
- AI 截图导入持仓：视觉大模型识别「名称+市值」并三态比对确认
- 基金穿透到真实持仓与申万行业，家庭整体汇总行业敞口
- Docker compose 一键部署（amd64+arm64），数据自托管且导出 CSV

## 适用场景

- 把全家散在各渠道的钱汇总成一张净资产全局图
- 区分工资攒的钱和投资赚的钱，看真实年化收益
- 基金持仓穿透看真实行业风险敞口
- FIRE 退休/子女教育等财务目标的三情景预测
