**面向程序员与PhD申请者的AI多智能体面试拷问报告生成器**

基于 Python 的面试准备工具，通过 6 个专业智能体（技术面试官、HR、导师等）协作，读取用户简历与目标岗位，生成 20-50 题的结构化面试报告，含提问理由、练习提示词、参考答案与资料推荐。支持求职/学术申请/混合三种模式，覆盖 23 个专业领域，可从 GitHub Trending、V2EX、IT之家爬取技术趋势融入题目。提供 CLI、FastAPI Web 界面与示例脚本；扫描版 PDF 简历需可选安装 OCR 依赖；LLM 能力通过外部 API 密钥调用。
