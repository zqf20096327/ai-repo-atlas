# li2092/one-prompt-video

⭐ 5 · JavaScript · MIT · 推送 2026-11-17 · [GitHub](https://github.com/li2092/one-prompt-video) · 个人维护 · 中文 README

**给 agent 用户的技能：一句话生成带配乐字幕的 MP4 短视频**

一个 Agent Skill，装入 Claude Code、Codex 或其他支持技能的 agent 后，用户说一句话，模型填写一份 video.json，脚本校验后逐帧渲染出 20-90 秒的 MP4，含配乐和字幕。画面由代码绘制，不使用视频生成模型；支持九种版式、15 个风格包、内置主题，可剪入实拍素材并导出 Final Cut Pro/剪映工程。依赖 Node.js 与 ffmpeg，无需显卡。作者注明仅在 macOS（Apple Silicon）实测过，Windows/Linux 代码路径未实测；版本 0.6.1，MIT 许可。

## 能力要点

- 模型填写 video.json，脚本负责校验、排时间线、渲染、自检并输出总览图
- 逐帧代码绘制画面，文字与数字与输入一致，同一输入输出可复现
- 支持剪入实拍素材并导出 .fcpxml、剪映草稿与 .srt 字幕
- 校验反馈逐条指明出错场次、字段与正确写法，小模型可跑通

## 适用场景

- 把一句话讲解或科普内容做成短视频
- 把一组数据快速做成柱状图知识卡片视频
- 生成横屏或竖屏的产品介绍短片
- 剪辑实拍素材并导出工程到 Final Cut Pro 或剪映继续剪
