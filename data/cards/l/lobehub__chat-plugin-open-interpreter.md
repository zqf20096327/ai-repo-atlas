**将 Open Interpreter 接入 LobeChat 的聊天控制电脑插件**

LobeHub 维护的 LobeChat 插件，把 Open Interpreter 集成到 LobeChat 中，用户可通过聊天界面控制电脑，属于 function calling 插件，可在 LobeChat 插件设置页安装。本地开发支持 Gitpod 在线开发，或 git clone 后用 pnpm 安装依赖并运行 dev。README 的 Features 部分为插件模板的通用描述，未列出本插件特有功能细节。MIT 许可。
