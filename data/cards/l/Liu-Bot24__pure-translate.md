⭐ 6 · TypeScript · MIT · 推送 2026-11-22 · [GitHub](https://github.com/Liu-Bot24/pure-translate) · [官网](https://blog.liu-qi.cn/tools/) · 个人维护 · 中文 README

**浏览器网页双语翻译扩展：免配置免费翻译当前页面**

Chrome 与 Edge 的网页翻译扩展（Manifest V3），提供整页翻译、双语对照、选中翻译、输入框翻译、悬停翻译与划词浮窗等交互方式，保留原页排版并支持滚动随译。内置 Google 与微软翻译可免配置使用；也可配置 OpenAI 兼容、Anthropic 兼容、DeepL/DeepLX 接口，支持模型池与多 API Key 轮换，并按功能分别指定模型。不做视频与 PDF 翻译，无账号系统。

## 能力要点

- 整页/选中/输入框/悬停多种翻译入口与双语对照切换
- 内置 Google 与微软翻译，装好即可免费用
- 支持 OpenAI 兼容、Anthropic 兼容、DeepL/DeepLX 多种接口
