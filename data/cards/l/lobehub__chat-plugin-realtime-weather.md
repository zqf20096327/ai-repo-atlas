# lobehub/chat-plugin-realtime-weather

⭐ 18 · TypeScript · MIT · 推送 2026-10-15 · [GitHub](https://github.com/lobehub/chat-plugin-realtime-weather) · [官网](https://realtime-weather.chat-plugin.lobehub.com) · 组织维护 · 中文 README

**LobeChat 的实时天气函数调用插件**

面向 LobeChat 的 Function Calling 插件：获取实时天气数据并可根据用户位置自动更新，以消息渲染形式返回结果。用户可在 LobeChat 插件设置页一键安装，无需单独部署。开发者可基于 Plugin SDK 与插件模板二次开发，支持 GitHub Codespaces 在线开发或 git clone 后用 bun 本地运行。属于 LobeChat 插件生态（插件索引、SDK、Plugins Gateway）的组成之一，MIT 许可，由 LobeHub 维护。

## 能力要点

- 提供实时天气数据并按用户位置自动更新
- 以 LobeChat Function Calling 插件形式在插件设置页安装
- 支持 GitHub Codespaces 在线开发与 bun 本地开发

## 适用场景

- 在 LobeChat 对话中查询实时天气
- 让聊天助手基于我的位置自动获取天气信息
- 作为参考实现开发自己的 LobeChat 插件
