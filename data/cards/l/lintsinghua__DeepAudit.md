# lintsinghua/DeepAudit

⭐ 7,363 · Python · AGPL-3.0 · 推送 2026-11-27 · [GitHub](https://github.com/lintsinghua/DeepAudit) · 个人维护 · 中文 README

**给开发者/安全人员的 Multi-Agent 代码漏洞审计平台**

基于 Multi-Agent 协作架构的代码安全审计平台，由 Orchestrator、Recon、Analysis、Verification 四类 Agent 协作完成策略规划、攻击面识别、漏洞挖掘与沙箱 PoC 验证，最终生成审计报告。结合 RAG 知识库（CWE/CVE 检索）与 AST 分析，支持 12 类漏洞类型检测、GitHub/GitLab/Gitea 项目导入、PDF/Markdown/JSON 报告导出，运行时可在浏览器配置 LLM。提供 Docker 一行命令部署与源码部署两种方式，支持 API 中转站与 Ollama 本地模型。README 声明仅供授权环境下的研究与教学使用。

## 能力要点

- Orchestrator/Recon/Analysis/Verification 四类 Agent 协作审计，含 Docker 沙箱 PoC 验证
- RAG 知识库增强，支持 CWE/CVE 检索与 AST 分析
- 支持 12 类漏洞类型检测与五维检测（Bug/安全/性能/风格/可维护性）
- 支持 Ollama 本地部署与 API 中转站，代码可不出内网

## 适用场景

- 导入代码仓库做自动化安全审计并生成报告
- 在沙箱中自动验证发现的漏洞是否真实可利用
- 用本地模型对敏感代码做内网私有化审计
