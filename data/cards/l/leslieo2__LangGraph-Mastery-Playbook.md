**LangGraph 记忆型 LLM Agent 教学课程：六个阶段的可运行脚本教程**

面向开发者的代码优先 LangGraph 教程项目：以六个递进阶段（基础图、短期记忆、状态管理、运行控制、高级记忆系统、生产级检索系统）组织约 30 个独立 Python 模块课程，每个模块含 main() 入口并生成图结构、检查点与流式日志等工件。通过 utils.create_llm 支持 OpenAI、OpenRouter、DeepSeek 等端点，配置经 .env 切换。使用 uv 管理依赖，git clone 后本地安装；Stage 06 需 Tavily key 及可选 Postgres/MongoDB/Redis 后端；全部课程可在 LangGraph Studio 中可视化调试。附中文版本 README。
