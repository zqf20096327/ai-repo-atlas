**本地优先的多智能体应用开发平台，自动串联创建评测部署**

构建在 PenguinHarness fork 之上的本地优先多智能体应用开发平台，运行于用户自己的电脑或服务器，自动串联 Agent 应用的创建、评测、优化与部署。核心机制包括一句话生成可运行的 Agent 应用（脚手架、代码、运行说明）、Agent 自进化引擎（跑 Benchmark、找失分点、发布 N+1 版并自动快照）、内置四类插件库与插件市场，以及桌面端内置浏览器与实时语音通话。限制：macOS 无官方安装包，Windows 安装包未签名，模型需自配 API Key。

## 能力要点

- 一句话描述需求自动生成完整可运行的 Agent 应用
- Agent 自进化引擎：自动跑 Benchmark、找失分点、发布新版本并快照
- 内置办公效率/软件开发/AI 应用开发/Agent 公司四类插件与一键安装的插件市场
- 支持 OpenAI 协议端点，可自定义接入 1000+ 在线与本地模型

- 一句话生成 RAG 文档问答等 Agent 应用

- 通过插件市场安装办公自动化与浏览器操作能力
