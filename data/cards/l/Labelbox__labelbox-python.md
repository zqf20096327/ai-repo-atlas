**Labelbox 平台的 Python SDK：供企业做数据标注与模型评估**

Labelbox 官方 Python SDK，通过 API key 连接 Labelbox 平台，支持数据整理（curate）、标注、生成人工反馈数据（覆盖计算机视觉与语言模型）、模型性能评估，以及 AI 与人工流程结合的任务自动化。通过 pip 安装，可选 labelbox[data] 附加数据处理能力；仓库提供 Jupyter Notebook 示例与官方文档。每个发布版本附带 SLSA Level 3 构建溯源与 PyPI attestation，供验证包未被篡改。维护者为 Labelbox 公司，代码 Apache 2.0 许可。
