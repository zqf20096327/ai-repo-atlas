**Galgame 风格桌面 AI Agent：以视觉小说界面封装 Claude Code CLI**

基于 Electron 31+ 的桌面应用，以《千恋＊万花》常陆茉子为角色主题，将 Claude Code CLI 封装为视觉小说式聊天体验：双角色立绘 110+ 张、6 张场景背景、30+ 首 BGM、GPT-SoVITS 预生成语音、打字机与 Markdown/KaTeX 渲染。支持一键切换 DeepSeek、Anthropic、OpenRouter 等 9 家 LLM 供应商，内置首次配置向导（自动检测/安装 Node.js、Git、Claude Code）、人设 Markdown 编辑器、33 条快捷指令与存档系统。需自备 LLM API Key，可能产生调用费用；素材版权归 Yuzusoft，仅限非商业使用。
