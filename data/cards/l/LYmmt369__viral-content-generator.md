**内容运营者用的热点风格成交内容生成 CLI：把选题变成多平台内容草案**

热点风格成交引擎：以 CLI 与 Python 库形式提供，将热点情报、YAML 账号指纹、155+ 外置风格基因卡、4 种成交目标（likes/comments/leads/sales）与 7 个中文平台适配规则编译成提示词并生成内容草案。支持 1-3 个风格混合、批量热点处理、多候选确定性质量门与可解释排序，用 FEEDBACK.md 记录发布后数据形成复盘闭环。支持 Python 3.10-3.12，声明不预测曝光或成交；提供无 API Key 的本地规则演示。

## 能力要点

- 155+ 外置风格基因卡（A-E 五类，含 style_dna/钩子/情绪曲线等字段）
- YAML 账号指纹 + 产品阶梯 + 4 种成交目标模式
- 公众号/视频号/小红书/知乎/抖音/B站/微博 7 平台动态适配

- 多账号运营时用账号指纹配置保持人设一致
- 发布后记录反馈数据，迭代风格卡与生成策略
