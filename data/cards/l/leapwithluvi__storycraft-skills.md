# leapwithluvi/storycraft-skills

⭐ 4 · JavaScript · MIT · 推送 2026-11-01 · [GitHub](https://github.com/leapwithluvi/storycraft-skills) · 个人维护

**为 AI 写作 agent 提供 23 个小说创作技能包**

一套面向小说写作全流程的可组合 agent 技能与方法论，覆盖从苏格拉底式头脑风暴、前提与人物架构，到章节大纲、自动起草、连续性审计与会话记忆保存。技能通过斜杠命令触发或自主编排，产出结构化的 premise/story-bible/story-state 等文件，并按网文、传统商业小说、轻小说三种发布格式调整章节长度与节奏参数。提供 17 个写作 agent 平台（Claude Code、Codex、Cursor、Gemini CLI 等）的插件安装方式，零依赖。

## 能力要点

- 23 个技能覆盖从构思到出版的完整小说流水线
- 跨 17 个 agent 平台（Claude Code/Codex/Cursor 等）的插件安装支持
- 按发布格式（网文/商业小说/轻小说）自适应章节长度与节奏
- novel-session-memory 生成 bootstrap 提示以恢复中断会话

## 适用场景

- 用 AI agent 从零构思并逐章起草一部小说
- 对已有书稿做连续性审计（时间线、伤情、物品状态）
- 按网文平台的章节长度和钩子密度要求批量产出章节
- 在长周期写作项目中跨会话保持故事状态
