# lealoth/Sibelium-cognitive-architecture

⭐ 15 · Python · MIT · 推送 2026-06-06 · [GitHub](https://github.com/lealoth/Sibelium-cognitive-architecture) · 个人维护

**模拟人工意识的认知架构框架，含示例实体 Nexus**

用 Python、llama-cpp 与 ChromaDB 构建的认知架构，通过 32 个带神经科学对应物的机制（叙事自我、情景记忆、NREM/REM 睡眠周期、注意力调节、共情共振、主动遗忘等）驱动 LLM 产生持续思维流与对话输出。README 明确声明它模拟认知机制、不产生意识或主观体验。提供参考实体 Nexus（含西语聊天记录）、FastAPI 服务端与 Vanilla JS 前端；本地需 Llama-3.1-8B 级 GGUF 模型与 8GB+ RAM，云端推荐 Gemini 2.0 Flash、可选 DeepSeek 与 OpenRouter。

## 能力要点

- 32 个认知机制，各有神经科学对应物（记忆巩固、睡眠周期、情绪调节等）
- ChromaDB 情景/联想/自我/用户四类记忆与主动遗忘（突触剪枝）
- 多模型管理：本地 GGUF（llama-cpp）+ 云端 API，丘脑式路由与 KV 缓存
- 附带参考实体 Nexus、FastAPI/SSE 接口与 Web 前端

## 适用场景

- 研究/复现具有记忆与情绪状态的 LLM 认知体架构
- 基于模板创建并观察自定义实体的持续思维流
- 作为人工意识模拟的实验平台进行机制探索
