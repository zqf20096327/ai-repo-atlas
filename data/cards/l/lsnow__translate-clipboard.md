# lsnow/translate-clipboard

⭐ 22 · JavaScript · GPL-3.0 · 推送 2026-01-17 · [GitHub](https://github.com/lsnow/translate-clipboard) · 个人维护

**GNOME 剪贴板内容翻译的桌面扩展，支持 Google 或 LLM**

GNOME Shell 桌面扩展，读取剪贴板内容并显示翻译结果；翻译后端可选 Google 翻译或 LLM，LLM 模式下可修改提示词以实现翻译、解释或回答问题等行为。项目受 clipboard-indicator、text-translator、gnome-translate-indicator 等扩展启发。README 目前仅含简介与致谢，安装方式、配置项与使用说明未在可见文本中给出。

## 能力要点

- 读取剪贴板内容并显示翻译
- 翻译后端可选 Google 或 LLM
- LLM 提示词可修改，支持翻译/解释/问答等用途

## 适用场景

- 在 GNOME 桌面取词翻译剪贴板文本
- 通过自定义提示词让 LLM 解释或回答剪贴板内容
