# LM-Kit/LynxTranscribe

⭐ 16 · C# · GPL-3.0 · 推送 2026-02-04 · [GitHub](https://github.com/LM-Kit/LynxTranscribe) · [官网](https://lm-kit.com/) · 组织维护

**离线本地语音转文字的跨平台桌面应用**

基于 .NET MAUI 与 LM-Kit.NET 构建的桌面转写应用，在本地设备上完成语音识别，不依赖云服务。支持文件拖放转写与麦克风实时录音转写，覆盖 WAV/MP3/MP4 等多种音视频格式，99+ 种语言，提供 VAD、听写格式化、分段时间戳视图、音频回放，可导出 txt/srt/vtt/docx/rtf。运行于 Windows 10 1809+ 与 macOS 15+，运行无需额外依赖；从源码构建需 Visual Studio/Rider 与 .NET 10 SDK。UI 提供英文与法文。

## 能力要点

- 完全离线本地转写，音频不出本机
- 文件转写与麦克风录音实时转写两种模式
- 支持 99+ 语言、VAD 与自动标点大写格式化
- 导出 txt/srt/vtt/docx/rtf，内置波形播放与点击跳转

## 适用场景

- 把会议录音或采访音频离线转成带时间戳的文字
- 实时录音转写并自动加标点
- 将转写结果导出为字幕或文档
