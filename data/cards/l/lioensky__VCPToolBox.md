**部署在模型 API 与前端之间的 Agent 运行时与协同中枢**

VCPToolBox 位于 AI 模型 API 与客户端之间，通过统一工具协议、多层级持久化记忆、插件引擎与多 Agent 群聊框架，为接入的大语言模型提供工具调用、记忆检索与审计能力。支持原生 Function Calling 客户端零侵入桥接、MCP 桥、独立记忆 HTTP API，提供 Node.js 服务与 Electron 前端应用群。支持 git clone 与 Docker 部署，采用 CC BY-NC-SA 4.0 许可证，README 提醒勿使用非官方中转 API 且非专业用户谨慎部署。
