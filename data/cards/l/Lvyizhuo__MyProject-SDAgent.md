**面向山东政策咨询场景的 RAG 多智能体问答系统**

基于 Spring Boot 3 + Spring AI 构建的山东省以旧换新政策咨询系统：政策 RAG 问答、补贴测算、语音/图片/发票/设备多模态识别，附带管理员控制台，支持多智能体实例创建与独立配置模型绑定、系统提示词、技能开关，以及 LLM/视觉/语音/嵌入/重排序五类模型统一管理。部署依赖 Java 21、Node.js 18、Docker，需配置 DashScope API Key；默认嵌入模型经 Ollama 本地部署，另有自建 Python 重排序服务。
