**从空间转录组数据生成微环境诱导与内源基因表达向量**

MintFlow 是一个 Python 包，基于流匹配与图神经网络，从空间转录组数据中生成解耦的微环境诱导与内源性基因表达向量，支持与 scverse 生态互操作以衔接空间转录组分析流程。训练自定义模型时建议配置 wandb 记录实验。通过 pip 安装，提供安装指南、教程与 API 文档，并以论文形式发布参考引用。
