# Ludeme/Ludii

⭐ 169 · Java · NOASSERTION · 推送 2026-10-21 · [GitHub](https://github.com/Ludeme/Ludii) · [官网](https://ludii.games/) · 组织维护

**通用博弈游戏系统：用博弈描述语言定义并运行上千种棋类游戏供 AI 研究**

ERC 资助的 Digital Ludeme 项目开发的通用博弈（General Game Playing）系统：以自定义的博弈描述语言（.lud 文件）描述游戏规则，同一系统可运行大量桌面/棋类游戏，内置 AI 可对弈，并支持用 Java 或 Python 编写自定义 AI（提供示例工程与 AI 竞赛项目）。以 Java 源码仓库提供，需 JDK 8+，从下载页可获取预编译的 Ludii.JAR；日常开发通过 Eclipse/IntelliJ 导入模块并运行 StartDesktopApp 启动 GUI。面向游戏 AI 研究者与游戏设计者。
