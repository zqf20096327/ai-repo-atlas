**ML/LLM/RL 全栈知识库：Obsidian 双链笔记，供人与 agent 共用**

基于 Obsidian vault 组织的自包含机器学习知识库，覆盖从 Tensor/autograd 到 RLHF、推理系统、分布式训练、Ray 调度与训练稳定性等内容。每个知识点按统一 8 小节模板写成一篇笔记，用 [[双链]] 互链成知识图谱，配有整体目录主索引与 QA 索引。人类读者可用 Obsidian 或任意 Markdown 编辑器阅读；AI 编程 agent 按 AGENTS.md 规则维护扩展笔记，并通过【user】批注机制自动 grep 全库、逐条回答并落盘存档。通过 git clone 获取。

## 能力要点

- 统一 8 小节模板的知识点笔记，双链互链成可检索图谱
- 【user】批注机制：agent 自动发现提问、答案以 callout 落盘并登记 QA.md
- AGENTS.md 规定 agent 维护规则：模板、双链规则、质量要求
- 按读者水平给出学习路径表（入门/LLM/对齐/系统）

- 在笔记里随手批注提问，由 agent 下次会话自动解答存档
