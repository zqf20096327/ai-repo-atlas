**给 AI 智能体安装的微信 RPA 技能：本地 MCP 服务驱动微信操作**

将本机微信桌面端封装为纯本地服务（127.0.0.1:9922），通过 MCP 协议（约 28 个工具）与 REST API 暴露发消息、发朋友圈、真实语音气泡、按标签群发、读联系人、群聊总结等能力。技术路线为纯 RPA/系统原生 UI 自动化，不读微信数据库、不改内存、不碰私有协议。安装器将服务驻留在用户桌面会话，Agent 仅作网络客户端接入，规避沙箱会话隔离。提供 YoBot 客户端集中管理方式与独立 MCP 安装包两种路径，激活采用激活码绑定。

## 能力要点

- 以 MCP 工具形式暴露约 28 项微信操作能力，宿主 Agent 连接后原生可调用
- 纯 RPA/UI 自动化路线：模拟真人鼠标键盘，不读数据库、不改内存
- 服务由安装器注册开机自启并崩溃自愈，Agent 只作网络客户端
- 支持发送真实微信语音气泡（需微信 ≥ 4.1.9 与 VB-Cable 虚拟音频驱动）

## 适用场景

- 让 OpenClaw/QClaw 等 Agent 通过自然语言代发微信消息和朋友圈
- 给指定标签客户批量创建定时群发任务
- 让 Agent 总结客户群聊天记录并跟进待办
- 企业自建智能体通过 API 接入处理微信咨询
