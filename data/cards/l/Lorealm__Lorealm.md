# Lorealm/Lorealm

⭐ 12 · Rust · MIT · 推送 2026-11-27 · [GitHub](https://github.com/Lorealm/Lorealm) · [官网](https://docs.lorealm.app/) · 组织维护

**可自托管的 LLM 聊天/角色扮演前端，逻辑随内容携带**

面向 LLM 聊天与角色扮演场景的自托管前端：角色、世界书或整个世界可携带自身脚本、状态与工具，导入者无需额外安装配置即可运行。核心机制包括 Weaver 编程语言、支持状态演化的世界书、以 Realm 组织多角色/群聊/游戏系统的舞台模型，以及沙盒化插件系统。支持 Windows/Linux/macOS 与 Docker 部署，默认仅本机可访问，密码与 API key 采用加密保护。初始 9 种语言翻译由 Claude 生成，经 Crowdin 管理并需人工审校。

- Weaver 语言使内容可携带脚本、状态与工具
