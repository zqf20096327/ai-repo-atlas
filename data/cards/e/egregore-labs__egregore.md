# egregore-labs/egregore

⭐ 292 · Shell · MIT · 推送 2026-10-16 · [GitHub](https://github.com/egregore-labs/egregore) · [官网](https://egregore.xyz/) · 组织维护

**给团队与其 AI 编码 agent 的共享组织记忆层**

在 Claude Code、Codex、Pi、Prime Agent 四种 agent 之间提供共享组织记忆：决策、发现与交接以 Markdown 形式存放在独立 Git 仓库中，链接进工作区的 memory/ 目录，支持本地关键词与语义搜索，让 agent 检索并引用来源记录。内置 handoff、reflect、ask 等工作流命令，通过 npx create-egregore 安装并创建实例。运行时开源（MIT），本地记忆与搜索可离线运行；另提供可选托管服务 Egregore Connect；默认开启可关闭的本地遥测。
