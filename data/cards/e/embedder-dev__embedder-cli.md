**面向嵌入式软件的企业 AI 平台：agent 直接对真实硬件写码烧录调试**

Embedder 是面向嵌入式软件开发的 AI 平台，整合代码仓库、硬件文档、板级设计与台架工具，使 agent 能够规划改动、编写代码、构建、烧录、测试并在真实硬件上调试。主界面为 VS Code 扩展（含编辑器感知对话、原理图、串口/调试器/实验仪器监控面板），也可通过终端/SSH 运行 CLI，另提供 headless 服务器、GitHub/Slack 守护进程与远程桥接。安装方式为 curl 脚本或 npm 全局安装。
