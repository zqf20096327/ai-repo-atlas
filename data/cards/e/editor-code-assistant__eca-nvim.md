**在 Neovim 中嵌入 ECA 代码助手的插件**

轻量级 Neovim 插件，将 ECA（Editor Code Assistant）集成到编辑器中，通过 :EcaChat 命令或快捷键发起对话。设计上保持简单且可定制，文档涵盖安装、用法、配置参考与故障排查，另列出 VS Code 插件等关联项目。要求 Neovim >= 0.8.0、curl 与 unzip。项目自述为 Work in Progress，仍在积极开发中。采用 Apache License 2.0。
