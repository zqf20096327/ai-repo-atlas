**Windows 桌面工具：管理招聘双方 agent 的沟通与任务**

面向 Windows 用户的招聘管理桌面软件：以项目为单位组织招聘流程，管理招聘/中介双方 agent 的联系信息，跟踪候选人在 agent 之间的流转，并以聊天式窗口集中查看消息与任务。通过 GitHub Releases 提供 .exe 安装包安装，数据存储在本地。README 为通用安装使用说明，未描述具体 AI 模型或技术实现细节；仓库主题标签提及 anthropic/llm/autonomous-agent。最低要求 Windows 10、i3 处理器、4 GB 内存、500 MB 存储与网络连接。
