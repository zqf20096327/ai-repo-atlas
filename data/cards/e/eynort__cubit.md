**给 Minecraft 玩家提供开箱即用的自动化机器人：战斗、挖矿、挂机 24/7**

以单个约 20 MB 二进制分发的 Minecraft Java 机器人程序，每个机器人占用约 70 MB 内存，无需 Java/Node 运行时。内置专家 PvP、逐层开挖、无透视条状挖矿、砍树、24/7 AFK 与断线重连功能，提供 A* 寻路。控制方式包括浏览器 Web 面板、游戏内命令、Discord 与 HTTP API；可选本机 Ollama AI 将自然语言转换为命令。支持 Linux/macOS/Windows/树莓派/Android，其他 MC 版本经 ViaProxy 接入。

## 能力要点

- 内置专家 PvP、无 x-ray 挖矿、砍树、24/7 AFK 与断线自动重连
- Web 面板管理多机器人，每机器人约 70 MB 内存，单二进制无运行时依赖
- 可选本地 Ollama AI 支持自然语言下达任务（数据不出本机）
- 提供 Discord 命令与带实时事件的 HTTP API

## 适用场景

- 让机器人在服务器上自动挖矿、砍树并存放物资
- 下线后让机器人代替自己挂机保持在线
- 作为护卫跟随玩家或防守区域
- 用脚本通过 HTTP API 批量驱动机器人
