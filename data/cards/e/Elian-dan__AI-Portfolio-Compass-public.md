⭐ 35 · Python · MIT · 推送 2026-07-14 · [GitHub](https://github.com/Elian-dan/AI-Portfolio-Compass-public) · 个人维护 · 中文 README

**面向多账户个人投资者的本地优先投资组合分析与 AI 诊断工作台**

本地 Web 工作台（React + Vite + FastAPI），把 A 股基金/股票、美股、港股等多账户多币种资产合并为统一组合视图，提供仓位分层（核心/中期/短线/期权/遗留）、组合诊断、决策卡、标的分析与交易复盘闭环。数据经 Futu/moomoo OpenD 只读同步或本地文件导入；AI 为能力层，外部模型（如 DeepSeek）经显式授权调用做组合诊断报告，未配置时降级为本地规则分析。不实现下单等交易操作，数据留在本地。

## 能力要点

- 多账户、多市场、多币种资产统一视图与合并分析
- 仓位分层识别与用户手动修正优先
- AI Agent 组合诊断报告 + 交易复盘闭环（纪律标签、后续表现）
- 只读同步 Futu/moomoo OpenD，数据源 provider 可配置，演示模式使用隔离虚构数据

- 记录买入理由与失效条件并事后复盘自己的交易纪律
