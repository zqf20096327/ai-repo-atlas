**AI Agent 技能库网站：搜寻、预览、下载可重用技能**

一个开源的 AI Agent 技能库网站，收录 100+ 个可浏览、预览与下载的技能，面向 Claude Code、Claude Desktop、ChatGPT、Gemini CLI 等 Agent 平台。使用流程：在网站浏览技能库，进入技能页查看用途、作者、标签与档案内容，下载技能包放入自己的 Agent 环境，按 setup guide 挂载使用。技能按 Development & Code Tools、Data & Analysis、Security & Web Testing 等 6 类组织。前端采用 React 19、Vite 7、TypeScript、Tailwind CSS 4，支持 git clone 源码方式本地运行。
