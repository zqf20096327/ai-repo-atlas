**嘉立创EDA专业版扩展：用大模型从数据手册PDF生成元件符号与封装**

嘉立创EDA专业版的扩展，基于大语言模型构建元件库：从 PDF 数据手册或图片中提取引脚信息、封装尺寸参数，自动生成标准化符号（两边排布布局）与封装，支持实时预览与参数微调。支持 BGA/DIP/QFN/QFP/SOP 五种封装类型，其中 BGA 中间矩形与 DIP 焊盘标注待 API 完善。使用时需在扩展管理器导入 eext 文件并配置模型厂商、模型与 API 密钥（文档列出通义千问、智谱AI）。

## 能力要点

- 从 PDF 数据手册/图片提取引脚信息与封装参数
- 支持 BGA/DIP/QFN/QFP/SOP 五种封装类型
- 未选择封装类型时自动两次提取并选择最佳结果
- 符号与封装的实时预览与参数手动微调
