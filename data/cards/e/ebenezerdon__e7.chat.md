# ebenezerdon/e7.chat

⭐ 21 · JavaScript · Apache-2.0 · 推送 2026-10-23 · [GitHub](https://github.com/ebenezerdon/e7.chat) · [官网](https://e7.chat) · 个人维护

**自托管的 AI 聊天应用：多模型对话与图像生成**

基于 Next.js 15 与 Appwrite 构建的 AI 聊天应用，通过 OpenRouter 接入 100+ 模型，支持邮件密码与 OAuth 登录、聊天分享、对话分支、图片与 PDF 附件、云同步与搜索，并集成 OpenAI DALL-E 图像生成。部署需 Node.js 18+、Appwrite 账号、OpenRouter API key，图像生成需另配 OpenAI key；通过 git clone 与 npm 安装运行，无桌面安装包，配置步骤涉及 Appwrite 数据库与权限设置。
