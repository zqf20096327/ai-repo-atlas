**给开发者的 ElevenLabs API 官方 Python SDK：语音合成与语音代理接入**

ElevenLabs 官方 Python SDK，通过 pip 安装后可调用其云端 API：文本转语音（支持 90+ 语言的 Eleven v4 系列与低延迟 Turbo/Flash 模型）、语音克隆、实时流式音频、异步客户端，以及 ElevenAgents 会话式语音代理（含客户端工具注册、自定义事件循环、链式 Agent 工作流与工具 schema 代码化定义）。语音克隆与 API 调用需要 API key；能力取决于 ElevenLabs 云端服务。
