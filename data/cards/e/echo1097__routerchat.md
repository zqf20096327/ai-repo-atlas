**本地运行的 OpenRouter/Anthropic 聊天与长文写作界面**

免费本地 Web 界面，连接 OpenRouter 或 Anthropic API 进行对话与长文写作，用户自带 API key。提供 Chat 模式（任意模型对话、附件、联网搜索、文件夹/置顶/搜索）与 Writing 模式（分章写作、头脑风暴画布、记录角色与世界观设定的 lorebook），另有语音输入与按模型/时间的用量统计。数据与密钥保存在本地，无账户与分析追踪。macOS 与 Windows 提供安装脚本，也可从源码构建。
