**面向个人投资者的 AI 股票研究工作台：研究、筛选与模拟交易**

自托管的股票研究 Web 应用，将行情数据、新闻与 AI 分析整合：提供研究助理对话、个股研究报告、多 AI 专家圆桌对比、策略筛选、模拟交易、组合跟踪与定时任务等模块。研究覆盖中国大陆、港、美、台、日、韩、英等 12 个市场，模拟交易支持前 6 个市场及 Binance 现货加密数据；不进行真实下单。技术栈为 Python 3.10+/FastAPI + React 19，用户需自行配置支持 tool calling 的模型 API key；也可用托管站点。
