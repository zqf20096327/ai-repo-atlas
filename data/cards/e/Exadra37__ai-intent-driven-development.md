**面向 AI 编码代理的意图驱动开发指南与指令集**

以 markdown 指令文件集合形式提供 AI Intent Driven Development (IDD) 方法论：将用户请求结构化为含 WHY（动机）、WHAT（需求，常用 Gherkin）与 HOW（分步任务计划）的 Intent 文档，指导 AI 编码代理在写代码前完成规划对齐。附带 Domain Resource Action 架构模式及开发工作流、代码规范等指南，当前覆盖 Elixir 与 Phoenix，计划支持其他 BEAM 语言。通过 git clone 安装并提供 bash 脚本，可将指南合并生成 AGENTS.md/CLAUDE.md 等代理文件，或复制为独立 markdown 文件。
