# El-12stu/RelaMind

⭐ 211 · Java · MIT · 推送 2025-12-14 · [GitHub](https://github.com/El-12stu/RelaMind) · 个人维护 · 中文 README

**面向个人用户的 AI 成长陪伴系统：对话、日记、任务智能体**

基于 Java 21 + Spring Boot 3 与 Vue 3 的全栈 Web 应用，面向希望记录与分析个人成长的终端用户。三大功能：智能对话（意图识别后自动路由到普通聊天、RAG 历史查询或工具调用）、成长日记（心情/标签记录并自动存入 PgVector 向量库）、基于 ReAct 模式的 Manus 任务智能体（最多 10 步，多工具协作，生成 txt/PDF 文件）。另含 Trie 树敏感词检测（命中即拦截、零 API 调用）与 MCP 服务集成（地图、图片搜索）。对话记忆持久化使用 Cassandra（可选），大模型通过 API Key 接入（DashScope 必填），提供 Docker 与本地 Maven 两种运行方式。

## 能力要点

- 意图识别智能路由：普通聊天 / RAG 历史查询 / 工具调用三种模式自动选择
- ReAct 模式 Manus 任务智能体，多步骤（最多 10 步）执行并生成 txt/PDF 文件
- Trie 树敏感词检测，命中即拦截不消耗大模型 API
- 日记自动存入 PgVector 向量库，支持语义检索与长期记忆

## 适用场景

- 日常记录心情与感想，构建个人成长知识库
- 通过对话查询自己的历史记录，如'我去年这个时候在做什么'
- 让智能体多步骤搜集信息并整理成 PDF/txt 文档
