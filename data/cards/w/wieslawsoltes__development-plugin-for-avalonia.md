**面向 Codex 的 Avalonia 开发技能插件：构建/迁移/设计等专项技能集**

为 Codex 提供的 Avalonia 应用开发插件，用多个专项技能（skill）替代单一巨型技能，覆盖启动生命周期、绑定与 XAML、线程调度、样式资源、渲染图形、无障碍验证等核心领域，以及 Fluent 设计系统、HTML/CSS、WinForms、WPF、WinUI 迁移与 Avalonia 11→12 迁移等专项。默认指导钉定 Avalonia 11.3.12，另设 12.0.0-rc1 迁移通道，附共享参考索引与 Python 脚本生成 API 索引。支持 repo 本地与 marketplace 两种发现路径。
