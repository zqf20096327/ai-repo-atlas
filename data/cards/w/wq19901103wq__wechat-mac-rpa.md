**macOS 微信 GUI 自动化 Bot：视觉感知+LLM Agent 自动回复**

面向 macOS 微信客户端的自动化框架，将微信视为黑盒 GUI 应用：截图经 OCR/多模态模型提取消息，LLM Agent 经 ReAct 循环决策回复，通过 AppleScript/cliclick 操作界面发送。含像素 diff 缓存降 API 调用、LCS 跨轮消息去重、三层记忆（工作/会话/长期，LLM Wiki+BGE 语义索引）与 LLM-as-a-Judge 数据飞轮评估回路。需 macOS 12+、Python 3.10+ 及屏幕录制/辅助功能权限；WeFlow 模式可选读取本地数据库副本初始化历史记忆；仅限个人学习研究用途。
