**LLM 结构化内容流式输出工作流框架（npm/TS）**

面向多 agent/bot 异步工作流的流式框架：核心是逐字符解析 LLM 输出的 JSON 数据流的实时转换器，以 jsonuri 增量格式输出，支持 JSONL、SSE、流中状态消息与 token 错误自动修正；提供 Ling/ChatBot 类 API、消息过滤、提示模板，并支持 MCP 客户端进行工具调用。兼容 OpenAI、Deepseek、Qwen、Moonshot、Yi 等 LLM 提供商。以 npm 包 @bearbobo/ling 分发，源自 Bearbobo 学习伴侣项目需求，Client SDK 尚未提供（路线图未勾选项）。

## 能力要点

- 逐字符实时解析 JSON 流并以 jsonuri 增量输出
- 支持 SSE、JSONL、流式状态消息与自定义事件
- MCP 客户端支持工具调用与外部服务集成
- 兼容 OpenAI/Moonshot/Deepseek/Qwen/Yi 等提供商

## 适用场景

- 多 agent 应用中流式展示结构化 LLM 输出以降低等待感
- 前端通过 EventSource 实时更新生成中的 JSON 内容
- 为 LLM 工作流接入 MCP 工具调用
