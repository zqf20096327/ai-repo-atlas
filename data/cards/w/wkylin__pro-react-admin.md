**给 React 团队的多租户管理后台脚手架**

基于 React 19、Ant Design 6、React Router 7、Zustand 与 TypeScript 的管理后台工程底座，提供租户登录、服务端授权、角色权限与审计的 Enterprise 预设，以及查询表格、表单、详情等业务页面模板。同一份源码支持 Webpack 与 Vite 双构建，包含多项目、微前端示例和独立 UI 组件包（wui-react），配 Storybook 预览、Jest 单测与 Playwright 端到端测试。运行要求 Node.js >=24.15.0 且 <25 与 pnpm 12.16.1，通过 git clone 与 pnpm 脚本安装启动；部署路径覆盖 GitHub Pages、Vercel，真实登录可选 Neon PostgreSQL 或 SQLite。README 未描述 AI 相关功能。
