# waiterve/wai-play

⭐ 255 · Python · 推送 2026-08-31 · [GitHub](https://github.com/waiterve/wai-play) · 个人维护 · 中文 README

**AI 自动试玩网页游戏并产出评分与优化建议的 Agent 平台**

面向 vibe coding 网页游戏创作者的自动试玩与质量诊断 Agent：用户选择游戏类型、填写游戏 URL（可选上传 ZIP 源码包），Agent 在真实浏览器中操作游戏，识别目标、关键节点与通关路线，失败后根据实际状态重新规划；输出五维质量评分、绑定截图或录像的问题卡片、优化建议与测试可信度诊断。通过 DeepSeek 与 Kimi API Key 驱动，无 Key 时仅部分规则测试可用。支持 Python 源码运行与 Docker 运行，当前版本定位为本地运行、学习和演示，作公开在线服务尚缺多用户与安全机制。

## 能力要点

- 真实浏览器中试玩并按五类游戏类型规划通关路线
- 失败后依据实际状态重新规划而非盲目重复动作
- 五维质量评分与绑定截图/录像（≤20秒）的可复现问题卡片
- 可选上传 ZIP 源码包辅助流程理解，仅分析临时副本不修改原项目

## 适用场景

- 网页游戏开发者快速验证游戏能否完整通关
- 获得带证据截图与录像的具体问题清单和修改建议
- 无自动化脚本基础时对自研网页游戏做质量评估
