**滑坡易发性制图与不确定性分析的机器学习 Python 工具**

面向滑坡风险研究者的开源 Python 工具，用于滑坡易发性空间制图与不确定性分析。采用"定性地图组合"机制，将多个致灾因子按权重叠加；权重及其不确定性由机器学习确定，并支持基于权重范围的敏感性分析及不同权重选择结果的空间对比。可通过高层命令或 Python 代码运行，输入经 JSON 文档提供，需 Python 3.6+。有配套论文与文档站点。
