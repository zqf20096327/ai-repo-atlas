**AI 生成内容并一键发布到多个社交平台的 Chrome 扩展**

Chrome 扩展（MV3，Vite+CRXJS 构建，TypeScript）：用户描述主题后由 ChatGPT、Claude 或 Gemini 生成帖子文案，从单一弹窗一键发布到 Facebook、Threads 和 X。无需 API key，复用浏览器已登录会话，各模型以临时/无痕会话方式调用。支持附图上传、Threads 定时发布（chrome.alarms）与 1-5 段多段帖子。需 npm 安装依赖后构建并手动加载 dist 目录。

## 能力要点

- 三模型可选生成：ChatGPT / Claude / Gemini，无需 API key
- 一键发布到 Facebook、Threads、X，复用浏览器登录会话
- Threads 支持定时发布与 1-5 段多段帖子
- 帖子可附一张图片并自动上传
