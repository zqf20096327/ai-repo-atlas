⭐ 31 · TypeScript · GPL-3.0 · 推送 2026-04-09 · [GitHub](https://github.com/wuhen8/webos) · [官网](https://webos.686860.xyz) · 个人维护 · 中文 README

**仿 macOS 风格的 Web 桌面操作系统，Go + React 构建**

基于 Go + Gin 后端与 React 18 前端构建的浏览器端桌面操作系统，提供 macOS 风格窗口管理、Dock、启动台、文件管理（本地/S3）、WebSocket 实时终端、Docker 容器可视化管理、Monaco 代码编辑器、视频/音乐播放器等内置应用。AI 部分为内置 AI 聊天应用，支持 Skills 扩展。支持 WASM 沙箱运行第三方应用，接入 Web、Telegram、飞书等多端。通过 Docker 或源码构建部署。
