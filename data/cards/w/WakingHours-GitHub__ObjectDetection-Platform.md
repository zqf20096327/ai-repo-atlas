**水面漂浮物目标检测 Web 平台（YOLOv5+Flask）**

基于 YOLOv5 与 Flask 的目标检测平台，识别与分类河面、海面等水面的漂浮物体，支持替换自有数据集以检测其他目标。作者为本科毕业设计构建此项目，曾提供在线网站服务；2026 年 2 月起网站因服务器维护成本下线，但源码继续在 GitHub 开放。本地运行方式为 pip 安装依赖后运行 app.py，可搭配 Nginx 部署。
