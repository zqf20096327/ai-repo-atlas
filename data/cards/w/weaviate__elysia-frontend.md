# weaviate/elysia-frontend

⭐ 182 · TypeScript · MIT · 推送 2026-02-06 · [GitHub](https://github.com/weaviate/elysia-frontend) · [官网](https://elysia.weaviate.io/) · 组织维护

**Elysia 平台的 AI 对话与数据探索前端界面**

基于 Next.js 14 / React 18 / TypeScript 构建的单页应用，作为 Elysia 生态的用户界面，提供 AI 对话、数据探索与可视化、配置管理、模型评测工具和数据集管理等界面。构建采用静态导出流程，export.sh 脚本将产物复制到后端静态目录集成部署。要求 Node.js 18 及以上，通过 npm 安装依赖并运行开发服务器。
