**OpenClaw 的跨平台桌面工作台：聊天、配置与多 Agent 管理**

基于 Electron 的 OpenClaw 桌面工作区，面向个人用户、开发者与长期运行 AI agent 的团队。将原本依赖终端、环境变量与手工配置的 OpenClaw 工作流转为桌面产品：内置聊天界面、可视化配置 AI 提供方/agent/密钥/工具、技能浏览与安装、定时任务与多 agent 工作流、文件/终端/分析统一入口，支持自动更新与托盘集成。发布 macOS（Apple Silicon/Intel）与 Windows 安装包，Linux 未发布构建；源码构建需 Node.js/npm。
