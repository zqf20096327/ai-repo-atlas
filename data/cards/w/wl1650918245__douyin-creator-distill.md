**本地优先的抖音创作者分析智能体：抓取、转写、爆款拆解与选题**

面向抖音创作者的本地优先内容分析工具：通过本地 Chrome 登录抓取创作者主页、单条作品与本人收藏夹目录，先落盘原始 JSON 证据并审核，再按用户选择的云端或本地 Whisper 通道转写；基于多条已转写作品生成爆款拆解报告、带来源的选题建议，以及由代表性材料构建的博主智能体画像用于审稿。内置本地 Embedding 语义检索（bge-small-zh-v1.5 或 Qwen3-Embedding-0.6B），普通检索不消耗 API。当前为单用户本地产品，仅支持 Windows 10/11 与 Node.js 22.5+，需本地 Chrome 登录，不承诺绕过平台验证。

## 能力要点

- JSON 证据层：按作品 ID 去重、数量审核、保留原始抓取证据
- 云端/本地 Whisper 双转写通道，支持优先级续接、断点继续与失败单独重试
- 本地 Embedding 语义检索（96MB 轻量 / 1.2GB 高精度双模式），增量索引不重复计算
- 爆款拆解、选题顾问、博主智能体均要求结论引用作品证据

## 适用场景

- 批量抓取创作者主页并筛选值得处理的视频
- 把视频转成带来源与作品 ID 的可追溯文本
- 从多条作品中提炼爆款规律并生成有据可依的选题
- 沉淀可审计的博主智能体画像用于新稿审阅
