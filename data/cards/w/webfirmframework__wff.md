# webfirmframework/wff

⭐ 17 · Java · Apache-2.0 · 推送 2026-10-14 · [GitHub](https://github.com/webfirmframework/wff) · [官网](https://webfirmframework.com) · 组织维护

**Java Web 框架：用 Java 代码生成 HTML5/CSS3 的实时 Web 应用开发库**

webfirmframework 的开源模块 wffweb，面向 Java 开发者，用于实时 Web 应用开发。核心机制是从 Java 代码生成 HTML5 与 CSS3：以 Java 对象表示标签与样式（如 new Html/Body/Div、Style、CssLengthUnit），支持 3.0.9 起的函数式编码风格，可后续动态添加/修改 CSS 属性以更新生成的 HTML。通过 Maven Central 分发，可在 Maven、Gradle、SBT 等构建工具中引入依赖。README 未展示 AI 相关功能。

## 能力要点

- 用 Java 对象生成 HTML5 与 CSS3 代码
- 支持函数式编码风格（3.0.9 起，推荐）
- 运行时动态添加/修改 CSS 属性并更新 HTML 输出
- 通过 Maven Central 分发，兼容多种构建工具

## 适用场景

- 在 Java 项目中以代码方式构建 HTML/CSS 而非模板
- 实时更新页面样式的 Web 应用开发
- 需要服务端生成 HTML 的场景
