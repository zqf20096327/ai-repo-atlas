**企业业务系统智能化改造的智能体开发与运行平台**

## 能力要点

- 页面扫描、改造推荐、AI Coding 实施、验收与上线的完整改造流程
- Capability / Tool / Workflow 三类对象独立建模与治理
- READ 自动执行、WRITE 需确认、IRREVERSIBLE 默认拒绝的运行策略
- MCP Hub 与 A2A 互联中心对外发布 Tool 与远程 Agent

## 适用场景

- 让员工在原有 ERP 页面里用自然语言查库存、建客户
- 为缺少接口文档的存量系统做有代码依据的智能化盘点
- 在企业内对 Agent 运行做身份继承、工具白名单和审计追踪
