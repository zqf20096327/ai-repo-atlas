**基于 node-chatgpt-api 的多 AI 网页聊天客户端**

基于 Nuxt 3（Vue 3）构建的 Web 聊天客户端，通过 node-chatgpt-api 后端与多种 AI 系统对话，支持 gpt-3.5-turbo、text-davinci-003、ChatGPT 与 Bing 等客户端。可为每个客户端创建多个自定义预设；全部数据存于浏览器本地存储，无需账号，支持导入导出到其他设备。也兼容其他实现相同端点的 API 服务器。需先安装依赖、运行 node-chatgpt-api 服务端并配置 .env 中的 API_BASE_URL，再以 npm run dev 或 npm run build 运行。
