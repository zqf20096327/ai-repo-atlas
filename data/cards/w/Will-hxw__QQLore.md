# Will-hxw/QQLore

⭐ 22 · TypeScript · MIT · 推送 2026-10-27 · [GitHub](https://github.com/Will-hxw/QQLore) · 个人维护 · 中文 README

**QQ 群聊记录的本地 RAG 检索与 Agent 问答系统**

基于 TypeScript/Node.js 的本地化 IM 聊天记录分析系统：从 QQ NT 桌面客户端本地数据库读取聊天记录（Windows x86_64 / macOS Apple Silicon，Linux 暂不支持），经消息清洗、会话划分、bge-m3 向量化后组织为消息-事件-主题三层知识结构。检索采用查询规划、混合召回（稠密+稀疏）、重排、上下文构建四阶段流水线，Agent 以 ReAct 方式调用语义检索、SQL 筛选、话题追踪等工具并输出带消息引用的回答。兼容 OpenAI 兼容 API 配置生成模型，Ollama 为必需的本地 Embedding 服务。提供 React WebUI 与 Docker Compose 部署，但 data-provider 模块必须在宿主机运行。

## 能力要点

- 消息-事件-主题三层知识组织与周期性摘要合成
- 查询规划+混合召回+重排的四阶段 Agentic 检索流水线，回答可追溯到具体消息
