# winkychannn/mcd-calorie-order-saver

⭐ 3 · Python · MIT · 推送 2026-10-13 · [GitHub](https://github.com/winkychannn/mcd-calorie-order-saver) · 个人维护

**面向控卡与预算敏感人群的麦当劳点餐搭配推荐助手**

以 WorkBuddy Skill 形式提供的麦当劳下单助手：读取麦当劳 MCP 提供的菜单、营养与价格数据，本地引擎 optimize.py 对约 2000 个候选组合做热量与预算双约束搜索，把套餐拆成组件按热量求和核算，输出「最贴热量/最省钱/最平衡/套餐优选」多方案，凑不出目标时给出放宽方向。安装需先在 open.mcd.cn 获取 MCP Token 并在 WorkBuddy 配置连接器，再 git clone 到 skills 目录；引擎可离线单独运行且不依赖第三方库。仅支持到店自取，下单需用户确认。

## 能力要点

- 套餐拆解为组件按热量求和，缺失营养数据时改选近似组件并标注 price_estimated
- 双约束求解输出带标签的多方案组合，含热量×价格散点图
- 本地引擎无第三方依赖、可离线复跑，tests/ 提供可重跑样本
- 营养表无匹配的餐品如实标注，不编造热量

## 适用场景

- 控卡上班族在热量与预算约束下选麦当劳餐品
- 想比较套餐与单点哪个划算
- 查门店可用优惠券并生成搭配方案
- 减脂期查询特定热量上限内可点的餐
