**让 DSH 用户用 ChatGPT 订阅直接调用 Codex 模型的插件**

DeepSeek Harness（DSH）的社区插件：用户以 ChatGPT Plus/Pro 订阅登录，即可在 DSH 中调用 Codex 模型、订阅联网搜索、图片生成与编辑，无需 OpenAI API Key。提供多账号与额度管理（短周期/每周额度、重置时间、用量拆分、续航预测）、草图画板与 Agent 绘图、ChatGPT 连接器调用已连接应用、以及通过 ChatGPT 手机 App 远程控制电脑上的 DSH（Beta，默认关闭）。模型与功能开放范围以账号实际返回为准；支持 npm/终端/headless 多种安装路径。

## 能力要点

- ChatGPT 订阅登录即可在 DSH 使用 Codex 模型，无需 API Key
- 多账号额度管理：用量拆分、热力图、阈值提醒与续航预测
- 草图画板与 Agent 绘图（SVG 原生笔画、参考图对比、绘制回放）
- ChatGPT 手机 App 配对远程控制 DSH（Beta，默认关闭）

## 适用场景

- 已有 ChatGPT Plus/Pro 订阅，想在 DSH 中使用 Codex 模型
- 在同一界面管理多个 ChatGPT 账号的额度与用量
- 用订阅出图并在草图画板上让 Agent 继续绘制
- 出门后用手机 App 继续操作电脑上运行的 DSH
