**生成 Git 仓库级协作模式报告的 Agent 技能插件**

面向 Claude Code 类 AI Agent 的 SKILL.md 技能：对指定 Git 仓库运行白名单内的只读 git 命令，本地聚合提交时间分布、代码流失、返工频次、Bug fix 占比、可见活动指数等六类仓库级指标，仅将数值指标（不含原始提交消息与文件路径）交给 AI 模型生成协作模式报告。零依赖、零脚本、不联网，默认 Dry-Run 预览。README 反复声明严禁用于绩效考核等人事决策。

## 能力要点

- 零依赖零脚本，只用白名单只读 git 命令
- 本地脱敏聚合后仅将数值指标交给 AI 模型
- 六类仓库级协作模式指标（时间分布/流失/返工/Bug fix 占比等）
- 默认 Dry-Run 预览，触发需显式仓库路径

## 适用场景

- 团队回顾时生成仓库协作模式报告作为讨论起点
- 识别仓库中的巴士因子风险与高返工区域
- 在自己的仓库上做提交习惯自我回顾
