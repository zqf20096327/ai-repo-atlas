**每日定时运行的 AI 行业情报筛选与知识库工作流**

通过 GitHub Actions 每日定时抓取 20 个分层信源，经去重、LLM 三维打分（相关度/新颖度/长期价值）后按分数三路分流：高分自动发布、中分每周交人审批、低分丢弃留档，形成可检索的 AI 行业知识库并发布为网站。含每周 GitHub Issue 审批单（12 条）实现人机协同，配置内容/模型/业务三条降级链（无 API key 可跑通流程），并内置数据完整性、打分路由、分类稳定性、摘要忠实度等评测脚本。面向关注 AI 行业动态的开发者与研究者。
