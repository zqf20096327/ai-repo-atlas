**3 天掌握 AI Agent 的引导式学习仓库，基于 nanobot 源码**

围绕轻量个人 AI 助手 nanobot（约 3,500 行 Python）的学习教程仓库：以 3 天计划（每天 2-3 小时）引导学习者阅读 agent/loop.py 中的 Perceive-Think-Act-Loop 实现、编写工具与技能、配置 Telegram 通道与 cron 定时、用 Dockerfile 容器化部署。提供 AI_COPILOT.md，可将 Cursor/Claude Code/Copilot 变成苏格拉底式导师；通过 git clone --recursive 同时获取学习指南与源码，pip 安装后用 CLI 命令交互。面向想理解 Agent 内部构造的学习者。
